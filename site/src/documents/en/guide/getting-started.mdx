# Installation and first search

<Lead>

Install kfind for the CLI, Rust, or npm, then run a [lemma](/reference/glossary#lemma) search, specify a [POS](/reference/glossary#part-of-speech), and produce machine-readable output.

</Lead>

## CLI installation [#cli-installation]

On macOS and Linux, the Homebrew formula installs the CLI and the matching morphology resources. A source checkout can be installed with Cargo.

```bash
brew install seokminhong/brew/kfind

# source checkout
cargo install --locked --path crates/kfind-cli

kfind --version
```

Search performs no network access. The Homebrew build discovers its full-POS [lexicon](/reference/glossary#lexicon), predicate metadata, and [component resource](/reference/glossary#component-resource) under the formula prefix. A schema or source-digest mismatch is a startup error.

## npm installation [#npm-installation]

JavaScript and TypeScript applications install the scoped `@kfind/kfind` package. It includes the WebAssembly engine and embedded lexicon and never guesses a filesystem path or URL.

```bash
npm install @kfind/kfind@1.0.0-rc.3
```

```javascript
import { Kfind } from '@kfind/kfind';

const engine = new Kfind();
const plan = engine.compile('걷다', { pos: 'verb' });
const matches = plan.findAll('나는 길을 걸었다.');
```

On Node.js 20 or later, the package also exposes the `kfind` command for one-shot execution. `yarn dlx` requires Yarn 2 or later.

```bash
npx @kfind/kfind 걷다 README.md
pnpm dlx @kfind/kfind 걷다 README.md
yarn dlx @kfind/kfind 걷다 README.md
```

## Lemma search [#first-search]

The first positional argument is the [query](/reference/glossary#query). The remaining arguments select files or directories. With no path, kfind reads piped stdin. With neither a path nor piped input, it searches the current directory.

```bash
kfind 걷다 src docs
kfind 사용자 .
printf '길을 걸었다.
' | kfind 걷다
```

The lemma `걷다` is analyzed as a ㄷ-[irregular verb](/reference/glossary#irregular-conjugation). Its [query plan](/reference/glossary#query-plan) contains fixed anchors and suffix decisions for surface forms such as `걷고`, `걷는`, and `걸어`.

## POS, [phrase](/reference/glossary#phrase), and alternative queries [#pos-and-phrase]

Use `--pos` when the lexicon analysis is ambiguous or the grammatical role is known. Phrase queries attach a POS tag to each [atom](/reference/glossary#atom). A quoted atom is treated as a literal containing spaces or punctuation. Use `|` to find any one of multiple atoms.

```bash
kfind --pos verb 걷다 src
kfind 'v:걷다 | n:사용자 | n:검증' src
kfind 'n:사용자 v:검증하다' src
kfind 'det:새 n:기능' docs
kfind '"Hello, world!"' README.md
```

Supported tags are `n:`, `pro:`, `num:`, `v:`, `adj:`, `det:`, `adv:`, `j:`, `intj:`, and `lit:`. Conflicting global and atom POS values are compile errors. Quote a query containing `|` so the shell does not treat it as a pipe. Each alternative is one atom and cannot be mixed with phrase atoms. Escape or quote a literal pipe as `\|` or `"|"`.

## Automation output [#automation-output]

Automation should specify POS, [boundary](/reference/glossary#boundary), resource mode, and output format. The `any` boundary preserves substring candidates for [recall](/reference/glossary#recall), while JSON Lines exposes stable source spans and [provenance](/reference/glossary#provenance).

```bash
kfind --embedded --boundary any --pos verb --json 걷다 src
kfind --embedded --boundary any --json 'n:사용자 v:검증하다' src
```

Recall-oriented output can include semantically irrelevant candidates. Read the surrounding text before acting on a match.

## Agent integration [#agent-skill]

`--init` installs the kfind skill and shell hook for supported coding agents. It cannot be combined with a search query or path.

```bash
kfind --init
kfind --init --agent codex --agent claude-code
kfind --uninstall --agent codex --agent claude-code
printf 'codex
gemini
' | kfind --init
```

Codex uses `.agents/skills/kfind/SKILL.md`, Claude Code uses `.claude/skills/kfind/SKILL.md`, and Gemini CLI uses `.gemini/skills/kfind/SKILL.md`. `--uninstall` removes only kfind-managed skills and hooks. It preserves existing skills without a kfind management marker and all existing agent settings. Once trusted, the project hook blocks shell commands that pass Korean search patterns to `rg` or `grep` and directs the agent to kfind.
