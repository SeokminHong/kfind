# 오류 목록

## 컴파일 오류 [#compile]

질의 문법, POS·literal 충돌, 잘못된 옵션, 빈 analysis와 plan 상한이 대상입니다. 질의나 옵션을 수정해야 합니다.

Resource capability required도 컴파일 단계에 나타날 수 있습니다. Boundary를 완화해 자동 복구하지 않습니다.

## resource 오류 [#resource]

파일 누락, 128 MiB 상한, magic·schema·version·source 불일치, section digest와 payload graph 오류를 구분합니다.

`kfind --check-data`로 설치된 리소스를 검색 없이 검증할 수 있습니다.

## I/O 오류 [#io]

경로 metadata, open, read, decode와 output write 실패를 원문 경로와 함께 보고합니다. Permission 오류를 검색 결과 없음으로 바꾸지 않습니다.

Locale은 설명 문장만 바꾸며 error class, 경로와 옵션 token은 유지합니다.
