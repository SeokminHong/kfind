# 종료 코드

## Native CLI [#native]

0은 하나 이상의 일치, 1은 검색 결과가 없는 정상 종료, 2는 사용법·I/O·리소스·컴파일 오류를 뜻합니다.

Broken pipe는 소비자가 출력을 닫은 정상 상황으로 처리합니다.

## npm CLI [#npm]

0, 1, 2의 의미는 native 검색과 같습니다. 잘못된 UTF-8·binary 파일은 진단 뒤 건너뛰지만, 명시한 경로를 읽지 못하면 2를 반환합니다.

`--help`와 `--version`은 성공 0입니다.

## 파이프라인 사용 [#pipelines]

`set -e`에서는 검색 결과 없음 상태 1이 script를 중단할 수 있습니다. 이 상태를 허용하려면 명시적으로 분기하되 2를 성공으로 바꾸지 않습니다.

일부 stdout을 출력한 뒤 2로 끝나면 결과를 폐기하거나 미완료로 표시합니다.
