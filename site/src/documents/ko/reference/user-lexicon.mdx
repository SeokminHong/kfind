# 사용자 사전

## 파일 형식 [#format]

`[[predicate]]`는 lemma, coarse `pos`, alternation과 선택적 flag를 선언합니다. `[[nominal]]`은 surface와 명사 속성을 선언합니다.

파일은 최대 16 MiB의 UTF-8 TOML입니다. 알 수 없는 필드, 잘못된 POS와 alternation을 초기화 전에 거부합니다.

```toml
[[predicate]]
lemma = "플러그인하다"
pos = "verb"
alternation = "Ha"

[[nominal]]
surface = "LLM"
```

## Entry 적용 [#entries]

기본 동작은 기존 분석에 entry를 추가합니다. 같은 lemma라도 alternation이나 세부 분석이 다르면 모두 보존합니다.

`replace = true`를 지정하면 해당 사용자 entry가 대응하는 내장·full POS 분석보다 우선합니다. 다른 lemma의 분석에는 영향을 주지 않습니다.

## 검증 [#validation]

표제어 NFC, 기본형, POS별 필수 필드, 중복과 override 충돌을 검사합니다. 하나라도 실패하면 전체 파일을 설치하지 않습니다.

`--explain-query`의 analysis source가 `user-lexicon`이면 적용된 entry를 확인할 수 있습니다.
