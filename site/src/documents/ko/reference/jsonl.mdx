# JSON Lines

## Record [#record]

Native record에는 `type`, `path`, `line`, `text`, `spans`가 포함됩니다. npm record에는 `path`, `line`, `column`, `start`, `end`, `surface`, `atoms`가 포함됩니다.

각 object 뒤에는 LF가 옵니다. 진단은 stderr에만 기록합니다.

## span [#spans]

Native UTF-8 text offset에는 `utf8-bytes`, raw byte에는 `bytes` encoding을 표시합니다. npm offset과 column은 UTF-16 code unit입니다.

Core는 질의 표제어에 대응하는 범위입니다. Token은 조사·어미 소비까지 포함한 범위입니다.

## provenance [#provenance]

Origin에는 lemma, POS와 ordered `rules` 또는 `analysisIndex`, `rulePath`를 보존합니다. 하나의 atom에 여러 origin이 있을 수 있습니다.

소비자는 모르는 필드를 무시할 수 있지만, 좌표 encoding을 확인하지 않고 원문을 잘라서는 안 됩니다.
