# 설정

## 설정 파일 [#files]

사용자 사전 기본 경로는 `$XDG_CONFIG_HOME/kfind/lexicon.toml`, 다음으로 `$HOME/.config/kfind/lexicon.toml`입니다.

검색 옵션 전체를 저장하는 일반 config 파일은 없습니다. 명령을 재현하려면 셸 script나 에이전트 skill에 옵션을 명시합니다.

## 환경 변수 [#environment]

`KFIND_DATA_DIR`은 full POS와 구성 요소 리소스 디렉터리를, `KFIND_USER_LEXICON`은 사용자 사전 경로를 지정합니다.

`LC_ALL`, `LC_MESSAGES`, `LANG`은 사람이 읽는 진단 언어만 선택하며 옵션과 JSON 필드는 바꾸지 않습니다.

## 우선순위 [#precedence]

명시적 `--data-dir`, `--user-lexicon`이 환경 변수보다 우선합니다. 환경 변수 다음에는 설치 경로와 기본 config 경로를 확인합니다.

명시한 경로가 잘못되면 다음 후보로 넘어가지 않고 오류를 반환합니다.
