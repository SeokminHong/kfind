# Rust API

## 안정적 facade [#facade]

Crate root는 `Engine`, `Matcher`, `ResourceBundle`, 컴파일 옵션, 오류와 일치 provenance type을 노출합니다. 이 공개 표면을 1.x 호환 계약으로 유지합니다.

Matcher는 UTF-8 byte slice를 검색하며 파일 순회·인코딩·출력은 처리하지 않습니다.

## resource 초기화 [#resources]

`Engine::with_resources`는 선택적 full POS, enriched predicate와 구성 요소를 하나의 profile로 검증합니다. `Engine::new`는 embedded profile을 만듭니다.

`load_component_resource`는 전체 검증 뒤 구성 요소 리소스를 교체합니다. 검증에 실패하면 기존 리소스를 유지합니다.

## expert API [#expert]

`kfind::expert`는 호출자가 구성한 `Lexicons`, `QueryPlan`과 matcher plan에 접근할 수 있게 합니다.

Expert type은 root facade의 인자나 반환값에 나타나지 않으며 1.x 안정 계약에 포함되지 않습니다.
