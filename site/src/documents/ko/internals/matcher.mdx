# matcher

## anchor index [#anchors]

여러 프로그램이 같은 anchor를 사용하면 automaton state와 일치 목록을 공유합니다. Anchor는 candidate coverage를 보존하는 범위에서 길고 드문 표면형을 우선합니다.

NFC와 NFD variant는 별도 byte pattern이지만 같은 logical 프로그램과 원문 span projection으로 연결됩니다.

## 후보 window [#candidate-window]

일치 offset 주변에서 core가 시작하고 끝날 수 있는 제한된 범위만 검사합니다. 조사와 어미 automaton은 suffix Unicode scalar를 전이하며 불완전한 소비를 거부합니다.

Structural verifier는 token 전체의 분석이 필요할 때만 compact 리소스 index를 조회합니다.

## match 선택 [#match-selection]

같은 시작점에서 여러 프로그램이 승인되면 더 긴 완성 token과 일정한 프로그램 key를 사용해 겹치지 않는 결과를 만듭니다. Origin은 손실 없이 합칩니다.

Phrase mode에서는 atom 후보를 먼저 보존한 뒤 순서와 gap을 적용합니다. 따라서 단일 atom의 가장 긴 일치가 다음 atom을 숨기지 않습니다.

Disjunction은 하나의 atom matcher에 대안 anchor를 함께 넣으므로 원문을 대안 수만큼 반복 검색하지 않습니다.
