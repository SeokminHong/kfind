# 파생

## 파생 모드 [#modes]

`inflection`은 원래 품사를 유지하고 `derivation`은 등록된 새 표제어와 그 활용을 포함합니다. Literal 질의에서는 파생을 사용하지 않습니다.

파생 결과도 일반 프로그램으로 컴파일되며 같은 anchor·boundary와 provenance 계약을 따릅니다.

`n:안정`은 `--expand derivation --boundary smart`에서 `안정되었다`의 명사 구성 요소와 일치합니다. `--expand inflection`에서는 noun을 파생 용언 내부로 확장하지 않으므로 같은 원문과 일치하지 않습니다.

## 파생 접미사 [#suffixes]

명사+`하다`, `되다`, `시키다`와 지정된 XSV·XSA·XSN 경로를 지원합니다. `안정하다`, `안정되었다`는 명사 구성 요소와 파생 용언 어간을 각각 증명해야 합니다.

접두사 XPN과 어근 XR은 lexicon이 선언한 결합에서만 사용합니다.

## 생성 제약 [#constraints]

원문 구성 요소 span, 품사 순서와 후속 어미가 완성돼야 내부 질의 core를 승인합니다. 표면형의 일부 문자열만 맞는 파생은 거부합니다.

파생 규칙을 추가할 때 canonical positive, hard negative와 query-matrix disposition도 함께 갱신합니다.
