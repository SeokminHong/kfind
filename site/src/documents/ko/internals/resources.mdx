# 리소스 구조

## 리소스 계층 [#resource-layers]

Core·enriched·full POS는 질의 분석에 쓰는 lexicon 계층입니다. Compact component는 원문 표면형에서 분석과 구성 요소를 조회하는 구조 index입니다.

생성에 사용한 원본과 checksum은 manifest에 고정합니다. 실행 중에는 네트워크에서 데이터를 가져오거나 배경에서 갱신하지 않습니다.

## container 형식 [#container]

Binary container는 magic, schema, 패키지 버전, source identity, section directory와 SHA-256을 포함합니다. 큰 index와 payload를 section별로 검증할 수 있습니다.

Encoded 구성 요소 리소스는 먼저 128 MiB 상한을 검사합니다. 길이와 offset을 확인한 뒤 digest와 payload graph를 읽습니다.

## 초기화 수명주기 [#lifecycle]

Native engine은 검증된 리소스를 소유하고 matcher 사이에서 재사용합니다. JavaScript는 `withResources` 또는 `loadComponentResource`로 byte 배열을 명시적으로 전달합니다.

새 byte 배열의 모든 검증이 끝난 뒤 한 번에 교체합니다. 검증에 실패하면 기존 상태를 보존합니다.
