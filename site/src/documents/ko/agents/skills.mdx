# skill 설치

네이티브 CLI를 직접 호출하는 데 통합 설치는 필요하지 않습니다. 세션 지침과 실행 전 hook을 프로젝트에 추가하려는 경우에 `--init`을 사용합니다. npm CLI에는 이 옵션이 없습니다.

## 설치 위치 [#installation]

프로젝트 루트에서 대상 에이전트를 지정합니다. `--agent`는 반복할 수 있으며, 생략하면 대화형 터미널에서 대상을 선택합니다.

```bash
kfind --init --agent codex
```

| 에이전트    | 프로젝트 skill 경로             |
| ----------- | ------------------------------- |
| Codex       | `.agents/skills/kfind/SKILL.md` |
| Claude Code | `.claude/skills/kfind/SKILL.md` |
| Gemini CLI  | `.gemini/skills/kfind/SKILL.md` |

설치기는 선택한 에이전트의 project hook도 등록합니다. 기존 설정은 유지하며 kfind 관리 표식이 없는 skill은 덮어쓰지 않습니다.

## 호출 방식 [#invocation]

통합 hook을 신뢰한 프로젝트에서는 한국어 표제어·활용형 검색에 kfind를 사용하라는 세션 지침을 전달합니다. 실행 전 hook은 고정 문자열 모드를 명시하지 않은 한글 패턴의 `rg`, `grep`, `git grep` 명령을 차단합니다.

정확한 오류 메시지나 표기를 찾는 `rg -F`, `grep -F`, `git grep -F`, `--fixed-strings`와 `fgrep`은 허용합니다. `kfind --literal`과 IDE 고정 문자열 검색도 사용할 수 있습니다. 정규식 검색은 이 예외에 포함되지 않습니다.

```bash
kfind --embedded --boundary any --pos verb --json 걷다 src
kfind --uninstall --agent codex
```

결과의 span 주변을 읽어 의미를 확인합니다. 실행 오류와 결과 없음은 [결과 해석과 진단](/cli/diagnostics)을 따르며, 리소스 오류를 숨기고 `any`로 자동 전환하지 않습니다.

## 갱신 [#maintenance]

CLI를 갱신한 뒤 같은 대상에 `--init`을 다시 실행하면 관리 중인 skill과 hook을 갱신합니다. `--uninstall`은 해당 대상에서 kfind가 관리하는 항목만 제거하며 다른 skill과 에이전트 설정은 보존합니다.
