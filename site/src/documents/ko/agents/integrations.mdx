# 에이전트별 통합

## Codex [#codex]

Codex 작업에서는 저장소의 `AGENTS.md`와 관련 spec을 읽은 뒤 kfind 질의를 실행합니다. 출력 경로는 현재 workspace 안으로 제한하고, 검색 결과를 수정 권한으로 해석하지 않습니다.

## Claude Code [#claude-code]

Claude Code에서는 프로젝트 command 또는 skill에 정확한 명령을 보존합니다. Hook에서 실행할 때 검색 결과 없음과 hook 실행 실패를 구분합니다.

## Gemini CLI [#gemini-cli]

Gemini CLI에서는 JSON Lines를 구조화된 입력으로 전달하고 stdout과 stderr를 분리합니다. 긴 결과를 셸에서 임의로 요약하지 말고 경로나 질의 범위를 좁혀 다시 실행합니다.
