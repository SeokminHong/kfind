# 품사 지정

## coarse POS [#coarse-pos]

공개 값으로 `noun`, `pronoun`, `numeral`, `verb`, `adjective`, `determiner`, `adverb`, `particle`, `interjection`, `literal`을 제공합니다. 내부 사전의 NNG·NNP는 noun에, VV는 verb에 포함됩니다.

`auto`는 사전에 등록된 모든 호환 분석을 보존합니다. 하나를 우선하지 않으므로 동형 표제어에서 여러 프로그램을 만들 수 있습니다.

## 선택 규칙 [#selection-order]

Atom tag와 전역 `--pos`에 모두 구체 값을 지정했다면 두 값이 같아야 합니다. 다르면 두 제약을 동시에 만족할 수 없어 컴파일 오류가 발생합니다.

`--literal`은 `expand=literal`, `pos=literal`의 단축입니다. 다른 `--expand`나 non-literal POS와 함께 쓰면 충돌합니다.

## 품사 중의성 [#ambiguity]

질의의 품사 중의성은 후보 프로그램 집합으로 보존합니다. 원문의 품사는 `smart` 구조 판정에서 compact 리소스가 제공하는 세부 분석과 비교합니다.

형태 구조로도 구분할 수 없는 명사·용언 중의성은 결과에 남습니다. 의미 빈도나 language model 점수로 임의의 순위를 매기지 않습니다.
