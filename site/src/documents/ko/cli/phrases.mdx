# 구 검색

## atom 순서 [#atom-order]

각 atom은 독립된 matcher로 원문 후보를 만듭니다. Phrase matcher는 이전 atom의 token 끝보다 뒤에서 시작하는 다음 후보만 연결합니다.

기본 계약은 같은 logical line 안에서만 atom을 결합합니다. Newline을 넘지 않으므로 원문의 행 위치를 보존합니다.

## 간격 [#gap]

`--max-gap`은 앞 token 끝과 다음 token 시작 사이에 허용할 Unicode scalar 수의 상한입니다. 기본값 24에는 공백과 문장부호가 포함됩니다.

UTF-8 byte 수나 UTF-16 code unit 수가 아닙니다. Emoji와 결합 문자가 있어도 scalar 기준으로 동일하게 계산합니다.

## 구 span [#phrase-span]

결과 span은 첫 atom의 core 시작부터 마지막 atom에서 소비한 token의 끝까지입니다. 각 atom은 별도의 core·token span과 provenance를 유지합니다.

겹치는 후보 조합은 일정한 순서로 정렬한 뒤 중복을 제거합니다. 표면형이 같아도 atom provenance가 다르면 origin 집합으로 합칩니다.
