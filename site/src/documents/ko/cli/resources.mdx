# 사전과 resource

## 사전 구성 [#profiles]

Embedded 사전은 핵심 품사, 기능어와 불규칙 정보를 제공합니다. Enriched predicate는 고정 사전 snapshot이 뒷받침하는 용언 정보를 추가하고, full POS는 세부 품사 후보를 확장합니다.

Compact component는 원문 표면형의 품사열과 구성 요소 span을 제공하며 질의 사전은 확장하지 않습니다.

## resource 해석 [#resolution]

Native CLI는 명시적 옵션, 환경 변수, 설치 prefix 순으로 리소스를 찾습니다. 필요한 capability가 없으면 초기화 또는 컴파일 오류가 발생합니다.

JavaScript API는 리소스 경로를 추정하지 않습니다. npm CLI만 패키지 내부 asset의 위치를 알고, 구성 요소가 필요한 질의에서 이를 지연 로드합니다.

## 호환성 검증 [#validation]

Binary 리소스 header의 패키지 버전, schema, source identity, section length와 SHA-256을 모두 검증합니다. 검증이 끝나기 전에는 byte 배열을 engine state에 설치하지 않습니다.

새 리소스를 불러오지 못해도 이미 검증된 구성 요소 상태는 유지합니다. 다른 패키지 버전의 asset으로 대체하지 않습니다.
