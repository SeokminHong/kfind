# 검색 절차

## 탐색 검색 [#exploration]

첫 검색에는 표제어와 기본 `inflection`, `smart` 경계를 사용합니다. 결과가 없으면 `--boundary any`로 구조 경계를 완화하고, 품사 중의성이 예상되면 `--pos`를 명시합니다.

탐색 단계에서는 파일 확장자보다 디렉터리 범위를 먼저 제한합니다. 결과의 표면형과 주변 문맥을 확인한 뒤 질의를 바꿉니다.

## 정밀 검색 [#precision]

정밀 검색에서는 atom 품사 태그, 구 순서와 `--max-gap`을 고정합니다. 입력 문자열 그대로 찾으려면 형태 생성을 끄는 `--literal`을 사용합니다.

형태 구조로 구분할 수 없는 의미 중의성은 검색기가 제거하지 않습니다. 해당 후보는 주변 코드나 문장 문맥에서 판정합니다.

## 자동화 [#automation]

에이전트와 script는 `--json` 또는 native CLI의 JSON Lines 출력을 사용합니다. 검색 결과가 없는 정상 종료와 실행 오류를 종료 코드로 구분하고, stdout만 파서에 전달합니다.

```bash
kfind --pos verb --boundary any --json 걷다 src | jq -c 'select(.surface != null)'
```
