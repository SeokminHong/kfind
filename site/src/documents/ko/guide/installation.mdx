# 설치

## 배포 구성 [#distribution-profiles]

Homebrew 배포물은 native CLI와 `full-POS`, `enriched predicate`, `compact component` 리소스를 함께 설치합니다. Cargo 설치는 소스에서 native CLI를 빌드하며, 사용자가 배포 리소스 경로를 준비해야 합니다.

npm 패키지 `@kfind/kfind`는 브라우저 API와 Node.js CLI를 제공합니다. `enriched predicate`와 `compact component`는 포함하지만 `full-POS`는 포함하지 않습니다.

## native 설치 [#native-installation]

macOS에서는 개인 tap의 Homebrew formula를 기본 배포 경로로 사용합니다. 빌드 도구가 있는 환경에서는 Cargo로 같은 버전의 CLI를 설치할 수 있습니다.

```bash
brew install seokminhong/brew/kfind
kfind --version

cargo install --locked --path crates/kfind-cli
```

## npm 설치 [#npm-installation]

Node.js 20 이상에서는 scoped package를 설치합니다. 패키지의 `bin` 이름은 `kfind`입니다. 로컬 script, `npx`, `pnpm dlx`, Yarn 2 이상의 `yarn dlx`와 `node_modules/.bin`에서 같은 명령을 사용합니다.

시험 배포판을 받으려면 `@next`를 사용합니다. 재현 가능한 설치에는 정확한 버전을 지정합니다.

```bash
npm install @kfind/kfind@1.0.0-rc.4
npx @kfind/kfind 걷다 README.md
pnpm dlx @kfind/kfind 걷다 README.md
yarn dlx @kfind/kfind 걷다 README.md
```

## 설치 확인 [#installation-check]

`kfind --version`은 실행 파일 버전을 출력합니다. `kfind --literal 한국어 README.md`가 경로, 행, 열과 표면형을 출력하면 기본 파일 입력과 검색이 동작합니다.

Full-POS 자동 판정, EUC-KR, Git ignore, TUI가 필요하면 native CLI를 사용합니다. npm CLI는 UTF-8 파일과 표준 입력을 다루는 이식 가능한 구성입니다.
