# GSD 어휘 단위의 품사 주석

고정 GSD 9,314건에서 관형사·부사로 시작하고 명사나 동사가 이어지는 형태 주석
15건을 문장별로 검토했습니다. `세페이드`, `모바일`, `맨유`, `이시가키` 등
한 어휘 단위를 여러 성분으로 잘못 나눈 9건의 질의와 품사를 교정했습니다.
부사와 용언이 실제로 이어지는 `못하고` 등은 유지했습니다.
원문과 UTF-8 정답 범위는 동일합니다.
[사례별 주석](../../tools/morph-compare/gsd-lexical-unit-pos-review.tsv)

기준선과 교정본에 같은 full POS 실행 파일 `70d3c7107e8b7b32f8d65c51454250bfeac99e98`을
사용했습니다. 행렬은 TP, FP, TN, FN 순이며 비율은 precision, recall, F1입니다.
양성 계약 검토는 0건입니다.

| 경계 | 입력 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- | --- |
| smart | 기준선 | 9024, 0, 0, 290 | 100.00, 96.89, 98.42 | 9024, 0, 0, 290 | 100.00, 96.89, 98.42 |
| smart | 교정 | 9033, 0, 0, 281 | 100.00, 96.98, 98.47 | 9033, 0, 0, 281 | 100.00, 96.98, 98.47 |
| any | 기준선 | 8866, 0, 0, 448 | 100.00, 95.19, 97.54 | 8866, 0, 0, 448 | 100.00, 95.19, 97.54 |
| any | 교정 | 8875, 0, 0, 439 | 100.00, 95.29, 97.59 | 8875, 0, 0, 439 | 100.00, 95.29, 97.59 |

정확 일치 여부는 교정한 9건에서만 달라졌습니다. 검색 코드가 같아 성능 측정을 생략했습니다.

```sh
node tools/morph-compare/apply-gsd-proper-name-review.mjs "$input" --lexical-units > "$corrected"
"$runner" boundary full-pos "$boundary" "$corrected" "$output"
```
