# 과거·추측 뒤 다고·다네·다지의 검색 범위

표준국어대사전과 한국어기초사전에서 `-다고/-다네/-다지` 예문 37건과
`-겠-` 예문 31건을 점검했다. 과거·추측과 평서형 뒤에 이어지는 어미를
확인했다. `어쨌다고`는 `어쩌다`의 활용 처리에서 아직 일치하지 않는다.

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
표적의 신규 계약 보정은 0건이다. 전체 사전은
[앞선 보정 10건](2026-11-14-honorific-request-sipsa.md#품질)을 유지한다.

| 입력 | 경계 | 버전 | Raw 행렬 / 비율 (%) | 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- | --- |
| 표적 37건 | smart | 기준선·후보 | 36, 0, 0, 1 / 100.00, 97.30, 98.63 | 36, 0, 0, 1 / 100.00, 97.30, 98.63 |
| 표적 37건 | any | 기준선 | 27, 0, 0, 10 / 100.00, 72.97, 84.38 | 27, 0, 0, 10 / 100.00, 72.97, 84.38 |
| 표적 37건 | any | 후보 | 36, 0, 0, 1 / 100.00, 97.30, 98.63 | 36, 0, 0, 1 / 100.00, 97.30, 98.63 |
| 사전 4,458건 | smart | 기준선·후보 | 4291, 0, 0, 167 / 100.00, 96.25, 98.09 | 4300, 0, 0, 158 / 100.00, 96.46, 98.20 |
| 사전 4,458건 | any | 기준선 | 4142, 0, 0, 316 / 100.00, 92.91, 96.33 | 4152, 0, 0, 306 / 100.00, 93.14, 96.45 |
| 사전 4,458건 | any | 후보 | 4153, 0, 0, 305 / 100.00, 93.16, 96.46 | 4163, 0, 0, 295 / 100.00, 93.38, 96.58 |

`-겠-` any 예문의 `가겠다고` 2건을 추가로 찾았다. 다른 예문 1건에도
`기다리겠다고`를 반환했다. 고정 GSD와 KAIST의 범위는 같았다.
음성 53,308건에서는 두 행의 범위가 달라졌다. `pud:n01002017:verb:하다`는
`허용하겠다고` 속 `하겠다고` 범위를 추가했고,
`pud:w02014013:verb:하다`는 `실시하겠다고` 속 `하겠다` 범위를
`하겠다고`까지 확장했다. 두 행의 음성 표적은 각각 `합법적`, `하나는`이며
표적과 겹치는 범위는 추가되지 않았다. 행 단위 raw·계약 보정 품질 지표는
[고정 입력 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `379b4d2d`, 후보 `edbafd6a`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `64298e68`과
`1bac9722`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서는 순환했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접
