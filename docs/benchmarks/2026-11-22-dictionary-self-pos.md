# 자신의 사전 품사

재귀 용법의 `자신(自身)`과 확신을 뜻하는 `자신(自信)`은
한국어기초사전과 표준국어대사전에서 명사로 분류한다. MeCab-ko full POS에서도
명사였으나 명시적 대명사 질의에서 사전 근거 없이 활용 후보를 만들어 검색했다.
core에서 품사가 확인된 표제어는 해당 분석과 사용자 사전에 명시한 분석을 사용한다.
다른 품사를 지정한 형태 질의는 검색 프로그램이 없는 atom으로 컴파일된다.
[한국어기초사전 자신(自身)](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62096) ·
[표준국어대사전 품사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=332783)

UD 2.18 GSD 10문장, PUD 43문장의 `자신` 표면을 전수 검토했다.
재귀 명사 50행과 `자신감` 3행이 있었다. 공백이 빠진 PUD 문장은
`ToDoOrigText`에서도 대조했다. NFC·NFD 모두 자동 품사와 명사 질의가
명사 기준선의 전체 범위를 그대로 반환했고, 재귀 명사 50행에서 표적 범위가
정확했다. 대명사 질의는 결과 0건, 종료 코드 1이며 진단은 없었다.
구·대안 질의, 문자 그대로 검색, 사용자 사전의 별도 정의도 검증했다.

기존 PUD 계약 양성 35행은 UD의 대명사 태그에 근거하고 있었다. 동일한
사전 계약으로 기준선과 후보를 채점하기 위해 해당 보정을 제거했다.
고정 음성 원본 입력과 gold는 그대로 사용했다.

| 고정 음성 Smart | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 제외 |
| --- | --- | --- | ---: |
| 기준선 | 0, 3,220, 50,088, 0 / 0, 0, 0 | 1,413, 1,696, 50,058, 0 / 45.45, 100, 62.49 | 141 |
| 후보 | 0, 3,170, 50,138, 0 / 0, 0, 0 | 1,413, 1,646, 50,108, 0 / 46.19, 100, 63.19 | 141 |

고정 12세트 83,081행을 Smart·Token·Any로 검색해 전체 반환 목록
249,243개를 대조했다. 달라진 목록은 모두 `자신` 대명사 질의였다.
Smart 50행, Token 47행, Any 53행에서 기존 범위가 사라졌다.
교정 GSD 9,298행의 Smart 결과는 같았다.

## 네이티브 형태 판정

`bd3b14a2`와 `97b06684` release runner를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
비교했다. 입력과 리소스 체크섬은
[앞선 비교](2026-11-22-pronoun-before-cause.md#네이티브-형태-판정)와 같다.
