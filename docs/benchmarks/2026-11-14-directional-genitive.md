# 방향 조사와 관형격 조사 경계

`바다로의`처럼 방향 조사 뒤에 관형격 조사가 이어지면 `smart`는
연쇄 전체를 반환합니다. `서로의`, `유로의`, `선로의`는 관형격 조사
앞의 독립 어휘를 확인해 내부 음절을 방향 조사 앞의 체언으로 반환하지 않습니다.
[관형격 결합 용례](https://www.korean.go.kr/common/download.do?c_file_name=eac79d12-5e8c-4ad2-bbd5-718a8f9ef147.pdf&file_path=reportData)

원본 GSD·PUD에서 방향 조사처럼 보이는 8곳을 확인했습니다. PUD의
실제 방향 결합 4곳과 분해하면 안 되는 대조 4곳에 별도 양성 3건을
추가했습니다. 기준선의 양성 7곳에서 정확 일치가 없었고 후보는
6곳을 반환합니다. `영국 제도로의 침략`의 `제도`는 계속 누락됩니다.
대조 4곳은 양쪽에서 반환하지 않았습니다.

교정 GSD 9,314행, PUD 양성 798행, 사전 양성 4,458행과
GSD·PUD 음성 53,308행의 반환 범위는 `smart`와 `any`에서 동일했습니다.
신규 gold 6건은 통과했고 기존 `verify-gold` 불일치 8건은 재현됐습니다.

행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서입니다.
아래 입력의 계약 검토는 0건입니다.

| 입력 | 실행 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- | --- |
| 방향 조사 대조 smart | 기준선 | 0, 0, 4, 7 | 0.00, 0.00, 0.00 | 0, 0, 4, 7 | 0.00, 0.00, 0.00 |
| 방향 조사 대조 smart | 후보 | 6, 0, 4, 1 | 100.00, 85.71, 92.31 | 6, 0, 4, 1 | 100.00, 85.71, 92.31 |
| GSD smart | 양쪽 | 9133, 0, 0, 181 | 100.00, 98.06, 99.02 | 9133, 0, 0, 181 | 100.00, 98.06, 99.02 |
| GSD any | 양쪽 | 8954, 0, 0, 360 | 100.00, 96.13, 98.03 | 8954, 0, 0, 360 | 100.00, 96.13, 98.03 |

## 성능

시작점 `70a5d2d4b76666a8ec1e2c5a8c8424a547af82aa`, 기준선
`96a1bd7b72a06f144ebb51b6d51cbfb164bef7e7`, 후보
`93f54d76566938daa703c799ed81ab2cc2fc6893`를 비교했습니다. Apple M1 Max,
macOS 26.6.2 (25G83), rustc·Cargo 1.97.0 release 빌드에서 같은 full POS
리소스를 사용했습니다. 실행 순서를 순환하며 입력마다 새 프로세스에서 워밍업
1회와 측정 5회를 수행했습니다. 값은 중앙값 [최솟값, 최댓값]입니다.
처리량은 평가 시간 기준이며 p95는 최근접 순위입니다.
[리소스 SHA-256](2026-11-13-corpus-rule-audit.md#성능)

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
