# 붙임 보조 용언의 반환 범위

기준선 `b5babe51c3751d4115602a1a4ef39a045fa5aae0`, 후보 `6bb630e3a695b40e71bea11e533438fd3784bf02`를 비교했습니다.
기준선 바이너리는 Rust 소스와 사전이 동일한 `a1b895e228af93807a5e90729b28aa937c9e1245`에서 빌드했습니다.
구조 검증이 인정한 붙임 보조 용언을 반환 token에 포함합니다. `걸어가십니까`에서 반환 token과
core의 범위를 각각 검증했습니다.

`타버렸고`의 반환 끝만 101에서 110으로 확장됐고 겹침 정답은 그대로였습니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Rust·Cargo 1.97.0에서 동일한 release 설정과 사전으로
새 프로세스 워밍업 1회 뒤 순서를 교대하며 5회 측정했습니다. 값은 중앙값 [최솟값, 최댓값]입니다.
p95는 nearest-rank이고 RSS는 `/usr/bin/time -l`의 최대 상주 메모리입니다.

| GSD 양성 | 후보 | 59.854 [59.680, 60.022] | 30996 [30408, 31050] | 0.0728 [0.0722, 0.0741] | 79.000 [78.891, 79.313] |
| GSD·PUD 음성 | 기준선 | 60.951 [59.566, 61.523] | 18470 [18080, 19024] | 0.1273 [0.1215, 0.1283] | 125.406 [125.203, 125.688] |

처리량 중앙값은 양성 1.58%, 음성 1.86% 증가했고 p95는 각각 0.68%, 2.78% 감소했습니다.
양쪽의 실행 범위는 겹쳤습니다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
KFIND_FULL_POS_LEXICON="$lexicon" KFIND_COMPONENT_RESOURCE="$components" \
KFIND_ENRICHED_PREDICATES="$enriched" \
  /usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
