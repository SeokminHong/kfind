# 원문 GSD 지정사·접미사 앞 명사 범위

원문·교정 GSD에서 문장, 질의, 품사와 정답의 시작이 같고 정답 끝만
달라진 548행을 대조했다. 명사형 질의의 원문 품사열이
`NNG·NNB·NNP + VCP + EP* + EF·EC·ETM`이고, 표제어 분절이
`질의 + 이 + 어미`인 경우를 확인했다. 명사가 두 음절 이상의 한글이고
원문에 한 번만 나타난 104행의 범위를 고정했다. `멧돼지이며`와
`거주지였다`에서 명사 범위는 각각 `멧돼지`와 `거주지`다.
[UD 원문 입력 재현](2026-11-22-reproduced-ud-audit-fixtures.md) ·
[원문 품사열과 범위](../../tools/morph-compare/raw-gsd-source-corpus-reviews.tsv)

같은 조건에서 원문이 `NNG + XSN`으로 시작하고 `-적`이나 `-님`이
명사에 바로 붙은 53행도 확인했다. `심리적인`의 `심리`와
`사장님이`의 `사장`이 해당한다. 명사는 두 음절 이상의 한글이고
문장에 한 번만 나타난다. `-적`은 39행, `-님`은 14행이다.
[한국어기초사전 -적](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=88966) ·
[한국어기초사전 -님](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=88852)

정답 범위는 원문 표제어의 첫 명사 성분을 UTF-8로 계산해 확정했다.
`852cae48`의 같은 원문 실행 결과를 재채점했으며 157행의 모든 범위가
일치했다. 원문 데이터 9,335행과 원문 정답으로 계산한 적중 행렬도
보존했다. 원문 양성 864행의 추가 반환 953개와 계약 FNc 888건은
계속 검토가 필요하다. 교정 GSD 9,298행의 결과는 같다.
