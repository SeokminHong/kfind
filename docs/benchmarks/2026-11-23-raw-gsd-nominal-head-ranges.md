# 원문 GSD 지정사·접미사 앞 명사 범위

원문·교정 GSD에서 문장, 질의, 품사와 정답의 시작이 같고 정답 끝만
달라진 548행을 대조했다. 명사형 질의의 원문 품사열이
`NNG·NNB·NNP + VCP + EP* + EF·EC·ETM`이고, 표제어 분절이
`질의 + 이 + 어미`인 경우를 확인했다. 명사가 두 음절 이상의 한글이고
원문에 한 번만 나타난 104행의 범위를 고정했다. `멧돼지이며`와
`거주지였다`에서 명사 범위는 각각 `멧돼지`와 `거주지`다.

## 한 음절 명사와 대명사의 지정사 경계

끝점만 다른 548행 중 미검토 지정사 결합을 다시 확인했다. 첫 성분이
`NNG·NNB·NNP·NP`, 이어지는 성분이 `VCP + EP* + EF·EC·ETM`이며
첫 성분의 표제어가 원문에 한 번 나타나는 39행이다. 명사 33행과
대명사 6행의 지정사 앞 범위를 고정했다. `집입니다`의 `집`,
`누구인지`의 `누구`, `언제일까`의 `언제`가 해당한다.
