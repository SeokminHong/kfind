# 부분 집합에서 장소를 세는 구문

`집 중 한 곳`에서 `곳`은 장소의 수를 세는 단위다. Smart는
앞 집합에 장소 명사가 오거나 `그중`이 쓰이고 `곳`의 조사·지정사
결합이 확인되면 `한`을 동사 범위에서 제외한다.
`연습을 한 곳`과 `수업 중 한 곳`의 동사 관형형 후보는 유지한다.
[한국어기초사전 ‘곳’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=18661) ·
[한국어기초사전 ‘그중’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62460)

[한국어기초사전 snapshot](../../data/SOURCES.toml)의 명사 중
‘건물 종류’와 ‘식생활 관련 장소’ 107항목의 뜻풀이를 확인했다.
앞 집합에 올 수 있는 장소 명사 86개와 표제어 ID를
[측정 당시의 장소 어휘 자료](https://github.com/SeokminHong/kfind/blob/d4b29d4f3f8fcd51658f2283687692bc558fd348/data/rules/krdict-partitive-place-groups.rs)에 기록했다.
`건축·시식회` 같은 활동, `골재` 같은 재료, `자판기` 같은 기기,
시간 구문을 허용하는 동형은 그 자료의 대상에서 제외한다.

## 품질

기준선 `0dc9d814`와 후보 `1e45bd77`의 고정 12세트 83,081행에서
Smart·Any·Token 반환 범위 249,243개를 비교했다. Smart
`gsd:test-s428:9`의 `하다` 범위 56..59만 사라졌다.
고정 11세트에서 Smart FNc는 두 버전 모두 0건이며 FPc는 2,469건에서
2,468건으로 줄었다. 동일한 계약 검토를 적용했다.

장소 명사 86개에 `중 한 곳이다`와 `중 한 곳에서는`을 각각 붙인 172행에서
동사 `하다`의 표적 반환은 기준선 172건, 후보 0건이었다. 원문, 관형사
질의, 복수 장소, 시간 구문, 목적어가 드러난 관형절도 별도로 대조했다.

행렬은 TP, FP, TN, FN 순서이고 비율(%)은 precision, recall, F1
순서다. 장소 대조에는 계약 검토가 0건이고, 교정 GSD는 4건이다.

| 장소 대조 172행 | Smart 후보 | 0, 0, 172, 0 / —, —, — | 0, 0, 172, 0 / —, —, — |
| 교정 GSD 9,298행 | Smart 기준선 | 9295, 0, 0, 3 / 100.00, 99.97, 99.98 | 9294, 1, 3, 0 / 99.99, 100.00, 99.99 |
| 교정 GSD 9,298행 | Smart 후보 | 9294, 0, 0, 4 / 100.00, 99.96, 99.98 | 9294, 0, 4, 0 / 100.00, 100.00, 100.00 |
| 교정 GSD 9,298행 | Any 양쪽 | 9258, 0, 0, 40 / 100.00, 99.57, 99.78 | 9254, 4, 0, 40 / 99.96, 99.57, 99.76 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 순서를
교대해 5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했고
p95에는 최근접 순위를 사용했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 61.155 [60.784, 63.054] | 30,448 [28,964, 31,104] | 0.07171 [0.07004, 0.07421] | 81.141 [80.906, 81.188] |
| 교정 GSD | 후보 | 60.749 [60.487, 62.734] | 30,688 [28,473, 30,910] | 0.07088 [0.07013, 0.07633] | 81.078 [80.922, 81.266] |
| 고정 음성 | 기준선 | 63.467 [61.592, 64.051] | 19,814 [16,938, 19,857] | 0.12629 [0.12558, 0.13913] | 127.641 [127.469, 127.734] |
| 고정 음성 | 후보 | 61.315 [60.530, 62.566] | 19,678 [19,012, 19,801] | 0.12817 [0.12575, 0.13121] | 127.656 [127.203, 127.688] |

교정 GSD의 처리량 중앙값은 +0.79%, p95는 −1.16%다. 고정 음성은
각각 −0.69%, +1.48%다. 두 입력에서 처리량과 p95의 관측 범위는 겹친다.
