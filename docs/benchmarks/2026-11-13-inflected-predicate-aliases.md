## 원본 대조

`VV.csv`, `VA.csv`, `VX.csv`의 독립 행을 `Inflect.csv`와 비교했습니다. CSV의 첫
여덟 필드가 같고, `Inflect`가 같은 세부 품사의 다른 어간 하나로 분석한 행의 표제어·품사
134개를 검토했습니다. 한국어기초사전·표준국어대사전·우리말샘의 고정 원본에서 같은 품사의
독립 표제어가 확인된 92개를 보존했습니다. 독립 표제어 근거가 확인되지 않은 42행은 추출에서
제외했습니다. 같은 표기의 다른 품사와 원본 `Inflect` 분석은 유지됩니다.
[고정 사전 원본](../../data/SOURCES.toml) · [제외 행과 원본 분석 어간](../../data/rules/mecab-inflected-predicate-aliases.rs)

예를 들어 `그/VV`의 원본 분석은 `긋/VV`입니다. `그는 서류에 줄을 그었다.`에서
`그다`는 일치하지 않고, `그`와 `긋다`는 각각 대명사와 용언을 찾는지 검사합니다.
`그렇다`의 형용사 품사와 실제 독립 동형 표제어인 `가다`도 추출 회귀로 확인했습니다.

## 품질

GSD 양성은 gold byte 범위와의 정확한 일치로, GSD·PUD 음성은 반환 범위의 유무로 채점했습니다.
행렬은 TP, FP, TN, FN이고 비율은 precision, recall, F1입니다. 양성만 있는 입력과 음성만
있는 입력은 함께 집계하지 않았습니다. 자동 품사 입력에는 계약 검토를 적용하지 않아 raw와
계약 보정 결과가 같습니다. 명시적 품사 음성에는 기존 검토 26건을 적용했습니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Darwin 25.6.0, Rust·Cargo 1.97.0에서
기준선의 동일한 release runner로 두 사전 산출물을 비교했습니다. 입력별로 새 프로세스에서
warm-up 1회 뒤 5회 측정하고 실행 순서를 교대했습니다. 처리량은 runner의 평가 시간으로
계산했고 p95는 nearest-rank, RSS는 `/usr/bin/time -l`의 프로세스 최대 상주 메모리입니다.
셀은 중앙값 [최솟값, 최댓값]입니다.

GSD 양성 처리량 중앙값은 1.64% 감소했고 p95는 0.94% 증가했습니다. GSD·PUD 음성은
처리량이 0.63%, p95가 0.18% 증가했습니다. 사전 제외는 빌드 때 실행되며 제품의 검색 경로에
검사나 캐시를 추가하지 않습니다.

```sh
scripts/build-full-pos.sh "$full_pos_dir"
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
KFIND_FULL_POS_LEXICON="$full_pos_dir/lexicon.bin" \
KFIND_COMPONENT_RESOURCE="$component_resource" \
KFIND_ENRICHED_PREDICATES="$enriched_predicates" \
  /usr/bin/time -l "$runner" untagged full-pos smart "$input" "$output"
```

명시적 품사 품질 재산정에는 같은 명령에서 `untagged`를 `boundary`로 바꿨습니다.
