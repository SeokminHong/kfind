# 직접 경험을 나타내는 데·데요

사전의 `-데/-데요` 예문 14건을 확인했다. `똑똑하데요`, `폈데요`,
`오셨데요`, `동창이데요`처럼 어간이나 선어말 어미 뒤에 붙은 종결형을
어절 끝까지 반환한다. 관형형 뒤에서 띄어 쓴 의존 명사 `데`도 대조했다.
[표준국어대사전 -데](https://stdict.korean.go.kr/search/searchView.do?word_no=415074&searchKeywordTo=3) ·
[표준국어대사전 -데요](https://stdict.korean.go.kr/search/searchView.do?word_no=511743&searchKeywordTo=3)

`데:5`의 `잘하데`는 표제어 `잘하다`의 활용이라 질의를 교정했다.
`데:6`, `데요:4`, `데요:7`은 지정사 `이다`가 질의이므로 앞의 체언을
빼고 `이데/이데요`로 기대 범위를 좁혔다.
