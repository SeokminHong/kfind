# 의존 명사 뒤의 지정사 의문형 축약

`끝날 건고`의 `건고`를 `것인고`의 축약으로 검색합니다. 앞말의 관형형과 의존 명사
결합 및 문장 종결 위치를 확인하고 축약 어절 전체를 반환합니다. 인용된 표기 자체와
관형형 없이 쓰인 형태를 대조군으로 검증했습니다.
[한국어기초사전 -ㄴ고](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=73889&nation=eng)

사전 예문 4,458건에서 `건고`, `것인고`, `거인고`를 검색하고 같은 어미 계열인
`-ㄴ고`, `-은고`, `-는고`, `-던고`의 예문 51건을 대조했습니다. `-ㄴ고` 16건은
수정 뒤 모두 정확히 일치했습니다. 같은 계열의 `일이겠는고`는 명시적 지정사 범위 검토,
`누구시던고`는 주체 높임과 회상형 결합의 검색 검증이 남았습니다.

## 성능

macOS 26.6.2 (25G83), Apple M1 Max, rustc 1.97.0, Cargo 1.97.0에서 측정했습니다.
입력별로 시작점 `70a5d2d4b76666a8ec1e2c5a8c8424a547af82aa`, 기준선, 후보를 순환해
새 프로세스에서 warm-up 1회와 측정 5회를 실행했습니다. 초기화와 평가 시간을 runner가
기록했습니다. 처리량은 평가 시간으로 계산했고 p95는 nearest rank, RSS는 최대 상주
메모리를 사용했습니다. 표는 중앙값 [최솟값, 최댓값]입니다.
