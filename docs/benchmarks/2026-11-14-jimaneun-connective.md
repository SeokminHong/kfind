# 지마는 연결 어미

사전 예문에서 `-지마는` 14행과 준말 `-지만` 14행을
대조했다. 원문의 `말씀드렸지마는` 질의를 `말씀드리다`로
교정했다. 두 표면형은 같은 연결 어미 경로를 사용하며, `짧은
거리지마는`의 생략 지정사는 앞 관형형과 뒤 명사의 결합으로
구별한다. `자주 거리지마는`의 동사 문맥은 대조군에 포함했다.
[한국어기초사전](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=78637&nation=eng) ·
[국립국어원 준말 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=315583)

`smart`에서 `-지마는` 9→14행과 준말 `실례지만` 1행을
복구했다. `any`의 12행은 용언 또는 명시 지정사 활용이다. 생략
지정사 2행은 `smart`에서 검색한다. 고정 음성 53,308행의 반환
범위는 동일하다. 새 정답 회귀 4건은 통과했고 기존 불일치 8건은 남았다.

행렬은 TP, FP, TN, FN 순서다. 음성의 기존 계약 검토는 3건이며
사전의 계약 검토는 0건이다.
