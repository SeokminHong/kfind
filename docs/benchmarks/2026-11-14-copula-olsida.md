# 지정사 종결형 올시다

사전 4,458건에서 `올시다/올습니다`가 표제인 정렬 용례는
`나그네올시다` 1건이다. 표준국어대사전 원자료에는 `아니올시다`도 있으며,
`올습니다`는 `올시다`로 연결하는 항목이다. 지정사의 명시형과 모음으로 끝나는
체언 뒤의 생략형, `아니다`를 검증했다. 받침 있는 체언과 동작 용언에 대해서는
생략형의 전체 어절을 반환하지 않는지 확인했다. [우리말샘 -올시다](https://opendict.korean.go.kr/dictionary/view?sense_no=235286)

행렬 순서는 TP, FP, TN, FN이며 비율 순서는 precision, recall, F1이다.
사전은 계약 검토 0건으로 raw와 보정이 동일하다.

| 사전 4,458건 | smart | 기준선 | 4161, 0, 0, 297 | 100.00, 93.34, 96.55 |
| 사전 4,458건 | smart | 후보 | 4162, 0, 0, 296 | 100.00, 93.36, 96.57 |
| 사전 4,458건 | any | 공통 | 3720, 0, 0, 738 | 100.00, 83.45, 90.98 |

교정 GSD 9,298건, 고정 음성 53,308건, KAIST 5,124건의 반환 범위는
동일했다. 해당 입력의 raw 및 계약 보정 지표는
[이유 연결형 지라 측정](2026-11-14-causal-jira.md)과 같다.
