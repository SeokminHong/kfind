# 붙여 쓴 차례 표현의 수량 관형사

Smart에서 수량 관형사 뒤의 단위 명사, 차례 접미사 `-째`, 선택 조사가
한 어절을 완성하면 관형사 범위를 반환한다. PUD의 `두번째로`와 일반
수량 표현 `세번째`, `네번째`, `스물두번째`에서 복구를 확인했다.
기존 `두 번째`, `열번째`, `첫번째`와 지명 `두산리`, 잘못된 조사 연쇄
`두번째로를`을 함께 대조했다.
[한글 맞춤법 제43항 국립국어원 해설](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=324880)

## PUD 원문 대조

[앞선 대조](2026-11-16-determiner-nominal-head.md#원문-대조)의 55행에
대해 원문의 별도 표기와 문법을 확인했다.

- `ToDoOrigText`가 공백만 다르고 목표 형태소가 양쪽에서 분리되는 42행은
  그 표기의 바이트 범위를 다시 계산했다. 기준선의 관형사 코드까지 반영한
  Smart가 42행 모두에서 정확한 범위를 반환했다.
- `전세계` 7행과 `이중` 1행은 각각 `전 세계`, `이 중`으로
  표적에 인접한 공백을 보완한 뒤 여덟 범위 모두를 확인했다.
  [전 세계 띄어쓰기](https://www.korean.go.kr/nkview/news_pdf/2020_09.pdf) ·
  [이 중 띄어쓰기](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5912&mn_id=217&pageIndex=212)
- `우리에게는`, `이것으로도`, `무엇보다도`는 PUD가 마지막 조사를 나눠
  토큰을 `0..12`로 정렬한다. 검색은 조사 연쇄가 끝나는 `0..15`를 반환했다.
  `그해에`의 `그`는 원문에서 분절되지만 사전에 등재된 한 단어 안의
  성분이다. [그해 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=334155&searchCondition=&searchKeyword=)
- `두번째로`는 허용된 붙여쓰기이며 원문 `w01049066`의 11번 `DT`가
  12번 `NNB+CM`을 수식한다. 질의 범위 `69..72`를 계약 양성으로
  확인하고 원본 음성표를 유지했다. 회귀 문장은 뒤의 `설립된국립공원`을
  `설립된 국립공원`으로 띄어 썼고 표적 범위는 같다.

## 품질

고정 입력 12개와 세 모드 249,243행에서 입력 ID, 리소스 해시 및 반환
범위를 대조했다. 원본 음성의 `두번째로`에서 Smart 관형사 범위 한 건만
추가됐다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.
고정 음성 53,308행을 반환 유무로 채점하고 양쪽 실행에 같은 계약 검토
159건을 적용했다. Token의 누락은 붙임 어절 내부의 관형사 범위를 요구한다.

| 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 4029, 49279, 0 / 0.00, 0.00, 0.00 | 158, 3871, 49278, 1 / 3.92, 99.37, 7.55 |
| Smart | 후보 | 0, 4030, 49278, 0 / 0.00, 0.00, 0.00 | 159, 3871, 49278, 0 / 3.95, 100.00, 7.59 |
| Any | 양쪽 | 0, 17622, 35686, 0 / 0.00, 0.00, 0.00 | 159, 17463, 35686, 0 / 0.90, 100.00, 1.79 |
| Token | 양쪽 | 0, 2864, 50444, 0 / 0.00, 0.00, 0.00 | 120, 2744, 50405, 39 / 4.19, 75.47, 7.94 |

골드 925건과 walk/hang, workspace 테스트, 포맷, Clippy,
benchmark Python 82건과 계약 대조 2건이 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`4564b469`와 `e9456d72`를 비교했다. 각 입력과 버전에 대해 새
프로세스로 워밍업 1회와 측정 5회를 실행하고 두 버전의 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| 교정 GSD Smart | 후보 | 62.087 [60.786, 63.574] | 28,804 [28,044, 29,018] | 0.07617 [0.07537, 0.07871] | 81.234 [81.141, 81.391] |
