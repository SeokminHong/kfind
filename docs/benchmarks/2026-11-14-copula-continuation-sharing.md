# 지정사 라 계열 어미 정의 공유

검색기와 참조 구현이 `-라` 뒤의 어미 20개와 인용·`-로-` 계열 18개의
표면형과 규칙 경로를 공유한다. full POS `smart`에서 다음 네 고정 입력
69,656건의 UTF-8 반환 범위가 모두 같았다. 골드 925건과 스트레스 입력도 통과했다.

행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서다. 사전과 교정 GSD의
계약 검토는 0건, 고정 음성은 34건, KAIST test는 25건(제외 4건)이다.
두 리비전의 값은 같다.
