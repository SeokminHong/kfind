# 분해형 부사의 조사 경계

기준선은 `407345a1`, 후보는 `fc3924f8`입니다.

## 품질

`canonical` 모드에서 NFD `때론`은 `때로` 질의의 축약형입니다. 기준선은
완성된 축약형과 함께, 마지막 받침 앞에서 끊긴 `때로` 후보를 구조 검증에 전달했습니다.
후보는 음절 내부 경계를 거부해 양성의 종료 코드가 2에서 0으로, 체언 구조와
미등록형 음성의 종료 코드가 2에서 1로 바뀝니다. 양성 범위는 양쪽에서 0..15바이트였습니다.

행렬은 TP, FP, TN, FN 순서이고 비율은 precision, recall, F1 순서입니다.
검토 0건인 행은 원본 기대값으로 계약 보정 지표를 계산했습니다.

| 입력과 모드 | 리비전 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) | 검토 |
| --- | --- | --- | --- | --- | --- | ---: |
| NFD 부사 대조 3건 canonical smart | 양쪽 | 1, 0, 2, 0 | 100.00, 100.00, 100.00 | 1, 0, 2, 0 | 100.00, 100.00, 100.00 | 0 |
| GSD 원본 9,335건 smart | 양쪽 | 8087, 0, 0, 1248 | 100.00, 86.63, 92.84 | 8087, 0, 0, 1248 | 100.00, 86.63, 92.84 | 0 |
| KAIST 행렬 test 2,592건 smart | 양쪽 | 1289, 2, 1294, 7 | 99.85, 99.46, 99.65 | 1290, 0, 1298, 0 | 100.00, 100.00, 100.00 | 25 |

## 성능

Apple M1 Max arm64, macOS 26.6.2, Darwin 25.6.0, Rust와 Cargo 1.97.0에서
release 빌드를 사용했습니다. 새 프로세스에서 warm-up 1회 뒤 5회 측정하고
리비전 순서를 교대했습니다. 표는 중앙값 [최솟값, 최댓값]입니다.

NFC 처리량 중앙값은 GSD −0.70%, KAIST −0.12%였고 p95는 각각 +0.65%,
+0.23%였습니다. p95는 nearest-rank로 산출했습니다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```

두 리비전 모두 50,000줄을 셌고 종료 코드는 각각 2와 0이었습니다.
