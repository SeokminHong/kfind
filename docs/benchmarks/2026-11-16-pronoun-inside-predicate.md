# 완결 용언 내부의 대명사 범위

대명사와 같은 표면이 어절 첫머리에 나타날 때, 같은 위치에서 시작해
대명사 범위를 가로지르는 용언 어간과 어미의 완결 경로를 확인한다.
대명사 뒤의 체언이 어절을 완성하거나 조사·지정사 결합 또는 원본에서
정렬된 대명사 성분이 확인되는 경우에는 후보가 남는다.
`이끄는`, `이야기했다`, `나왔다`의 내부 범위와 `이를`, `누구지`,
`우리사회는`의 대명사 범위를 대조했다.

## 품질

고정 입력 12세트를 Smart·Any·Token으로 실행하여 249,243행의 ID,
리소스 체크섬과 전체 UTF-8 반환 범위를 비교했다. 고정 음성에서
대명사 질의 33행의 오탐이 없어졌다. 질의는 `이` 16건, `나` 14건,
`그` 2건, `저` 1건이다. GSD 양성 한 행에서 `그러던 그는`의
`그러던` 내부 범위가 없어졌고 독립 대명사 `그는`은 회수했다.
나머지 범위는 모두 같았다. 양쪽에 같은 계약을 적용했고 고정 평가
11세트의 Smart 계약 FN은 0건이다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
고정 음성에 적용한 기존 계약 검토는 171건, 교정 GSD는 0건이다.

| Smart 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 고정 음성 53,308행 | 기준선 | 0, 3910, 49398, 0 / 0.00, —, 0.00 | 171, 3739, 49398, 0 / 4.37, 100.00, 8.38 |
| 고정 음성 53,308행 | 후보 | 0, 3877, 49431, 0 / 0.00, —, 0.00 | 171, 3706, 49431, 0 / 4.41, 100.00, 8.45 |
| 교정 GSD 9,298행 | 양쪽 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 |

Workspace 테스트 644건, gold 및 walk/hang, 포맷과 Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
기준선 `efd55618`과 후보 `88ec5caf`를 비교했다. 각 입력·버전은
새 프로세스에서 워밍업 1회 뒤 5회씩 실행하고 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| Smart 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 62.061 [61.516, 63.718] | 29,428 [29,272, 29,696] | 0.07471 [0.07400, 0.07583] | 80.938 [80.734, 81.250] |
| 교정 GSD | 후보 | 63.659 [61.389, 64.855] | 29,517 [27,710, 29,841] | 0.07446 [0.07417, 0.07804] | 80.859 [80.719, 80.906] |
| 고정 음성 | 기준선 | 62.211 [61.676, 63.935] | 19,903 [19,813, 19,996] | 0.12512 [0.12450, 0.12688] | 127.766 [127.547, 127.953] |

−1.14%, p95는 +2.33%다. 각 지표의 측정 범위가 겹쳤다.
