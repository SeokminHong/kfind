# 위치 명사의 기준점과 동형 품사

기준점에 통째 체언 분석이 있는 경우를 짧은 어간과 어미로 쪼갠
분석과 대조했다. `나무 사이`와 `서울 일대`의 관형사, `책장 옆`의
대명사, `코 주위`와 `운동장 중간`의 부사 오탐을 제거했다.
관형격 기준점과 `유치에 일대 전기를`의 관형사 대조도 확인했다.
[국립국어원 어휘 자료](https://www.korean.go.kr/common/download.do?c_file_name=5e2f0471-a53f-46f0-a0ab-dde253ac0241_1.pdf&file_path=reportData) ·
[회귀 fixture](../../data/fixtures/ud_morphology_cases.tsv)

국립국어원 교재와 위치·방향 어휘 자료에서 추린 위치 표현 54개를
모두 명사로 검색했다. 각 표제어에 부사·관형사·대명사·수사를
지정한 216행 중 자동 분석에서도 해당 품사가 나오는 13행을
대조했다. 이 중 경쟁 품사 반환은 8행에서 3행으로 줄었다.
남은 3행은 범위 의존 명사 `내`에 해당한다. 교정 GSD에서 위치
표현과 짧은 부정 부사를 조회한 105행은 모두 정확했다.

행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1이다.
고정 음성에 기존 계약 검토 3건을 적용했다. 나머지 입력은 검토
0건으로 raw와 보정 결과가 같다.

| 입력 | 버전 | Raw 행렬 | Raw P/R/F1 (%) | 보정 행렬 | 보정 P/R/F1 (%) |
| --- | --- | --- | --- | --- | --- |
| 위치 회귀 | 기준선 | 4, 6, 0, 0 | 40.00, 100.00, 57.14 | 4, 6, 0, 0 | 40.00, 100.00, 57.14 |
| 위치 회귀 | 후보 | 4, 0, 6, 0 | 100.00, 100.00, 100.00 | 4, 0, 6, 0 | 100.00, 100.00, 100.00 |
| 교정 GSD 양성 | 양쪽 | 9298, 0, 0, 0 | 100.00, 100.00, 100.00 | 9298, 0, 0, 0 | 100.00, 100.00, 100.00 |
| 고정 음성 | 양쪽 | 0, 4092, 49216, 0 | 0.00, 0.00, 0.00 | 3, 4089, 49216, 0 | 0.07, 100.00, 0.15 |

고정 양성·음성의 반환 범위가 모두 같았다. `verify-gold`의 새
회귀 7행은 통과했고 기존 불일치 8행은 재현됐다.

## 성능

시작점 `70a5d2d4`, 기준선 `2b2f8f71`, 후보 `98f2304e`를 Apple M1 Max
arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 같은 release 설정과
사전으로 측정했다. 각 입력을 fresh process에서 워밍업 1회 뒤
5회씩 교대 실행했다. 표는 중앙값 [최솟값, 최댓값]이다.
p95는 nearest-rank이며 RSS는 `time -l`의 최대 상주 메모리다.
