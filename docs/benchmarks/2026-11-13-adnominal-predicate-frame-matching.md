# 바깥 서술어의 목적격 문형 판정

`것으로/걸로/거로` 뒤의 독립 종결 서술어가 목적격을 받을 수 없으면 앞의 목적격을
관형절에 연결합니다. 한국어기초사전의 모든 뜻에 구조화된 문형이 있고 목적격
슬롯과 자유 서술형 주석이 없는 조합을 사용합니다. 표준국어대사전에서 목적격
문형이 확인되거나 다른 표제어가 같은 활용 어간에서 목적격을 받을 가능성이
있으면 그 어간을 제외합니다. 사용 시에는 compact component resource로 종결
분석을 확인합니다. [사전 문형 전수 점검](2026-11-13-verify-gold-predicate-frames.md)

생성기는 규칙 활용과 `하다`의 활용 어간을 제공합니다. 생성 범위 밖의 불규칙형과
사전에서 확인되지 않은 활용 어간에는 기존 구조 판정을 적용합니다.
문형 집계 30,935행에서 활용 어간 18,834개를 생성했습니다.

```sh
python3 tools/nikl-lexicon/audit_predicate_frames.py "$krdict_zip" \
  --stdict "$stdict_zip" --cache-dir "$cache" > "$frames"
cargo run --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml \
  --example predicate_frame_stems < "$frames" > "$anchors"
```

문형 집계 SHA-256은 `98c00ae30ff5239a76a43b0f037ba880ee23448ec529c5e5e95792d1a7c6b344`,
활용 어간 SHA-256은 `23eb62c2268a5c158c2b2e37d7ff045334891c34e7e387ad353fc6d481b2a662`입니다.
[사전 원본 체크섬](../../data/SOURCES.toml)

## 성능

작업 시작점 `70a5d2d4`, 기준선 `9029a070`, 후보 `16df13a8`을 Apple M1 Max,
macOS 26.6.2, rustc 1.97.0의 release 빌드로 비교했습니다. 입력마다 실행 순서를
순환하며 새 프로세스에서 워밍업 1회와 측정 5회를 실행했습니다. 값은 중앙값
[최솟값, 최댓값]이며 p95는 개별 사례 지연의 최근접 순위입니다. 이후 병합한
#500은 구의 `any` 경계에 적용됩니다. 이 측정의 단일 원자 `smart` 입력은
해당 분기를 실행하지 않습니다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
