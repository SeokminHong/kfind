# 앞말에 붙은 ASCII 큰따옴표의 조사 경계

`확인하면서"…유지해야한다"고`에서 첫 큰따옴표가 앞 어절에 붙어
인용 조사 `고`가 독립 명사로 검색됐다. 왼쪽 문맥에 줄 시작이 있으면
ASCII 큰따옴표를 같은 줄의 등장 순서대로 짝짓는다. 기존 왼쪽 문맥
상한인 256바이트 안에서 조사와 인용구를 확인한다.

## 품질

기준선 `f5f47261`과 후보 `6c735164`에서 고정 12세트 83,081행의
Smart·Any·Token 반환 범위 249,243개 결과를 비교했다. 입력에는 ASCII
큰따옴표가 있는 행 4,636개와 문자나 숫자에 붙은 여는 부호 후보 뒤에
큰따옴표가 다시 나타나는 행 1,484개가 있다. 전체 결과에서 달라진
범위는 `pud:w01117034:noun:고`의 Smart 오탐 하나다.

인용·괄호 회귀 25행에서 여는 부호가 붙은 인용절, 앞에 다른 인용구가
있는 인용절, 인용된 명사 뒤 조사, 인용절 내부 용언, 두 종류의
짝이 없는 여는 부호 뒤 성씨를 확인했다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1
순서다. 추가 회귀의 계약 검토는 0건, 고정 음성은 1,255건이다.
목표 집계 11세트의 Smart FNc는 0, FPc는 2,376건에서 2,375건으로 줄었다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 추가 회귀 6행 | Smart 기준선 | 3, 3, 0, 0 / 50.00, 100.00, 66.67 | 3, 3, 0, 0 / 50.00, 100.00, 66.67 |
| 추가 회귀 6행 | Smart 후보 | 3, 0, 3, 0 / 100.00, 100.00, 100.00 | 3, 0, 3, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3628, 49680, 0 / 0.00, —, 0.00 | 1255, 2373, 49680, 0 / 34.59, 100.00, 51.40 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3627, 49681, 0 / 0.00, —, 0.00 | 1255, 2372, 49681, 0 / 34.60, 100.00, 51.41 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 교대로
5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했다. p95는
최근접 순위로 구했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.474 [60.330, 61.025] | 30,714 [30,141, 30,848] | 0.07129 [0.07017, 0.07204] | 80.813 [80.750, 81.188] |
| 교정 GSD | 후보 | 61.150 [60.883, 61.499] | 30,690 [29,986, 30,851] | 0.07050 [0.07008, 0.07133] | 81.031 [80.875, 81.078] |
| 고정 음성 | 기준선 | 60.785 [60.265, 61.496] | 19,912 [19,553, 19,957] | 0.12525 [0.12508, 0.12858] | 127.375 [127.125, 127.641] |
| 고정 음성 | 후보 | 60.680 [60.495, 61.879] | 19,763 [19,461, 19,883] | 0.12662 [0.12558, 0.12921] | 127.500 [127.172, 127.688] |

교정 GSD의 처리량 중앙값은 −0.08%, p95는 −1.11%다. 고정 음성은
각각 −0.75%, +1.10%였다. 두 입력에서 처리량과 p95의 관측 범위는
겹친다.
