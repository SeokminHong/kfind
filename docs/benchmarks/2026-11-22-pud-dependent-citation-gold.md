# PUD 인용형 앞 의존 명사 거의 표적 범위

UD 2.18 GSD·PUD의 전체 test 토큰에서 독립 `거`와 `거라고·거라는·거라며·거라면·거라도`를
찾았다. GSD 세 위치는 기존 양성의 전체 범위와 일치했다. PUD는 6문장 7위치였다.
관형형 뒤 `거`는 의존 명사 `것`의 구어형이다.
[국립국어원 의존 명사 `거`와 띄어쓰기](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6618&mn_id=201&pageIndex=1)

| PUD 문장 | 원문에서 확인한 의존 명사 범위 |
| --- | --- |
| `n01005024` | `있을 거라고` 92..95 |
| `n01014003` | `있을 거라고` 166..169 |
| `n01070017` | `많을 거라고` 68..71 |
| `n01079015` | `보좌관일 거라는` 132..135 |
| `n01144038` | `일어날 거라고는` 131..134와 `못했을 거라고` 171..174 |
| `n02081019` | `작동할거라고`의 299..302. 원출처의 공백을 복원한 별도 입력은 300..303 |

첫 네 행은 음성 생성 과정에서 표제어 `_` 때문에 양성으로 인식되지 않았다.
`n01144038`에는 기존 양성 외에 두 번째 범위를 기록했다. `n02081019`의
원문 표적 앞 공백은 `ToDoOrigText`에 있다. 원본 평가는 보존하고 비표준
붙여쓰기를 계약 평가에서 제외했다. 복원 입력은 전체 표적 범위가 정확히
일치했다.

## 품질

`d30d2d78`의 Smart 반환에 두 등록부를 적용했다. 목표 11세트의 FNc는 0이고
FPc는 1,745→1,741이다. 제품 반환과 원본 행렬은 동일하다. 고정 음성의
`PNᶜ = TPᶜ + FNᶜ`는 1,403→1,407이다. 원본에는 양성 분모가 없다.

| 등록부 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 제외 |
| --- | --- | --- | ---: |
| 기준선 | 0, 3,232, 50,076, 0 / 0, —, 0 | 1,403, 1,745, 50,051, 0 / 44.57, 100, 61.66 | 109 |
| 검토 후 | 0, 3,232, 50,076, 0 / 0, —, 0 | 1,407, 1,741, 50,050, 0 / 44.70, 100, 61.78 | 110 |

교정 입력은 고정 음성과 원문을 `pud-dependent-spacing-cases.mjs`에 전달해
생성했다. 이 변경에는 제품 실행 코드나 사전 리소스 변경이 없어 기존 성능
기준선을 사용한다.
