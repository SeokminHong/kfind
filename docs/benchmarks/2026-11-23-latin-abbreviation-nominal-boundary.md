# 대문자 약어 뒤의 일반 명사 검색 범위

Smart 명사 `산업` 검색이 원문 GSD의 `MICE산업은`에서
첫 일치를 놓쳤다. 시사경제용어사전에는 이 용어가
붙여 쓰인 표기로 등재되어 있다. 한글 맞춤법 제50항은 전문 용어의
단어별 띄어쓰기와 붙여쓰기를 허용한다. 기존 복합 명사 판정에서
왼쪽 약어와 오른쪽의 사전에 확인된 일반 명사를 구분한다. 명사와
조사가 어절 끝까지 이어지면 조사까지 반환하고, 지정사 활용은
명사 범위에서 제외한다.
[시사경제용어사전 MICE산업](https://mofe.go.kr/sisa/dictionary/detail?idx=164)
· [한글 맞춤법 제50항](https://www.korean.go.kr/kornorms/regltn/regltnView.do)

어절 첫머리에서 대문자 라틴 문자 두 개 이상과 한글이 이어지는
표면을 찾았다. 원문 GSD 양성 9,335행, 고정 음성 53,308행, 등록
교정 GSD 양성 9,298행에서 서로 다른 표면은 각각 28개, 56개,
28개였다. 이 위치에서 명사 질의와 앞부분이 겹친 행은 각각
1개, 9개, 0개였다. 원문 한 행에서만 검색 결과가 달라졌다.
`산업은` [22, 31)이 복원됐고 `산업` [67, 73)은 유지됐다.
원문과 표준 표기의 657개 질의에서도 이 원문 한 행만 달라졌다.
띄어 쓴 대조문에서는 두 명사의 범위가 각각 나온다.
[원문과 띄어쓰기 대조](2026-11-23-raw-gsd-copula-source-spelling.md)

별도 질의 14개에서 기준선이 놓친 8범위를 확인했다.
`DNA검사에서` [3, 15), `GPU서버를` [16, 25), `AI반도체의`
[2, 14), `IT산업이다` [29, 35)가 포함된다. `MICE산업은 다른
산업에도 영향을 준다`는 [4, 13)과 [21, 33)을 반환했다.
한 음절 생략 후보와 식별자 내부 범위를 반환하지 않았으며
로마자 수의 `III세가` 범위는 유지됐다. CLI의 canonical 정규화로
같은 14개 질의의 NFD 원문 바이트 범위도 확인했다.

처리량·p95 중앙값은 고정 음성에서 −0.61%·+0.78%, 교정 GSD에서
−0.39%·+1.62%였다. 동일 기준선 반복에서는 각각 −1.01%·+1.33%,

관측된 변동과 재측정을 고려해 성능 회귀 판정은 유보한다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline" 5aa0a15a "$lexicon" "$component" "$predicates" \
  --candidate "$candidate" 0ffe07a5 "$lexicon" "$component" "$predicates"
```
