# 교정 GSD 양성의 원문 재현

[공개 UD 2.18 원문의 GSD 양성 9,335행](2026-11-22-reproduced-ud-audit-fixtures.md)에
기존 교정 단계를 적용해, [주제 보조사 검증에서 사용한 교정 입력](2026-11-22-topic-after-case.md)을
재현했다. 기존 교정 입력과 신규 출력 9,298행은 바이트 단위로 일치했다.

최초 검토에는 원문 문장 전체 5개와 개별 질의의 형태 또는 범위 검토 30행이
있다. 초기 중간 입력이 `a6955363dbf837f16b5ec4ef6465eabf8e6611df43c591a21588aa638efde129`와
일치한 뒤, 저장소의 교정 도구를 정해진 순서로 실행한다.

초기 범위 교정 33행은 리비전 `adcdaa1d`에서 쓰인 회귀 자료의 문장과 범위를
교정 등록부에 보존한다. 이후 회귀 fixture에 계약 검토 열이 추가되고 등록부가
가리키던 문장 다섯 건이 바뀌면서, 기존 교정 도구가 중간 입력을 재현할 수 없었다.
등록부에서 직접 읽도록 바꾼 결과 중간 입력
`d34735e79fad865a62685522859f2664e56d9f37330a1a11d17614aab82cda1e`도 일치했다.

최종 교정 양성의 SHA-256은
`cd3a8e532e67ba0748875311d10eba91c5fcb0d644e5c541bf3a4d22ac7c5a37`이다.
같은 입력을 사용한 기존 품질·성능 측정과 직접 비교할 수 있다.
