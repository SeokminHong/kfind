# 활용형에서 추정한 어간과 대명사 주제 조사

명시적 동사 `그다`가 대명사 `그`와 주제 조사 `는`을 현재 관형형으로
반환했다. MeCab의 `그/VV`는 `긋/VV`의 활용형과 같은 원본 분석이다.
같은 조건의 원본 42행을 제외해도 compact 리소스는 배포본과
37,103,633바이트 전체가 같았다. 별도 어간을 표시한 `Inflect` 행이
같은 품사와 범위로 압축됐기 때문이다. [표제어 검토 기록](2026-11-13-inflected-predicate-aliases.md)

명시 품사로 추정한 어간에 기존의 활용형 검토 근거가 있고, 같은 범위가
대명사와 주제 조사로 분석되면 Smart에서 생성 관형형과 구조 어미 경로를
함께 제외한다. 독립 용언·어미 분석 또는 사전의 독립 표제어가 있으면
일치를 유지한다. 전체 CLI 리소스로 `긋다`의 `그어`, `그었다`, `긋는`을
확인했고, `날다`의 `나는 새`와 사용자 사전에 동사로 등록한 표제어를
대조했다.

## 품질

고정 입력 12세트의 모드별 결과 249,243행 중 Smart 음성에서
`그는`의 잘못된 범위 61개가 제거됐다. 58행은 적중이 없어졌고
3행은 같은 문장의 다른 오탐을 반환한다. 새 반환 범위는 없다.
고정 평가 11세트의 Smart 계약 FN은 0건이며 초기 사전 입력
4,458행의 계약 FN 33건은 양쪽에서 같다.

고정 음성 53,308행에 기존 계약 검토 171건을 양쪽에 적용했다.
행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
양성 분모가 0인 원본 recall은 `—`로 표기한다.

| 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 4026, 49282, 0 / 0.00, —, 0.00 | 171, 3855, 49282, 0 / 4.25, 100.00, 8.15 |
| Smart | 후보 | 0, 3968, 49340, 0 / 0.00, —, 0.00 | 171, 3797, 49340, 0 / 4.31, 100.00, 8.26 |
| Any | 양쪽 | 0, 17622, 35686, 0 / 0.00, —, 0.00 | 171, 17451, 35686, 0 / 0.97, 100.00, 1.92 |
| Token | 양쪽 | 0, 2864, 50444, 0 / 0.00, —, 0.00 | 120, 2744, 50393, 51 / 4.19, 70.18, 7.91 |

## 성능

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
기준선 `4932e8e6`과 후보 `073839d0`을 비교했다. 기준선은 해당 머지의
런타임 소스와 동일한 `97795f58` 빌드다. 같은 입력·리소스로 새 프로세스
워밍업 1회, 측정 5회를 실행 순서를 교대하며 수행했다. 표는 중앙값
[최솟값, 최댓값]이며 p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD Smart | 기준선 | 61.095 [60.730, 61.150] | 31,160 [29,692, 31,201] | 0.07050 [0.07000, 0.07467] | 80.922 [80.922, 81.375] |
| 교정 GSD Smart | 후보 | 60.997 [60.764, 61.070] | 30,974 [30,716, 31,191] | 0.07083 [0.07050, 0.07158] | 80.922 [80.844, 80.953] |
