# 붙여 쓴 체언 구의 조사 경계

앞 체언의 조사 후보가 다음 체언의 시작과 겹치면 `any` 구 검색에서 조사 없는
범위도 유지합니다. `예금이자를`의 `예금`과 `이자를`, `상대성이론`의
`상대성`과 `이론`이 이어집니다. `예금이 이자를`의 실제 주격 조사는 유지됩니다.
일반 구와 괄호로 묶은 선택 구에서 각 원자의 UTF-8 범위를 검사했습니다.
[회귀 테스트](../../crates/kfind-matcher/tests/query_plan.rs) ·
[#496](https://github.com/SeokminHong/kfind/issues/496)

붙여쓰기가 허용된 명사 구성 18개에 띄어 쓴 구, 붙여 쓴 구, 붙여 쓴 단일
질의의 세 조합과 조사·선택 구 대조 4건을 적용했습니다. 아래 표는 구의 반환
여부를 평가하며, 행렬은 TP, FP, TN, FN 순서이고 비율은 precision, recall, F1
순서입니다. 계약 검토는 0건입니다.
[입력 58건](../../tools/morph-compare/nominal-phrase-spacing-cases.jsonl)

| 경계 | 리비전 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |

붙여 쓴 명사 18개에서 띄어 쓴 질의의 `any` 일치는 16→18건입니다.
`smart`의 `상대성이론` 내부 명사 판정은 미해결입니다.
사전 양성 4,458건과 GSD 양성 9,314건의 두 경계, GSD·PUD 음성
53,308건의 `smart` 반환 범위는 동일했습니다.
