# 예스러운 높임 연결형 사·으사의 검색 범위

고정 사전의 `사/으사` 용례 2건을 전수 비교했다. `염려하사`,
`깊으사`와 ㄹ이 탈락하는 `만드사`를 검사했다. 첫 후보에서 명사,
고유명사와 파생어 내부 6건이 음성 입력에서 반환됐다. 어미 오른쪽
경계와 명사의 결합을 검사한 뒤 전체 음성 입력을 다시 비교했다.
[표준국어대사전 -사](https://stdict.korean.go.kr/search/contentViewOne.do?word_no=164765) ·
[표준국어대사전 -으사](https://stdict.korean.go.kr/search/contentViewOne.do?word_no=256679)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
관련 어미의 계약 검토는 0건이고 전체 사전은 [앞선 계약 보정](2026-11-14-formal-siap.md#품질)을 유지했다.

GSD 9,298건, 음성 53,308건과 KAIST dev/test 2,532/2,592건의 반환 범위는
기준선과 같다. Raw·계약 보정 지표는 [앞선 보고서](2026-11-14-prefinal-coordinate.md#품질)와 같다.
Any에서 `드사이다`의 짧은 범위도 추가됐다. 전체 청유형은 사전 누락으로 남는다.

## 성능

시작점 `70a5d2d4`, 기준선 `4910f25b`, 후보 `2e79c30c`를 비교했다.
기준선의 런타임 소스·형태 리소스는 측정 빌드 `ff9cedc9`와 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다.
p95는 최근접 순위이고 RSS는 최대 상주 메모리다.
