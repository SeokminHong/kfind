# 지정사 높임 관형형 이신의 부착 경계

`이신 씨`와 독립된 `이신`은 앞 체언이 없으며, `선생님이신`과
`의사이신`은 체언에 붙은 지정사 관형형이다. 종결된 높임 관형형
경로에서 어절 안의 부착을 검사하고 양쪽 경계에서 대조했다.

## 품질

사전 4,458건, GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과
test 2,592건의 반환 범위가 모두 기준선과 일치했다.
[Raw·계약 보정 지표](2026-11-15-fused-copula-ngeol.md#품질)

## 성능

시작점 `70a5d2d4`, 기준선 `14c0ed56`, 후보 `b06096c8`을 비교했다.
기준선과 후보의 측정 빌드 `35377b5c`, `b9a4c503`은 각각 파일 트리가 동일하다.

full POS Smart로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
