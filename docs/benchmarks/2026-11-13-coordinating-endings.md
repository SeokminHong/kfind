# 대조와 선택 연결 어미

같은 활용 경로에서 `-지만`, `-거나`, `-(으)나`를 기본형, 높임형,
시제 선어말 어미와 결합한 형태에 적용했습니다. `이뤄지거나`와
`다뤄지지만`은 보조 용언까지 소비합니다.
[국립국어원 -지만](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=78638) ·
[-거나](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=66346) ·
[-나](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=80176) ·
[-으나](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=80160)

기준선은 `66e3ea5e7f0c2cf4b82a24c99772341cf5a4fd90`, 후보는
`fedf6439bdfef7cd0a78e8041e429cc989254901`입니다. 기준선 이후 main의 변경은
GSD 회귀 자료와 보고서에만 해당합니다. 리베이스한 후보 `6c532c92aeb06829c523a16b2ebabeba37a4654f`와
측정 후보의 코드와 실행 리소스는 동일합니다.

회귀와 GSD 양성은 정확한 범위, KAIST는 겹침, 일반 음성은 반환 여부로 채점했습니다.
GSD 정확한 범위는 16건 늘었고 KAIST dev와 test에서도 1건씩 늘었습니다.
명사 뒤의 `이지만/이거나`가 지정사 활용으로 확인된 6행은 명사 성분까지만 반환합니다.
일반 음성에서 반환 유무가 바뀐 행은 0건입니다.

행렬 순서는 TP, FP, TN, FN이며 비율은 precision, recall, F1입니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Darwin 25.6.0, Rust·Cargo 1.97.0에서
같은 release 설정과 리소스를 사용했습니다. 입력별로 새 프로세스에서 warm-up 1회 뒤
5회 측정했고 실행 순서는 교대했습니다. 처리량은 평가 시간, p95는 nearest-rank,
RSS는 `/usr/bin/time -l`의 최대 상주 메모리입니다. 중앙값 [최솟값, 최댓값]을 표기합니다.

| GSD 교정 양성 | 후보 | 60.226 [59.856, 62.142] | 30750 [29139, 31038] | 0.0739 [0.0721, 0.0756] | 79.031 [78.984, 79.219] |

양성 처리량은 0.73% 줄고 p95는 2.64% 늘었습니다. 음성 처리량은 0.69% 줄고
p95는 1.14% 늘었습니다.

```sh

KFIND_COMPONENT_RESOURCE="$component_resource" \

  /usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
