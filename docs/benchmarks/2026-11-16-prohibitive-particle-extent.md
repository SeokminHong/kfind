# 금지 보조 동사 앞 보조사의 반환 범위

`떠들지도 마시고`와 `떠들지도 마시라고`에서 `떠들다`의 반환 범위에
보조사 `도`를 포함한다. 금지 동사의 명령형, 높임 활용과 사전에 등록된
준말을 함께 검증한다. 어미가 없는 어간이나 같은 표면으로 시작하는 명사
`마시멜로`는 후행 보조 용언으로 승인하지 않는다.
[국립국어원 금지 보조 동사의 활용](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=313136)

## 품질

`2716b68c`와 `e1824441`을 고정 입력 12종의 세 모드에서 비교했다.
249,243개 반환 결과의 행 ID, 리소스 해시, 전체 UTF-8 범위가 일치한다.
고정 평가 11세트의 Smart 계약 FN은 0건, 고정 음성 53,308행의
Smart 원본 FP와 계약 FP는 각각 3,867건과 3,040건이다.

새 회귀 2행의 기대 범위는 둘 다 0..12다. Smart와 Any는 기준선에서
0..9를 반환했고 Token은 적중하지 않았다. 후보에서는 세 모드 모두
0..12를 반환했다. 이 회귀에는 계약 검토 0건을 적용한다.
행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.

| 버전 | 모드 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 기준선 | Smart, Any, Token 각각 | 0, 0, 0, 2 / —, 0.00, 0.00 | 0, 0, 0, 2 / —, 0.00, 0.00 |
| 후보 | Smart, Any, Token 각각 | 2, 0, 0, 0 / 100.00, 100.00, 100.00 | 2, 0, 0, 0 / 100.00, 100.00, 100.00 |

기존 `마/마요/마라/마세요/마십시오`, 비축약형 `말아라`, 새 높임 활용
2종과 불완전·명사 대조 3종을 보조 동사와 보조 형용사 품사에서 검사했다.

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0의 release 빌드를
사용했다. [실행 명령과 체크섬](2026-11-16-auxiliary-competition.md#재현)에
기록한 교정 GSD·고정 음성 입력과 사전 리소스를 사용했다.
