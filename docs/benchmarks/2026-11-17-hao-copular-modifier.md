# 부사 수식이 드러나는 지정사 관형형과 인용구

`국수주의가 갖는 매우 개인적인 성향`에서 `개인적+인`과
`갖는`은 뒤의 `성향`을 수식한다. 명사 파생 경로까지 확인한 뒤
지정사의 관형형을 인정한다. `끈을 매우 공적인 용도로`에서는
동사 뒤에 덧붙인 부사격 성분이 성립한다.
[국립국어원 지정사 관형형과 관형사](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=316184)

`"매우 합리적"이라고`에서는 짝이 맞는 따옴표 안의 두 어절을
하나의 인용 대상으로 확인하고 `-적`의 명사 파생 경로를 검증한다.
`"끈을 매우."라고`의 종결형은 범위 전체를 반환한다.
[한국어기초사전 -적](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=88966)
· [국립국어원 인용 조사 라고·이라고](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=27&pageIndex=1&qna_seq=335358)

## 품질

기준선의 Smart 잔여 용언 반환 중 `우`로 끝나는 범위는 두 개다.
두 문장에서 `매우`, `매다`, `맵다`를 각각 질의했다.
별도 대조는 파생 어휘를 바꾼 관형형과 인용, 실제 하오체 인용과
후치를 포함한다. 대조를 포함한 39개 질의에서 양성 13개가 유지됐다.
실제 하오체를 부사로 반환하던 별도 대조 6건은 남는다.

고정 12세트 83,081행을 세 모드로 실행해 반환 목록 249,243개를
비교했다. 아래 Smart 오탐만 사라졌다.

| 원문 ID | 질의 | 제거한 UTF-8 바이트 범위 |
| --- | --- | --- |
| `pud:n01029006` | `v:매다` | 78..84 |
| `pud:w01134078` | `v:매다` | 59..65 |

목표 11세트 FNc 0, FPc 1,799→1,797이다. 기존 계약 검토를
양쪽에 동일하게 적용했다. 행렬은 TP, FP, TN, FN 순서이고 비율은
precision, recall, F1 순서다. 고정 음성 원본의 recall은 양성 분모가
없어 정의되지 않는다. 대조의 계약 검토는 0건이다.

| --- | --- | --- | --- |
| 고정 음성 | 기준선 | 0, 3265, 50043, 0 / 0, —, 0 | 1387, 1795, 50018, 0 / 43.59, 100, 60.71 |
| 고정 음성 | 후보 | 0, 3263, 50045, 0 / 0, —, 0 | 1387, 1793, 50020, 0 / 43.62, 100, 60.74 |
| 교정 GSD | 양쪽 | 9296, 0, 0, 2 / 100, 99.98, 99.99 | 9292, 4, 2, 0 / 99.96, 100, 99.98 |
| 원문과 대조 39질의 | 기준선 | 13, 12, 14, 0 / 52.00, 100, 68.42 | 13, 12, 14, 0 / 52.00, 100, 68.42 |
| 원문과 대조 39질의 | 후보 | 13, 6, 20, 0 / 68.42, 100, 81.25 | 13, 6, 20, 0 / 68.42, 100, 81.25 |

CLI canonical의 NFC와 NFD에서 부사와 동사의 반환 범위를 비교했다.
`맵다`의 NFD 조건형은 양쪽에서 16..37을 반환하며
기존 구조 검증 미완료 진단이 함께 출력됐다. Workspace, Clippy, gold
형태 사례 925건과 walk/hang stress를 검사했다.

## 성능

기준선 `ffd752ac`와 후보 코드 `9a1f502d`를 Apple M1 Max arm64,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Node.js 26.11.1에서
같은 release 설정으로 빌드했다. `/usr/bin/time -l RUNNER boundary
full-pos smart INPUT OUTPUT`을 새 프로세스에서 입력별 워밍업
1회 뒤 두 버전을 번갈아 각 5회 실행했다. 중앙값 [최솟값, 최댓값]이다.
