# 대조·선택 연결 어미 내부의 나

동사 `나다` 검색에서 `겪었으나`, `있으나`, `낮추거나`,
`되거나`의 마지막 `나`가 독립 용언으로 반환됐다.
후보는 앞 용언과 연결 어미가 어절을 완성하면 그 내부 후보를 제외한다.
`김이 나`, `연기가 나거나`, `피해가 났으나`의 독립 동사와 어미는
정확한 범위로 반환한다.
[한국어기초사전 -으나](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=80160&nation=eng) ·
[한국어기초사전 -거나](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=66346)

고정 음성의 동사 `나다` 질의 193행에서 `으나`·`거나`로 끝나는
어절 다섯 곳을 확인했다. 원문 네 곳과 교정문 다섯 곳에서 오탐이
재현됐다. 교정문에는 `살아 있거나`의 공백을 복원한 GSD 한 행을
포함했다. 모든 교정문을 같은 기준선과 후보에서 실행했다.
교정문 GSD s270·s366의 다른 위치에서 반환된 `나`·`난`·`날`은
별도 범위로 남았다.

## 네이티브 형태 판정

`ea2fdcf6`와 `3f15dd8f`의 release runner를 같은 Cargo target에서
빌드했다. 두 입력, 기기, 명령과 도구는
[피동 접미사 비교](2026-11-23-derived-passive-doeda.md)와 같다.
두 실행은 SHA-256
`f102271da21d561fa2d4073c5ac130a027bfe8ef7c5c72716b12699acc14872d`인
component와 동일한 full POS·보강 용언을 사용했다. 각 실행군에서 새 프로세스로
워밍업 1회와 교대 측정 5회를 실행했다. 표는 재측정의
중앙값 [최솟값, 최댓값]이다.

첫 측정에서 고정 음성 처리량이 3.46% 낮고 p95가 3.29% 높아 재측정했다.
기준선을 다시 빌드한 결과 SHA-256이 이전 파일과 같았다. 재측정에서 고정
음성 처리량은 0.03% 높고 p95는 0.24% 낮았다. 교정 GSD 처리량은
0.13% 높고 p95는 0.28% 높았다. 재측정에서 초기화와 RSS를 포함한 각
지표의 범위가 겹쳤고 첫 측정의 고정 음성 저하는 재현되지 않았다.
