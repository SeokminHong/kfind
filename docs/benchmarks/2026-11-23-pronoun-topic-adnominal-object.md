# 주격 성분과 목적어 사이 관형형의 반환 범위

`파열음이 나는 선거 분위기를 감지할 수 있었다`에서 `나는`은
`선거 분위기`를 수식하는 관형형이다. Smart는 앞의 주격
성분, 용언 관형형, 목적격 명사구와 그 목적어를 받는 서술어를
확인한다. 단일 용언과 진행, 가능성의 완결 서술을 대조했다.
인용이나 시간절에 따로 쓰인 `나는`과 한 문장에 있는 다른
대명사 범위는 보존했다.

## 원문·교정문과 품질

PUD n01058064 11번 `나는`은 `VV` 관형형이다. 원문의
`교차하고갈등의`와 `감지할수`에 `ToDoOrigText`의 공백을 복원했다.
고정 질의 96건의 원문·교정문 비교에서 교정문의 명사·대명사
`나` 오반환 [108, 114) 두 건이 사라졌다. `나다`는 같은 범위를
유지했다. 원문의 붙여 쓴 가능성 구성에서는 두 오반환 [107, 113)이
남는다.
[PUD n01058064](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L3443)

GSD s401의 `느낌이 나는 무늬를 쓰는 것도`는 별도의 명사절을
포함한다. 원문과 `자리 잡고`로 띄어 쓴 교정문에서 `나` 반환
[103, 109)가 남는다. 대조 입력 75개에 이 문장, 같은 문장에
실제 대명사도 있는 예문과 인용·시간절의 대조를 포함했다.
고정 회귀 12행은 리소스 장착 Smart·Any와 기본 Token의
NFC·NFD에서 빌드당 72개 조합을 확인했다.

원문·교정문 고정 질의와 대조 질의의 SHA-256은 각각
`562b8cce5fb0d03724096e0a0c2c77d0cf86ee563daa98e98e3737289a6e5ec1`,
`1b4c3cfc879b204ba8be42340271991f2ff8609a3f2a582339aa`다.
역사 입력 258,541개 조합과 다음 고정 입력에서 반환 범위는
양쪽이 같았다. 행렬은 TP, FP, TN, FN 순서이며 정밀도,
재현율, F1의 단위는 %다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 양쪽 | 0, 3,035, 50,273, 0 / 0, 0, 0 | 1,430, 1,491, 50,239, 0 / 48.96, 100, 65.73 | 1,493 | 0 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 592 / 99.93, 93.60, 96.66 | 13 | 592 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

미판정 추가 반환은 원문 GSD 553행 613범위, 교정 GSD 104행
110범위다. 고정 음성 계약 양성 1,207행의 전체 정답과 제외
42행의 37범위도 검토가 남아 있다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0,
Python 3.14.8에서 `386ccbad`와 `89fda3af`의 release 빌드를
비교했다. 새 프로세스로 빌드별 워밍업 1회 뒤 순서를 교대해
5회 측정했다. 각 실행에서 p95를 최근접 순위로 계산했다.
