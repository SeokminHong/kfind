# 감탄·권유 종결형 구나·구려·구먼

고정 사전 예문 4,458행에서 표제 어미가 `구나/구려/구먼`으로 끝나는
77행을 전수 검사했다. 지정사 자체를 질의한 여섯 행은 앞 체언을
제외한 지정사 시작점으로 정렬했다. 장사가 순조롭게 진행된다는
`잘되더구나` 한 행은 표제어 `잘되다`에 정렬했다. 원본 입력도 동일하게
실행해 두 평가의 차이를 보존했다.
[국립국어원 구나·는구나](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=325240) ·
[한국어기초사전 구려](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=73809&nation=eng) ·
[는구려](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=79406&nation=eng) ·
[장사가 잘되는 용례](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=76568)

높임·전망·선어말 어미 연쇄, 지정사와 체언의 경계, 동사의 현재
감탄형과 권유형을 검사한다. 동작 용언과 지정사, 받침 있는 체언의
지정사 생략, 명사와 보조사 결합을 대조했다. 골드 검증은 전체
925건과 stress 입력을 통과했다.

행렬은 TP, FP, TN, FN, 비율(%)은 precision, recall, F1 순서다.
계약 검토는 고정 음성 3건, KAIST dev 6건(제외 2건), test 25건
(제외 4건)이다. 다른 입력은 검토 0건으로 raw와 계약 보정이 동일하다.
