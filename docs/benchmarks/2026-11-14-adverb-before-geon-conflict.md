# 건으로 끝나는 부사의 검색

어절 전체에 부사 분석이 있고, 명사 분석과 축약 연결 어미 `-건` 분석이
경합할 때 앞 관형어가 명사 해석을 지지하지 않으면 부사 분석을 보존한다.
`무조건 쉬세요`와 `무조건 내복을 입으세요`에서 부사를 반환하고,
`그 무조건 항복 요구를 거부했다`에서는 명사 분석을 유지했다.
GSD에서 질의 표면형이 `건`으로 끝나는 7행(사건 3, 건 2, 보건 1,
무조건 1)을 검토해 `무조건` 1행의 정확 범위를 회복했다.
음성 53,308행의 반환 범위는 모두 같았다.

기준선 ed851664와 후보 f6162067의 full POS `smart`를 비교했다.
양성은 정확 범위, 음성은 반환 여부를 채점했다. 행렬 순서는 TP, FP,
TN, FN이다. 양성 검토는 0건이며 음성에는 기존 검토 3건을 적용했다.

| 입력 | 버전 | Raw 행렬 | Raw P/R/F1 (%) | 계약 보정 행렬 | 보정 P/R/F1 (%) |
| --- | --- | --- | --- | --- | --- |
| 양성 | 기준선 | 9289, 0, 0, 11 | 100.00, 99.88, 99.94 | 9289, 0, 0, 11 | 100.00, 99.88, 99.94 |
| 양성 | 후보 | 9290, 0, 0, 10 | 100.00, 99.89, 99.95 | 9290, 0, 0, 10 | 100.00, 99.89, 99.95 |
| 음성 | 양쪽 | 0, 4092, 49216, 0 | 0.00, 0.00, 0.00 | 3, 4089, 49216, 0 | 0.07, 100.00, 0.15 |

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 같은 release
설정, 입력과 사전 리소스를 사용했다. 시작점 70a5d2d4, 기준선, 후보를
워밍업 1회 뒤 새 프로세스로 5회씩 측정했다. 버전 실행 순서는 교대했다.
p95는 nearest-rank이며 RSS는 최대 상주 메모리다. 표는 중앙값 [최솟값,
최댓값]이다.

기준선 대비 양성·음성 처리량은 각각 +0.96%, +1.19%이고 p95는
−0.40%, −2.73%다. 초기화는 −0.06%, +0.32%, RSS는 −0.08%,
+0.14%다. 시작점 대비 처리량은 +8.48%, +10.19%이며 양성 p95는
12.99% 줄었고 음성 p95는 12.89% 늘었다.
