# 축약 연결형 해와 동형 명사

`해주세요` 등 다섯 표면형은 사전의 보조 동사·어미 연쇄를 갖지만
`해주` 또는 `해주시`로 시작하는 명사 분석도 갖습니다. 목적을 나타내는
앞 연결절, 문장 끝의 부사어·목적격 성분, 관형형 앞의 주격·부사격 성분과
뒤 명사를 확인합니다. `해주시는 올해 예산을 늘렸다`를 대조했습니다.

GSD 양성 9,314행에서 어절 첫머리의 `해`와 `주/줘/줬/준/줄/줌/줍`
결합을 검색했습니다. 8개 문장 89행에 해당 표기가 있었고 `하다` 동사
표적 8행을 모두 대조했습니다. 다섯 행이 정확 일치로 바뀌었으며,
같은 문장의 다른 표적 두 행에도 적법한 반환 위치가 추가됐습니다.
사전 양성 4,458행과 PUD 양성 798행에는 해당 표기가 없었습니다.
사전 양성과 GSD·PUD 음성 53,308행의 반환 범위가 같았습니다.
신규 회귀 4건을 통과했고 기존 `verify-gold` 불일치는 8건입니다.

행렬은 TP, FP, TN, FN 순서입니다. 비율은 precision, recall, F1이며
양성 검토는 0건, 음성에는 기존 판정 27건을 적용했습니다.
