# 완료 보조 용언의 명사형

동작 용언의 `-아/어` 뒤에 한 어절로 이어지는 완료 보조 용언
`내다`의 `-기/-ㅁ` 명사형을 어절 끝까지 검색한다. `만들어내기`와
`그려냄`, 띄어 쓴 `만들어 내기`, 별개 단어가 이어진 `만들어 내일`을
대조했다.

## 품질

[기존 12개 입력](2026-11-15-corpus-source-alignment.md)의 세 모드
249,243행을 ID·리소스 해시·반환 바이트 범위로 대조했다. 바뀐 결과는
PUD 양성 `w01133014:13` 한 행의 Any와 Token이다. 본용언 `만들어`의
원본 바이트 범위는 `108..117`이며, 원문에서 바로 이어지는 `내기`는
`AUX/VX`다. Token은 기존에 반환이 없었고 Any는 본용언까지만 반환했다.
후보는 두 모드에서 `108..123`의 `만들어내기`를 반환한다. Smart는
기준선부터 이 범위를 반환했다. 고정 음성 53,308행의 반환은 세 모드에서
모두 유지됐다.

PUD 양성 798행에 원본 범위와
[CoNLL-U 제품 범위 검토 6건](2026-11-15-untagged-and-pud-contract-audit.md#pud-정확-범위)을
적용했다. 제품 범위는 붙여 쓴 보조 용언까지 포함한 어절의 끝이다.
TP, FP, TN, FN 순으로 표기하며 비율(%)은 precision, recall, F1 순이다.

| 모드 | 코드 | 원본 행렬 / 비율 (%) | 제품 범위 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 양쪽 | 792, 0, 0, 6 / 100.00, 99.25, 99.62 | 798, 0, 0, 0 / 100.00, 100.00, 100.00 |
| Any | 기준선 | 795, 0, 0, 3 / 100.00, 99.62, 99.81 | 795, 0, 0, 3 / 100.00, 99.62, 99.81 |
| Any | 후보 | 794, 0, 0, 4 / 100.00, 99.50, 99.75 | 796, 0, 0, 2 / 100.00, 99.75, 99.87 |
| Token | 기준선 | 744, 0, 0, 54 / 100.00, 93.23, 96.50 | 747, 0, 0, 51 / 100.00, 93.61, 96.70 |
| Token | 후보 | 744, 0, 0, 54 / 100.00, 93.23, 96.50 | 748, 0, 0, 50 / 100.00, 93.73, 96.77 |

Token에서 남은 50행 중 48행은 정답 왼쪽에 문자가 붙어 있어 Token 경계가
성립하지 않는다. 나머지 두 행은 붙여 쓴 `되어준다`와 `타버렸고`다.
고정 음성의 원본과 계약 수치는
[앞선 보고서](2026-11-15-corpus-source-alignment.md#검색-결과)와 동일하다.

골드 925건과 walk/hang, workspace 테스트 636건, 포맷과 Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release,
Full POS에서 기준선 `56bc2fd0`과 후보 `5601104b`을 비교했다.
실행 파일은 두 revision과 제품 코드·리소스가 각각 같은 `a38389e6`,
`b3d63744`에서 빌드했다. 워밍업 1회 뒤 새 프로세스로 5회씩 실행하고
순서를 교대했다. 표는 중앙값 [최솟값, 최댓값]이다. p95는 최근접 순위,
RSS는 최대 상주 메모리다.

PUD Any·Token·Smart와 고정 음성 Smart 순으로 처리량 중앙값은
−1.14%, −1.54%, −1.03%, +1.39%이며 p95는 +2.20%, +3.40%, −1.07%,
−2.47%다. 모두 처리량과 p95 범위가 각각 겹쳤다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name auxiliary-completion-nominalization -- \
  /usr/bin/time -l "$runner" boundary full-pos "$mode" "$input" "$output"
```
