# 결과 상태 명령형 거라의 검색 범위

결과 상태를 유지하라는 명령 `서 있거라`와 `물러 있거라`의
축약형 `섰거라`, `물렀거라`에서 어절 끝까지 반환한다. 두 축약형과
띄어 쓴 `서 있거라`를 대조했다. 축약형의 통시 분석과 현대 분석은
자료에 따라 다르며, 두 자료에서 모두 확인되는 어간을 적용 범위로 삼았다.
[국립국어연구원 새국어생활](https://m.korean.go.kr/nkview/nknews/200102/31_4.htm) ·
[국립국어원 온라인가나다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=327283)

## 품질

고정 사전의 표제 어미 `거라` 예문 9건을 전수 비교했다. Any에서
`거라:8`은 12..15에서 12..21, `거라:9`는 35..41에서 35..47로
바뀌었다. 이 9건의 계약 보정은 0건이다. 전체 사전은
[기존 계약 보정](2026-11-15-dictionary-gajyeodajuda-review.md#재현)을 적용했다.
행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.

| 입력 | 경계 | 버전 | Raw 행렬 / 비율 (%) | 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- | --- |
| 거라 9건 | Smart | 양쪽 | 9, 0, 0, 0 / 100.00, 100.00, 100.00 | 9, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 거라 9건 | Any | 기준선 | 7, 0, 0, 2 / 100.00, 77.78, 87.50 | 7, 0, 0, 2 / 100.00, 77.78, 87.50 |
| 거라 9건 | Any | 후보 | 9, 0, 0, 0 / 100.00, 100.00, 100.00 | 9, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | Smart | 양쪽 | 4387, 0, 0, 71 / 100.00, 98.41, 99.20 | 4458, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | Any | 기준선 | 4296, 0, 0, 162 / 100.00, 96.37, 98.15 | 4371, 0, 0, 87 / 100.00, 98.05, 99.01 |
| 사전 4,458건 | Any | 후보 | 4298, 0, 0, 160 / 100.00, 96.41, 98.17 | 4373, 0, 0, 85 / 100.00, 98.09, 99.04 |

Any의 계약 보정 후 불일치 85건은 지정사 `이다` 질의 83건과
`웃기담`, `좋을거나`다. 지정사 83건은 정답 위치의 체언에서 지정사
어간이 생략되거나 받침으로 융합된 경우다. `웃기담`과 `좋을거나`는
사전의 예문과 품사별 결합 설명이 달라 Any 생성 조건을 유지했다.

## 성능

시작점 `70a5d2d4`, 기준선 `dd639f7c`, 후보 `f321ec13`을 비교했다.
기준선에 적용된 후속 사전 보정은 실행 코드를 바꾸지 않는다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release,
full POS Smart에서 버전 순서를 순환했다. 워밍업 1회 후 새 프로세스로
5회씩 실행했다. 값은 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위,
RSS는 최대 상주 메모리다.
