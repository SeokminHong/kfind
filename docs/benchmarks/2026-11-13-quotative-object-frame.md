## 성능

Apple M1 Max arm64, macOS 26.6.2, Darwin 25.6.0, Rust와 Cargo 1.97.0에서
full-POS release runner를 사용했습니다. fresh process로 warm-up 1회 뒤 5회
측정하고 실행 순서를 교대했습니다. 첫 측정의 GSD 초기화가 최대 159.418 ms까지
늘어 같은 조건에서 양쪽을 다시 측정했습니다. 표는 재측정의 중앙값 [최솟값, 최댓값]이며
p95는 nearest-rank로 산출했습니다.
