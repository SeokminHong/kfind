# 표준국어대사전의 대- 결합 명사

표준국어대사전의 직접 구성 성분 표기를 사용해 `대학교`, `대법원`,
`대용량` 같은 명사의 첫 성분을 접두사로 판정한다. 고정 사전에서
붙여 쓴 동형 표제어가 모두 `대-`로 분절되는 `大`·`對` 계열 명사
429개를 추출했다. `대프랑스`는 사전의 `대프랑스 동맹`과 접두사
`대-(對)`에 근거한다. `대나무`의 명사 성분과 `차 두 대가`의 단위 명사는
고정 회귀에서 바이트 범위를 확인했다.
[표준국어대사전 붙임표 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?qna_seq=335713) ·
[표준국어대사전 대-(對)](https://stdict.korean.go.kr/search/searchView.do?word_no=79514) ·
[표준국어대사전 대프랑스 동맹](https://stdict.korean.go.kr/search/searchView.do?word_no=412086)

UD 2.18 GSD·PUD test에서 어절 첫머리가 확인된 결합 명사인
표면 20곳을 검토했다. 명사 `대` 질의의 오반환 14곳이 NFC·NFD에서
같이 제거됐다. 사전 목록 전체의 기본형·주격 결합형·지정사 결합형
1,287개에서 기준선이 반환한 첫 성분 1,197곳을 제거했다.
`대지구대` 계열에 남은 마지막 음절 3곳은 별도의 접미사 판정 대상이다.

고정 12세트의 Smart·Token·Any 반환 목록 249,243개 중 Smart 음성
11건이 달라졌다. 교정 GSD 9,298행의 전체 반환 범위는 같았다.

## 네이티브 형태 판정

`82d130fb`와 `deb2b45e`의 release runner를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
비교했다. 고정 입력과 리소스 체크섬은
[앞선 비교](2026-11-22-pronoun-before-cause.md#네이티브-형태-판정)와 같다.
각 입력의 측정군별 새 프로세스로 워밍업 1회, 교대 측정 5회를 실행했다.
표의 값은 중앙값 [최솟값, 최댓값]이다.

사전 입력은 [추출 도구](../../tools/nikl-lexicon/README.md#어휘-항목-audit)의
TSV를 사전순으로 읽어 각 표제어의 기본형, 주격 결합형, 지정사 결합형을
이 순서로 작성한다. 1부터 시작하는 번호를 `stdict-prefix:`에 붙인 ID와
`query="대"`, `pos="noun"`, `expected=false`를 사용한다.
JSONL SHA-256은 `2117547f68e10f187c77167b1a2ab4d024873f3a20e8a965402660adcb24bcfe`다.
같은 명사 질의를 반복하므로 전체 형태 판정과 분리해 해석한다.
