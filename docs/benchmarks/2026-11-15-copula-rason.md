# 완성 체언 뒤 라손의 지정사 생략

`비겁자라손`의 지정사 어간은 생략됐다. 앞부분을 단일 사전 표제어로
확정하지 못해도 완성 체언 경로가 있으면 Smart에서 어절 전체를 검색한다.
`초보자라손`과 명령을 인용한 `가라손`을 함께 검증했다.
[국립국어원 라손 설명](https://www.korean.go.kr/nkview/nklife/2006_2/2006_0214.pdf)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
사전의 `라손` 예문 2건을 전수 대조했다. 추가 계약 보정은 0건이며,
전체 사전에는 [기존 보정](2026-11-15-copula-polite-honorific.md)을 적용했다.

후보의 측정 이후 회귀 문장만 수정했다.
