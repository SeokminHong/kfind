# GSD 의존 명사 앞의 띄어쓰기와 정답 범위

GSD 교정 내역에서 공백만 추가된 표기와 원문 명사 질의의 미검출
범위가 겹치는 후보 39행을 찾았다. 이 중 시간이 지난 정도의
`만`, 일이 발생하는 경우의 `시`, 진행을 뜻하는 `중`에 앞선
명사 다섯 행을 원문과 교정문에서 확인했다. 나머지 34행은
어휘 경계와 품사를 더 검토해야 한다.
[한글 맞춤법 제42항](https://www.korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0001)
· [국립국어원 얼마 만에](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=322213)
· [국립국어원 이용 시](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=321544)
· [국립국어원 회의 중](https://www.korean.go.kr/nkview/nknews/200002/19_11.htm)

s204:11의 원문에서도 `사고는` [45, 54)를 명사의 정답으로
남겼다. 검증용 출력에서 이 범위를 빼고 다른 범위 [55, 64)를
넣었을 때 FNc와 FPc가 각각 1 증가했다. 별도 동사 `사다`
질의는 원문과 교정문 양쪽에서 [45, 54), [82, 88)을 잘못
반환한다.

## 평가

Smart full-pos `f6234f01`의 같은 실행 결과를 두 계약 검토
버전으로 채점했다.
입력 SHA-256은 원문
`eaafbae7757dbb62c9a0ca6b370dadf0f41b53c3e3d044f21b191c2aab8e3682`,
등록 교정문
`5231c0e7c4d3c72de2982e0c38fc5420f01dcbecd764428e993b903e56dc8308`이다.
등록 교정문의 다섯 행은 전체 정답 범위와 일치했다.
행렬 순서는 TP, FP, TN, FN이며 정밀도·재현율·F1 단위는 %다.

```sh
"$runner" boundary full-pos smart "$input" "$output"
python3 tools/morph-compare/score-ud-audit.py --residual "$input" "$output"
```
