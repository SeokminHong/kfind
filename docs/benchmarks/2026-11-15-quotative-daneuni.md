# 진술·청유 나열형의 범위

평서형 뒤의 `느니`와 청유형 `자느니`를 같은 어절의 끝까지
소비한다. 모음·받침 동사, 형용사, 과거, 청유와 별도 어절을 검증했다.
[한국어기초사전 -ㄴ다느니](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=86069&nation=eng) ·
[표준국어대사전 -자느니](https://stdict.korean.go.kr/search/contentViewOne.do?word_no=474835)

## 품질

고정 사전의 `ㄴ다느니/는다느니/다느니/자느니` 예문 4건을 모두 비교했다.
이 어미에 대한 추가 계약 보정은 0건이다. 전체 사전은
[기존 보정 입력](2026-11-15-honorific-directive-report.md#재현)을 사용했다.
행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.
