# 부사 내부의 명사 오탐

Smart에서 명사 `시`를 질의하면 부사 `역시`의 마지막 음절이
반환됐다. 어절 전체에 접속 부사 분석이 있고 체언·수량 구조의 근거가
없을 때, 내부에서 시작하는 명사는 사전 성분 정렬과 조사 결합을
확인한다. 같은 문장의 시간 명사 `시`, `부산광역시`의 명사 성분,
`일일 이용권`의 수량 단위를 대조했다.
[한국어기초사전 역시](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=67372)

고정 음성에서 명사 `시`를 질의했고 `역시`를 포함한 원문 두 행을
모두 확인했다. 동일 문장이 두 ID로 배정되어 있으며 두 행의 [46, 49)가
사라졌다. GSD 양성의 `관세 철폐 시` [99, 102)는 그대로 반환됐고
`역시`의 원문 [167, 170), 교정문 [169, 172)가 제거됐다.
고정 12세트와 교정 GSD에서 비교한 반환 목록 258,541개 중
해당 네 출력이 달랐다. 원본 GSD 양성에서도 같은 표적의 한 범위가 바뀌었다.

## 네이티브 형태 판정

`5058e081`과 `852cae48`의 release runner를 같은 Cargo target에
빌드했다. 입력, 기기, 도구, 리소스와 교대 실행 명령은
[평서 어미 비교](2026-11-23-declarative-ending-overlap.md#네이티브-형태-판정)와 같다.
워밍업 1회와 교대 측정 5회를 서로 다른 프로세스에서 실행했다.
표는 고정 음성 최초 측정과 교정 GSD 재측정의 중앙값 [최솟값, 최댓값]이다.

고정 음성 처리량은 0.85% 높고 p95는 0.72% 낮았다. 교정 GSD 첫 측정은
처리량 3.31% 감소와 p95 1.49% 증가였고, 재측정은 처리량 2.35% 증가와
p95 1.32% 감소였다. 교정 GSD의 변화 방향이 일정하지 않아 회귀 판정을 유보했다.
