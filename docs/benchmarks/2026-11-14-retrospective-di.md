# 회상 의문 종결형 디의 검색 범위

사전의 `-디` 예문 9건을 점검했다. `사과하디`, `오셨디`, `해내겠디`는
어간과 선어말 어미 뒤에 붙은 종결형을 어절 끝까지 반환한다. `왔다. 디저트도`를
띄어쓰기 대조군으로 확인했다.
[표준국어대사전 -디](https://stdict.korean.go.kr/search/searchView.do?word_no=96198&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서다.
사전 계약 검토 0건으로 raw와 계약 보정이 같다.

| 표적 9건 | any | 기준선 | 0, 0, 0, 9 | 0.00, 0.00, 0.00 |
| 표적 9건 | smart·any | 후보 | 9, 0, 0, 0 | 100.00, 100.00, 100.00 |

고정 GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
검색 범위가 모두 일치했다. Raw·계약 보정 지표는
[고정 입력 보고서](2026-11-14-gu-exclamative.md)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `e0b9e335`의 검색 코드 `8828591f`,
후보 `37608865`와 제품 파일이 같은 `5b3a5bfa`를 비교했다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`를 사용했다. 워밍업 1회 후 새 프로세스로 5회씩 실행하고
버전 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다.
p95는 최근접 순위, RSS는 최대 상주 메모리다.
