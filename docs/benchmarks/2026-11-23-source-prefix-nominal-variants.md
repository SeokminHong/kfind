# 사전 접두사와 독립 명사 표제어

표준국어대사전의 `토-요일` 표기와 원어 `土曜日`은 기존 생성 조건에서
접두사 `토-(土)`와 일치했다. 그 접두사는 흙으로 된 것을 뜻한다.
독립 명사 `토04`의 요일 뜻풀이 406762는 `토요일`의 뜻풀이 364487을
직접 가리킨다. 한국어기초사전도 요일의 `토`와 `토요일`을 같은 뜻의
참고어로 연결하며 MeCab의 정렬된 성분은 `토/NNG+요일/NNG`다.
사전 생성 과정에서 이런 뜻풀이 참조와 원어가 일치하면 접두사 분절을
내지 않는다. 기존 생성 명사 5,641개와 접두사 표면 83개를 전부 대조해
`토요일` 한 행을 제거했다. 동일한 접두사 표면을 가진 나머지 31개는
명사 `토` 질의의 반환 목록이 두 리소스에서 같았다.
[한국어기초사전 토](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=90013)
· [한국어기초사전 토요일](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=30214)

원문 GSD와 PUD에서 `토요일`이 있는 세 문장을 찾았다. PUD n01092025는
원주석의 `ToDoOrigText`에 따라 `관련해서 토요일`, `제기하게 되었다`의
두 공백을 복원했다. 허용되는 `해주시는`은 원문 표기를 유지했다.
판정에는 기준선과 후보에서 각각 동일한 원문·교정문을 사용했다.

| 입력 | 정답의 UTF-8 범위 | 기준선에서 `토` | 후보에서 `토` |
| --- | --- | --- | --- |
| GSD s966 원문 | [7, 10) | 없음 | [7, 10) |
| PUD n01115005 원문 | [21, 24) | 없음 | [21, 24) |
| PUD n01092025 원문 | [19, 22) | [19, 22) | [19, 22) |
| PUD n01092025 교정문 | [20, 23) | 없음 | [20, 23) |

두 리소스에서 전체 명사 `토요일`의 반환 범위는 일치했다. n01092025의
전체 명사는 교정문 [20, 29)에서 반환됐다. 새 회귀 6행은 기존 리소스로
실패하고 후보 리소스로 통과했다. `토담을 쌓고 토요일에 쉰다.`의 `토`
반환은 [17, 20) 한 곳이다.
[GSD 원문](https://github.com/UniversalDependencies/UD_Korean-GSD/blob/r2.18/ko_gsd-ud-test.conllu)
· [PUD 원문](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/e942f9c5e9351f37bcb8f202bb9df70f78c60d35/ko_pud-ud-test.conllu)
· [정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

고정 12세트와 교정 GSD의 258,541개 반환 목록, 원문 GSD 양성 9,335행은
양쪽에서 일치했다. 세 입력의 [원본·계약 행렬](2026-11-23-coordinated-single-syllable-nouns.md)은 같다.
고정 평가에서 요일 `토` 추가 질의는 별도 회귀에 있다.

## 리소스와 네이티브 형태 판정

기준선 `828cb2ae`와 후보 `8c29293f`의 검색 코드는 같다. 기준선
component `f102271da21d561fa2d4073c5ac130a027bfe8ef7c5c72716b12699acc14872d`는
37,441,397바이트, 후보
`8f318f9f77d70d56bc4429901ee80b7b06f5e93ec2fca18873c8473acafd78a4`는
37,441,361바이트다. 기본 WASM에 추가하는 데이터는 0바이트다.
같은 release 러너에서 component만 바꿔 Apple M1 Max 32 GiB,
macOS 26.6.2 arm64, Rust·Cargo 1.97.0, Python 3.14.8로 측정했다.
워밍업 1회 뒤 새 프로세스에서 순서를 교대해 각 5회 실행했다.
