# 같은 단위를 세는 부분 집합의 수 관형사

`35,000명 중 한 명꼴로`에서 의존 명사 `중`은 전체 수량에서
일부를 고른다. 앞뒤의 단위가 일치하므로 `한`은 수 관형사다.
숫자를 앞 단위에 붙인 표기와 고유어 수 관형사를 띄운 표기를
검사한다. 뒤 단위에는 조사, 지정사 또는 비율 접미사 `-꼴`이
이어질 수 있다. `수업 중 한 말`과 `연습 두 회 중 한 말`에는
`하다`의 관형형이 남는다.
[한국어기초사전 중](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=79404)
· [국립국어원 비율 접미사 자료](https://www.korean.go.kr/common/download.do?c_file_name=f7222492-4580-40c6-864f-b66caeeeab3c_0.pdf&file_path=reportData)
· [한글 맞춤법 제43항](https://korean.go.kr/kornorms/regltn/regltnView.do)

고정 음성과 원본·등록 교정 GSD 양성에서 독립 어절 `중 한`을
검색했다. 고정 음성 342행의 고유 문장은 아홉 개다. 원본·등록
교정 양성은 각각 32행과 두 문장이었고, 두 문장은 고정 음성과
겹쳤다. 여섯 문장의 띄어쓰기를 다음과 같이 교정했고 고정 음성
342개 질의를 원문과 검토문 각각에 실행했다.

| 원문 ID | 교정한 표기 |
| --- | --- |
| `pud:n01012003` | `시작했고그 다음은` → `시작했고 그다음은` |
| `pud:n01051007` | `한 명 꼴로` → `한 명꼴로`, `발생하는가장` → `발생하는 가장` |
| `pud:n01053008` | `그 중` → `그중` |

| `pud:w01023120` | `인해종마` → `인해 종마` |
| `pud:n02066010` | `조사하는캐나다` → `조사하는 캐나다`, `착륙시킨것` → `착륙시킨 것` |

같은 원문과 교정문에 두 러너를 실행했을 때 `pud:n01051007`의
`하다` [34, 37)만 양쪽 입력에서 사라졌다. `한`의 관형사 범위
[34, 37)은 보존됐다. `악당들`과 `조사하는 캐나다`가 있는 두
문장의 오탐은 띄어쓰기 교정만으로 두 러너에서 사라졌다.
`그중 한 사람`과 `종마 중 한 마리`의 `하다` 오탐은 교정문에도
남았다. 원래 문장과 교정문은 별도로 집계했다.
[그중 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=332401)
· [그다음 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=311843)

별도 회귀에서 `두 권 중 한 권은`의 `한다` [43, 49),
`23회 중 한 회에만`의 `했다` [66, 72)와 `연습 두 회 중 한 말`의
관형형 [19, 22)을 확인했다. 앞 단위를 `3천 명`으로 띄운 문장에서도
수 관형사를 구별했다.

## 네이티브 형태 판정

Apple M1 Max 32 GiB, macOS 26.6.2 arm64, Rust·Cargo 1.97.0,
Python 3.14.8에서 기준선 `ae20c304`와 후보 `aef6d630`의 release
러너를 비교했다. 같은 사전 리소스와 고정 음성·등록 교정 GSD
입력을 사용했다. 각 러너를 한 번 가동한 뒤 교대 순서로 새 프로세스
5회를 측정했다. 초기화는 사전 로딩을 포함하고 p95는 각 실행의
최근접 순위다. 표는 중앙값 [최솟값, 최댓값]이다.
[입력·사전 체크섬](2026-11-23-person-suffix-component.md#네이티브-형태-판정)
