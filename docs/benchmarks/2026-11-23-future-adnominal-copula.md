# 명사 서술어 앞 미래 관형형의 반환 범위

`쓰레기 더미만 남을 정도였다`에서 `남을`은 `남다`의 미래
관형형으로 명사 `정도`를 수식한다. Smart는 같은 줄의 명사와
지정사가 종결 어미까지 완성되면 그 앞의 미래 관형형에서
목적격 후보를 제외한다. 지정사의 축약도 검증하며 목적어를 받을
수 있는 독립 동사 분석이 성립하면 목적격 후보를 유지한다.
[한국어기초사전 남다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=64552)
· [국립국어원 이었다와 였다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=306465)

## 원문·교정문과 품질

PUD w01039058 원문의 `발전하면서강의`, `악화돼하수와`를
띄어 쓴 대조문과 지정사 원형 `정도이었다`를 쓴 문장을
비교했다. 축약 `악화돼`는 유지했다. 세 문장의 37개 질의씩을
비교한 결과에서 `나다`와 명사 `남`의 오반환만 사라졌다.
원문의 `하다`가 반환하는 `하면` [22, 28)은 두 빌드 모두
원문 지표에 남고, 띄어 쓴 대조문 두 곳에서는 반환되지 않았다.

| 입력 | 사라진 두 오반환 | `남다` | `정도` | `이다` |
| --- | --- | --- | --- | --- |
| 원문 | [87, 93) | [87, 93) | [94, 100) | [100, 106) |
| 띄어 쓴 교정문 | [89, 95) | [89, 95) | [96, 102) | [102, 108) |
| 지정사 원형을 쓴 교정문 | [89, 95) | [89, 95) | [96, 102) | [102, 111) |

대조 입력의 SHA-256은
`5616c2f58274a063752b474097a67b68d09f005b89f58bcac5b99c7e5baa3c9e`다.
역사 입력 258,541개 조합에서 달라진 범위는 같은 PUD 두 행의
Smart 오반환뿐이었다.

행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.
양쪽을 같은 정답 기준으로 채점했다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 기준선 | 0, 3,038, 50,270, 0 / 0, 0, 0 | 1,426, 1,498, 50,236, 0 / 48.77, 100, 65.56 | 1,499 | 0 |
| 고정 음성 후보 | 0, 3,036, 50,272, 0 / 0, 0, 0 | 1,426, 1,496, 50,238, 0 / 48.80, 100, 65.59 | 1,497 | 0 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 592 / 99.93, 93.60, 96.66 | 13 | 592 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

추가 반환 미판정은 원문 GSD 553행 613범위와 교정 GSD
104행 110범위다. 고정 음성 계약 양성 1,207행의 전체 정답과
제외 42행의 37범위도 검토가 남아 있다.

고정 회귀 10행의 NFC·NFD와 리소스 장착 Smart·Any, 기본
Token을 빌드당 60개 조합으로 확인했다. Smart 오반환 12개가
사라졌고 `남을 도운`과 `새싹이 남을 관찰했다`의 목적격
범위가 유지됐다. 보조 용언 회귀 78개 조합도 다시 확인했다.
같은 줄의 직접 결합을 검증했다. `영화였다`처럼 구조 사전에
목적어를 허용하는 경쟁 분석이 남는 표면과 명사 앞에 다른 수식어가
끼어 있는 입력은 이 판정에서 보류된다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0과
Python 3.14.8에서 `7be578cd`와 `9b812cba`를 비교했다.
새 프로세스로 빌드별 워밍업 1회 뒤 순서를 교대해 5회 측정했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 각 실행의 최근접 순위다.
[고정 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
· [리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "future-adnominal-copula-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 7be578cd "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 9b812cba "$lexicon" "$component" "$predicates"
