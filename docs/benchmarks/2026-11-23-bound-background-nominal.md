# 연결·종결 어미와 의존 명사의 반환 범위

Smart에서 어절 끝의 연결·종결 어미를 형성하는 경로가
의존 명사 후보 앞에서 시작하면, 어절 끝의 일부를 독립 의존
명사로 반환하지 않는다. 경쟁하는 명사 구조나 원본 사전에서
정렬된 명사 성분이 확인되면 유지한다.
`가고 싶은 데에 표시하고 싶은데`의 목적지와 연결 어미,
`더 큰 걸`과 `조금 더 빨리 갈걸`의 목적어와 종결 어미를
구분한다. `측량용 수준일지`의 경쟁 명사 구조와
`공부한 지 이틀 만에`의 띄어 쓴 의존 명사를 확인했다.
[국립국어원 있는데와 있는 데](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6792&mn_id=27&pageIndex=1)
· [간접 의문형의 경쟁 명사 검증](2026-11-16-complete-interrogative-ji.md)

## 원문·교정문과 검색 품질

GSD s257의 원문과 등록 교정문의 문장은 같다. 장소를 뜻하는
`있는 데를`의 [37, 43)은 목적격 조사까지 포함한다.
`가고 싶은데`의 [57, 60)은 뒤 질문의 배경을 나타내는
어미 일부다. 이 판단을 두 평가의 범위 검토에 등록했다.
[원문과 대조 예문](../../tools/morph-compare/contract-contrast-evidence.jsonl)

두 입력에서 질의 68개를 비교한 결과, 명사 질의만 바뀌었다.
`데를`은 유지됐고, 어미의 마지막 음절은 제거됐다.
형용사 `싶다`의 [51, 60)은 두 입력에서 그대로 확인했다.
비교 입력 SHA-256은
`80a45f36e01097b42c24516e759d8b30f2ddfb92977e3568f03250f8678462ae`다.
기존 평가의 반환 258,541개를 대조했고, 같은 문장의 명사
질의 2행에서 범위 하나씩 사라졌다. 명사 `데`, `걸`, `거`,
`지`, `수`, `때`, `듯`의 질의 945행도 검사했다.

범위 확인을 반영한 같은 채점 기준에서 원문과 교정 GSD의 FPc가
한 건씩 줄었다. 기존 채점에서 미판정이던 범위를 등록했을 때
기준선 FPc가 각각 한 건 늘었으며, 아래 표는 그 기준을 양쪽에
적용한 결과다.

| 입력·빌드 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc | FNc |

| 고정 음성 양쪽 | 0, 3,038, 50,270, 0 / 0, 0, 0 | 1,426, 1,498, 50,236, 0 / 48.77, 100, 65.56 | 1,499 | 0 |

전체 범위 미검증은 고정 음성 계약 양성 1,207행이다. 제외
42행의 37범위도 판정이 남았다. 원문 GSD 추가 반환 미판정은
575행 637범위, 교정 GSD는 115행 121범위다.

고정 회귀 12행을 WASM의 NFC·NFD와 리소스 장착 Smart·Any,
기본 Token에서 빌드당 72개 조합으로 검사했다. 후보는
Smart의 내부 명사 오반환 12개를 제거했고, 나머지 반환은
각 모드의 기대값과 일치했다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0과
Python 3.14.8에서 기준선 `a95ce8bf`와 후보 `8c7e1564`를
측정했다. 같은 리소스를 장착하고 빌드별로 새 프로세스에서
워밍업 1회 뒤 순서를 교대하며 5회 측정했다. 대표값은
중앙값 [최솟값, 최댓값]이고 p95는 실행별 최근접 순위다.
[고정 평가 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
· [리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "bound-background-nominal-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" a95ce8bf "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 8c7e1564 "$lexicon" "$component" "$predicates"
```
