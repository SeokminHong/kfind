# 문장 끝 가의 이동 동사 범위

`기차로 대전역 어떻게 가?`의 마지막 `가`는 장소로 이동하는
동사 `가다`의 활용이다. 같은 줄에서 독립 부사 앞의 도착지나
`(으)로` 부사격 체언과 조사 없는 고유명사의 결합을 확인한다.
`벽난로 가에 의자를 놓고 집으로 어떻게 가?`에서는 명사
`가에` [10, 16)와 동사 `가` [54, 57)를 각각 반환한다.
부르는 이름과 인용된 표기도 정확한 범위로 확인했다.
[한국어기초사전 가다¹의 활용과 문형](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=27500)

## 원문·교정문과 품질

고정 음성, 원문 GSD, 교정 GSD에서 명사 `가`와 동사 `가다`의
질의 818행을 검사했다. 명사 `가` 258행 중 독립 어절 `가`가
17행에 있었고, 동사 질의 중 같은 어절이 등장한 행은 고정 음성
16행, 원문과 교정 GSD 각각 4행이다. 기존 평가 258,541건에서
Smart 2행의 명사 반환만 달라졌다.

두 문장의 질의 88개를 원문과 교정문으로 실행했다. s158은
`자전거로 대전역 어떻게 가`에 물음표를 추가했고, s321
`기차로 대전역 어떻게 가?`는 원문 표기를 사용했다. 구어에서
도착지 조사가 생략된 문형을 보존했다. 동사 반환은 두 입력 모두
각각 [33, 36), [30, 33)이다. 명사 반환은 같은 위치에서 사라졌다.
대조 입력 SHA-256은
`21678df5230c6aac5687dc5388ca40771ef4d40fec592d97ab24b10aceccbf60`이다.
종결 어미가 붙은 `가니`·`가지`와 관형형 `가는`의 잔여
반환은 지표에 포함한다.

고정 음성 계약 양성 1,207행은 전체 범위가 미검증이며, 제외
42행에서 37범위의 판정이 남아 있다. 추가 반환 미판정은 원문
GSD 576행 638범위, 교정 GSD 116행 122범위다.

고정 회귀 8행은 WASM의 NFC·NFD와 리소스 장착 Smart·Any,
기본 Token에서 빌드당 48개 결과를 비교했다. Smart의 명사
오반환 6개가 사라졌다. Any·Token 및 동사 범위는 보존됐다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0, Python
3.14.8에서 기준선 `eb0e22d8`와 후보 `0fc4bd74`를 같은
리소스로 비교했다. 빌드별로 새 프로세스에서 워밍업 1회 뒤
순서를 교대하며 5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이며
p95는 각 실행의 최근접 순위다.
[고정 평가 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
· [리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml

  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
