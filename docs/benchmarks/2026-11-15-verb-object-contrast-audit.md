# ㄹ 탈락으로 겹치는 활용의 목적격 문형

한국어기초사전과 표준국어대사전에서 집계한 30,935행에서, 동사의
ㄹ 받침 탈락으로 어간이 같아지고 목적격 문형이 다른 여섯 쌍을 추출했다.
목적격을 받지 않는 동사는 한국어기초사전에 모든 뜻의 구조화된 문형이
있고 두 사전에서 목적격 슬롯이 확인되지 않는 경우에 한정했다.
[사전 문형 집계 방법](2026-11-13-adnominal-predicate-frame-matching.md)

종결형 후보는 바로 앞 어절의 목적격과 경쟁 동사의 완결 활용을 확인한다.
시간 범위를 나타내는 목적격은 이 판정에서 제외한다. 높임형 후보는 앞의
본용언 연결형과 뒤 보조 동사의 결합 조건을 확인한다. 두 판정은 모두 사전
문형에서 찾은 경쟁 동사의 활용을 같은 용언 활용기로 검증한다.

## 품질

12개 고정 입력을 Smart·Any·Token으로 실행한 249,243행에서 입력 ID,
리소스 해시와 반환 바이트 범위가 모두 기준선과 같았다. 골드 925건,
walk/hang, workspace 테스트, 포맷과 Clippy를 통과했다.

`경비를 서나이다`에서 `설다`는 제외하고 `서다`는 유지했다. 같은
`서나이다`가 `밥이 조금` 뒤에 올 때는 `설다`의 활용을 유지했다.
`안녕을 비나이다`와 기간을 나타내는 `한 학기를 비나이다`도 대조했다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.

| 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) | 계약 검토 |
| --- | --- | --- | --- | --- |
| 교정 GSD Smart 9,298건 | 양쪽 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 0 |
| 고정 음성 Smart 53,308건 | 양쪽 | 0, 4028, 49280, 0 / 0.00, 0.00, 0.00 | 156, 3872, 49280, 0 / 3.87, 100.00, 7.75 | 156 |
| `서나이다` 대조 3건 | 기준선 | 2, 1, 0, 0 / 66.67, 100.00, 80.00 | 2, 1, 0, 0 / 66.67, 100.00, 80.00 | 0 |
| `서나이다` 대조 3건 | 후보 | 2, 0, 1, 0 / 100.00, 100.00, 100.00 | 2, 0, 1, 0 / 100.00, 100.00, 100.00 | 0 |

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`048a471b`와 `0448e366`을 비교했다. 입력마다 새 프로세스로 워밍업 1회와
측정 5회를 실행하고 두 실행 순서를 교대했다. 표는 중앙값 [최솟값, 최댓값]이며
p95는 최근접 순위로 구했다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD Smart | 기준선 | 62.641 [62.116, 63.130] | 28,169 [27,593, 28,584] | 0.07737 [0.07592, 0.07963] | 81.172 [81.078, 81.266] |
| 교정 GSD Smart | 후보 | 62.332 [62.010, 62.927] | 28,412 [27,624, 28,886] | 0.07704 [0.07496, 0.07913] | 81.406 [81.344, 81.688] |
| 고정 음성 Smart | 기준선 | 62.637 [61.957, 63.085] | 19,256 [18,687, 19,445] | 0.12896 [0.12792, 0.13125] | 127.594 [127.531, 128.453] |
| 고정 음성 Smart | 후보 | 63.632 [62.430, 64.418] | 19,262 [18,293, 19,335] | 0.12892 [0.12833, 0.13217] | 127.922 [127.828, 128.891] |

교정 GSD와 고정 음성의 처리량 중앙값은 각각 +0.86%, +0.03%이고
p95는 −0.43%, −0.03%다. 네 지표의 측정 범위가 겹쳤다. 교정 GSD RSS는
+0.29%였고 측정 범위가 겹치지 않았다.
