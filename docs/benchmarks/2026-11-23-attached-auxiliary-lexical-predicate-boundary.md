# 모음 연결형 뒤 보조 용언과 독립 사전 어간

Smart에서 동사 `듣다`가 PUD 원문의 `들어맞는다는` [124, 142)를
반환했다. MeCab-ko-dic에 `들어맞`이 동사 어간으로 있고,
한국어기초사전에도 `들어맞다`가 동사로 등재되어 있다.
기존 경로는 어절 전체의 보조 용언 분석을 짧은 질의 활용 앞에도
적용했다. 짧은 모음 연결형과 더 긴 사전 어간이 경합하면
연결형 뒤에서 시작하는 사전의 보조 용언 분석 또는 기존 결합 문법을 확인한다.
원문과 한국어기초사전을 대조하고 `들어맞는다는`의 표기를 유지했다.
[한국어기초사전 들어맞다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=51119&nation=eng)
· [PUD 문장](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/e942f9c5e9351f37bcb8f202bb9df70f78c60d35/ko_pud-ud-test.conllu)

원문·독립 대조 질의 18행에서 전체 반환 범위를 비교했다.
`들어맞고`, `들어맞는다는`, `들어맞는지`, `들어차고`의
`듣다` 오탐이 제거됐다. 독립 `들어맞다`는 원문의 [124, 142)와
연결형 대조문의 [27, 39)를 반환했고, 독립 `들어차다`는
[36, 48)을 반환했다. `들어보고` [13, 25), `들어도` [10, 19),
`들어갔다` [55, 67), `들어왔다` [47, 59), `걷어붙이고` [10, 25)도
확인했다. `기록을 다시 들어 보고`는 `들어` [17, 23)을 반환했다.
기준선은 연결형과 인용형 대조문에서 정답 외 범위를 추가했고,
후보는 고정 회귀와 걷다·걸다 전체 검증을 통과했다.
[국립국어원 보조 용언 띄어쓰기](https://korean.go.kr/kornorms/m/m_regltn.do)
· [정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

고정 음성의 `듣다` 잔여 19행을 대조했다. `들어맞는다는` 한 건이
제거돼 18행이 남았다. `가시권에 들어와있음을`과 교정형
`가시권에 들어와 있음을`은 각각 [278, 296), [279, 288)의

후보 `d908532d`를 비교했다. 빌드 명령은 양쪽
`cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml`
이다. Apple M1 Max, macOS 26.6.2 arm64, Rust·Cargo 1.97.0,
Python 3.14.8에서 입력과 리소스를 공유했다. 새 프로세스에서
