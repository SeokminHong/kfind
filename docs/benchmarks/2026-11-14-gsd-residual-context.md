# GSD의 합성 명사와 구어 조건형 주석

교정 GSD 9,306행에서 `분출주` 표면과 `분출+주로` 주석은
1행이다. 종목이 주어이고 분류 대상이 명사 `분출주`이므로
부사 `주로` 대신 부사격 조사 `로`로 분석했다.

`실라면/을라면/갈라면/할라면/볼라면` 및 명사 뒤
`이+라면` 주석을 대조한 2행에서, `가실라면`은 동사
`가다`의 높임 조건형으로 교정했다. `수준이라면`의
명사와 서술격 조사 분석은 유지했다. 두 교정 모두 원문과
UTF-8 정답 범위를 보존했다.
[국립국어원 구어 전사 자료](https://www.korean.go.kr/common/download.do?c_file_name=180cf280-6e36-4899-9f92-0a7cb53adf00.pdf&file_path=reportData&o_file_name=KR20120116.pdf) ·
[교정 주석](../../tools/morph-compare/gsd-residual-context-annotations.tsv)

동일한 검색 실행 파일로 양성 9,306행을 평가했다.
행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서다.
계약 검토는 0건이다.

| 경계 | 입력 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- | --- |
| smart | 교정 전 | 9257, 0, 0, 49 | 100.00, 99.47, 99.74 | 9257, 0, 0, 49 | 100.00, 99.47, 99.74 |
| smart | 교정 후 | 9258, 0, 0, 48 | 100.00, 99.48, 99.74 | 9258, 0, 0, 48 | 100.00, 99.48, 99.74 |
| any | 교정 전 | 9066, 0, 0, 240 | 100.00, 97.42, 98.69 | 9066, 0, 0, 240 | 100.00, 97.42, 98.69 |

`분출주로`는 양쪽 경계에서 정확 일치했다. `가실라면`은
`any`에서 부분 일치하며 `smart`에서 해당 위치가 누락됐다.
#421 비교군 1,113행 중 교정 후 `smart`는 정확 1,070행,
부분 15행, 누락 28행이고 `any`는 정확 946행, 부분 160행,
누락 7행이다. 검색 코드 변경이 없어 성능 측정은 생략했다.

```sh
node tools/morph-compare/apply-gsd-sentence-edits.mjs "$input" --residual-context > "$corrected"
"$runner" boundary full-pos "$boundary" "$corrected" "$output"
```

교정 SHA-256은 `bc9e38af4f43f07f27e10d10d483afbfdda1c4d7b4236ddf28b4519df64747ae`다.
