# 하오체 종결형과 부사의 문맥 구분

`목소리가 매우 친절합니다`에서 부사 `매우`가 뒤 술어를 수식한다.
기준선은 같은 33..39를 동사 `매다`의 하오체 종결형으로도 반환했다.
`-우`는 독립된 말 끝에서 성립하는 종결 어미다. `끈을 매우`나
`끈을 매우 느슨하게`에서는 동사 분석이 성립한다.
[한국어기초사전 -우](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=86113)

## 품질

교정 GSD, PUD 양성, 고정 음성에서 `매우·맵다·매다` 질의 204행을
추렸다. 기준선 Smart 잔여의 용언 반환 전체를 대상으로 `우`로 끝나는
범위를 찾았으며, 해당 9범위는 모두 부사 `매우`였다. 각 원문에서 세
질의를 실행해 원래 반환 범위와 문법상 범위를 비교했다.

고정 12세트 83,081행을 모드별로 실행해 반환 목록 249,243개를
비교했다. 바뀐 범위는 고정 음성의 Smart 오탐 6개다.

| 원문 ID | 제거한 바이트 범위 | 뒤 성분 |
| --- | --- | --- |
| `gsd:test-s365` | 33..39 | 친절합니다 |
| `gsd:test-s376` | 17..23 | 좋고 주인 아주머니의 서비스도 좋네요 |
| `gsd:test-s925` | 59..65 | 좋다 |
| `gsd:test-s926` | 30..36 | 고급스럽습니다 |
| `pud:n01015033` | 43..49 | 흔치 않은 이름이었을 것이 분명하다 |
| `pud:w01031015` | 73..79 | 높은 경향이 있으며 |

`매우 합리적`, `매우 만족하였다`, `매우 개인적인`의 `매다`는
고정 음성에 계속 집계한다. 별도 대조의 하오체 명령과 인용 7개에서도
부사 검색의 오탐이 남는다. `국이 매우면`과 `매운 국`에서는
`맵다`만 활용 전체를 반환했다.

목표 11세트의 Smart FNc는 0, FPc는 1,807→1,801이다. 아래 행렬은
TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.
대조의 계약 검토는 0건이고 보정 결과는 원본과 같다. 고정 음성의
원본 recall은 양성 분모가 없어 정의되지 않는다.

고정 음성 계약 평가에서 제외한 108건은 두 버전에서 같다.

## 성능

기준선 `97cc1644`와 후보 코드 `07c06072`를 Apple M1 Max arm64,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Node.js 26.11.1에서
같은 release 설정으로 빌드했다. `/usr/bin/time -l RUNNER boundary
full-pos smart INPUT OUTPUT`을 새 프로세스에서 입력별 워밍업
1회 뒤 두 버전을 번갈아 각 5회 실행했다. 중앙값 [최솟값, 최댓값]이다.
처리량은 초기화를 제외하고 p95는 nearest-rank로 구했다.
