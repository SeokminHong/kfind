# 조사 앞 단일 체언의 끝 성분

`시나리오를`에서는 조사 `를` 앞의 `시나리오`가 하나의
외래어 명사다. 기존 관형사 경로는 조사 앞 사전 명사의
마지막 음절을 다시 분해했다. 같은 범위는 지명과 의존 명사를
합치는 경로에서도 반환됐다. 두 경로에서 조사 앞 단일 체언을
확인하고, 사전에 정렬된 명사 성분과 완결된 수사·단위 경로를
유지한다. `이달에`의 `달에`, `뱃길을`의 `길을`,
`칠월에`의 `월에`를 대조했다.
[한국어기초사전 시나리오](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=15963)

## 품질

Smart full-pos `8435ad07`의 기준선과 `95713bd3`의 후보를
비교했다. 표의 품질 지표는 모두 같은 검토 근거로 채점했다.
교정 GSD s779:3에서 성씨 `오 [14, 17)`와 외래어 내부
`오를 [96, 102)`를 구분해, 함께 채점한 기준선에서 오탐 한 건을
확인했다. 공개 기준선에서는 그 범위가 미판정이었다.
[입력과 리소스 체크섬](2026-11-23-gsd-standalone-noun-spacing-review.md#평가)

고정 음성의 Smart 검색에서 변화한 범위는 세 개다. s43의
`한국을` 안 `국을 [28, 34)`, s392의 `한국에` 안
`국에 [10, 16)`, PUD w04007021의 `오스트리아는` 안
`아는 [111, 117)`이 사라졌다. s43의 `중국` 안
`국 [55, 58)`은 같은 문장의 별도 오탐으로 남았다. s392의
`초총하여 → 초청하여`, w04007021의 `포기할수밖에 →
포기할 수밖에` 등 문장 전체의 표기도 확인했다. 원문과 교정문
22개 질의에서 같은 결과를 확인했고 전체 고유명사와 외래어
범위는 유지됐다. 대조 입력의 SHA-256은
`d22d72baa97132a536a852573743c42764de314bb5c2a8b6007186916e7eb48a`다.

기존 입력의 원시 반환 범위를 Smart, Any, Token에서 258,541행
비교했다. 위 세 고정 음성과 교정 GSD s779:3을 각각 기록한
두 실행만 달랐다. MeCab 2.1.1의 NNG와 Foreign 명사,
MM 앞 성분 또는 두 음절 이상 고유명사 앞 성분, 독립 명사
표면으로 등록된 끝 성분을 조합해 진단 109,484행도 실행했다.
범위가 바뀐 12,203행 중 12,176행에서 반환이 없어졌다.
기준선이 반환한 사전 정렬 대상 44,452행은 반환 범위가 모두 같다.
사전 분절이 없는 진단행의 범위 차이는 진단 결과로 기록한다.
진단 입력의 SHA-256은
`79bfd3c6622c4df5abc7bb6acae69f087998ae72c7939c4001f01499067b8759`다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0,
Python 3.14.8에서 두 release 빌드를 같은 입력과 리소스로
실행했다. 빌드마다 워밍업 1회 뒤 새 프로세스에서 순서를
교대해 5회 측정했다. 실행별 p95는 최근접 순위로 계산했다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "atomic-nominal-tail-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 8435ad07 "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 95713bd3 "$lexicon" "$component" "$predicates"
```
