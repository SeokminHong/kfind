# 숫자 뒤 사전 단위의 성분 경계

`16세기에`의 `세기`는 백 년 단위다. `세`와 의존 명사 `기`로 나눠도
구조 사전의 품사열은 완성되지만, 같은 범위를 기존 한국어기초사전 단위
목록의 `세기`가 채운다. Smart는 이 경우 단위 전체를 유지한다. 단위와
조사가 완성된 `16 세기에`에도 같은 근거를 적용해 형용사 `세다`의 반환을
차단한다. 독립 활용 `바람이 세기에`와 숫자 뒤 `14세`, 명사 `세를`은
기존 범위를 반환한다. [한국어기초사전 ‘세기’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62053)

## 품질

등록 단위 60개의 내부 성분 경계 64개를 compact 사전으로 확인했다.
기준선에서 단위와 의존 명사로 분리되는 14개를 붙임·띄어쓰기 두 형식으로
검사했다. 전체 단위 28범위를 유지했다. `2년도`에서 보조사 `도`가 붙은
`년`, `3기가`에서 주격 조사 `가`가 붙은 `기`처럼 완성된 조사 분석을
보존했다. `2연대로`의 `연+대로`도 조사 분석으로 남는다.

고정 12세트 83,081행의 세 모드에서 반환 목록 249,243개를 비교했다.
달라진 목록은 전부 PUD의 `세기`에서 나온 Smart 명사 `세` 오탐이다.
16행에서 17범위가 제거됐다. 기존 계약을 적용한 목표 11세트의
Smart FNc는 0, FPc는 1,941에서 1,925다. 남은 명사 `세` 네 행은
나이 단위 두 행, 군주 이름의 서수 단위 한 행, 관형사 `세 곡` 한 행이다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
직접 대조 13질의의 계약 검토는 0건이다. 고정 음성의 계약 평가에서
기존 제외 71행을 적용했다.

### PUD 원문 정답과 띄어쓰기

남은 네 행을 CoNLL-U의 `# text`, `# ToDoOrigText`, 토큰 위치와 대조했다.
`w01018101`의 `14세` 두 범위, `n02002007`의 `53세`, `w02014030`의
`1세`는 숫자 뒤의 의존 명사다. 숫자와 결합해 나이 또는 왕조 서수를
나타내며, `세 곡`의 관형사는 뒤 명사를 수식한다. 앞 세 행을 원문에
정렬된 명사 양성으로 교정했다. [국립국어원 ‘세(歲)’의 결합](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?qna_seq=325362)

`w01130101`의 원출처에는 `작곡한 세 곡도`의 관형사 앞에 공백이 있다.
이 경계만 복원한 문장과 원출처 전체에서 각각 관형사 `세`만 돌아온다.
원본의 `작곡한세`는 계약 평가에서 제외했다. 네 행의 원문, 필요한 공백만
복원한 문장과 원출처에서 두 품사 질의 18개를 비교했다. 같은 문장의 명사
`곡`을 포함해 `곡` 대조문 다섯 행을 동사 `곡해했다`와 비교했다. 두 질의는
각 원문과 대조문에서 해당 품사의 전체 범위만 반환했다.
[한글 맞춤법 제2항](https://korean.go.kr/kornorms/m/m_regltn.do)

`b99cc815`의 기존 고정 음성 반환을 다시 채점했다. 계약 제외는 72행이다.

## 성능

값은 중앙값 [최솟값, 최댓값]이다. p95는 각 실행의 질의 시간에서
nearest-rank 방식으로 계산했다.

GSD 처리량·p95 중앙값은 +0.67%·−0.34%, 고정 음성은 +0.21%·−0.03%다.
측정 범위는 모두 기준선과 겹쳤다.
