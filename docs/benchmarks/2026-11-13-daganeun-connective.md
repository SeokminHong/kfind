# 연결 어미 다가는·다간·단 검색

고정 사전 어미 목록에서 `다가는` 11건, `다간` 8건, `단` 9건을 찾아
28건을 전수 대조했습니다. 두 경계 모두 28건의 UTF-8 정답 범위가 일치했습니다.
사전의 나머지 4,430건, GSD 양성 9,314건과 GSD·PUD 음성 53,308건의
반환 범위는 동일했습니다. GSD에서 표면형이 `다가는/다간/단`으로 끝나는
8건은 모두 체언, 부사 또는 조사 결합이었습니다.
