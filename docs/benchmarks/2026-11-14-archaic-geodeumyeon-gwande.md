# 거드면·관데의 검색 범위

표준국어대사전의 조건형 `-거드면` 2건과 원인 연결형 `-관데` 2건을 전수 검토했다.
지정사·용언의 어간과 선어말 어미 뒤의 활용을 확인하고, 다른 어절로 인용한 어미를 대조했다.
[표준국어대사전 -거드면](https://stdict.korean.go.kr/search/contentViewOne.do?word_no=12565) ·
[표준국어대사전 -관데](https://stdict.korean.go.kr/search/contentViewOne.do?word_no=400918)

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
표적의 계약 보정은 지정사 시작 범위 1건이다.

## 성능

시작점 `70a5d2d4`, 기준선 `f5e04ee5`, 후보 `724ea80a`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `b00a29ea`와
`299106a0`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다.
p95는 최근접 순위, RSS는 최대 상주 메모리다.

기준선 대비 사전·GSD·음성 처리량은 +0.19%, −0.60%, −1.02%이며,
p95는 +0.44%, +0.67%, +0.17%다. 시작점 대비 음성 처리량은 +24.90%,
p95는 −0.61%다. 음성 입력은 첫 측정에서 후보 초기화 최댓값이 139.747 ms였고
처리량 중앙값은 기준선 대비 −1.95%, p95는 +0.79%였다.
같은 설정·입력으로 한 독립 반복의 음성 결과를 표에 사용했다.
