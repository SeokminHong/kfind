# Any의 의존 명사와 지정사 축약

compact 리소스가 있는 Any는 사전에 등록된 `것·거`의 지정사 축약형
`겁니다·겁니까`에 Smart와 같은 활용 검증을 적용한다. 후보가 어절
전체이고 앞 용언의 관형형과 의존 명사·지정사·어미 분석이 확인되어야
반환한다. `갈 겁니까`와 동사 `걸다`의 `소금을 겁니다`를 대조했다.

## 품질

기준선 `4133e2f5`와 후보 `f8e52bf1`을 같은 입력 12세트에서 실행해
249,243개 결과의 UTF-8 범위를 비교했다. Any 교정 GSD 한 행에서
`있을 겁니다`의 `겁니다`가 추가됐다. 고정 음성 53,308행과 hard
negative 45행에 새 반환 범위가 없다. compact 없이 실행한 Any 83,081행의
반환 범위도 같다. Smart의 고정 평가 11세트에서 계약 FN은 0건이다.

CLI에서도 교정 GSD 원문 961문장에 `것·거·수` 명사 질의를 각각 적용했다.
`것`과 `거` 질의에서 같은 문장의 의존 명사 축약형 `겁니다`가
한 범위씩 추가됐다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.
교정 GSD의 계약 검토는 0건이며 원본과 계약 결과가 같다.

| Any 교정 GSD 9,298행 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- |
| 기준선 | 9255, 0, 0, 43 / 100.00, 99.54, 99.77 | 9255, 0, 0, 43 / 100.00, 99.54, 99.77 |
| 후보 | 9256, 0, 0, 42 / 100.00, 99.55, 99.77 | 9256, 0, 0, 42 / 100.00, 99.55, 99.77 |

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
새 프로세스 워밍업 1회 이후 5회씩 실행 순서를 교대했다.
러너 표는 재측정의 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.
첫 측정에서 고정 음성 처리량은 −1.35%, p95는 +1.96%였다.
재측정에서 처리량은 +0.17%, p95 중앙값은 양쪽이 같았다.
