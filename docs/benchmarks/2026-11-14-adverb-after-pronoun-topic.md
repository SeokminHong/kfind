# 대명사와 보조사 결합 뒤 부사 검색

`전 약간 비린 느낌이어서`에서 `전`의 관형사 분석 때문에
뒤의 부사 `약간`이 누락됐다. 앞 어절에 대명사와 보조사가
결합한 분석도 있으면 부사 분석을 보존한다. `넌 약간 피곤해`와
`난 약간의 돈을 받았다`를 대조했다. GSD에서 해당 축약 표기
뒤의 부사 질의 3행을 검토했고 `약간`의 정확 범위 1행을 회복했다.
음성 53,308행의 반환 범위는 모두 같았다.
[회귀 입력](../../data/fixtures/ud_morphology_cases.tsv)

기준선 ad530bd6과 후보 54afe9c7의 full POS `smart`를 비교했다.
양성은 정확 범위, 음성은 반환 여부를 채점했다. 행렬은 TP, FP,
TN, FN 순서다. 양성 검토 0건, 음성은 기존 검토 3건을 적용했다.

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 같은
release 설정과 사전을 사용했다. 시작점 70a5d2d4, 기준선, 후보를
워밍업 1회 뒤 새 프로세스로 5회 측정했다. 버전 실행 순서는
교대했다. p95는 nearest-rank이며 RSS는 최대 상주 메모리다.
표는 중앙값 [최솟값, 최댓값]이다.
