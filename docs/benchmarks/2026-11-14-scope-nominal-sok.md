# 범위 명사 속의 검색

`화보 속 박하선은`에서 뒤 체언 때문에 `속`을 관형사로
선택하던 판정을 수정했다. 조사 없는 앞 체언이 범위를 정하면
`속`을 일반 명사로 검색한다. `소설 속 인물`과 일반 관형사를
포함한 세 회귀를 검증했다.

교정 GSD에서 `속` 및 조사가 붙은 주석 5행을 검토했다.
`화보 속` 1행의 정확 범위를 복구했고 음성 53,308행의 반환
범위는 같다. 기존 `verify-gold` 불일치 8건은 동일하다.

45a3b236과 후보 0b1c4c89의 full POS `smart`를 비교했다.
양성은 정확 범위, 음성은 반환 여부를 채점했다. 행렬 순서는 TP,
FP, TN, FN이다. 양성 계약 검토는 0건이고 음성은 기존 3건이다.

| --- | --- | --- | --- | --- | --- |
| 양성 | 기준선 | 9296, 0, 0, 2 | 100.00, 99.98, 99.99 | 9296, 0, 0, 2 | 100.00, 99.98, 99.99 |
| 양성 | 후보 | 9297, 0, 0, 1 | 100.00, 99.99, 99.99 | 9297, 0, 0, 1 | 100.00, 99.99, 99.99 |
| 음성 | 양쪽 | 0, 4092, 49216, 0 | 0.00, 0.00, 0.00 | 3, 4089, 49216, 0 | 0.07, 100.00, 0.15 |

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 같은
release 설정과 사전을 사용했다. 시작점 70a5d2d4, 기준선, 후보를
워밍업 1회 뒤 새 프로세스로 5회씩 측정했다. 실행 순서는
교대했다. p95는 nearest-rank이며 RSS는 최대 상주 메모리다.
표는 중앙값 [최솟값, 최댓값]이다.
