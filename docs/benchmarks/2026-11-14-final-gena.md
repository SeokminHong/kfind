# 친근한 명령 종결형 게나의 검색 범위

표준국어대사전과 한국어기초사전의 `-게나` 예문 4건을 점검했다.
받침 없는 동사, 자음 및 ㄹ 받침 동사, 높임 뒤에서 어절 끝까지 반환한다.
`읽게 나만`에서 분리된 대명사의 범위는 건드리지 않는다.
[표준국어대사전 -게나](https://stdict.korean.go.kr/search/searchView.do?word_no=15343&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
표적의 계약 검토는 0건이다. 전체 사전에는
[앞선 보정 9건](2026-11-14-propositive-quotation.md#품질)을 유지한다.

고정 GSD 9,298건과 음성 53,308건, KAIST dev 2,532건과 test 2,592건의

[고정 입력 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `926bf4d1`, 후보 `2a92d51f`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `4f32e9bd`와
`c27e8106`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서는 순환했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접
순위, RSS는 최대 상주 메모리다.
