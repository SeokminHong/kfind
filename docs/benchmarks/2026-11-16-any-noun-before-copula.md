# Any의 지정사 앞 명사 반환 범위

Any가 `일품이었다`에서 명사 `일품`을 검색할 때 지정사의 `이`를
주격 조사로 소비해 `일품이`를 반환했다. 어절 첫 명사 뒤의 문자열 전체가
지정사 활용을 완성하면 명사에서 범위를 끝낸다. `일품이 첫째로 뽑혔다`의
주격 조사는 유지한다.

## 품질

고정 입력 12세트와 세 모드의 249,243행을 비교했다. Any 221행의
226범위가 끝의 `이`를 한 음절 덜 반환했다. GSD 121행이 바뀌었고,
이 가운데 109행에서 정답과 범위가 정확히 일치했다. 음성 55행에서도
반환이 짧아졌으며 적중 여부는 같다. 새 적중 음성과 새 계약 FN은 없다.
리소스 유무에 따른 두 실행에서 동일한 범위 차이를 확인했다.
고정 평가 11세트의 Smart 계약 FN은 0건을 유지했다.

교정 GSD의 아래 질의에는 별도 계약 검토가 없다. 고정 음성 53,308행에는
양쪽에 기존 계약 검토 171건을 적용했다. 행렬은 TP, FP, TN, FN 순서이며
비율(%)은 precision, recall, F1 순서다. 양성 분모가 0인 raw recall은
`—`로 표기한다.

| Any 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 교정 GSD 9,298행 | 기준선 | 9097, 0, 0, 201 / 100.00, 97.84, 98.91 | 9097, 0, 0, 201 / 100.00, 97.84, 98.91 |
| 교정 GSD 9,298행 | 후보 | 9206, 0, 0, 92 / 100.00, 99.01, 99.50 | 9206, 0, 0, 92 / 100.00, 99.01, 99.50 |
| 고정 음성 53,308행 | 양쪽 | 0, 17622, 35686, 0 / 0.00, —, 0.00 | 171, 17451, 35686, 0 / 0.97, 100.00, 1.92 |

Workspace 테스트 643건, gold 925건과 walk/hang 스트레스, 포맷,
Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
기준선 `753652f8`과 후보 `e14135d9`의 런타임을 비교했다. 기준선 빌드는
머지 트리와 같은 `f86de35a`, 후보 빌드는 런타임이 같은 `c2abe640`에서
만들었다. 같은 입력과 리소스로 새 프로세스 워밍업 1회, 측정 5회를 실행
순서를 교대하며 수행했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD Any | 기준선 | 60.599 [60.183, 62.555] | 61,689 [57,331, 62,010] | 0.03896 [0.03896, 0.04175] | 80.766 [80.703, 80.844] |
| 교정 GSD Any | 후보 | 60.410 [60.250, 60.720] | 61,653 [59,822, 61,891] | 0.03896 [0.03892, 0.04000] | 80.922 [80.828, 81.250] |
| 고정 음성 Any | 기준선 | 60.876 [60.367, 61.967] | 27,649 [27,345, 27,668] | 0.10321 [0.10296, 0.10417] | 139.750 [139.672, 140.219] |
| 고정 음성 Any | 후보 | 60.991 [60.258, 61.412] | 27,525 [27,237, 27,784] | 0.10325 [0.10258, 0.10462] | 139.906 [139.844, 140.203] |

교정 GSD의 처리량과 p95는 −0.06%, 0.00%였고 고정 음성은 각각
−0.45%, +0.04%였다.
