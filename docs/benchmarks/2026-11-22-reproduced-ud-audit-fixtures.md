# 공개 GSD·PUD 원문 감사 입력 재현

UD 2.18의 GSD·PUD test 원문에서 이전 감사의 GSD 원본 양성 9,335행과
고정 음성 53,308행을 생성했다. 기존 두 JSONL 파일과 바이트 단위로
일치했고, GSD와 PUD 경로를 맞바꿨을 때 생성기가 원문 SHA-256 불일치를
보고하며 출력 디렉터리를 만들기 전에 종료했다.
[저장소에서 실행하는 명령과 입력 체크섬](../../tools/morph-compare/README.md#gsdpud-고정-감사-입력)

## GSD 원본 양성 성능

`d30d2d78`의 같은 release runner를 두 측정군으로 설정했다.
[Smart 성능 기준선](2026-11-22-smart-performance-baseline.md)의 장비와
같은 full POS·component·보강 용언을 사용하고, 재현한 `positives.jsonl`을
입력했다. 명령은 `morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`이다.
새 프로세스에서 측정군별 워밍업 1회와 교대 측정 5회를 실행했다.
표는 중앙값 [최솟값, 최댓값]이다. p95는 실행별 최근접 순위로, RSS는
macOS `/usr/bin/time -l`의 최대 resident set으로 측정했다.

| 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS MiB |
| --- | --- | --- | --- | --- |
| A | 64.03 [63.66, 66.08] | 27,495 [26,729, 28,467] | 0.07908 [0.07629, 0.08217] | 81.69 [81.36, 82.20] |
| B | 64.02 [63.19, 64.34] | 27,648 [26,410, 28,165] | 0.07804 [0.07754, 0.08175] | 81.59 [81.50, 82.09] |

원본 양성의 두 측정군은 처리량 중앙값이 0.56%, p95가 1.32% 차이 났다.
이 값은 원본 양성에서 관측한 변동이다. 교정 GSD를 쓰는 비교에는 해당
교정 입력의 체크섬과 측정 결과를 사용한다.
