# 완성 고유명사 안의 부분 용언

`박지원`의 `박지`와 `모나코`의 `모나`는 각 어절의 일부만
용언으로 소비한다. 통째 고유명사가 확인되면 전체 용언 경로,
정렬된 합성 용언, 보조 용언 결합의 근거로 부분 후보를 검증한다.
`만들어진`의 `진`은 실제 보조 용언 범위로 유지한다.
[국립국어원 ‘만들어지다’의 보조 용언](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5986)

## 품질

계약 오탐 중 동사·형용사가 어절 일부만 반환한 375범위와 그
296표면을 compact 사전과 대조했다. 통째 고유명사 품사만 있는
10범위의 원문을 확인했다. `만들어진`은 실제 보조 용언이며
`안에서`는 위치 명사와 조사의 결합이다. `기네스`는 준비된
격자에서 고유명사 단위가 확인되지 않고, `캐나다`는 뒤쪽에
보조 용언 격자 경로도 생겨 두 반환이 남았다.

고정 12세트 83,081행에서 세 모드의 반환 249,243개를 비교했다.
Smart 음성 10행에서 각 1범위가 제거됐다. `박지원`, `무자헤딘`,
`제네시스`, `조지타운`, `사우스`, `모나코`, `주니어`, `안에서`와
`자산`에 대한 두 용언 질의다. 동일한 근거에서 정답을 변경한
행은 없다. 고정 음성 계약 검토 1,341행과 제외 67행을 유지한다.
목표 11세트의 Smart FNc는 0, FPc는 2,145에서 2,135로 줄었다.

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
회귀는 계약 검토 0행이다.

## 성능

기준선 `b6dcf433`, 후보 코드 `49088c35`, Apple M1 Max arm64,
macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release다. 새 프로세스에서
워밍업 1회 후 기준선과 후보를 교대로 5회 실행했다. 중앙값
[최솟값, 최댓값]을 기록했다. p95는 실행별 최근접 순위이며 RSS는
`/usr/bin/time -l`의 최대 상주 메모리다.

5,177,408바이트에서 5,176,896바이트로 줄었다.
