# 의문 인용 연결형 냐며·냐면서

`아니냐며`는 `아니냐고 하며`가 줄어든 형태다. 검색은 의문형의
어간 결합을 사용해 `-냐며/-으냐며/-느냐며`와 `-냐면서` 계열까지
소비한다. 독립 의문문 `어제 일을 아니?`의 `아니`는 `알다`의 활용
범위다.
[국립국어원 국제 통용 한국어교육 표준모형](https://www.korean.go.kr/common/download.do?c_file_name=2bfd3feb-997c-4c4d-8052-3d2a406c4be4_2.pdf&file_path=reportData&o_file_name=%EA%B5%AD%EC%A0%9C%ED%86%B5%EC%9A%A9+2%EB%8B%A8%EA%B3%84+%EA%B2%B0%EA%B3%BC%EB%B3%B4%EA%B3%A0%EC%84%9C%28%EC%B5%9C%EC%A2%85%EB%B3%B8%29.pdf)

## 품질

고정 12세트 83,081행에서 `냐며`가 있는 39행은 전부 PUD `n02075020`
한 문장에 속한다. 이 문장의 표적 `아니냐며`에 `아니다`를 질의하는 행은
없었다. 직접 대조에서 실제 원문과 독립 예문에 `아니다`를 질의해 전체
활용 범위를 확인했다. 동사·형용사·지정사와 높임·과거·추측을 포함한
17질의에서 기준선의 Smart 누락 13개가 복구됐다.
CLI의 NFC와 canonical 모드 NFD에서 34개 범위가 모두 일치했다.
NFD 과거·추측 대조의 기존 구조 검증 미완료 진단은 양쪽에서 같았다.

고정 세 모드에서 249,243개 반환을 비교했으며 변경은 0개다. 목표 11세트의
계약 검토와 Smart FNc 0, FPc 2,041은 그대로다. 직접 대조의 Any는
`알다`가 `아니냐며`의 앞부분을 반환하고, Token은 `학생이냐며` 안의
`이냐며`를 어절 내부로 처리한다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
직접 대조의 계약 검토는 0건이다.

## 성능

각 값은 중앙값 [최솟값, 최댓값]이다. p95는 각 실행의 질의 시간을
nearest-rank 95백분위수로 집계했다.

| Smart 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | 최대 RSS (MiB) |

| GSD | 기준선 | 60.989 [60.529, 62.930] | 29,748 [29,383, 30,617] | 0.07246 [0.07038, 0.07275] | 81.172 [81.047, 81.375] |

| 고정 음성 | 후보 | 60.730 [60.374, 61.376] | 19,691 [19,464, 19,968] | 0.12688 [0.12387, 0.12875] | 127.453 [127.328, 127.672] |

GSD 처리량·p95 중앙값은 +0.10%·−0.23%, 고정 음성은 −0.26%·+0.73%였다.
모든 지표의 측정 범위가 겹쳤으며 러너 크기는 양쪽 5,177,904바이트였다.

## 재현

- 기준선 `46d89f07`의 검색 코드 `abee64a7`과 후보 `01143779`를 Apple M1 Max arm64,
  macOS 26.6.2 (25G83), Rust/Cargo 1.97.0에서 `cargo build --release --locked
  --manifest-path tools/morph-compare/runner/Cargo.toml`로 빌드했다.
- GSD `gsd-saint-determiner.jsonl`과 고정 음성 `negatives.jsonl`을
  `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로 실행했다.
  실행마다 새 프로세스를 만들고 예열 1회 후 측정 5회를 번갈아 수행했다.
- 고정 반환 비교는 `morph-benchmark-runner boundary full-pos MODE INPUT OUTPUT`을 사용했다.
