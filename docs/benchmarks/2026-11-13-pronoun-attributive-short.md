# 독립 체언 앞의 대명사 준말 울

GSD 9,314건과 GSD·PUD 음성 53,308건에서 독립 어절 `울`을 찾았습니다.
양성 입력에서는 `울 꼬맹이도`와 `울 아들` 두 문장이 해당했습니다.
음성 입력의 두 문장에도 `울`이 있었으며 해당 질의의 반환은 바뀌지 않았습니다.
고정 사전 양성 4,458건에서도 반환 범위 차이는 없었습니다.
[국립국어원 준말 용법](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=90&qna_seq=337260)

대명사 `우리` 질의가 `울 꼬맹이도`의 `울`을 반환합니다. `울 것 같다`의 의존
명사 앞에서는 대명사 후보를 제외합니다. `울 아이가 먼저 나왔어요`는 대명사와
용언의 관형형으로 모두 읽을 수 있어 두 질의의 반환을 검증했습니다.
[양성·음성 대조](../../data/fixtures/ud_morphology_cases.tsv)

`99c50ed41d33ab05c9cdf01446702d8fb8f4623c`입니다. 행렬은 TP, FP, TN, FN 순이며
비율은 precision, recall, F1입니다. 양성 계약 검토는 0건이며 음성 검토 27건을
적용했습니다.
