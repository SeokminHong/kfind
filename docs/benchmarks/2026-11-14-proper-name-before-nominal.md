# 수사와 동형인 한 음절 고유 명사 검색

교정 GSD에서 한 음절 고유 명사 32행과 한 음절 수사 5행의
다음 어절을 확인했다. 고유 명사 중 유일하게 누락된 `오 시장`과,
전체 결과 비교에서 발견된 `구 관계자`의 명사 범위를 회복했다.
`오 시장이 주민투표 문제를 매듭짓고`의 수사 주석은 원본
비교군에 들어 있으며, 별도 회귀에서 성씨의 범위를 확인했다.
`오 년`, `오 개`, `오 명`, `오 번`, `삼 개`는 수사 범위를
유지했고 명사 질의에 반환되지 않았다.
[회귀 입력](../../data/fixtures/ud_morphology_cases.tsv)

기준선 1b5fa1bd와 후보 d71d4149의 full POS `smart`를 비교했다.
교정 GSD 9,300행은 정확 범위, 음성 53,308행은 반환 여부로
평가했다. 두 새 음성 적중은 `조 스턴리엡`과 `원 왕조`의
독립 고유 명사다. 양성 검토 0건, 음성 검토 3건이다. 행렬은
TP, FP, TN, FN 순서다.

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0 release
빌드와 같은 사전을 사용했다. 시작점 70a5d2d4, 기준선, 후보마다
워밍업 1회 후 5회 새 프로세스로 측정했다. 버전 실행 순서는
교대했다. p95는 nearest-rank이며 RSS는 최대 상주 메모리다.
표는 중앙값 [최솟값, 최댓값]이다.

기준선 대비 처리량은 양성 +1.75%, 음성 +1.46%이고 p95는
양성 −1.11%, 음성 −0.93%다. 시작점 대비 처리량은 +5.92%,
+9.88%이고 p95는 −10.47%, +14.00%다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```

음성에서는 출력을 FIFO로 받아 gzip으로 압축했다. 초기화·평가
시간은 출력 직렬화 전 러너가 기록한다. 입력과 리소스의 SHA-256은
[호칭 씨 측정](2026-11-14-surname-before-ssi.md#성능)과 같다.
