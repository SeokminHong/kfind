# 통째 부사 내부의 체언 범위

Smart는 `또한`의 뒤 음절을 명사 `한`으로 반환했다. 실행 경로에서는
통째 관형사와 접속 부사가 있는 사실이 내부 한 음절의 일반·고유 명사
추론을 허용했고, 의존 명사 추론에도 정렬 근거가 필요하지 않았다.
통째 부사와 사전에 있는 경쟁 분석이 모두 비체언 수식이면, 조사 없는 내부
한 음절 체언에 통째 단어의 근거를 적용하지 않는다.

UD 2.18 GSD·PUD의 원문에서 독립 어절 `또한` 8곳·34곳, `가능한`
3곳·0곳, `십대` 0곳·1곳을 확인했다. 이 46위치에 88개 질의를
실행했다. `또한` 42곳의 부사 전체 범위를 유지했고, 내부 명사 범위는
42곳에서 모두 제거했다. `가능한`에서는 기준선이 반환한 내부 범위
1곳을 제거했다. 같은 문장의 독립 의존 명사 `한`은 유지했다.
`십대`에 포함된 의존 명사 `대`도 동일하게 반환했다.
[국립국어원 십대의 허용 표기](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6569&mn_id=217)

## 품질

고정 12세트의 83,081행을 Smart·Any·Token으로 실행해 반환 범위 목록
249,243개를 비교했다. Smart 고정 음성의 범위 5개가 제거됐고 나머지
목록은 일치했다. 고정 평가 11세트의 FNc는 0, FPc는 1,712→1,708이다.
`가능한 한`은 뒤 의존 명사의 반환이 남아 고정 음성의 행 단위 집계에서는
계속 집계됐다. 교정 GSD 양성 9,298행의 전체 반환 범위는 일치했다.

| 고정 음성 Smart | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 제외 |
| --- | --- | --- | ---: |
| 기준선 | 0, 3,231, 50,077, 0 / 0, —, 0 | 1,428, 1,712, 50,050, 0 / 45.48, 100, 62.52 | 118 |
| 후보 | 0, 3,227, 50,081, 0 / 0, —, 0 | 1,428, 1,708, 50,054, 0 / 45.54, 100, 62.58 | 118 |

## 네이티브 형태 판정

`fe26a93b`와 `b2bac39f`의 release runner를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
비교했다. 입력은 [재현한 교정 GSD 양성과 고정 음성](../../tools/morph-compare/README.md#gsdpud-고정-감사-입력)이며
리소스의 SHA-256은 [Smart 기준선](2026-11-22-smart-performance-baseline.md)의
`087e0dbe`와 같다. 실행별 새 프로세스, 측정군별 워밍업 1회, 교대 측정
5회를 사용했다. 표는 중앙값 [최솟값, 최댓값]이다.

| 입력 | 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 63.31 [63.12, 63.56] | 28,598 [27,270, 29,366] | 0.0761 [0.0740, 0.0792] | 81.72 [81.31, 81.88] |
| 교정 GSD | 후보 | 63.39 [62.89, 65.29] | 28,865 [28,551, 29,223] | 0.0755 [0.0740, 0.0757] | 81.47 [81.41, 81.73] |
| 고정 음성 | 기준선 | 63.75 [63.06, 65.48] | 18,682 [16,735, 19,070] | 0.1332 [0.1300, 0.1407] | 127.88 [127.80, 128.11] |
| 고정 음성 | 후보 | 63.52 [62.01, 63.69] | 19,066 [18,981, 19,782] | 0.1303 [0.1248, 0.1315] | 127.75 [127.72, 127.94] |

처리량과 p95 중앙값 차이는 교정 GSD +0.93%·−0.79%, 고정 음성
+2.06%·−2.18%였고, 초기화와 최대 RSS 중앙값 차이는 절댓값 0.36% 이하다.
각 지표의 관측 범위가 겹쳐 작은 차이의 재현성 판정은 유보한다.
