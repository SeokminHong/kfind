# 지정사가 생략된 설명 종결형 ㄴ걸

고정 사전의 `-ㄴ걸/-은걸/-는걸/-던걸` 용례 44건을 비교했다.
`마찬가진걸`과 `어린앤걸`에는 복원 가능한 체언과 설명 종결형이
결합한다. `의산걸`, 명시적 지정사의 `인걸`, 동사의 `먹은걸`,
띄어 쓴 `먼 걸`을 대조했다.
[사전 표적 범위 검토](2026-11-13-dictionary-copula-nieun-extension-span.md)
