# GSD 장소 명사의 띄어쓰기

교정 GSD 9,300행에서 `방·집·교실·건물·실내·차` 뒤에
`안·밖`이 붙거나 한 칸을 사이에 두고 나오는 문장 4건을
대조했다. 실제 공간을 나타내는 `방안에 가둔다`를
`방 안에 가둔다`로 교정했다. 이미 띄어 쓴 `방 안의 악취`와
가족 내부의 갈등을 뜻하는 `집안싸움`은 그대로 두었다.
나머지 1건은 `주차 안내`였다.
[국립국어원 띄어쓰기 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=302502) ·
[문장 교정](../../tools/morph-compare/gsd-spatial-spacing-edits.tsv)

같은 #570 검색 실행 파일에서 `방`의 UTF-8 정답 범위가
76–85에서 76–79로 바뀌었다. 두 모드 모두 76–79를 반환했다.
계약 검토는 0건이다. 행렬은 TP, FP, TN, FN, 비율은 precision,
recall, F1 순서다.

| smart | 교정 전 | 9258, 0, 0, 42 | 100.00, 99.55, 99.77 | 9258, 0, 0, 42 | 100.00, 99.55, 99.77 |
| smart | 교정 후 | 9259, 0, 0, 41 | 100.00, 99.56, 99.78 | 9259, 0, 0, 41 | 100.00, 99.56, 99.78 |
| any | 교정 전 | 9062, 0, 0, 238 | 100.00, 97.44, 98.70 | 9062, 0, 0, 238 | 100.00, 97.44, 98.70 |

#421 비교군 1,113행에서 교정 후 `smart`는 정확 1,072행,
부분 15행, 누락 26행이다. `any`는 정확 948행, 부분 158행,
누락 7행이다. 검색 코드 변경이 없어 성능 측정을 생략했다.

```sh
node tools/morph-compare/apply-gsd-sentence-edits.mjs "$input" --spatial-spacing > "$corrected"
"$runner" boundary full-pos "$boundary" "$corrected" "$output"
```
