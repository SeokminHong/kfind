# 고유명사 내부의 미정렬 선두 명사

`트위터`의 `트위`를 명사로 질의하면 Smart가 사전의 전체 고유명사
분석과 별개로 `트`와 `위`를 조합해 반환했다. 완성된 고유명사
경계 안의 선두 명사는 정렬된 사전 성분이나 같은 범위에 독립
명사 분석이 있는 경우에 유지한다. 전체 고유명사, 조사 결합,
사전에 정렬된 `동대문시장`의 `동대문`, 별명으로 독립한 `트위는`
[0, 9), 생산적으로 결합한 `텃밭학교`의 `텃밭` [0, 6)을 확인했다.
MeCab-ko-dic에 전체 고유명사로 올라 있는 `유튜브에서`의 `유튜`
[7, 13)과 지정사 결합 `트위터다`의 `트위` [34, 40)도 대조했다.
[우리말샘 트위터](https://opendict.korean.go.kr/dictionary/view?sense_no=979539)

MeCab-ko-dic에서 독립 명사 분석이 없는 두 음절 이상 질의가
단일 `NNP` 항목 내부의 선두에 반환된 경우를 고정 음성 53,308행,
원문 GSD 9,335행과 등록 교정 GSD 9,298행에서 찾았다.
해당하는 두 행은 두 GSD 입력의 동일한 문장과 질의였으며
`트위` [35, 41)만 제거됐다. 총 258,541개의 고정·등록 반환 목록에서
등록 교정 GSD와 별도의 Smart GSD 비교 세트의 해당 행만 바뀌었다.
사전에 완성 고유명사가 없는 입력은 별도 판정이 필요하다.
대조 입력 `인스타그램에서`의 `인스타그` [0, 12)는 양쪽에서 반환됐다.

해당 문장을 원문과 띄어쓰기 원칙을 적용한 `소셜 네트워크 서비스`
표기로 각각 검사했다. 전문 용어는 붙여 쓸 수도 있다. 같은 14개
질의를 양쪽 표기에 실행한 결과, 각 입력에서 `트위` [35, 41)만
사라졌다. `페이스` [46, 55)와 다른 질의의 전체 반환 목록을 유지했다.
두 표기의 실험 입력 SHA-256은
`ce08a731583c21f348f4f253bbcce61323a4322641af9e5c42f4cfb95d8b4929`다.
[한글 맞춤법 제50항](https://www.korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0001)

등록 교정 세트에 이미 확인한 원문의 정답 판정을 적용하면 동일한
기준선 출력의 FPc가 2에서 3으로 바뀐다. 정답과 입력을 고정한
제품 비교에서는 3에서 2로, 원문 GSD는 12에서 11로 줄었다.
원문과 등록 교정 GSD의 추가 반환 미판정은 각각 603행 665범위,
119행 125범위다. 고정 음성의 양성 범위 1,207행과 제외 문장의
42행 38범위도 검증이 남아 있다.

macOS 26.6.2 arm64, Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다.
입력과 사전을 고정했다. 한 번씩 가동한 뒤 순서를 교대하며 새 프로세스로
5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 실행별 최근접

## WebAssembly

wasm-pack 0.15.0 release bundler 빌드의 원본 크기는
2,836,381 → 2,837,370바이트였다. `gzip -9nc`는 962,465 →
963,715바이트, `brotli -q 11 -c`는 711,027 → 709,694바이트였다.
양쪽의 사전 리소스는 같다. Node 26.11.1에서 component 없이 명시적
Smart 명사 질의를 거부하는 동작과 component 장착 시 전체 고유명사,
사전 성분, 미등록 독립 명사 및 두 음성의 전체 반환 범위를 확인했다.

```sh
wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release
```
