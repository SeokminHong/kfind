# 조건 연결형 야만

`끊다`로 `끊어야만`을 검색하면 `만`까지 반환한다. 사전 4,458건에서
`아야만/어야만/여야만/야만` 표제 11건과 별도 지정사형 `라야만` 3건을 점검했다.
`것이어야만`의 지정사 정답을 `이어야만`으로 교정했다. 교정 전에는 후보가
표적 10/11건을 두 모드에서 찾았다.
[표준국어대사전 -어야만](https://stdict.korean.go.kr/search/searchView.do?word_no=460875&searchKeywordTo=3)

행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서다.
사전은 계약 검토 0건으로 raw와 보정이 동일하다.
