# PUD 관형형과 용언 경계

일반 명사와 조사의 결합이 인명 분석과 경쟁하면 앞 어절의 관형형을 유지한다.
붙여 쓴 `-게 되다`, `-게 하다`에서는 어근·접미사·연결 어미와 뒤 용언을 확인한다.
`-기 위하다`에서는 명사형 어미와 뒤 용언의 완결 활용을 확인한다.

## 품질

PUD 양성 798건, GSD·PUD 음성 53,308건, 교정 GSD 9,298건, 사전 원본 및
보정본 각 4,458건, hard-negative 45건, KAIST dev 2,532건과 test 품사
명시·미지정 각 2,592건 및 KAIST 1,000건 표본 세 종의 ID와 반환 범위를
Smart·Any·Token에서 전수 비교했다.

Smart PUD에서 반환이 바뀐 15건을 원문과 대조했다. `큰 이유로` 1건,
`-게 되다` 3건, `-기 위하다` 10건이 정확한 범위로 반환됐다.
`pud:w01103022:5`는 같은 문장의 `사망하게된`에서 `된`이 반환됐고,
표적인 `인해몰락하게된`의 `된`은 남아 있다.

음성표에서 늘어난 네 행은 같은 문장·질의·품사가 PUD 양성표에도 있고
그 표의 정답 중 하나와 반환 범위가 일치한다. 기존 레이블로 채점한 원본·계약
FP는 각각 4건 증가했다. 대상은 `pud:n01023034:verb:되다`,
`pud:n01135002:adjective:크다`, `pud:w01103022:verb:되다`,
`pud:w01105054:verb:되다`다. 나머지 세트의 Smart 범위와 Any·Token의
전체 범위는 동일했다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1 순서다.
PUD는 양성의 정확한 바이트 범위를, KAIST는 정답 범위와의 겹침을 채점했다.
PUD 양성과 품사 미지정 KAIST test의 계약 검토는 0건이다. 음성은 반환
유무로 채점했으며 기존 계약 양성 35건을 적용했다.

| 입력 (Smart) | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| PUD 양성 798건 | 기준선 | 764, 0, 0, 34 / 100.00, 95.74, 97.82 | 764, 0, 0, 34 / 100.00, 95.74, 97.82 |
| PUD 양성 798건 | 후보 | 778, 0, 0, 20 / 100.00, 97.49, 98.73 | 778, 0, 0, 20 / 100.00, 97.49, 98.73 |
| GSD·PUD 음성 53,308건 | 기준선 | 0, 4069, 49239, 0 / 0.00, 0.00, 0.00 | 35, 4034, 49239, 0 / 0.86, 100.00, 1.71 |
| GSD·PUD 음성 53,308건 | 후보 | 0, 4073, 49235, 0 / 0.00, 0.00, 0.00 | 35, 4038, 49235, 0 / 0.86, 100.00, 1.70 |
| 품사 미지정 KAIST test 2,592건 | 양쪽 | 1285, 3, 1293, 11 / 99.77, 99.15, 99.46 | 1285, 3, 1293, 11 / 99.77, 99.15, 99.46 |

골드 925건과 walk/hang, workspace 테스트 634건, Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release의 Full POS
Smart에서 `d4583371`과 `372753c4`를 비교했다. 기준선 실행 파일의 소스
`9381027d`는 `d4583371`과 런타임 소스·리소스가 같다. 워밍업 1회 후 새
프로세스로 5회씩 실행하고 버전 순서를 교대했다. 표는 중앙값 [최솟값,
최댓값]이며 p95는 최근접 순위, RSS는 최대 상주 메모리다.
