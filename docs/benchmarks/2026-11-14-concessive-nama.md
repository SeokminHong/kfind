# 양보 연결형 나마와 으나마

교정 사전 4,458행에서 `나마`가 든 문장 10행을 확인했다.
양보 연결 어미가 질의 표적인 여덟 행에서 정확한 활용 범위를
복구했다. 다른 질의 두 행의 반환 범위는 동일하다. 보조사
`(이)나마`와 ㄹ 탈락 동사에 겹치는 고유명사를 대조했다. 고정
음성의 PUD `파나마 지협` 두 위치와 목적어가 있는 `옷을 파나마`를
각각 음성·양성 회귀로 검사했다. 지정사와 보조사가 같은 표면인
`이나마`는 지정사의 문맥 판정 범위에 추가하지 않았다.
[나마](https://krdict.korean.go.kr/m/eng/searchResultView?ParaWordNo=80167&nation=eng) ·
[으나마](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=80164)

RAM 32 GiB, 로컬 APFS SSD, Darwin 25.6.0, Rust/Cargo 1.97.0의
release 빌드로 비교했다. full POS `smart`에서 입력마다 워밍업
