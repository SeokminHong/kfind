# 명사형과 보조사가 줄어든 용언

교정 GSD에서 표면형이 `긴`으로 끝나는 8행과 품사 주석에서
`기+ㄴ` 또는 `기+는`이 이어진 4행을 대조했다. 합집합 9행에는
`-긴`으로 줄어든 용언 4행, 줄이지 않은 `삐끗하기는` 1행,
관형형 `긴`, `생긴` 2행, `담긴` 1행이 있다.
`any`에서 줄어든 용언 4행 모두 정확한 범위를 찾았다.
별도 대조 입력에서는 `멋있긴`, `맛없긴`, `재밌긴`, `재미있긴`,
`맛있기는`을 찾고 `맛이 있긴`을 `맛있다`로 반환하지 않았다.
[보조사 ㄴ](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=322610)

## 성능

Apple M1 Max, Darwin 25.6.0 arm64, Rust와 Cargo 1.97.0의 릴리스
빌드에서 작업 시작점 70a5d2d4도 비교했다. 기준선 실행 파일은
제품 소스가 동일한 938c01c7에서 빌드했다. 각 경계와 버전에서
새 프로세스로 워밍업 1회와 측정 5회를 실행했다. 측정 순서는
