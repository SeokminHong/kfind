# `-(으)ㄹ락 말락`의 사전 경로와 반환 범위

Smart 동사 `모다`에서 명사 `몰락`이 반환됐다. 사전의 `락/EC`를
미래 관형형 `몰`에 붙인 경로가 뒤 어절을 검사하지 않았다. 해당 결합은
`말락`을 확인하는 생성 경로에서 판정한다. 같은 표면의 동사 `몰다`,
`들리다`와 `녹다`의 정상 `-(으)ㄹ락 말락`, `울다`의 교대형 `울락`,
미래 관형형 `들릴 때`를 대조했다.
[국립국어원 한국어기초사전](https://krdict.korean.go.kr/vie/dicSearch/SearchView?ParaWordNo=70651&nation=vie) ·
[국립국어원 교육 어휘 목록의 명사 몰락](https://korean.go.kr/common/download.do?c_file_name=f8313ff7-b33b-43b6-a01e-a8af43eb6a1d.pdf&file_path=reportData)

고정 음성, 원본 GSD 양성, 교정 GSD 양성에서 `락`으로 끝나는 어절을
포함한 행은 각각 250행, 36행, 35행이다. 고정 12세트와 교정 GSD의
반환 목록 258,541개를 비교한 결과 아래 세 `모다` 질의만 달랐으며,
원본 GSD 양성 9,335행의 반환 목록은 일치했다.

## 네이티브 형태 판정

기준선 `e5346883`의 실행 소스는 `852cae48`과 같다. `525654fb` 후보와
같은 Cargo target에서 `cargo build --locked --release --manifest-path
tools/morph-compare/runner/Cargo.toml`로 빌드했다. 입력과 리소스의 체크섬,
기기, 빌드 도구 및 `measure-smart.py` 호출은 [실행 조건](2026-11-23-embedded-alternative-connectives.md#네이티브-형태-판정)과
