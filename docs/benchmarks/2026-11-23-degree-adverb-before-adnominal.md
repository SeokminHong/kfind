# 절 성분 뒤 관형형을 수식하는 정도 부사

`먹을 만한 것은 거의 없는 것이`에서 `것은`은 화제 성분이고 `거의`는
관형형 `없는`을 수식한다. PUD의 원문에서 `만한것은` 사이 공백을 복원한
문장에서도 기준선은 명사 `거`와 관형격 조사로 [45, 51)을 반환했다.
후보는 두 문장 모두에서 해당 명사 반환을 제거했다. `네 거의 낡은 덮개`와
`네가 준 거의 낡은 덮개`에서는 앞말이 의존 명사 `거`를 수식할 수 있으므로
기존 명사 반환을 유지했다. [한국어기초사전 거의](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=60090)

고정 음성의 명사 `거` 질의 95행을 살폈다. `거의`가 표적인 16행에서
한 행이 바뀌었다. 고정 12세트의 Smart·Token·Any와 교정 GSD의
전체 반환 목록 258,541개에서 이 한 범위가 바뀌었다. 원본 GSD 양성
9,335행의 반환도 대조했다.

| 고정 음성 53,308행 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 기준선 | 0, 3,128, 50,180, 0 / 0, 0, 0 | 1,418, 1,599, 50,148, 0 / 47.00, 100, 63.95 | 1,600 | 0 |
| 후보 | 0, 3,127, 50,181, 0 / 0, 0, 0 | 1,418, 1,598, 50,149, 0 / 47.02, 100, 63.96 | 1,599 | 0 |

교정 GSD는 [대명사 내부 명사 비교](2026-11-23-atomic-pronoun-nominal-tails.md)의
후보와 원본·계약 적중 행렬과 확정 FPc·FNc가 같다.

## 네이티브 형태 판정

`993070ed`와 `0f3ffa4f`의 release runner를 Apple M1 Max 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다.
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
`boundary full-pos smart INPUT OUTPUT`을 새 프로세스에서 워밍업 1회와
교대 측정 5회 실행했다. 입력·리소스 체크섬은
[공통 component 비교](2026-11-23-source-aligned-nominal-prefixes.md)와 같다.
값은 중앙값 [최솟값, 최댓값]이다.

| 고정 음성 | 기준선 | 63.399 [63.337, 65.191] | 18,090 [18,020, 18,252] | 0.1333 [0.1309, 0.1336] | 131,584 [130,752, 131,744] |

고정 음성 처리량은 0.05% 높고 p95는 0.53% 낮았다. 교정 GSD 처리량은
0.27% 높고 p95는 1.68% 낮았다. 두 입력 모두 처리량·p95 측정 범위가
겹쳤다. 고정 음성 초기화 중앙값은 0.196 ms 늘었다.
