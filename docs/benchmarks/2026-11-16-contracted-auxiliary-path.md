# 축약 연결형과 붙임 보조 용언

Smart에서 `써오셨다`의 `쓰다`와 `봐오셨다`의 `보다`가 누락됐다.
두 어절에서 앞부분은 질의 품사의 `용언 + EC`로 분석되고, 뒷부분은
보조 용언의 완결 활용이다. 기존 사전 경로와 활용 검증을 함께 사용했다.
긴 단일 용언이 어절을 끝까지 분석하는 `따라간`의 `따르다`와
`도와준다고`의 `돕다`는 그대로 제외했다.
[국립국어원 보조 용언 붙여쓰기 해설](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=44&qna_seq=332151)

## 품질

고정 입력 12개를 세 모드로 실행한 249,243행에서 입력 ID, 리소스
해시, 반환 바이트 범위를 비교했다. 원본 사전 양성의 `도와줍시다`만
Smart에서 `20..35`가 추가됐다. 기존 계약 검토를 적용한 사전 양성에는
같은 반환 범위가 유지됐다. 고정 음성의 Smart 반환 범위와 Any·Token의
반환 범위는 모두 동일했다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.
사전 양성은 정확한 범위로, 고정 음성은 반환의 유무로 채점했다.

| 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) | 기존 검토 |
| --- | --- | --- | --- | --- |
| 사전 양성 Smart 4,458건 | 기준선 | 4424, 0, 0, 34 / 100.00, 99.24, 99.62 | 4458, 0, 0, 0 / 100.00, 100.00, 100.00 | 57 |
| 사전 양성 Smart 4,458건 | 후보 | 4425, 0, 0, 33 / 100.00, 99.26, 99.63 | 4458, 0, 0, 0 / 100.00, 100.00, 100.00 | 57 |
| 교정 GSD Smart 9,298건 | 양쪽 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 0 |
| 고정 음성 Smart 53,308건 | 양쪽 | 0, 4028, 49280, 0 / 0.00, 0.00, 0.00 | 156, 3872, 49280, 0 / 3.87, 100.00, 7.75 | 156 |

골드 925건과 walk/hang, workspace 테스트 639건, 포맷과 Clippy를
통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`b9a88d79`와 `2dc4f223`을 비교했다. 두 입력마다 새 프로세스로
워밍업 1회와 측정 5회를 실행하고 기준선과 후보의 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD Smart | 기준선 | 60.094 [59.912, 61.190] | 29,560 [28,660, 30,937] | 0.07408 [0.07133, 0.07663] | 81.422 [81.000, 81.438] |
| 교정 GSD Smart | 후보 | 60.626 [59.708, 62.045] | 29,632 [28,541, 30,842] | 0.07358 [0.07146, 0.07646] | 81.234 [80.859, 81.656] |
| 고정 음성 Smart | 기준선 | 60.029 [59.859, 60.698] | 19,376 [18,846, 19,498] | 0.12904 [0.12837, 0.12929] | 127.922 [127.875, 128.016] |
| 고정 음성 Smart | 후보 | 60.290 [59.803, 60.806] | 19,481 [19,281, 19,648] | 0.12800 [0.12683, 0.12913] | 127.797 [127.594, 128.734] |

처리량 중앙값은 교정 GSD에서 +0.24%, 고정 음성에서 +0.54%였다.
p95는 각각 −0.68%, −0.81%였으며 네 지표의 측정 범위가 겹쳤다.
