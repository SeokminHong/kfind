# 품사 미지정 용언과 수량 검색

사전의 용언에서 `-아/어` 연결형을 재현할 수 있으면 해당 연결형과
`지다`가 결합한 품사 미지정 질의를 동사로 분석한다. 내장 사전에는
한국어기초사전 66877의 `앞다투다`를 수록한다. 고정 XML의 활용 항목은
`앞다투어`, `앞다퉈`, `앞다투니`다.

Smart는 구조 사전이 확인한 숫자·단위·조사 경계를 유지한다. 붙여 쓴
수량 관형사 뒤에서 단위·조사 분석이 완결되면 관형사를 반환한다.
`여러분이`, `여러분의`, `여러모로`의 체언·부사 분석을 대조했다.

## 품질

KAIST 품사 미지정 test 2,592건과 1,000건 표본, 품사 명시 dev/test
2,532/2,592건과 각각 1,000건 표본, PUD 양성 798건, 교정 GSD
9,298건, 사전 원본·보정 입력 각 4,458건, GSD·PUD 음성 53,308건,
hard-negative 45건의 ID와 반환 범위를 세 모드에서 전수 비교했다.

품사 미지정 test의 `길어지다`, `세워지다`, `받아들여지다`, `앞다투다`는
세 모드에서 반환됐다. Smart는 `수미터`, `6월에는`, `2킬로미터`에서
각 수량·단위 범위도 반환했다. 1,000건 표본에서 바뀐 네 행은 test와
겹치는 사례다. 다른 입력의 반환 범위는 유지됐다.

KAIST는 반환이 정답 범위와 겹치면 적중으로 채점한다. 다음 두 입력의
계약 검토는 0건이다. 행렬은 TP, FP, TN, FN 순서다. 비율(%)은
precision, recall, F1 순서다.

## 성능

기준선 `a1b34e87`과 후보 `05870bb3`을 Apple M1 Max arm64, macOS
26.6.2, Rust/Cargo 1.97.0 release의 Full POS에서 비교했다. 기준선
실행 파일의 빌드 소스 `372753c4`는 `a1b34e87`과 런타임 소스·리소스가
같다. 워밍업 1회 뒤 새 프로세스로 5회씩 실행하고 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위, RSS는 최대 상주 메모리다.
