# 정답 검증의 문맥 대조

`verify-gold`에서 반환이 없어야 하는 여덟 위치를 원문 그대로 보존하고,
같은 질의가 성립하는 대조문을 연결했습니다. 품사와 UTF-8 표적 범위를
같이 검사했습니다. [대조 입력](../../tools/morph-compare/verify-gold-context-cases.jsonl)

- `병원으로 가세요`와 `숫돌로 가세요`의 조사 구조는 같습니다.
  앞 명사가 목적지 또는 도구를 가리키는지에 따라 활용의 표제어가 달라집니다.
- `한국 내`와 `지역 내`는 앞 명사의 범위를 나타냅니다. 대조문은 뒤
  명사를 꾸미는 소유 대명사의 해석을 보여 줍니다.
- `재산을 가지지 않았다`와 `산길을 가지지 않았다`는 목적격 조사와
  술어 표면이 같으며, 목적어가 소유 대상인지 이동 경로인지가 다릅니다.
- `약속에 늦죠`의 `에`는 동사의 일정 보어를 표시합니다. 형용사
  대조문에서는 시계가 기준 시각보다 늦거나 특정 시간에 늦습니다.
  [동사 문형](https://krdict.korean.go.kr/m/eng/searchResultView?ParaWordNo=61181) ·
  [형용사 문형](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=64526)

기준선 `7a0f9188`과 검색 코드가 같은 full POS 실행 파일로 두 경계를
검사했습니다. 두 경계 모두 양성 8건의 정확한 범위를 반환했고 음성
8건에서도 표적을 반환했습니다. 행렬은 TP, FP, TN, FN 순서이며 비율은
precision, recall, F1입니다. 기대값은 원본 검증과 동일하며 계약 검토는
0건입니다.

| 경계 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- |
| smart | 8, 8, 0, 0 | 50.00, 100.00, 66.67 | 8, 8, 0, 0 | 50.00, 100.00, 66.67 |
| any | 8, 8, 0, 0 | 50.00, 100.00, 66.67 | 8, 8, 0, 0 | 50.00, 100.00, 66.67 |

```sh
"$runner" boundary full-pos "$boundary" tools/morph-compare/verify-gold-context-cases.jsonl "$output"
```
