# 인용부호에 붙은 조사 고의 검색 경계

짝이 확인된 닫는 인용부호에 `고`가 붙으면 Smart는 그 범위를
인용 조사로 다룬다. 인용문 안의 `고 씨`와 부호에서 띄어 쓴 `고 씨`는
명사로 검색할 수 있다.
[국립국어원 구문 분석 말뭉치 지침](https://www.korean.go.kr/common/download.do?c_file_name=5c0801ae-9e2b-4a68-a2e8-e331f7b3e495.pdf&file_path=reportData)

## 품질

기준선 `586227bf`와 후보 `654be4b6`에서 고정 12세트 83,081행을
Smart·Any·Token으로 실행했다. 249,243개 결과 가운데 Smart의 명사
`고` 오탐 범위 25개가 사라졌다. GSD의 23행과 PUD의 2행에서 각각
하나씩 제거됐다. 다른 오탐이 남은 3행이 있어 FPc는 22건 줄었다.

기준선에서 명사 `고`의 계약 음성 오탐은 43행 48범위였다. 변경 뒤
21행 23범위가 남았다. 그중 `pud:w01117034:noun:고`는 여는 따옴표가
앞 어절에 붙어 있어 인용부호의 짝을 확인하지 못했다. 다른 잔여
범위는 어절 내부나 독립 어절에 있다.

계약 검토를 동일하게 적용한 고정 11세트의 Smart FNc는 0건,
FPc는 2,414건에서 2,392건으로 줄었다. 추가 회귀는 양성 4행,
음성 4행이며 계약 검토는 0건이다. 기준선은 양성 2행에 오탐
범위를 하나씩 더 반환했다. 후보는 양성과 음성의 전체 범위를 맞췄다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1
순서다. 고정 음성의 계약 검토는 1,255건이다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 추가 회귀 8행 | Smart 기준선 | 4, 4, 0, 0 / 50.00, 100.00, 66.67 | 4, 4, 0, 0 / 50.00, 100.00, 66.67 |
| 추가 회귀 8행 | Smart 후보 | 4, 0, 4, 0 / 100.00, 100.00, 100.00 | 4, 0, 4, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3666, 49642, 0 / 0.00, —, 0.00 | 1255, 2411, 49642, 0 / 34.23, 100.00, 51.01 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3644, 49664, 0 / 0.00, —, 0.00 | 1255, 2389, 49664, 0 / 34.44, 100.00, 51.23 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 교대로
5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했다.
p95는 최근접 순위로 구했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 63.087 [62.716, 64.264] | 29,700 [28,333, 30,029] | 0.07279 [0.07196, 0.07654] | 80.969 [80.953, 81.297] |
| 교정 GSD | 후보 | 62.278 [61.884, 62.395] | 29,806 [28,950, 30,025] | 0.07233 [0.07204, 0.07517] | 81.031 [80.922, 81.250] |
| 고정 음성 | 기준선 | 63.337 [62.459, 63.632] | 19,264 [19,135, 19,286] | 0.12929 [0.12913, 0.13067] | 127.516 [127.406, 127.563] |
| 고정 음성 | 후보 | 62.730 [62.013, 62.973] | 18,984 [16,764, 19,382] | 0.13250 [0.12867, 0.13925] | 127.531 [127.266, 128.500] |

교정 GSD의 처리량 중앙값은 +0.36%, p95는 −0.63%다.
고정 음성은 처리량 중앙값이 −1.46%, p95가 +2.48%였다.
두 입력에서 처리량과 p95의 관측 범위는 겹친다.

## 재현

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0,
Node.js 26.11.1에서 `cargo build --release --locked --manifest-path
tools/morph-compare/runner/Cargo.toml`로 빌드했다. 각 실행에는
`/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`을
사용했다. [평가 입력과 리소스 체크섬](2026-11-16-auxiliary-competition.md#재현)
