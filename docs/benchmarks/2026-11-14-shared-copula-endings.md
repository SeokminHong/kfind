# 지정사 어미 정의 공유

지정사와 `아니다`의 공통 어미 28개를 검색기와 참조 구현이 같은 정의에서 읽는다.
별도 대조에서 `이군요`의 보조사 `요` 규칙 경로와 범위, `아니올시다`의 범위,
`이올시다말`과 `먹올시다`의 거부를 확인했다. 기존 `verify-gold` 925건과 stress도 통과했다.

full POS의 사전 4,458건, 교정 GSD 9,298건, 고정 음성 53,308건과
KAIST test query matrix 2,592건에서 기준선과 후보의 UTF-8 반환 범위가 모두 같았다.
행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.
양성은 정확한 바이트 범위로, 음성은 반환 유무로 판정했다. 사전과 GSD의 계약 검토는
0건이며, 고정 음성에는 현재 저장소에서 원문과 일치하는 계약 검토 34건을, KAIST에는
입력에 포함된 검토 22건(제외 3건)을 적용했다. 두 버전의 값은 같다.

## 성능

기준선 `65c9f34c`, 후보 `db36c2fa`를 Apple M1 Max arm64, RAM 32 GiB,
APFS SSD, Darwin 25.6.0, Rust/Cargo 1.97.0 release에서 비교했다. full POS
`smart`에서 입력마다 새 프로세스로 워밍업 1회 후 5회씩 순서를 교대했다.
p95는 nearest-rank이며 RSS는 프로세스 최대 상주 메모리다. 표는 중앙값 [최솟값, 최댓값]이다.

사전·GSD의 처리량 중앙값은 −0.34%, −0.65%, p95는 +1.51%, +0.71%였다.
고정 음성은 첫 측정과 역순 재측정에서 각각 −3.23%, −1.98%였고,
p95는 +1.14%, +1.05%였다. 관측 범위는 겹치지만 중앙값은 두 번 모두
같은 방향으로 움직였다. 이 결과는 질의 준비와 문장 검색을 포함하는 러너 비용이다.
