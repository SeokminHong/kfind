# GSD 사전 피동 관계의 정답 범위

고정 사전 자료의 피·사동 원형 221개를 원문과 교정문 GSD의
미판정 질의에 대조했다. 해당 원형을 질의한 원문 7행과 교정문
3행에서 다른 토큰의 사전 표제어와 UTF-8 범위가 맞는 것은
양쪽의 s42:3과 s42:18이었다. 원문과 교정문의 문장은 같다.

두 행의 동사 `덮다` 질의는 능동 관형형 `덮은 [23, 29)`과
`덮은 [152, 158)`을 검색한다. 같은 문장의 s42:9는 `덮인
[77, 83)`을 `덮이+ㄴ`으로 주석했다. 한국어기초사전에서
직접 확인한 피동 관계이므로 이 범위도 기본 활용 검색의 정답이다.
다른 6개 입력·행 조합에는 이 사전 관계를 적용할 근거가 없다.
[한국어기초사전 덮다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=67468)
· [검색 사양](../../specs/matching.md#36-확장-경계와-품사를-분리한다)

## 평가

동일 입력과 리소스로 실행한 Smart full-pos `6b1fd0c7`의
출력을 두 계약 검토 버전으로 채점했다. 위 세 범위를 모두
반환했다. 고정 음성의 평가 결과는 이전 검토와 같다.
[입력·리소스와 이전 결과](2026-11-23-gsd-standalone-noun-spacing-review.md#평가)

행렬 순서는 TP, FP, TN, FN이며 정밀도·재현율·F1의 단위는 %다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc | 검토 / 제외 |
| --- | --- | --- | ---: | ---: | ---: |
| 원문 GSD | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,654, 6, 82, 559 / 99.93, 93.93, 96.84 | 15 | 559 | 583 → 585 / 34 |
| 교정 GSD | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 5 | 0 | 133 → 135 / 0 |

미판정 추가 반환은 원문 525행 585범위에서 523행 583범위로,
교정문 102행 108범위에서 100행 106범위로 줄었다.
