# 축약 지정사와 겹치는 합성명사 성분

`가족여행에서`의 `여`가 축약 지정사 표면과 겹쳐 `가족`의 후보를 일찍 버렸습니다.
기존의 완성 합성명사 경로가 확인되면 첫 성분을 반환합니다. 실제 지정사 구문
`가수였다`에서는 `가수`의 기존 범위를 유지합니다.
[검색 사양](../../specs/matching.md) · [회귀 예문](../../data/fixtures/ud_morphology_cases.tsv)

기준선은 `e580339151703f763027df36dca5ffaea53d3b33`이며 실행 파일을 빌드한
`fda2a4b5963dc8fa74198d1f9a8f4f598c141438`와 제품 코드가 같습니다. 후보는
`96e6ed197f72f5cd71637e92335aa76a4b5e4185`입니다. 행렬은 TP, FP, TN, FN,

0건입니다. GSD·PUD 음성의 기존 계약 검토 26건을 유지했습니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust 1.97.0에서 같은 release 설정과 리소스를
사용했습니다. 시작점 `70a5d2d4b76666a8ec1e2c5a8c8424a547af82aa`, 기준선, 후보의
실행 순서를 순환했습니다. 새 프로세스에서 입력별 warm-up 1회와 측정 5회를 수행했습니다.
처리량은 평가 시간으로 계산하고 p95는 nearest-rank, RSS는 최대 상주 메모리를 사용했습니다.
값은 중앙값 [최솟값, 최댓값]입니다.
