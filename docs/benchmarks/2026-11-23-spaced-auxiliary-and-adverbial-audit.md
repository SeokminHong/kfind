# 띄어 쓴 보조 동사와 논항 사이 수식어

`c0c158ae..61dbd52d`의 다섯 변경에서 형태 판정과 원문·교정 평가를
대조했다. #1080에서 복구한 `말해준다`의 `준다` [30, 36)과
`전해줬다`·`설명해 주었다`의 보조 동사 범위가 반환됐다.
[붙임 보조 용언의 검증 기록](2026-11-23-derived-auxiliary-tail.md)

- `버스를 타고 가 가지고 늦지 않았다.`의 `가다`에는 [17, 20)만
  해당한다. 같은 절의 방향 논항이나 목적격 성분을 취하는 선행
  연결형으로 왼쪽 `가`의 이동 해석을 확인했다. 뒤의 `가지고`,
  `가지고도`, `가지고는`에는 두 번째 `가다` 범위를 반환하지 않는다.
  [국립국어원 보조 동사 가지다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=90&pageIndex=1&qna_seq=329254)
- 사전 부사와 형용사 `-게`가 이어지면 같은 줄에서 앞의 주격 성분을
  확인한다. 사전 어간과 파생 경로를 함께 검사해 `일정하게`·`강하게`를
  수식어로 인식한다. 동사 어간이 확인되는 `소리가 들리게 나는 기계를
  켰다.`의 대명사 [20, 26)은 보존했다.
- `수는 분명히 있었다`처럼 가능성 의존 명사와 술어 사이에
  수식어가 있으면 그 너머의 종결 술어를 검증한다.

세 소리 주어, 네 수식어 배열, 네 이동 논항, 세 보조사 표기와 대조군의
54개 전체 반환 범위를 검증했다. 기준선의 오반환 28개가 제거됐다.
고정 회귀 10건에 정확한 양·음성 반환 범위를 기록했다. 별도 탐색
24건은 띄어 쓰기, 붙여 쓰기, 인용, 가능성과 안긴 관형절을 대조했다.
`가가지고`의 본용언 누락과 `느낌이 나는 무늬를 쓰는 것도`에서
대명사로 반환되는 경로는 관측 결과에 남았다.

두 입력의 SHA-256은 차례대로
`2c1c6fa6813a2f0341899d7010e8400db7e6c1bf36a7fa73eb0a50e26a055732`,
`533c8a5fae6c1e504ff4387502a6293824672a4772b968bc97c2eee2f67e7cdd`이다.

## 네이티브 성능

Python 3.14.8에서 `61dbd52d`와 `e2f45e37`의 release를 비교했다.
한 번씩 가동한 뒤 순서를 교대하며 새 프로세스로 5회 측정했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 각 실행의 최근접 순위다.
[입력과 사전 체크섬](2026-11-23-motion-and-nominal-focus-audit.md#성능)

scripts/benchmark-run.sh run --name morphology-audit-recheck-1084 -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
