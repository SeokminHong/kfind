# GSD·PUD 음성표의 양성 정렬과 연결형 오탐

## 원문 대조

고정 음성 53,308행과 PUD 양성 798행, 교정 GSD 양성 9,298행을
원문·질의·품사로 대조했다. 겹친 123행 중 24행은 기존 검토에 있고 99행을
추가로 검토했다. 그중 PUD 동사 79행은 양성표와 음성표의 표면형·태그·문장
ID가 같으며 CoNLL-U 원문의 표면형·태그·표제어와 일치한다. 나머지 20행은
문장의 다른 위치에 실제 질의 대상이 있거나 교정 GSD에서 원문의 품사·표제어
정렬을 바로잡은 경우다. 각 양성의 바이트 범위를 따로 확인했다.

음성표의 원본 레이블을 보존했다. 계약 검토는 원문 SHA-256, ID, 질의,
품사와 레이블이 모두 맞을 때만 적용했다. 반환이 하나라도 있으면 음성 적중인
행 단위 채점과 반환 범위의 정확성은 별개다. 예를 들어 `보고한것으로 볼 때`는
`볼`이 정답이고 앞의 `보고`는 오탐이었다.

## 검색 결과

Smart는 어절 앞의 동사 `-고` 후보가 더 긴 명사·어근과 `-하-`가 이루는
완결 파생 용언 안에 있으면 해당 후보를 거른다. 파생 용언의 관형형에 명사가
붙은 경우와 별도 어절로 쓰인 동사 연결형을 대조했다.

[기존 12개 입력](2026-11-15-nominal-prefix-competition.md#품질)의 세 모드
249,243행에서 ID·리소스 해시·반환 바이트 범위를 확인했다. Smart에서
고정 음성 3행의 잘못된 반환이 사라졌다. 두 문장은 적중에서 벗어났고, 다른
한 문장은 `볼`이 남아 양성 적중을 유지했다. PUD 양성표의 같은 문장에서도
`볼`의 정확한 반환 범위가 유지됐다. 다른 행과 모드의 반환은 동일했다.

다음 표는 고정 음성의 행 단위 결과다. TP, FP, TN, FN 순이며, 비율(%)은
precision, recall, F1 순이다. 코드 효과는 같은 검토 156건을 적용한
기준선과 후보를 비교했다.

| 모드 | 코드 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 4030, 49278, 0 / 0.00, 0.00, 0.00 | 156, 3874, 49278, 0 / 3.87, 100.00, 7.45 |
| Smart | 후보 | 0, 4028, 49280, 0 / 0.00, 0.00, 0.00 | 156, 3872, 49280, 0 / 3.87, 100.00, 7.46 |
| Any | 양쪽 | 0, 17622, 35686, 0 / 0.00, 0.00, 0.00 | 156, 17466, 35686, 0 / 0.89, 100.00, 1.75 |
| Token | 양쪽 | 0, 2863, 50445, 0 / 0.00, 0.00, 0.00 | 118, 2745, 50407, 38 / 4.12, 75.64, 7.82 |

기준선에 기존 검토 57건을 적용하면 계약 FP는 Smart 3,973건, Any
17,565건, Token 2,835건이다. 검토 추가로 Token의 계약 FN은 29건에서
38건으로 드러났으며 양쪽 검색 결과는 동일하다. 새 PUD 동사 검토 중
Token이 놓친 6행은 모두 다른 용언과 한 어절로 붙어 있다.

골드 925건과 walk/hang, workspace 테스트 636건, 포맷과 Clippy,
benchmark Python 테스트 82건과 계약 대조 테스트 2건을 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release,
Full POS Smart에서 기준선 `d19861d4`와 후보 `a38389e6`을 비교했다.
기준선 실행 파일은 제품 코드와 리소스가 동일한 `b3158ce8`에서 빌드했다.
워밍업 1회 후 새 프로세스로 5회씩 실행하고 기준선과 후보의 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이다. p95는 최근접 순위, RSS는 최대 상주 메모리다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| PUD 양성 | 기준선 | 61.293 [60.893, 62.306] | 14461 [14233, 14705] | 0.13467 [0.13367, 0.13971] | 63.688 [63.563, 63.813] |
| PUD 양성 | 후보 | 61.821 [61.525, 62.960] | 14561 [13959, 14686] | 0.13742 [0.13396, 0.13938] | 63.859 [63.813, 64.219] |
| 교정 GSD | 기준선 | 61.359 [60.746, 61.746] | 28954 [28830, 29767] | 0.07533 [0.07371, 0.07596] | 80.953 [80.906, 81.047] |
| 교정 GSD | 후보 | 61.568 [61.260, 62.317] | 28986 [27426, 29490] | 0.07604 [0.07475, 0.08050] | 81.313 [81.125, 81.594] |
| GSD·PUD 음성 | 기준선 | 61.829 [61.064, 62.900] | 19282 [18808, 19567] | 0.12908 [0.12758, 0.13054] | 127.438 [127.406, 128.156] |
| GSD·PUD 음성 | 후보 | 61.840 [61.622, 63.036] | 19326 [19239, 19454] | 0.12904 [0.12850, 0.12929] | 127.547 [127.438, 128.453] |

PUD, 교정 GSD, 고정 음성의 처리량 중앙값 증감은 각각 +0.69%, +0.11%,
+0.23%이고 p95 증감은 +2.04%, +0.94%, −0.03%다. 세 입력에서 처리량과
p95 범위가 각각 겹쳤다. 교정 GSD의 RSS 중앙값은 0.359 MiB 늘었고,
측정 범위는 겹치지 않았다.
