# 활용 규칙 식별자의 할당 비용

고정 음성 53,308건에서 질의 준비·매처 생성·검색을 각각 계측했다.
동사 질의 28,425건 가운데 `7efa7ec6`에서 전체 시간이 가장 긴
1,422건을 골라 시작점 `70a5d2d4`의 같은 행과 비교했다.
워밍업 1회 뒤 5회 실행에서 행별 중앙값을 산출했다.

| 측정 항목 | 시작점 중앙값 | 7efa7ec6 중앙값 |
| --- | ---: | ---: |
| 프로그램 수 | 92 | 215 |
| 질의 준비 ms | 0.09917 | 0.12204 |
| 매처 생성 ms | 0.02125 | 0.01963 |
| 검색 ms | 0.01042 | 0.01479 |

활용 앵커와 후속 어미의 내장 식별자는 정적 문자열을 빌려 쓰고
외부에서 읽은 식별자는 문자열을 소유한다. 두 경우 모두 문자열 값으로
비교한다. 형태 규칙, 질의 프로그램 수와 반환 범위는 같다.

## 품질

고정 사전 smart·any 8,916건, GSD 9,298건, 음성 53,308건,
KAIST dev 2,532건과 test 2,592건의 반환 범위가 모두 일치했다.
Raw 및 계약 보정 결과는 [사전 보고서](2026-11-14-concessive-giroseoni.md#품질)와
[고정 입력 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

계측을 제거한 시작점 `70a5d2d4`, 기준선 `7e00290a`와
후보 `bc6ca9bc`를 비교했다. 기준선과 후보의 런타임 소스 및 형태
리소스는 측정 빌드 `37047d14`와 `245c909d`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서는 순환했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접
순위, RSS는 최대 상주 메모리다.

## 재현

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name borrowed-predicate-rule-ids -- zsh
/usr/bin/time -l "$runner" boundary full-pos "$boundary" "$input" "$output"
```

질의 준비 종료는 `compile_query` 반환 직후, 매처 생성 종료는
`MorphMatcher` 생성 직후, 검색 종료는 `find_all_spans` 반환 직후에
측정했다. 프로그램 수는 계획의 각 atom에 속한 프로그램의 합이다.
