# 조건과 한정 수량의 한

`가능한 한 빠른 시일`에서 `한`은 조건의 범위를 나타내는 의존 명사다.
`오직 한 번의 행동만`의 `한`은 단위 명사를 수식하는 수 관형사다.
앞의 조건·한정 표현과 뒤의 용언·수량 구성을 확인한다. `증언을 한
목격자`의 동사 범위와 `가능한 한 가지 방법`의 수 관형사 범위를 보존했다.
[국립국어원 가능한 한](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=9116) ·
[한국어기초사전 단](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=29733)

UD 2.18 GSD·PUD test의 `하다` 고정 원본 405행에서 독립된 `한`을 찾은
양성 8행과 음성 62행을 비교했다. 고정 12세트와 교정 GSD의 반환 목록
258,541개에서 두 문장의 결과가 달라졌다. 고정 음성의 `가능한 한` [178, 181)과
원본·교정 GSD의 `오직 한 번` [123, 126)이 빠졌다. 같은 문장의 동사 `할`
[144, 147)은 검출됐다. `한 유닛`, `한 턴` 및 다른 문장의 `한 신입사원`은
동사 질의에 추가 반환으로 남는다.

고정 음성의 계약 제외는 141행이다. 원본·교정 GSD는 각각 적중 행렬과
확정 오탐 행 수가 같고, 확정 추가 범위 수가 두 입력에서 각각 4개에서
3개로 줄었다. [원본·교정 정답 범위 검토](2026-11-22-reviewed-range-scoring.md)

`c81739dc`와 `94686f70`의 release runner를 Apple M1 Max 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다.
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
