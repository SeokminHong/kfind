# PUD 범위 의존 명사 내의 표적

UD 2.18 GSD·PUD test에서 독립 `내`와 `내가·내에·내의·내도·내는·내를`로
시작하는 토큰을 찾아 각각 5곳과 28곳을 확인했다. 고정 음성의 명사 `내` 질의는
92행이고 검색 조건에 해당하는 원문 토큰이 있는 행은 GSD 2행과 PUD 26행이었다.

PUD에서 11행의 `내`는 `미국·직장·발칸반도·구조·지역·사원·해머스미스·정당·카푸아`
등 앞 명사가 정하는 공간 또는 소속 범위의 안을 나타낸다. 해당 토큰은 원문에서
별도 어절이며, PUD 표제어가 비어 있어 고정 음성에 들어갔다. 이미 명사로 검토한
격조사 결합은 유지했다. 대명사 `내가`, 뒤 명사를 수식하는 `내`, `자리를 하나
내줄 것이다`의 동사 어간은 범위 명사에 포함하지 않았다.
[국립국어원 범위 의존 명사 내의 쓰임](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=9201&mn_id=46&pageIndex=1)

## 품질

`b6caa522`의 제품과 같은 Smart runner에서 11행 모두 등록한 원문 바이트 범위만
반환했다. 고정 11세트의 FNc는 0이고 FPc는 1,723→1,712다. 고정 음성
53,308행의 원본 반환 범위는 동일하다.

| --- | --- | --- | ---: |
| 기준선 | 0, 3,231, 50,077, 0 / 0, —, 0 | 1,417, 1,723, 50,050, 0 / 45.13, 100, 62.19 | 118 |
| 검토 후 | 0, 3,231, 50,077, 0 / 0, —, 0 | 1,428, 1,712, 50,050, 0 / 45.48, 100, 62.52 | 118 |
