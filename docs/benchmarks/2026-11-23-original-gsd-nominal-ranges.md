# 원문 GSD 체언 범위 검토

[기존 체언 범위 주석](../../tools/morph-compare/gsd-aligned-nominal-spans-annotations.tsv)의
12행 전체와 같은 문장의 `국제반` 한 행을 원문에서 검토했다.
합성 표현의 첫 명사 또는 축약 지정사 앞 명사만 질의하지만 원본
정답은 뒤 성분과 조사·어미를 포함한 어절 전체였다. 직접 인용의
`북남`과 질문의 `-야`를 유지했다. 원문의 품사와 질의도 유지했다.
[기존 교정 검토](2026-11-14-gsd-aligned-nominal-spans.md)
· [국립국어원 의문형 종결 어미](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=328460)

[원문별 근거](../../tools/morph-compare/contract-contrast-evidence.jsonl)에
질의가 문장 안에서 유효한 모든 UTF-8 범위와 띄어쓰기·문장부호를
보완한 대조문을 기록했다. `기독교` 세 곳과 `국제` 두 곳을
각각 같은 문장의 정답으로 확인했다. 원문, 짧은 대조문, 문장 전체를
다듬은 대조문의 39개 질의에서 검토한 범위와 반환이 일치했다.
대조 입력 SHA-256은
`fc770413b27c38e3d344b7df10c6d39c62c8b795b770bca546603170fd6de798`다.

동일한 `05db4873` 제품 검색 출력을 두 정답 기준으로 채점했다.
원문 출력 SHA-256은
`9a481e0bdf3c23a048c3124e634fe2dbec267c784f72c815bc6c4718bbdf6640`다.
행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 양쪽 | 0, 3,038, 50,270, 0 / 0, 0, 0 | 1,426, 1,498, 50,236, 0 / 48.77, 100, 65.56 | 1,499 | 0 |
| 원문 GSD 기존 검토 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,639, 6, 82, 605 / 99.93, 93.46, 96.58 | 13 | 605 |
| 원문 GSD 추가 검토 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 592 / 99.93, 93.60, 96.66 | 13 | 592 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

원문 FNc 13건 감소는 정답 범위 검토의 효과다. 원문에서 추가
반환 미판정은 568행 630범위에서 553행 613범위가 됐다.
등록한 13행과 같은 원문·질의의 `기독교` 형제 행 두 곳에도
정답 근거가 적용됐다. 교정 GSD는 104행 110범위가 남아 있다.

```sh
"$runner" boundary full-pos smart "$input" "$output"
python3 tools/morph-compare/score-ud-audit.py --residual "$input" "$output"
```

평가 근거만 바꿨으므로 제품 성능 측정을 생략했다.
