# 원문 GSD 목적격 합성 명사의 정답 범위

원문 GSD 9,335행을 `11b5576d`의 Smart full-pos로 실행한 결과에서
`NNG+NNG+JKO`로 주석된 계약 누락 54행을 전수 확인했다. 표준국어대사전
2026-07-05 XML, 우리말샘 2026-07-02 XML, MeCab-ko-dic의 전체 구문과
현대 원문의 문맥을 대조했다. 원문에 쓰인 `정상회의를`과 `기준금리를`처럼
조사가 합성 명사 전체에 붙을 때 첫 성분의 정답은 조사 앞 전체 어절이
아니라 명사 성분의 UTF-8 범위다. `버섯칼국수를`의 `버섯` [14, 20)과
다른 위치의 `버섯과` [80, 89)는 두 동일 질의에서 모두 정답이다.

22행의 명사 성분 범위를 독립적으로 확인했다. 그중 20행은 이미
해당 범위를 반환한다. `전공과를`의 `전공` [99, 105)과 `군복무를`의
`군` [40, 43)은 실제 누락이다. 등록 교정 세트에서 첫 행은 전체 명사
`전공과`를 질의하고 둘째 행은 띄어 쓴 `군 복무`에서 `군`을 질의한다.
등록 교정 세트에서 각각 [99, 111), [40, 43)을 반환했다.
[표준국어대사전 전공과](https://stdict.korean.go.kr/search/searchView.do?word_no=476351),
[우리말샘 군 복무](https://opendict.korean.go.kr/dictionary/view?sense_no=840051)

`쿠사나기 사이슈`의 `사`와 `지정서를`의 `지`는 독립 명사로 분절되지
않으며 두 질의 모두 반환이 없다. 나머지 30행은 원문 표기에서 정확한
분절을 확정하지 못했다. 띄어 쓴 표제어, 차용어의 내부 구조, 사전 표제어의
뜻과 다른 원문 용례가 포함된다. `버섯과`의 별도 원문 행에도 동일한 두
범위를 기록했다. 원본 데이터와 출처는 검토 자료에 보존했다.
[SNK 공식 인물 소개](https://www.snk-corp.co.jp/us/games/kof-portal/characters/),
[교육부 펠로우 지정서 수여 자료](https://www.moe.go.kr/upload/brochureBoard/1/2016/12/1482215029877_331906456945202.pdf),

## 원문과 교정문 대조

54개 행에 해당하는 문장의 721개 질의를 원문과 맞춤법을 점검한 표기로
같은 Smart 러너에서 실행했다. 원문의 `첨엔` 같은 준말을 보존했다.
문장을 고친 13개 사례의 교정 근거는 다음과 같다.

| 원문 ID | 교정 표기와 근거 |
| --- | --- |
| `s1` | `주요20개국` → `주요 20개국`으로 관형어와 수량 표현을 띄어 썼다. |
| `s238` | `순회 경선과 그리고` → `순회 경선과`로 등록 교정의 중복 접속을 반영했다. |
| `s242` | `사주 일가`, `불법 유출`로 명사들을 띄어 썼다. |
| `s264` | `'앙숙'독일` → `‘앙숙’ 독일`로 인용 내용과 뒤 명사를 구분했다. |
| `s459` | `고래 역사 문화`, `국내 유일의`, `고래 테마 관광 도시`로 각각 띄어 썼다. |
| `s474` | `샤브샤브` → `샤부샤부`로 외래어 표기법을 적용했다. |
| `s531` | `이 씨`, `A 씨`로 성명·지칭 기호와 호칭을 띄어 썼다. |
| `s568` | `17년(1520년)`으로 앞 표현을 보충하는 괄호를 붙였다. |
| `s697` | `과학 인재`로 연속 명사를 구분했다. |
| `s782` | `군 복무`에 전문 용어의 띄어쓰기 원칙을 적용했다. 붙여 쓴 원문도 평가했다. |
| `s835` | `기본 원칙`으로 연속 명사를 구분했다. |
| `s887` | `이사 온`으로 명사와 용언을 띄어 썼다. |
| `s924` | `사 먹습니다`로 두 동사를 띄어 썼다. |

`군 복무`의 `군` [40, 43)은 띄어 쓴 문장에서 반환됐다. 두 표기가
허용되므로 원문의 누락도 계속 채점한다. `샤브샤브` 질의에서는 원문
[57, 69) 반환만 관측됐다. 호칭을 띄어 쓴 문장의 명사 `이` 질의에는
성씨 [27, 30), [66, 69)가 추가됐다. `이를 토대로`의 `이를`
[10, 16)은 양쪽에서 반환되며 대명사와 동형인 자리로 따로 검토해야 한다.
대조 입력 SHA-256은 `9bb45e53d66093c96317e43ba2fa8595599fe8f177e3594ae9ddc6fb568ae88a`다.
