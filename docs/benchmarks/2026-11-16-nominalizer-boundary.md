# 완성 체언 내부의 명사형 경계

`남아`에서 `나다`의 명사형 `남`이, `대기업`에서 `대다`의
명사형 `대기`가 추론 성분으로 반환됐다. 더 긴 체언 분석이 성립하고
그 분석에 명사형 범위가 정렬되지 않으면, 어절 중간에서 멈춘 명사형
후보를 제외한다. `쉼터`의 `쉼` 같은 사전 성분과 `남을`처럼
조사를 소비한 명사형은 확인한 범위를 유지한다.

## 품질

기준선 `684f68dd`와 후보 `e887e0ad`에서 고정 12세트 83,081행의
Smart·Any·Token 반환 범위 249,243개 결과를 비교했다. Smart에서
`남아`의 명사형 5범위와 `대기업·탐사·섬유·참고`의 명사형
각 한 범위가 사라졌다. 한 행에는 별도 반환 범위가 남아 총 9행 중
8행의 오탐이 해소됐다. Any와 Token은 같은 결과를 반환했다.

잔여 음성에서 모음·ㄹ 어간의 `-ㅁ` 명사형과 일치하면서 뒤에
글자가 붙은 범위는 31개였다. 변경으로 이 중 8개와 별도
`-기` 범위 한 곳이 제거됐다. `남동생·쉼터`처럼 사전이 같은
위치에 명사 성분을 정렬한 경우에는 그 근거를 보존한다.
추가 회귀 12행은 잘못 끊긴 명사형, 완결 용언과 체언, 어절 끝과
조사를 소비한 명사형, 합성어의 정렬된 명사형을 검사한다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1
순서다. 추가 회귀의 계약 검토는 0건, 고정 음성은 1,255건이다.
목표 집계 11세트에서 Smart FNc는 0, FPc는 2,360건에서
2,352건으로 줄었다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 추가 회귀 12행 | Smart 기준선 | 8, 4, 0, 0 / 66.67, 100.00, 80.00 | 8, 4, 0, 0 / 66.67, 100.00, 80.00 |
| 추가 회귀 12행 | Smart 후보 | 8, 0, 4, 0 / 100.00, 100.00, 100.00 | 8, 0, 4, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3612, 49696, 0 / 0.00, —, 0.00 | 1255, 2357, 49696, 0 / 34.75, 100.00, 51.57 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3604, 49704, 0 / 0.00, —, 0.00 | 1255, 2349, 49704, 0 / 34.82, 100.00, 51.66 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 교대로
5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했다. p95는
최근접 순위로 구했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.704 [60.497, 60.932] | 30,652 [29,526, 31,041] | 0.07129 [0.07017, 0.07342] | 81.109 [81.031, 81.406] |
| 교정 GSD | 후보 | 60.369 [60.195, 60.992] | 30,794 [29,807, 30,994] | 0.07062 [0.07017, 0.07308] | 81.000 [80.891, 81.328] |
| 고정 음성 | 기준선 | 61.335 [60.895, 63.056] | 19,828 [17,047, 19,877] | 0.12604 [0.12517, 0.13596] | 127.609 [127.266, 127.938] |
| 고정 음성 | 후보 | 61.104 [60.699, 61.515] | 19,799 [19,528, 19,827] | 0.12567 [0.12558, 0.12887] | 127.656 [127.516, 127.703] |

교정 GSD의 처리량 중앙값은 +0.46%, p95는 −0.93%다. 고정 음성은
각각 −0.15%, −0.30%였다. 두 입력에서 처리량과 p95의 관측 범위는
겹친다.
