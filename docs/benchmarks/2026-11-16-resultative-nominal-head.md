# 관형절의 체언과 결과 관형형

`원빈이 나온 사진 보여줘`에서 `사진`은 `나온`이 수식하는 체언이다.
Smart는 앞의 용언 관형형, 체언 어절의 사전 분석, 뒤의 종결 용언을
확인해 `사다 + -아지다 + -ㄴ` 후보를 제거한다. `창가를 찍은 사진 보내줘`처럼
뒤 용언에 보조 용언을 붙여 쓴 경우와 실제 결과 관형형 `꾸며진 정원`을 함께 검사했다.

## 품질

`799f1805`와 `33f02172`에서 고정 입력 12종의 249,243개 반환 결과를
비교했다. 고정 음성의 Smart에서 `사진` 17..23 한 범위만 제거됐다.
고정 평가 11세트의 Smart 계약 FN은 0건이다. 원문 사전 진단 세트에는
별도로 33건이 남아 있다.

PUD 합성 명사 21행에서 원문 토큰과 compact 사전의 결합 성분을 대조했다.
5행 6범위의 마지막 명사 성분을 확인해 계약 양성으로 등록했다. `그해`와
`연료값`은 기존 검토에 있다. 나머지 14행은 해당 원문의 표기와 성분 경계를
뒷받침할 근거를 추가로 확인해야 한다. 원문에 띄어쓰기가 있었던 43행은
이 합성 명사 대조의 대상과 별개다.

새 계약 5행은 Smart와 Any에서 모두 지정 범위를 반환하고 Token에서는
어절 내부 범위를 반환하지 않는다. `네바다주의 주요 산업`의 `주요`에서
Smart와 Any가 반환하는 `주` 16..19, Any에서 `항해했다`와 `수상했다`
내부에 반환하는 각각 `해` 217..220과 `상` 74..77은 별도의 잘못된 범위다.
행 단위의 계약 TP에는 이 추가 범위가 반영되지 않는다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
고정 음성은 53,308행이다. 기준선과 후보에 동일한 계약 검토 827건을 적용했다.

| 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 3868, 49440, 0 / 0.00, —, 0.00 | 827, 3041, 49440, 0 / 21.38, 100.00, 35.23 |
| Smart | 후보 | 0, 3867, 49441, 0 / 0.00, —, 0.00 | 827, 3040, 49441, 0 / 21.39, 100.00, 35.24 |
| Any | 양쪽 | 0, 17616, 35692, 0 / 0.00, —, 0.00 | 827, 16789, 35692, 0 / 4.69, 100.00, 8.97 |
| Token | 양쪽 | 0, 2847, 50461, 0 / 0.00, —, 0.00 | 736, 2111, 50370, 91 / 25.85, 89.00, 40.07 |

기존 계약 822건에서 새 계약을 적용하면 Smart와 Any의 계약 FP가 각각
5건 감소한다. Token의 계약 FN은 같은 이유로 86건에서 91건으로 집계된다.

## 성능

Smart에서 입력과 버전마다 새 프로세스로 워밍업 1회 후 5회 측정했다.
기준선과 후보의 실행 순서를 교대했다. 표는 중앙값 [최솟값, 최댓값]이며
p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 63.534 [63.250, 66.748] | 27,248 [20,886, 28,152] | 0.08121 [0.07996, 0.12300] | 81.266 [80.953, 81.813] |
| 교정 GSD | 후보 | 63.718 [62.885, 64.792] | 27,270 [26,962, 28,447] | 0.08163 [0.08046, 0.08425] | 81.234 [81.203, 81.328] |
| 고정 음성 | 기준선 | 60.971 [60.088, 61.686] | 19,707 [19,524, 19,729] | 0.12783 [0.12767, 0.12900] | 127.594 [127.094, 127.688] |
| 고정 음성 | 후보 | 61.101 [60.636, 61.990] | 19,529 [19,463, 19,630] | 0.13021 [0.12863, 0.13029] | 127.688 [127.641, 127.891] |

교정 GSD의 처리량은 +0.08%, p95는 +0.51%다. 고정 음성은 각각 −0.90%,
+1.86%다. 두 입력 모두 처리량과 p95의 관측 범위가 겹쳤다.
