# 보조 용언 앞 미래 관형형의 반환 범위

`역사에 남을 만하다`에서 `남을`은 `남다`의 미래 관형형이다.
Smart는 같은 범위의 명사형과 목적격 조사 경로가 이 관형형 및
보조 용언의 결합과 충돌할 때 해당 경로를 제외한다. 같은 줄에서
사전에 확인된 보조 용언이 이어져야 한다. 보조 용언의 표면에
명사 분석도 있으면 뒤의 관형형과 명사구 또는 주격과 목적어를
받지 않는 종결 서술어를 확인한다.
[한국어기초사전 만하다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=53017)
· [국립국어원 보조 용언 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=335782)

## 원문·교정문과 품질

PUD n01021012에서 `만한기록적인`과 `사용되어일어난`을
각각 띄어 쓴 대조문과, 허용되는 `남을만한`을 적용한 대조문을
사용했다. 원문과 대조문 3개에서 51개 질의씩 비교했다.

| 입력 | `나다` 기준선 | `나다` 후보 | `남다` 양쪽 |
| --- | --- | --- | --- |
| 원문 | [74, 80) | [74, 80) | [74, 80) |
| 띄어 쓴 교정문 | [74, 80), [140, 143) | [140, 143) | [74, 80) |
| `남을만한`으로 붙여 쓴 교정문 | [139, 142) | [139, 142) | [74, 80) |

띄어 쓴 대조문에서 `나다`의 잘못된 [74, 80)만 사라졌다.
`일어난` 안의 `난` 범위는 별도 판정 대상이다. 두 교정문에서
`일어나다` 전체는 각각 [134, 143), [133, 142)로 유지됐다.
대조 입력의 SHA-256은
`a2685f2a08bd4f797904658015bd48e7f4d3d5a663f9ee0aa88ed478b96cc0bd`다.

행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 양쪽 | 0, 3,038, 50,270, 0 / 0, 0, 0 | 1,426, 1,498, 50,236, 0 / 48.77, 100, 65.56 | 1,499 | 0 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 592 / 99.93, 93.60, 96.66 | 13 | 592 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

역사 입력 258,541개 조합의 반환은 모두 같았다. 추가 반환
미판정은 원문 GSD 553행 613범위와 교정 GSD 104행 110범위다.
고정 음성 계약 양성 1,207행의 전체 정답과 제외 42행의 37범위도
검토가 남아 있다.

고정 회귀 13행을 WASM의 NFC·NFD와 리소스 장착 Smart·Any,
기본 Token에서 빌드당 78개 조합으로 확인했다. Smart의 오반환
14개가 사라졌다. `삶을 뻔했다`의 `삶다`와
`새싹이 남을 지켜봤다`의 `나다`처럼 실제 정답을 유지했다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0과
Python 3.14.8에서 `d5372517`과 `df082a36`을 비교했다.
새 프로세스로 빌드별 워밍업 1회 뒤 순서를 교대해 5회 측정했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 각 실행의 최근접 순위다.
