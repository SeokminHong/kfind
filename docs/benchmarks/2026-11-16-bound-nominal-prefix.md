# 접두사와 합성 명사의 검색 범위

`대지진`, `대부분`, `신기록`에서 첫 성분은 명사를 만드는 접두사다.
Smart는 확인된 결합 어휘를 조사·지정사 활용과 대조해 이 성분을
명사로 반환하지 않는다. `대나무`는 명사 성분이 정렬된 합성어다.
첫 성분을 반환할 때 다음 성분의 `나`를 조사로 소비하지 않는다.
[국립국어원 접두사 예](https://www.korean.go.kr/common/download.do?c_file_name=da8d8206-94f0-4f8f-a66f-527b37db259a_0.pdf&file_path=bookData) ·
[국립국어원 합성어 분석](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=316141)

## 품질

고정 12세트 83,081행을 Smart, Any, Token에서 비교했다. Smart 31행의
31범위가 제거됐고 새 반환은 없었다. 바뀐 질의는 명사 `대`와 `신`이다.
출처에서 접두사 용법이 확인된 결합, 조사와 지정사가 붙은 형태, 합성어의
명사 성분, 독립 단위 명사를 포함한 대조 11건을 고정 회귀로 검증했다.
`대용량`, `대소동`, `대학` 등은 이 비교의 변경 범위에 들어 있지 않다.

고정 평가 11세트에서 Smart FNc는 0건이다. 초기 사전 정렬 대조본의
raw FN 33건은 양쪽에서 같다. 고정 음성 53,308행에 같은 계약 검토
1,199건을 적용했다. 행렬은 TP, FP, TN, FN 순서이고 비율(%)은
precision, recall, F1 순서다.

| 리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- |
| 기준선 | 0, 3706, 49602, 0 / 0.00, —, 0.00 | 1199, 2507, 49602, 0 / 32.35, 100.00, 48.89 |
| 후보 | 0, 3676, 49632, 0 / 0.00, —, 0.00 | 1199, 2477, 49632, 0 / 32.62, 100.00, 49.19 |

## 성능

각 셀은 중앙값 [최솟값, 최댓값]이다. 새 프로세스에서 워밍업 1회 후
기준선과 후보의 실행 순서를 번갈아 바꿔 5회 측정했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.838 [60.597, 62.676] | 30,444 [28,854, 31,086] | 0.07192 [0.06992, 0.07417] | 81.234 [81.016, 81.344] |
| 교정 GSD | 후보 | 60.692 [60.322, 60.718] | 30,876 [30,383, 31,016] | 0.07050 [0.06992, 0.07187] | 81.047 [80.984, 81.297] |
| 고정 음성 | 기준선 | 61.155 [60.720, 62.759] | 19,610 [19,498, 19,881] | 0.12833 [0.12554, 0.12917] | 127.656 [127.281, 127.781] |
| 고정 음성 | 후보 | 61.167 [60.862, 61.567] | 19,826 [19,765, 19,839] | 0.12546 [0.12500, 0.12604] | 127.594 [127.344, 127.641] |

교정 GSD의 처리량은 +1.42%, p95는 −1.97%다. 고정 음성은 각각
+1.10%, −2.24%다. 두 입력에서 관측 범위가 겹쳤다.
