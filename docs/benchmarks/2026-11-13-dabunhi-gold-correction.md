# KAIST dev 부사 다분히

제품 리비전은 `e992a051`입니다. KAIST dev의 `MH2_0159-s128`은 `다분히`를
형용사 `다분하-`와 연결 어미의 결합으로 주석했습니다. `자유주의적인`을 꾸미는
`다분히`는 국어사전에 등재된 부사입니다. 원본 행렬은 그 주석을 raw 지표에 보존하고,
계약 검토에서 형용사 질의를 음성으로 정정합니다.
