# 대조 연결 어미 내부의 용언 범위

`-지만/-지마는`과 `-건만/-건마는`의 끝부분은 독립 용언의 관형형
`만` 또는 `마는`과 겹친다. 어절 끝에서 이 연결 어미와 앞 용언의
구조가 함께 성립하면 Smart는 어미 내부의 용언 후보를 제외한다.
형용사, 과거 동사, 지정사와 긴 연결형을 확인했고 `김밥을 만 사람`,
`김밥을 마는 사람`의 관형형을 대조했다.

## 품질

고정 입력 12세트의 세 모드 249,243행에서 전체 UTF-8 반환 범위를
비교했다. Smart에서 대조 연결 어미 내부의 범위만 44개 사라졌다.
`마다` 질의의 23개와 `말다` 질의의 21개다. 이 중 43행은
오탐이 해소됐고 한 행은 같은 문장의 `말다툼`에 별도의 반환이 남았다.
나머지 입력의 범위는 모두 같으므로 11개 고정 평가에서 Smart 계약 FN은
0건이고 Any와 Token의 품질 지표도 같다. 두 버전에 같은 정답과
계약 검토를 적용했다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.
고정 음성에는 계약 검토 171건을 적용했다. 교정 GSD의 별도 계약 검토는
0건이다.

| Smart 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 고정 음성 53,308행 | 기준선 | 0, 3953, 49355, 0 / 0.00, —, 0.00 | 171, 3782, 49355, 0 / 4.33, 100.00, 8.29 |
| 고정 음성 53,308행 | 후보 | 0, 3910, 49398, 0 / 0.00, —, 0.00 | 171, 3739, 49398, 0 / 4.37, 100.00, 8.38 |
| 교정 GSD 9,298행 | 양쪽 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 |

Workspace 테스트 644건, gold 및 walk/hang, 포맷과 Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
기준선 `a88ff076`과 후보 `41e067c1`을 비교했다. 각 입력·버전은
새 프로세스에서 워밍업 1회 뒤 5회를 측정하고 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| Smart 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.590 [60.540, 61.017] | 30,652 [30,495, 30,759] | 0.07171 [0.07133, 0.07258] | 81.016 [80.953, 81.141] |
| 교정 GSD | 후보 | 60.937 [60.492, 62.168] | 30,729 [30,236, 30,963] | 0.07171 [0.07096, 0.07250] | 81.078 [80.938, 81.375] |
| 고정 음성 | 기준선 | 61.732 [61.282, 63.127] | 19,907 [19,701, 20,010] | 0.12517 [0.12421, 0.12721] | 127.719 [127.438, 127.797] |
| 고정 음성 | 후보 | 60.807 [60.465, 62.418] | 19,832 [19,679, 20,056] | 0.12671 [0.12417, 0.12804] | 127.750 [127.313, 127.875] |

교정 GSD의 처리량 중앙값은 +0.25%, p95는 소수 둘째 자리에서
0.00%다. 고정 음성의 처리량은 −0.38%, p95는 +1.23%다. 네 지표의
기준선과 후보 측정 범위가 모두 겹쳤다.
