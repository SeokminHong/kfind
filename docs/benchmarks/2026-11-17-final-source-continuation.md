# 종결 어미 뒤 어미 연쇄의 검색 범위

`사우디가`나 `그라운드에서`의 앞부분이 용언 종결형과 겹칠 때 Smart가 뒤의
문자를 별개의 어미 연쇄로 해석해 부분 범위를 반환했다. 원본 용언 뒤의
일반 어미 연쇄는 비종결형에 적용한다. 종결형 뒤의 `마는`은 원본 용언과
조사의 결합 경로로 확인한다. `가라는`과 `먹자고`는 등록된 인용 구조로
어절 끝까지 검색한다.
[국립국어원 종결 어미 뒤의 보조사](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?qna_seq=316636)

## 품질

앞선 [종결 어미 어절 경계 검증](2026-11-17-final-ending-boundary.md)에서
남은 13범위를 실행 경로로 확인했다. 일반 어미 연쇄에서 승인된 8범위가
모두 사라졌다. `남자는`, `피자도`, `거라는`, `몰라도` 두 곳의 5범위는
보조사 경로에서 승인된다.

고정 12세트 83,081행의 세 모드 반환 목록 249,243개 중 고정 음성의
Smart 목록 8개에서 각 오탐 범위가 사라졌다. 목표 11세트의 Smart는
FNc 0, FPc 1,961→1,953이다. 고정 음성에 기존 계약 검토 1,399행을 적용했다.

직접 대조 8질의에서는 다른 어휘 내 부분 반환 5개, `떠오마는`의 종결형
1개, `가라는·먹자고`의 전체 범위 2개를 확인했다. 같은 질의에서 CLI의 NFC
및 canonical NFD 전체 반환 목록 16개를 검사했다. 직접 대조의 계약 검토는
0건이다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.

| 입력·모드 | 리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 직접 대조 Smart | 기준선 | 2, 5, 0, 1 / 28.57, 66.67, 40.00 | 2, 5, 0, 1 / 28.57, 66.67, 40.00 |
| 직접 대조 Smart | 후보 | 3, 0, 5, 0 / 100, 100, 100 | 3, 0, 5, 0 / 100, 100, 100 |
| 고정 음성 Smart | 기준선 | 0, 3334, 49974, 0 / 0.00, —, 0.00 | 1332, 1957, 49952, 0 / 40.50, 100, 57.65 |
| 고정 음성 Smart | 후보 | 0, 3326, 49982, 0 / 0.00, —, 0.00 | 1332, 1949, 49960, 0 / 40.60, 100, 57.75 |

## 성능

각 값은 중앙값 [최솟값, 최댓값]이다. p95는 질의 시간의 nearest-rank
95백분위수다.

| Smart 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | 최대 RSS (MiB) |
| --- | --- | ---: | ---: | ---: | ---: |
| GSD | 기준선 | 62.082 [61.972, 62.537] | 29,339 [28,134, 29,680] | 0.07358 [0.07258, 0.07617] | 81.031 [80.922, 81.313] |
| GSD | 후보 | 61.999 [61.692, 63.756] | 28,804 [26,926, 29,411] | 0.07533 [0.07354, 0.07942] | 81.391 [81.094, 81.453] |
| 고정 음성 | 기준선 | 62.477 [62.296, 62.501] | 19,128 [16,419, 19,368] | 0.12900 [0.12775, 0.13850] | 127.438 [127.250, 127.625] |
| 고정 음성 | 후보 | 61.963 [61.707, 64.147] | 19,027 [18,317, 19,153] | 0.13058 [0.12883, 0.13517] | 127.594 [127.500, 127.609] |

GSD 처리량·p95 중앙값은 −1.82%·+2.38%, 고정 음성은
−0.53%·+1.23%였다. 두 입력 모두 기준선과 후보의 처리량 및 p95 범위가
겹쳤다. 양쪽 러너의 크기는 5,198,576바이트다.

## 재현

- 기준선 `cea0fa8f`와 후보 `483ce961`을 Apple M1 Max arm64,
  macOS 26.6.2 (25G83), Rust/Cargo 1.97.0에서 `cargo build --release --locked
  --manifest-path tools/morph-compare/runner/Cargo.toml`로 빌드했다.
- GSD `gsd-saint-determiner.jsonl`과 고정 음성 `negatives.jsonl`은
  `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로
  실행했다. 실행마다 새 프로세스를 만들고 예열 1회 후 측정 5회를 번갈아 수행했다.
- 고정 반환 비교는 `morph-benchmark-runner boundary full-pos MODE INPUT OUTPUT`을
  사용했다. 두 비태그 세트에는 `boundary` 대신 `untagged`를 사용했다.
  [고정 입력, 공통 자원 및 SHA-256](2026-11-16-nominal-predicate-path.md#재현)
