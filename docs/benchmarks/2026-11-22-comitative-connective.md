# 동반 조사와 연결 어미의 경계

`나와서`는 `나오다`의 연결형이다. Smart에서 대명사 `나`를 지시하면
동반 조사로 소비한 `나와` 뒤에 남은 `서`가 있어도 후보가 통과했다.
어절 전체의 사전 연결형이 확인되면 잘린 동반 조사 후보를 제외한다.
`도`나 `는`이 연결형에 이어지는 형태도 같은 원칙을 적용한다.
`나와 함께`, `나와는`에서 대명사와 조사의 완결 범위는 유지한다.

GSD·PUD test에서 `와서` 또는 `과서`를 포함하는 앞 성분 있는 토큰을
전수 추출했다. GSD 4곳과 PUD 2곳에는 동사 연결형 5곳과
명사 `교과서`의 조사 활용 1곳이 있었다. Smart에서 `나와서`가 나온 GSD
두 문장의 대명사 반환만 제거됐다. 고정 12세트, 세 경계 모드의 반환 목록
249,243개를 대조했다. NFC·NFD에서 14건의 실제 CLI 결과를 확인했다.

| 고정 음성 Smart | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 제외 |
| --- | --- | --- | ---: |
| 기준선 | 0, 3,170, 50,138, 0 / 0, 0, 0 | 1,413, 1,646, 50,108, 0 / 46.19, 100, 63.19 | 141 |
| 후보 | 0, 3,168, 50,140, 0 / 0, 0, 0 | 1,413, 1,644, 50,110, 0 / 46.22, 100, 63.22 | 141 |

교정 GSD 9,298행에서는 전체 반환 범위가 같았다.

## 네이티브 형태 판정

`fa998819`와 `7668680a` release runner를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
고정 음성 53,308행에 실행했다. 입력과 리소스 체크섬은
[앞선 비교](2026-11-22-dictionary-self-pos.md#네이티브-형태-판정)와 같다.
측정군별 새 프로세스로 워밍업 1회, 교대 측정 5회를 두 번 실행했다.
