# 관형사 뒤의 사전 명사 성분

Smart는 `전 원내대표`에서 앞 관형사가 선택한 체언 전체를
유지했지만 사전에 정렬된 `원내`와 `대표`를 제외했다. 같은 체언의
사전 분절에 일반 명사나 고유 명사가 정렬되고 해당 위치의 경쟁
분석이 없으면 독립 성분의 범위를 유지한다. `원내대표` 전체와
그 뒤 조사는 기존 조건을 따른다.
[우리말샘 원내대표](https://opendict.korean.go.kr/dictionary/view?sense_no=755096)

MeCab-ko-dic의 단독 관형사와 일반·고유 명사 복합 분절을
고정 음성 53,308행, 원문 GSD 9,335행, 등록 교정 GSD 9,298행에
대조했다. 관형사 뒤에 조사 없는 합성 명사가 있고 질의가 해당
사전 성분과 일치하는 행은 다섯 개다. 원문에서 `원내` 한 행과
`대표` 두 행이었고 등록 교정문에서 `대표` 두 행이었다.
등록 교정문은 이 자리의 `원내대표` 전체도 별도로 평가한다.

`대표`의 정답을 원문과 교정문에 각각 세 범위로 확인했다.
`대표가` [20, 29), `대표 경선`의 `대표` [53, 59),
`원내대표`의 끝 성분 [124, 130)이다. 세 번째 범위까지 기록한
정답으로 기준선과 후보를 채점했다. 제품 수정은 두 입력에서
세 범위를 모두 반환하고 원문의 `원내` [118, 124)도 복원했다.
등록 교정문의 `원내대표` 전체 [118, 130)은 유지됐다.
등록된 교정의 `순회 경선과 그리고` → `순회 경선과`를 적용해
서로 같은 76개 질의를 원문과 교정문에 실행했다. 두 입력에서
`원내` 한 행과 `대표` 두 행의 동일한 범위만 복원됐다.
[원문·교정문과 정확한 범위](../../tools/morph-compare/contract-contrast-evidence.jsonl)

다른 관형사와 명사를 사용한 대조 문장에서 `현 국무총리`의
`국무` [4, 10), `새 교통경찰`의 `경찰` [10, 16)을 확인했다.
조사 결합의 전체 체언, 띄어 쓴 `원내 대표`와 사전 분절에 없는
`서울역` 내부의 `서`도 검사했다. 기준선은 새 양성 회귀 네 건을
놓쳤다.
[정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

고정·등록 세트의 258,541개 반환 목록 중 등록 교정 GSD와 별도의
Smart GSD 비교 세트에서 각각 두 행이 바뀌었다. 비교 세트의 입력
SHA-256은 `1040ed9371fa5ca3a223dfacba83f07765c99b901b41a675701d851a8c130c21`이다.
별도로 비교한 원문 GSD에서는 세 행이 달라졌다.
고정 음성의 양성 범위 1,207행과 제외 문장 42행의 반환
38범위는 미검증이다. 원문과 등록 교정 GSD의 추가 반환
미판정은 각각 603행 665범위, 119행 125범위다.

같은 기준선 출력에서 `대표`의 세 번째 범위를 기록하면
원문 FNc는 647 → 649, 등록 교정문은 0 → 2로 바뀐다.
