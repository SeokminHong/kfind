# 주격 체언 뒤의 비교 부사

같은 줄의 주격 체언이 뒤 형용사의 주어이고 가운데 `더`·`덜`이 정도를
나타내면 그 범위를 부사로 판정한다. `더가 더 빠르다`와 `덜이 덜 느렸다`의
명사 질의에서는 조사로 표시된 이름만 검출하고, 부사 질의에서는 두 번째
어절만 검출한다. 주어 자리가 열려 있는 `형보다 더 높다`의 이름 후보는
보존했다. [국립국어원 비교의 더](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=309492)

고정 음성의 명사 `더` 77행을 전체 반환 범위로 비교했다. 다섯 문장의 부사
범위 6개가 명사 반환에서 빠졌다. `셔틀콕이 더 무거우며 경기 진행 속도가
더 빠르다`에서는 두 오탐을 모두 제거했다. 고정 12세트와 교정 GSD의
전체 목록 258,541개에서 이 다섯 행이 바뀌었다. 원본 GSD의 양성 반환도
검사했다.

| 고정 음성 Smart 53,308행 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 기준선 | 0, 3,133, 50,175, 0 / 0, 0, 0 | 1,413, 1,609, 50,145, 0 / 46.76, 100, 63.72 | 1,610 | 0 |
| 후보 | 0, 3,128, 50,180, 0 / 0, 0, 0 | 1,413, 1,604, 50,150, 0 / 46.83, 100, 63.79 | 1,605 | 0 |

계약 제외는 141행이다. 양쪽 입력과 정답은 같다. 원본·교정 GSD의
적중 행렬과 확정 오류는 [한의 두 문형 비교](2026-11-23-han-quantified-noun-frames.md)와 같다.

## 네이티브 형태 판정

`98fed868`과 `e65e1995`의 release runner를 Apple M1 Max 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다.
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
같은 입력과 리소스를 읽는 새 프로세스를 워밍업 1회와 교대 측정 5회
실행했다. 입력·리소스 체크섬은 [한의 두 문형 비교](2026-11-23-han-quantified-noun-frames.md)와
같다. 값은 중앙값 [최솟값, 최댓값]이다.

| 입력 | 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS KiB |
| --- | --- | --- | --- | --- | --- |
| 고정 음성 | 기준선 | 64.862 [64.171, 187.677] | 17,882 [16,710, 18,255] | 0.1338 [0.1316, 0.1370] | 131,088 [130,928, 132,000] |
| 고정 음성 | 후보 | 64.605 [64.043, 65.563] | 17,910 [17,624, 18,039] | 0.1340 [0.1336, 0.1352] | 131,120 [130,880, 131,920] |
| 교정 GSD | 기준선 | 63.758 [62.855, 64.736] | 26,162 [23,405, 26,647] | 0.0830 [0.0821, 0.0875] | 84,096 [83,808, 84,288] |
| 교정 GSD | 후보 | 64.322 [63.245, 65.443] | 26,036 [25,476, 26,429] | 0.0837 [0.0828, 0.0870] | 83,904 [83,856, 84,224] |

고정 음성 처리량은 0.15%, p95는 0.15% 높았다. 교정 GSD 처리량은 0.48%
낮고 p95는 0.84% 높았다. 고정 음성 기준선의 초기화 한 실행은 187.677 ms였다.
두 입력의 처리량과 p95 측정 범위는 각각 겹쳤다.
