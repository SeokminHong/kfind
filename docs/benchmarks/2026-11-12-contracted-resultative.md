# 축약 연결형과 지다 보조 용언 검색

기준선은 `5e1343ba17e60601794dd5134fe9ec58f21286d4`, 후보는
`22a123c4b646891c76b84cdc474e22035422c553`입니다.

## 품질

UD GSD/PUD 회귀 48건에서 반환 토큰과 표적의 겹침을 확인했습니다. `이루다`가 `이뤄지고`를
검색하는 사례를 추가했습니다. `smart`의 기준선은 반환 범위가 없었고 후보는 UTF-8 바이트
86부터 98까지를 반환했습니다. `이루어지다` 질의의 기존 결과를 유지했습니다.
JSONL 입력 SHA-256은 `4718e4dc1df3c1319e827869e3fa5081453d0d386d73e65f20bac86c72cad242`입니다.

혼동 행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서입니다. 이 입력에는
계약 검토가 0건이므로 계약 보정 값과 원본 값이 같습니다.

## 성능

Apple M1 Max arm64, Darwin 25.6.0, rustc 1.97.0에서 같은 릴리스 빌드 설정, 사전과
GSD 양성 입력 9,335건을 사용했습니다.
