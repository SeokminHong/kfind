# 구어 서술격 조사 앞 명사의 검색 범위

교정 GSD에서 체언 품사 뒤에 `VCP`가 오고 표면형이
`입니다/입니다요`로 끝나는 23행을 확인했다. `짱입니다요` 1행의
정답 끝을 118에서 106으로 옮겨 명사 `짱`만 포함했다.
나머지 22행은 이미 명사 범위를 사용했다.
[정답 범위 교정](../../tools/morph-compare/gsd-colloquial-noun-copula-span-review.tsv)

같은 교정 양성 9,306행에서 `smart`는 9,256 → 9,257행,
`any`는 9,066행이 정확히 일치했다. `smart`에서 바뀐
결과는 `짱` 한 건이다. 음성 53,308행의 반환 범위는 동일했다.
계약 검토 0건으로 raw와 계약 보정 값이 같다. 행렬은 TP, FP,
TN, FN, 비율은 precision, recall, F1 순서다.

| smart | 양성 | 기준선 | 9256, 0, 0, 50 | 100.00, 99.46, 99.73 |
| smart | 양성 | 후보 | 9257, 0, 0, 49 | 100.00, 99.47, 99.74 |

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0 릴리스
빌드에서 작업 시작점 70a5d2d4와 #564 머지 102f70de의 검색 코드,
후보 b92ef12b를 비교했다. 새 프로세스에서 워밍업 1회 후 5회 측정했다.
시작점·기준선·후보와 역순을 교대로 실행했다. p95는
nearest-rank이며 표는 중앙값 [최솟값, 최댓값]이다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
node tools/morph-compare/apply-gsd-copula-span-review.mjs "$input" --after-colloquial-pos > "$corrected"
/usr/bin/time -l "$runner" boundary full-pos "$boundary" "$corrected" "$output"
"$runner" boundary full-pos "$boundary" "$negatives" "$output"
```
