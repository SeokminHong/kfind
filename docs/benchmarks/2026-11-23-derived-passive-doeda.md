# 피동 접미사와 독립 동사 되다

`기소되었다`, `구성되며`, `철거되었다`에서 명사 뒤의 `-되-`는
피동 접미사다. Smart 동사 `되다`의 기준선은 이 접미사와 어미를 별도
동사로 반환했다. 후보는 그 결과를 제거하고, 같은 문장의 독립 동사
`된`, `된다`, `되`를 각각 보존했다. `구속되면서`에서 접미사의
짧은 범위 `되면`도 검사했다. PUD 두 문장은 누락된 공백을 복원한
뒤에도 같은 오탐이 재현됐다. [한국어기초사전 -되-](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=74902)

고정 12세트와 교정 GSD의 반환 목록 258,541개 중 21개에서 접미사 범위가
제거됐다. 원본 GSD 양성 9,335행에서 4행의 접미사 범위 6개가 제거됐고
네 행의 원본 정답 범위는 모두 유지됐다. 교정 GSD에서 같은 네 행이 바뀌었다.
고정 음성에서 이전에 확정한 세 오탐 범위는 [59, 68), [61, 67),
[157, 166)이다. 문장 적중 행렬은 두 실행에서 같았다.

## 네이티브 형태 판정

기준선 `a85ee914`와 후보 `ff5d82ba`의 release runner를 Apple M1 Max,
macOS 26.6.2, Rust 1.97.0, Python 3.14.8에서 비교했다. 양쪽은 같은 full POS,
component와 보강 용언을 읽었다. [직전 측정의 입력·리소스 체크섬](2026-11-23-aligned-royal-title-components.md)

[`measure-smart.py`](../../tools/morph-compare/measure-smart.py)로
`boundary full-pos smart INPUT OUTPUT`을 새 프로세스에서 워밍업 1회 후 교대로
5회 실행했다. 고정 음성 SHA-256은
`482e55d417516e8db503dbd421725fcc7affc6c6afcf5b5d42cec3bbd4d35d54`,
교정 GSD는 `cd3a8e532e67ba0748875311d10eba91c5fcb0d644e5c541bf3a4d22ac7c5a37`이다.
값은 중앙값 [최솟값, 최댓값]이다.

| 입력 | 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS KiB |

최대 RSS 중앙값은 128 KiB 높았다. 각 지표의 측정 범위는 기준선과 후보에서 겹쳤다.
