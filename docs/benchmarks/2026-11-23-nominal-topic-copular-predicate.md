# 명사 주제어와 연결형 동사의 반환 범위

`가게는 하나뿐임`의 `가게는`은 명사와 보조사의 결합이다.
Smart는 `-게` 연결형과 같은 표기의 사전 명사에 `는`이 붙고
같은 줄에서 지정사를 포함한 명사 서술어가 이어질 때 연결형
후보를 제외한다. 지정사 앞의 관형사와 관형격 체언을 확인한다.
`친구를 가게는 한 일이었다.`처럼 뒤에 용언 관형형도 성립하면
동사 후보를 유지한다. `학교에 가게는 됐다.`와
`자네 먼저 저 가게에 가게.`의 동사도 반환한다.

· [한국어기초사전 -게](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=77326)

## 원문·교정문과 품질

GSD s479의 등록 교정문은 `스키용품`과 `안된다네요`를
`스키 용품`과 `안 된다네요`로 띄고 여는 괄호를 앞말에 붙인다.
같은 뜻으로 쉼표, 조사, 마침표를 보완한 대조문에서는
`꼬리표를`로 풀어 썼다. 세 문장의 47개 질의씩을 비교했으며
`가다`에서만 `가게` [96, 102)가 사라졌다. `갔는데` [65, 74),
`갔더니` [153, 162), 명사 `가게는` [96, 105)를 유지했다.
대조문의 `갔더니`는 [157, 166)이다. 대조 입력 SHA-256은
`f3813f48ddcefe9b8481e09fa052003004117c8ad84da6b93fa76bd5ea40cb25`다.

등록 원문·교정문에서 두 GSD 행이 같은 문장의 서로 다른 이동
동사를 표적으로 삼는다. 두 실제 범위를 각각의 독립 검토 근거에
기록하고, 같은 근거로 기준선과 후보를 채점했다. 이전 기록에서
미판정이었던 추가 반환은 원문과 교정문에서 각각 두 행 두 범위가
줄었다. 역사 입력 258,541개 조합의 반환 차이도 동일 문장 두 행의
Smart 결과 네 개에 한정됐다.

행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.
FPc와 FNc는 검토한 전체 범위의 추가와 누락도 포함한다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 양쪽 | 0, 3,038, 50,270, 0 / 0, 0, 0 | 1,426, 1,498, 50,236, 0 / 48.77, 100, 65.56 | 1,499 | 0 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,639, 6, 78, 609 / 99.93, 93.41, 96.56 | 15 → 13 | 609 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 5 → 3 | 0 |

추가 반환 미판정은 원문 GSD 572행 634범위, 교정 GSD
104행 110범위다. 고정 음성 계약 양성 1,207행의 전체 정답과
제외 42행의 37범위도 검토가 남아 있다.

고정 회귀 10행은 WASM NFC·NFD, 리소스 장착 Smart·Any와
기본 Token에서 빌드당 60개 조합을 비교했다. Smart 기준선의
오반환 10개가 사라졌고 유효 범위는 유지됐다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0과
Python 3.14.8에서 `21fc6853`과 `b4ad29e5`를 비교했다.
새 프로세스로 빌드별 워밍업 1회 뒤 순서를 교대해 5회
측정했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 각 실행의
최근접 순위다. [고정 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
· [리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "nominal-topic-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 21fc6853 "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" b4ad29e5 "$lexicon" "$component" "$predicates"
```

`raw:`, `corrected:`를 붙인 574행이다. SHA-256은
`7fb3e60ea817c522e0db06e8c73719bf755b32a1baf027a8dabd636ffadad2d2`다.
