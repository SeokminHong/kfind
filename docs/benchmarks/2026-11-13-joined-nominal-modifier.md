# 붙여 쓴 관형 구 검색

`따뜻한구름`과 `강조의허위`를 띄어 쓴 구로 검색할 때 `smart`에서 앞 성분을
놓쳤습니다. 어절 처음의 관형형 또는 관형격 조사 결합과 뒤의 독립 명사를 확인해 두
성분의 범위를 반환합니다. 뒤에 조사가 붙은 경우 명사 범위에 포함합니다.
[제50항 해설](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=322955) ·
[회귀 입력](../../tools/morph-compare/non-nominal-phrase-spacing-cases.jsonl)

제50항 해설의 비명사 구성 예시 5쌍을 모두 검사했습니다. 조사 부착 및 다른 명사
대조 4건과 체언으로 완성되지 않는 대조 2건을 추가했습니다. GSD·PUD 원본 UD에서
`ETM+NN*` 또는 `JKG+NN*`인 어절도 전수 확인했습니다. GSD 10건, PUD 0건이며
일반 명사를 수식하는 동일한 표준 허용형은 없었습니다. 후보에서 새로 일치한 5건의
UTF-8 범위는 수식 성분과 조사까지 포함한 명사 범위에 맞았습니다.

행렬은 TP, FP, TN, FN 순이며 비율은 precision, recall, F1 순입니다. 계약
검토는 0건입니다.

| 경계 | 실행 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- | --- |
| smart | 기준선 | 9, 0, 2, 5 | 100.00, 64.29, 78.26 | 9, 0, 2, 5 | 100.00, 64.29, 78.26 |
| smart | 후보 | 14, 0, 2, 0 | 100.00, 100.00, 100.00 | 14, 0, 2, 0 | 100.00, 100.00, 100.00 |
| any | 양쪽 | 14, 2, 0, 0 | 87.50, 100.00, 93.33 | 14, 2, 0, 0 | 87.50, 100.00, 93.33 |

`any`의 음성 대조 2건은 토큰 경계를 검사하지 않는 경로에서 반환됩니다.
GSD 양성 9,314건과 사전 양성 4,458건의 두 경계, GSD·PUD 음성 53,308건의
`smart` 반환 범위는 기준선과 같습니다.

## 성능

시작점 `70a5d2d4b76666a8ec1e2c5a8c8424a547af82aa`, 기준선
`28b7caeef4ab6b5eca26fd07048bc5eef55fb34f`, 후보
`1047cb6c71c6bc7c650d106a1c555938daf2e280`을 비교했습니다.
Apple M1 Max, macOS 26.6.2 (25G83), rustc 1.97.0 release 빌드입니다. 같은
full POS 리소스를 사용했습니다. 실행 순서를 순환하며 새 프로세스에서 워밍업 1회,
측정 5회를 수행했습니다. 각 값은 중앙값 [최솟값, 최댓값]이며 p95는 사례 지연의
최근접 순위입니다. [리소스와 시작점](2026-11-13-compound-copula-prefix.md#성능)

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" untagged full-pos smart "$phrase_cases" "$output"
/usr/bin/time -l "$runner" boundary full-pos smart "$corpus_cases" "$output"
```
