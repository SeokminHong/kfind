# 목적격 뒤 비교 부사의 수식 범위

`입장료를 좀 더 올리더라도`에서 `입장료를`은 `올리다`의
목적격 성분이다. 그 사이의 `좀 더`는 정도를 나타낸다.
`올리더라도`는 사전에서 어간과 연결 어미가 따로 나타나므로 두
조각을 결합해 확인한다. `좀`의 본말인 `조금`과 `덜`도 대조했다.
[한글 맞춤법 제46항의 부사 연쇄](https://www.korean.go.kr/kornorms/m/m_regltn.do)
· [국립국어원 조금과 좀](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=326869)

`그는 좀 더 불러 달라고 말했다`에서는 부름의 대상이 생략될 수
있고 `더`를 이름으로도 읽을 수 있다. `책 ‘더 이상’을 읽지
않았다`는 부정 술어가 있어도 앞 전체가 제목이다. `철수 이상
참여하지 않았다`의 `철수`처럼 `이상` 앞에 명사 기준이 올 수
있으므로 부정형만으로 경쟁 명사를 제외하지 않는다.
[국립국어원 더 이상](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=338085)

## 품질

고정 음성의 `n:더` 잔여 54행·59범위에서 바로 앞의 `좀·조금` 또는
바로 뒤의 `이상`을 조사했다. 이 조건에 맞는 11개 원문과 별도
대조 12개에서 양쪽 품사 46질의의 반환 범위를 비교했다.
`달라`는 이번에 확인한 종결형과 연결형 경로에서 여전히 명사
오탐이 남는다. 인용 제목을 부사로도 반환하는 사례 역시 남는다.

고정 12세트 83,081행을 세 모드로 실행한 반환 목록 249,243개 중
`gsd:test-s455:noun:더`의 Smart 17..20만 사라졌다. 목표
11세트 FNc 0, FPc 1,797→1,796이다. 기존 계약 검토를 양쪽에
동일하게 적용했다. 행렬은 TP, FP, TN, FN 순서이고 비율은
precision, recall, F1 순서다. 고정 음성 원본 recall은 양성 분모가
없어 정의되지 않는다. 대조의 계약 검토는 0건이다.

## 성능

기준선 `214c3604`와 후보 코드 `bfe913fd`를 Apple M1 Max arm64,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Node.js 26.11.1에서 같은
release 설정으로 빌드했다. `/usr/bin/time -l RUNNER boundary full-pos
smart INPUT OUTPUT`을 입력별로 새 프로세스에서 워밍업 1회 후
두 버전을 번갈아 각 5회 실행했다. 중앙값 [최솟값, 최댓값]이다.
처리량은 초기화를 제외하고 p95는 nearest-rank로 구했다.
