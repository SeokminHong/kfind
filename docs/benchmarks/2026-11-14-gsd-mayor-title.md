# GSD 직함 앞 성씨 주석

교정 GSD의 한 음절 고유 명사 32행과 한 음절 수사 5행을
검토했다. `오 시장이 주민투표 문제를 매듭짓고 대선에 출마하는`
문장의 `오`는 시장의 성이다. `오 시장은`과 같은 고유 명사
주석으로 교정했다. 원문과 UTF-8 범위 14–17을 보존했다.
[교정 주석](../../tools/morph-compare/gsd-mayor-title-annotations.tsv)

7ca3b9a8의 동일한 full POS 러너로 교정 전후 9,300행의
정확 범위를 비교했다. 계약 검토는 0건이고 각 행렬은 TP, FP,
TN, FN 순서다. 검색 실행 코드 변경이 없어 성능 측정을 생략했다.

| 경계 | 입력 | Raw 행렬 | Raw P/R/F1 (%) | 계약 보정 행렬 | 보정 P/R/F1 (%) |
| --- | --- | --- | --- | --- | --- |
| smart | 교정 전후 | 9266, 0, 0, 34 | 100.00, 99.63, 99.82 | 9266, 0, 0, 34 | 100.00, 99.63, 99.82 |
| any | 교정 전후 | 9063, 0, 0, 237 | 100.00, 97.45, 98.71 | 9063, 0, 0, 237 | 100.00, 97.45, 98.71 |

#421 비교군 1,113행은 현재 교정 입력에 ID로 모두 연결된다.
`smart`는 정확 1,079행, 부분 15행, 누락 19행이다.
`any`는 정확 948행, 부분 158행, 누락 7행이다.

"$runner" boundary full-pos "$boundary" "$corrected" "$output"
