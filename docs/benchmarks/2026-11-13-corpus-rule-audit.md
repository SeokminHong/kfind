# 형태 분석의 입력 특례 제거

기준선은 `fdaff35e51f296d81688297fa3704773fdf84a29`, 후보는
`11f1acf2b61026870a303517d536b9cc6e0c8013`입니다. 기준선 실행 파일은
소스와 입력 리소스가 같은 `d83b03dfea4cd8ecffe053b268a2008b4729d4a5`에서
빌드했습니다. 두 리비전 사이에는 저장소 지침만 바뀌었습니다.

## 형태 규칙 조사

matcher, 형태 판정 및 활용 생성, 질의 컴파일, 사전·규칙 데이터, benchmark runner와
채점 경로에서 고정 어휘, 품사·어미 제약, 사례 ID와 기대값 사용처를 확인했습니다.
Runner의 명시적 품사 검색은 입력 텍스트와 질의로 span을 반환하고, 채점은 별도로
raw 정답과 계약 검토를 적용합니다.

| 경로 | 제거한 입력 의존 판정 |
| --- | --- |
| 결과형 | `재산·주식·소유권` 앞에서만 `가다` 후보를 지우는 분기 |
| `-지요/-죠` | `동화·공·힘껏`과 일부 일정 명사를 조합해 형용사 후보를 지우는 분기 |
| `-나이다/-나이까` | `안녕·만수무강` 등 일곱 명사를 기준으로 `비다` 후보를 지우는 분기 |
| 높임형 | `병원으로`에서 끝나는 앞 어절을 기준으로 `갈다` 후보를 지우는 분기 |
| 전망형 | `곧장`의 위치를 기준으로 생략 지정사 후보를 지우는 분기 |
| 관형격 준말 | `한국·지역·구역·범위` 바로 뒤의 `내`를 대명사 검색에서 제외하는 분기 |
| 관형절 | 특정 `-하다/-나다` 어휘의 목록으로 바깥 서술어가 목적어를 받을 수 없다고 판정하는 분기 |
| 수량 수식 | 시점 어휘 목록으로 `불과`의 명사 후보를 지우는 분기 |
| 익명 호칭 | `씨 등` 앞의 `모`를 관형사로 반환하는 분기 |

`이 모 씨`의 `모`는 대명사이고 `모 식당`의 `모`는 관형사입니다. 이 구분을
회귀에 반영했습니다. 보조 용언 `주다`의 연결형 요구, 조사·어미 이형태, 사전의
단위 명사 및 정렬된 파생 형태는 각각 해당 결합을 증명하는 근거로 사용합니다.
[국립국어원 익명 호칭](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=27&pageIndex=1&qna_seq=335953) ·
[한국어기초사전 보조 용언 주다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=77245)

범위 평가의 누락 2건은 동일 익명 호칭을 관형사로 표기한 사례입니다. GSD의
`한국 내`는 고정 입력에서 `나+의`로 표기되어 있어 후보가 새로 반환한 범위가
raw TP가 됩니다. 이 점수는 문장 해석의 개선을 나타내지 않습니다. 음성 집합의
두 span 변경은 PUD의 `지역 내`와 이미 다른 위치에서 오탐이 있던 GSD의
`요양병원으로 가세요`입니다. `특허를 가지지 않았다`, `건물 내`, `공항으로 가세요`,
`신발을 있는 힘껏 차죠`, `면접에 늦죠`, `합격을 비나이다`는 두 실행에서 모두
오탐입니다. 이동 결과형과 `가지다`, 관형격 `내`, 도구를 쓰는 `갈다`, 기간을
나타내는 `비다`의 대조 양성은 모두 반환했습니다.

원래 음성 기대값은 유지했습니다. Release의 `verify-gold`는 후보에서 실패하며
첫 검사 묶음의 실패는 `갈다` 1건, 관형격 `내` 2건, 소유 문맥의 `가다` 2건입니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Rust·Cargo 1.97.0에서 같은 release
설정과 사전으로 입력별 새 프로세스 warm-up 1회 뒤 실행 순서를 교대하며 5회
측정했습니다. p95는 nearest-rank이고 RSS는 `/usr/bin/time -l`의 최대 상주
메모리입니다. 값은 중앙값 [최솟값, 최댓값]입니다.

양성·음성 처리량 중앙값은 각각 1.65%, 1.15% 줄었고 p95는 1.19%, 1.64%
늘었습니다. 양성·음성 모두 실행별 범위가 겹칩니다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
KFIND_FULL_POS_LEXICON="$lexicon" KFIND_COMPONENT_RESOURCE="$components" \
KFIND_ENRICHED_PREDICATES="$enriched" \
  /usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```

범위 입력은 기준선의 `ud_morphology_cases.tsv`, `jiyo_span_cases.tsv`,
`prospective_span_cases.tsv`, `humble_span_cases.tsv`,
`adnominal_object_attachment_cases.tsv`를 이 순서대로 헤더 없이 JSONL로 변환했습니다.
사례 열은 `id,query,pos,text,expectation,expected,gold_byte_start,gold_byte_end,group`이고
`group`은 확장자를 뺀 파일명입니다.
