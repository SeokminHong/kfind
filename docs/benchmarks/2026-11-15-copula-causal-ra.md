# 이유 연결 어미 라 앞의 지정사 생략

`제가 바보라 그렇습니다`에서는 주격과 뒤 절의 서술어가
이유 연결형을 지지한다. Smart는 생략형 `바보라`를 반환한다.
뒤 절의 부사, 다른 종결 서술어, 별도 명령형을 고정 회귀로 비교했다.
[국립국어원 포럼 발표집의 이유 연결 어미 라 설명](https://www.korean.go.kr/common/download.do?c_file_name=1f91d6f2-08c2-4abe-8dc5-20eff2796186_0.pdf&file_path=reportData&o_file_name=2014+%ED%86%B5%ED%95%A9%EA%B3%BC+%EC%86%8C%ED%86%B5%EC%9D%98+%EA%B5%AD%EC%96%B4%EC%A0%95%EC%B1%85+%EA%B0%9C%EB%B0%9C_2%EC%B0%A8+%ED%8F%AC%EB%9F%BC+%EB%B0%9C%ED%91%9C%EC%A7%91.pdf)

## 성능

시작점 `70a5d2d4`, 기준선 `d600a9d5`, 후보 `652a05e5`를 비교했다.
기준선 측정 빌드 `2cefc83b`는 기준선과 파일 트리가 동일하다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS Smart로 워밍업 1회 후 새 프로세스로 5회씩 버전 순서를 순환했다.
사전의 첫 측정에서 편차가 커 해당 입력을 다시 실행했다.
