# 소지 연결형과 이동 동사의 반환 범위

`유모차 가지고 갔더니`에서 `가지고`와 `갔더니`를 소지와
이동을 나타내는 각각의 용언으로 분석한다. 목적격 체언 또는
조사 없이 쓰인 명사가 소지의 논항을 제공하고, 뒤에서 별도
이동 동사의 활용을 확인한다. 사이에 다른 부사나 부사격으로
표시한 목적지가 있는 문장도 확인했다.
[한국어기초사전 가지다¹](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=65234&nation=eng&nationCode=6)
· [가다¹](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=27500)

## 원문·교정문과 품질

GSD s522의 원문은 `홀대허더이다`, 등록 교정문은
`홀대하더이다`를 쓴다. 조사 없는 목적어와 줄임표는 유지했다.
`유모차를 가지고 갔더니 홀대하더이다.`처럼 목적격과 문장 부호를
명시한 문장도 대조했다. `가다`는 원문과 교정문에서
`갔더니` [20, 29), 목적격을 명시한 문장에서 [23, 32)만
반환한다. `가지다`의 범위는 각각 [10, 19), [13, 22)다.
세 문장의 질의 33개 중 `가다` 질의만 달라졌다.
대조 입력 SHA-256은
`57b9035ba5c168fa7bb0e52fe5e8a78b6857fc3f0059c5b881baf00a3ff4d3c0`이다.

등록 질의 580행의 `가다`와 `가지다`를 비교했다. 독립 어절
`가지고`가 있는 `가다` 질의는 원문·교정 GSD 각각 한 건이고,
`가지다` 질의는 각각 3건이다. 기존 258,541개 반환을 대조했을
때 Smart의 같은 문장 2행에서 추가 범위가 제거됐다.
띄어 쓴 보조 용언 `가 가지고`와 허용되는 붙임형의 범위에는
별도의 판정이 남아 있다.
[한국어기초사전 가지다²의 결합](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=61191&nation=eng)

두 GSD 평가의 `가다` 정답 범위를 원문 주석과 사전으로 검토해
등록했다. 기준선에 독립 오반환 한 건이 계수되며, 같은 범위
정답을 후보에 적용하면 한 건 줄어든다.
[평가 범위와 대조 예문](../../tools/morph-compare/contract-contrast-evidence.jsonl)

추가 반환 미판정은 원문 GSD 574행 636범위와 교정 GSD
106행 112범위다. 고정 음성 계약 양성 1,207행의 전체 정답과
제외 42행의 37범위도 검토가 남아 있다.

고정 회귀 9행은 WASM NFC·NFD, 리소스 장착 Smart·Any와
기본 Token에서 빌드당 54개 조합을 비교했다. Smart의
오반환 8개가 각각 사라졌으며 유효 범위는 정확히 반환됐다.
별도 대조문 `공원에 갔다가 우산을 가지고 집으로 갔다.`에서
동사 `가다`는 [10, 19), [50, 56), `가지다`는 [30, 39)를
반환했다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0과
Python 3.14.8에서 `ad495720`과 `7cc47f8b`를 비교했다.
새 프로세스로 빌드별 워밍업 1회 뒤 순서를 교대해 5회
측정했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 각 실행의
최근접 순위다. [고정 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
· [리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "possession-motion-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" ad495720 "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 7cc47f8b "$lexicon" "$component" "$predicates"
```
