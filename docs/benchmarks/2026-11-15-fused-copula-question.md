# 지정사 축약 의문형과 목적격 명사구

`벽에 그림을 걸까?`에서는 목적격 명사구와 동사 활용이 성립한다.
`상자 안에 넣은 걸까요?`에서는 관형형 뒤 의존 명사와 지정사가
축약된다. 기존 지정사 분석은 첫 문장을 반환했고, 둘째 문장의
`요`에는 명사 나열 조건을 적용했다. 목적격 명사구 뒤의 동사 경쟁을
확인하고 높임 의문형은 축약 의문형의 조건을 적용했다.
[한국어기초사전 -ㄹ까](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=86335)

## 품질

대조 9건은 `걸까·걸까요`의 지정사와 동사, 대명사 축약 `누굴까`,
표기에 남은 `일까`를 포함한다. 사전 원본·보정본에서 `이다`를 질의하고
`까·까요` 어미 후보가 있는 행 32건과 33건을 확인했다. KAIST dev/test와
교정본 전체에서도 반환 범위 변화는 없었다. 골드 925건, walk/hang,
workspace 테스트 634건과 Clippy를 통과했다.

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
대조와 GSD는 검토 0건이다. 사전 두 행은 각각 원래 정답 범위와
[기존 계약 보정](2026-11-15-dictionary-gajyeodajuda-review.md)을 적용한
결과다. KAIST 양성은 표적 겹침, 사전·GSD·대조 양성은 정확한 범위로
채점했다.

음성 집계에는 입력의 ID·질의·품사·원문 SHA-256과 일치하는 기등록
양성 검토 35건을 반영했다. 음성 행렬은 release 리소스로 측정했다.

## 성능

기준선 `76bb9703`과 후보 `ebb7019a`를 Apple M1 Max arm64,
macOS 26.6.2, Rust/Cargo 1.97.0의 release 빌드에서 비교했다.
워밍업 1회 후 새 프로세스로 각각 5회 실행하고 실행 순서를 번갈았다.
값은 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위, RSS는 최대 상주 메모리다.
