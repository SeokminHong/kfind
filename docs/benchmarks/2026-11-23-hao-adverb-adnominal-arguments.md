# 하오체 종결형과 형용사 앞 부사의 구분

PUD w01105055의 교정문 `매우 높은 각 해상도를 얻게`에서 `매다`의
하오체 종결형으로 `매우` [49, 55)가 반환됐다. 사전 부사 뒤에 형용사
관형형과 주격 명사구가 이어지는 기존 판정에, 목적격 명사구가 뒤의
용언으로 이어지는 구조를 포함했다. 사전에서 확인한 관형사나 명사
수식어가 명사구에 끼는 경우도 확인한다. `매우 작은 나무 상자`가
앞에 있는 문장에서도 `끈을 단단히 매우.`의 실제 명령형 [59, 65)는
유일한 동사 반환 범위다.
