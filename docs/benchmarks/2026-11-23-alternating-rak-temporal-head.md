# 시간 명사 앞의 교대 어미 오탐

Smart 동사 `몰다`는 명사 `몰락`을 `-락` 교대형으로 반환했다.
활용 생성과 사전 어미 경로가 모두 같은 범위를 제시했다. 어절 전체의
명사 분석과 뒤의 `전·후·이전·이후·직전·직후` 시간 명사 결합을 확인해
이 문맥에서는 교대형을 제외한다. 앞에 목적어가 있는 교대형은 유지한다.
`비행기 추락 이후`, `왕조의 몰락 전`, `시장의 몰락 직후`를 대조했다.
[한국어기초사전 전](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=17301&lang=eng) ·
[한국어기초사전 직후](https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=28963&nation=jpn)

## 네이티브 형태 판정

기준선 `d74f5bbd`와 후보 `168728af`의 실행 파일을 같은 Cargo target에
`cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml`로
빌드했다. 입력, 기기, 도구, 리소스와 교대 실행 명령은 [실행 조건](2026-11-23-embedded-alternative-connectives.md#네이티브-형태-판정)과
같다. 각 입력에서 별도 프로세스로 워밍업 1회와 교대 측정 5회를
실행했다. 아래는 중앙값 [최솟값, 최댓값]이다.

4.02% 높았다. 후보 끝의 `락`을 확인한 뒤에만 어미 경로를 검사하도록
수정했다. 최종 고정 음성 처리량과 p95는 +0.21%, −0.16%, 교정 GSD는
−1.02%, +0.27%다. 최종 차이는 [기준선 반복 변동](2026-11-22-smart-performance-baseline.md)
범위 안이다.
