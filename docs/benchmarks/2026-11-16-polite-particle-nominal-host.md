# 관형사 뒤 체언과 높임 보조사

`그 해요`와 `저 해요`에는 각각 연도와 해를 가리키는 명사 뒤에 높임
보조사 `요`가 붙는다. Smart는 발화를 마치거나 쉼표로 구분하는 위치에서
관형사, 체언, 보조사가 사전에 확인되면 해당 체언의 범위를 검색한다.
[국립국어원 높임 보조사 ‘요’ 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=90&pageIndex=1&qna_seq=332404)

## 품질

기준선 `10ddfc45`와 후보 `5933dbfe`에서 고정 입력 12종을 세 모드로 실행했다.
249,243개 반환 결과의 ID, 리소스 해시, 전체 UTF-8 반환 범위에 차이가 없다.
고정 평가 11세트의 Smart 계약 FN은 0건이다.

추가 대조 10행에서 Smart의 정확 범위 일치가 4건에서 7건으로 늘었다.
`작년에 본 그 해요.`와 `창밖에 뜬 저 해요.` 및 쉼표로 이어진 대조문에서
각각 18..21의 `해`를 회수했다. `어느 주요?`, `비단은 두 필요.`,
`그 필요를`, `그 해가`의 기존 범위를 확인했다. `그 주요 임무`,
`저 주요 관광지`, `그 가요 한 곡`의 음성도 확인했다. 계약 검토는 0건이다.

고정 음성에서 명사 질의 바로 뒤에 `요`가 붙은 16행을 확인했다.
`주요` 13행, `해요` 2행, `필요` 1행에서 해당 위치를 Smart와 Any가
반환했다. `주요 생산지이다` 한 행은 앞 명사가 수식하는 `주`에
지정사 어간을 생략한 열거 연결형 `-요`가 붙은 분석도 성립한다.
동형이의 대조로 계약에 반영했다. 남은 15행과 이미 적중한 PUD 행에
포함된 `주요` 안의 추가 범위는 문맥을 더 검토해야 한다.
[국립국어원 열거형에서의 지정사 어간 생략 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=326386)

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
고정 음성은 53,308행이다. 기준선과 후보에 동일한 계약 검토 828건을 적용했다.

| 모드와 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart 추가 대조 | 기준선 | 4, 0, 3, 3 / 100.00, 57.14, 72.73 | 4, 0, 3, 3 / 100.00, 57.14, 72.73 |
| Smart 추가 대조 | 후보 | 7, 0, 3, 0 / 100.00, 100.00, 100.00 | 7, 0, 3, 0 / 100.00, 100.00, 100.00 |
| Smart 고정 음성 | 양쪽 | 0, 3867, 49441, 0 / 0.00, —, 0.00 | 828, 3039, 49441, 0 / 21.41, 100.00, 35.27 |
| Any 고정 음성 | 양쪽 | 0, 17616, 35692, 0 / 0.00, —, 0.00 | 828, 16788, 35692, 0 / 4.70, 100.00, 8.98 |
| Token 고정 음성 | 양쪽 | 0, 2847, 50461, 0 / 0.00, —, 0.00 | 736, 2111, 50369, 92 / 25.85, 88.89, 40.05 |

기존 계약 검토 827건으로 집계했을 때보다 Smart와 Any의 계약 FP는
각각 1건 적다. Token의 계약 FN은 91건에서 92건으로 집계된다.

## 성능

변경 경로인 Smart에서 입력·버전별로 새 프로세스 워밍업 1회 후 5회
측정하고 두 버전의 순서를 교대했다. 표는 중앙값 [최솟값, 최댓값]이며
p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.731 [60.354, 61.392] | 30,668 [29,711, 30,867] | 0.07158 [0.07142, 0.07388] | 81.109 [81.000, 81.141] |
| 교정 GSD | 후보 | 60.866 [60.404, 62.878] | 30,539 [28,793, 30,947] | 0.07138 [0.07092, 0.07563] | 80.875 [80.828, 80.906] |
| 고정 음성 | 기준선 | 61.296 [60.813, 64.492] | 19,700 [16,698, 20,004] | 0.12800 [0.12454, 0.13321] | 127.766 [127.328, 127.922] |
| 고정 음성 | 후보 | 60.915 [60.744, 62.105] | 20,003 [19,837, 20,092] | 0.12446 [0.12396, 0.12583] | 127.297 [127.250, 127.594] |

교정 GSD의 처리량은 −0.42%, p95는 −0.29%다. 고정 음성은 각각
+1.54%, −2.77%다. 두 입력 모두 처리량과 p95 관측 범위가 겹쳤다.

## 재현

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0에서
`cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml`로
각 revision의 runner를 만들었다. 명령, 입력 체크섬과 리소스는
[보조 용언 범위 검증의 재현 절차](2026-11-16-auxiliary-competition.md#재현)와 같다.
