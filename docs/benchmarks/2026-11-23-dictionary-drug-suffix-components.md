# 약 이름의 접미사와 독립 명사

표준국어대사전의 접미사 `-제(劑)`는 약의 뜻을 더한다. 같은 한자의
의존 명사 `제`는 한약의 분량을 세는 단위다. 표제어 한자가 일치하고
MeCab-Ko의 명사 분절이 해당 위치에 있는 348개 표제어를 공통 component에
등록했다. 표제어에 다른 어원이 함께 있으면 분절을 채택하지 않는다.
Smart는 접미사로 확인된 범위를 명사 질의에서 빼고, 약 이름 전체와
`약 한 제를`, 제사 명사와 성씨의 반환 범위를 보존한다.
[표준국어대사전 접미사 299654](https://stdict.korean.go.kr/search/searchView.do?word_no=299654)
· [단위 명사 480217](https://stdict.korean.go.kr/search/searchView.do?word_no=480217)
· [분절 자료 생성](../../tools/nikl-lexicon/README.md#어휘-항목-audit)

GSD r2.18 학습 문장 4,400개에서 등록된 표제어와 붙은 조사를 조사했다.
찾은 4문장에서 명사 `제`가 아래 범위를 추가로 반환했다. 원문과 교정문에
같은 두 리소스를 각각 적용했다. 맞춤법 교정은 `잔류기준` → `잔류 기준`,
`최근호` → `최근 호`, `잔존효능` → `잔존 효능`이며 검색 품사는
같다. 범위는 UTF-8 바이트 반개구간이다.
[GSD r2.18 학습 원문](https://github.com/UniversalDependencies/UD_Korean-GSD/blob/r2.18/ko_gsd-ud-train.conllu)

| 문장 | 음성 범위 원문 / 교정문 | 후보 |
| --- | --- | --- |
| train-s2201 | 항생제의 접미사 [60, 63) / [60, 63) | 반환 없음 |
| train-s2685 | 산화제의 접미사 [13, 16) / [13, 16) | 반환 없음 |

약 이름 전체는 두 입력에서 모두 보존됐다. train-s4372의 독립 오반환
`제때 [93, 96)`가 남았다. 테스트 말뭉치 2,016문장에는 등록된 약 이름이
없었다. 별도 진단의 `요오드제`도 표제어 전체가 사전 자료에 없어
교정문에서 `제의 [186, 192)`가 남았다.

## 품질

행렬 순서는 TP, FP, TN, FN이며 뒤 세 값은 정밀도·재현율·F1(%)이다.
분절 대조는 새 표제어 348개를 자료 순서로 `목록의 마지막 항목은 W`,
`목록에 W를 적었다.`, `문서에서 W의 이름을 확인했다.`,
`보고서의 표제어는 W입니다.`에 대입해 각각 명사 `제`와 명사 `W`로
검색했다. 양성 범위는 순서대로 `W`, `W를`, `W의`, `W`다.
분절 대조와 GSD 학습 용례에 계약 검토는 0행이다.

고정 입력의 검토 / 제외는 순서대로 1,589 / 149, 619 / 39,
153 / 0행이다. 고정 음성의 계약 양성 1,207행과 제외 42행 37범위에는
미판정 범위가 남았다. 원문 GSD는 511행 569범위, 교정 GSD는 86행
92범위다. 전체 71,941행과 기존 비교 258,541행에서 두 리소스의
반환 범위가 일치했다. `verify-gold` 927행, 네이티브 테스트 375개,
자료 도구 테스트 29개를 통과했다. 동일 WASM에서 리소스 장착 API 두 개,
NFC·NFD, Smart·Any·Token의 96개 조합을 각 리소스로 확인했다.
기준선의 음성 16개가 사라졌으며 Any와 Token 범위는 모두 같았다.

러너를 사용했다. Apple M1 Max 32 GiB, macOS 26.6.2 (25G83),
Rust·Cargo 1.97.0, Python 3.14.8에서 실행했다. 두 실행에 같은 full-pos
lexicon `47bb7a3a…`과 확장 용언 `67e99dc4…`을 장착했다.
component SHA-256은 `83915ef0…`에서 `f7df2acb…`로 바뀌었다.
