# 평서 어미와 독립 동사 늘다

동사 `늘다`는 ㄹ 탈락으로 독립적인 `는다`·`는다고`를 만들 수 있다.
`믿는다`·`읽는다고`에서는 같은 표면이 앞 동사의 어미다.
앞 동사와 그 어미의 완결된 분석이 확인되면 어절 내부의 독립 동사
후보를 제외한다. 실제 동사 `늘다`의 평서형과 인용형을 대조했다.
[한국어기초사전 -ㄴ다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=85033)

원본과 교정 GSD에서 동사 `늘다`를 질의한 한 행의 문장과 정답은
같다. `늘었으리라` [44, 59)는 유지했고 `믿는다` 안의 `는다`
[63, 69)는 제거했다. 기준선과 후보에 같은 정답 범위를 적용했다.
고정 12세트와 교정 GSD의 반환 목록 258,541개에서 이 범위의
두 출력만 바뀌었다. 원본 GSD 양성에서도 같은 한 범위가 바뀌었다.

| 입력 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc 기준선 → 후보 | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 53,308행 | 0, 3,126, 50,182, 0 / 0, 0, 0 | 1,424, 1,590, 50,150, 0 / 47.25, 100, 64.17 | 1,591 → 1,591 | 0 |
| 원본 GSD 9,335행 | 8,290, 0, 0, 1,045 / 100, 88.81, 94.07 | 8,290, 0, 0, 1,045 / 100, 88.81, 94.07 | 3 → 2 | 1,045 |
| 교정 GSD 9,298행 | 9,288, 0, 0, 10 / 100, 99.89, 99.95 | 9,288, 0, 10, 0 / 100, 100, 100 | 3 → 2 | 0 |

추가 반환은 원본 GSD 1,026행 1,115개, 교정 GSD 136행
143개가 미확정이다.

## 원문과 교정 입력의 공통 분모

같은 후보 바이너리의 원문·교정 출력에서 공통 ID 9,298개를 대조했다.
원문 정답 기준 적중은 8,255행, 누락은 1,043행이다. 교정 정답 기준
적중은 9,288행, 누락은 10행이다.
원문 전체 9,335행에서 누락된 1,045행 중 548행은 정답 범위만,
138행은 질의나 품사가 바뀌었다. 351행은 문장 교정이 있고,
6행은 같은 문장·질의·범위에서 기존 계약이 원래 품사나 형태를 기각했다.
두 행은 교정 분모에서 빠졌다. 이 분류는 기존 교정 내용을 기록한다.

[단일 명사 비교](2026-11-23-atomic-nominal-before-particles.md#네이티브-형태-판정)와
