# 원문 GSD의 범주·성질 접미사 앞 명사

원문 양성에서 품사열이 `NNG+XSN`으로 시작하고 두 번째 성분이
`별`, `상`, `성`, `형`인 25행을 점검했다. 기존 검토 14행에 더해
아래 9행의 명사 범위를 확정했다. `분기`와 `단지`가 같은 문장에 두 번
나오면 두 범위를 기록했다. 수여 기관장의 직함으로 쓰인 `대구은행장상`의
`賞`과 사람 이름 `조인성`의 두 행은 별도 분석 대상이다.
[국립국어원 -별과 -상](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=320662)
· [사실상과 지구상](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5970)
· [접미사 -성](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=70804)
· [접미사 -형](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=88490)
· [원문과 정답 범위](../../tools/morph-compare/contract-contrast-evidence.jsonl)

일곱 문장의 원문 질의 143개를 원문과 교정문에 각각 실행했다.
양쪽에서 Smart full-pos `b0505678`와 같은 사전 리소스를 사용했다.
아래 범위는 UTF-8 바이트다.

같은 질의의 반환 표면이 바뀐 것은 두 행이다. `고생하다`는
교정문에서 `고생했었는데` [42, 60)를 반환했다. `들어오다`는
공백을 기준으로 [278, 296)에서 [279, 288)로 바뀌었다.
별도 동사 `듣다` 질의에서도 `들어와있음을` [278, 296)와
`들어와` [279, 288)가 각각 반환됐다. 두 문장 모두
`가시권에 들어오다`의 이동 표현이므로 이 오탐은 교정 후에도 남는다.

원문 GSD 양성 9,335행에서 동일한 실행 결과에 정답 범위만 추가했다.
미판정은 741행 820범위에서 732행 808범위로 줄었다.
