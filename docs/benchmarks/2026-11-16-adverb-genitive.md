# 종결 용언 앞 통째 부사와 관형격 조사

`거의 없었다.`에서 `거+의` 분석은 관형어가 수식할 뒤 체언이
없다. 전체 어절에 부사 분석이 있고 다음 어절이 문장 끝의 독립
종결 용언이면 Smart에서 이 체언 검색 후보를 제외한다.
`그 거의 색`이나 `저 거의 주인이었다`처럼 관형어를 받는 체언이
있으면 체언 후보를 유지한다.
[국립국어원 관형격 조사 설명](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6127&mn_id=62)

## 품질

기준선 `f132247b`와 후보 `5804397b`에서 고정 12세트 83,081행의
Smart·Any·Token 반환 범위 249,243개를 비교했다. Smart의
`pud:n03001007:noun:거`에서 76..82 범위 한 곳이 사라졌다.
잔여 음성의 체언 반환 범위 중 질의에 `의`가 붙은 표면형은 32개였다.
그중 `거의` 15범위를 모두 확인했다. `거의 모든 주`처럼 뒤 체언이
있거나 바로 뒤 어절에서 문장이 끝나지 않는 14범위는 그대로 반환됐다.

추가 회귀 8행은 현재·과거 형용사와 동사 앞의 명사 음성,
뒤 체언에 연결된 관형격 조사, 부사 자체의 양성 범위를 확인한다.
`그 거의 부러졌다 싶었던 부분`에서는 뒤에 체언이 이어지므로
`거+의`의 범위를 유지한다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1
순서다. 추가 회귀의 계약 검토는 0건, 고정 음성은 1,255건이다.
목표 집계 11세트의 Smart FNc는 0, FPc는 2,375건에서
2,374건으로 줄었다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 추가 회귀 8행 | Smart 기준선 | 5, 3, 0, 0 / 62.50, 100.00, 76.92 | 5, 3, 0, 0 / 62.50, 100.00, 76.92 |
| 추가 회귀 8행 | Smart 후보 | 5, 0, 3, 0 / 100.00, 100.00, 100.00 | 5, 0, 3, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3627, 49681, 0 / 0.00, —, 0.00 | 1255, 2372, 49681, 0 / 34.60, 100.00, 51.41 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3626, 49682, 0 / 0.00, —, 0.00 | 1255, 2371, 49682, 0 / 34.61, 100.00, 51.42 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 교대로
5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했다. p95는
최근접 순위로 구했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 61.104 [60.566, 61.563] | 30,532 [29,706, 30,692] | 0.07071 [0.07042, 0.07337] | 81.078 [81.016, 81.359] |
| 교정 GSD | 후보 | 60.682 [60.346, 60.945] | 30,467 [29,374, 30,549] | 0.07104 [0.07075, 0.07446] | 80.984 [80.953, 81.297] |
| 고정 음성 | 기준선 | 60.641 [60.446, 60.916] | 19,669 [19,258, 19,839] | 0.12762 [0.12575, 0.13108] | 127.609 [127.531, 127.703] |
| 고정 음성 | 후보 | 61.023 [60.323, 61.249] | 19,845 [19,702, 19,885] | 0.12575 [0.12546, 0.12637] | 127.547 [127.203, 127.656] |

교정 GSD의 처리량 중앙값은 −0.22%, p95는 +0.47%다. 고정 음성은
각각 +0.89%, −1.47%였다. 두 입력에서 처리량과 p95의 관측 범위는
겹친다.
