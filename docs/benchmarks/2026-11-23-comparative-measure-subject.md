# 주격 수량 뒤 비교 부사 판정

숫자와 단위 뒤에 읽기에 맞는 주격 조사가 있으면 비교 구문의
주격 수량으로 확인한다. `3미터가`, `3 m가`, `2 kg이`, `3%가`에
같은 구성을 적용한다. 뒤의 형용사 관형형과 수식받는 체언이 확인되면
`큰`처럼 관형형과 명사 표면이 같은 경우도 구별한다.
[한국표준과학연구원 SI 기본 단위](https://www.kriss.re.kr/menu.es?mid=a10302030000) ·
[BIPM SI 접두어](https://www.bipm.org/en/measurement-units/si-prefixes) ·
[국립국어원 퍼센트 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=330407)

## 정확한 반환 범위

고정 음성과 GSD 원문·교정문에서 아라비아 숫자, 단위 기호, 주격
조사가 이어지는 6건을 다섯 문장에서 확인했다. 남한산성의
`39.4m가 더 높은`에서 비교 부사와 동형인 명사 `더`의 [140, 143)이
반환됐다. 띄어 쓴 `39.4 m가` 표기에서도 동일한 오류가 [142, 145)에
있었다. 두 표기의 부사 검색 범위를 보존했다. 이 조건으로 찾은
원문 목록의 SHA-256은
`62b2d4390894273235fa005a14e9f6b4528787d6e39fcb1c52a14b82b21b3936`이다.
[국립국어원 숫자와 단위 기호의 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?pageIndex=1&qna_seq=331340)

다섯 문장의 178개 질의를 각각 원문과 점검한 표기에 적용했다.
남한산성 문장은 단위 기호를 띄어 썼다. 노동부 문장은
`실시한 최악의`, `5~14세`, `7~14세`, `참여하고 있으며`,
`겸하고 있음을`로 교정했다. 356개 결과의 후보 비교에서
남한산성 문장 두 표기의 명사 범위만 달라졌다. 이 입력의 SHA-256은
`80f0f3114b41ab31b5eccac125e425826ad43b0c6f8273e1bb16d507824fe8b0`이다.

일곱 기본 단위와 접두어, 백분율을 이용한 183개의 새 문맥에서
명사 오반환 183개가 제거됐고 부사 범위 183개가 보존됐다.
이 입력의 SHA-256은
`574a83576f5d2032326c811d1efee583cccdde1ca286a1d2614f85cd20b4c0d4`다.
`더가 3 m가 더 높은 쪽을 골랐다`의 인명 [0, 6)과 부사 [14, 17),
`형보다 더 높다`에서 가능한 인명 [10, 13)도 확인했다.
[정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

## 네이티브 형태 판정

Apple M1 Max 32 GiB, macOS 26.6.2 arm64, Rust·Cargo 1.97.0,
Python 3.14.8에서 기준선 `2a407bf2`와 후보 `2e06e70c`를
release로 비교했다. 같은 입력과 리소스로 한 번 가동한 뒤 순서를
교대하며 새 프로세스로 5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이며
p95는 실행별 최근접 순위다.
[입력·사전 체크섬](2026-11-23-saisiot-nominal-components.md#네이티브-형태-판정)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name comparison-unit -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 2a407bf2 "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 2e06e70c "$lexicon" "$component" "$predicates"
```

## WASM

`wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release`로
양쪽을 빌드했다. 원본은 2,843,841 → 2,845,136 B (+1,295),
`gzip -9`는 966,578 → 967,210 B (+632), Brotli는
714,880 → 713,715 B (−1,165)였다. Node 26.11.1에서 동일한
component를 장착해 NFC·NFD의 정확 범위 대조 14건을 검증했고 기본
API에서는 component 없이 명시적으로 요청한 Smart의 거절을 확인했다.
