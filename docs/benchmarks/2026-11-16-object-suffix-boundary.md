# 목적격 조사 분석과 통째 체언의 경계

`서울`의 둘째 음절 `울`에는 compact 리소스의 목적격 조사 표지가
있다. `서`를 조사 앞 체언으로 선택한 경우, 통째 체언 분석과 경쟁하는
부분 반환은 뒤 표면이 기존 조사 검증을 통과하는지 확인한다.
`서+울`에는 유효한 목적격 조사 결합이 성립하지 않는다.
[국립국어원 목적격 조사 이형태 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=318262)

## 품질

기준선 `7c59428f`와 후보 `fc627426`에서 고정 12세트 83,081행의
Smart·Any·Token 반환 범위 249,243개 결과를 비교했다. `서울`에서
Smart가 독립 명사 `서`를 반환하던 11행·11범위가 사라졌다.
한 행은 별도 어절에 반환이 남아 오탐 행은 10개 줄었다.

추가 회귀 12행은 `서울·소울·사울·거울`의 잘못된 목적격 조사 분리와
`서울을·소를`의 조사 결합, `서쪽`의 정렬 성분, `철분`의 명사
성분과 `뭐야`·`독일 수 있다`의 지정사 구성을 확인한다.
지명 `독일`에서 발생하는 `독`의 다른 반환 경로는 남아 있다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1
순서다. 추가 회귀의 계약 검토는 0건, 고정 음성은 1,255건이다.
목표 집계 11세트에서 Smart FNc는 0, FPc는 2,352건에서
2,342건으로 줄었다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 추가 회귀 12행 | Smart 기준선 | 8, 4, 0, 0 / 66.67, 100.00, 80.00 | 8, 4, 0, 0 / 66.67, 100.00, 80.00 |
| 추가 회귀 12행 | Smart 후보 | 8, 0, 4, 0 / 100.00, 100.00, 100.00 | 8, 0, 4, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3604, 49704, 0 / 0.00, —, 0.00 | 1255, 2349, 49704, 0 / 34.82, 100.00, 51.66 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3594, 49714, 0 / 0.00, —, 0.00 | 1255, 2339, 49714, 0 / 34.92, 100.00, 51.76 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 교대로
5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했다. p95는
최근접 순위로 구했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.994 [60.849, 61.194] | 30,511 [29,922, 30,944] | 0.07121 [0.07029, 0.07371] | 80.984 [80.891, 81.359] |
| 교정 GSD | 후보 | 61.042 [60.899, 61.172] | 30,571 [30,232, 30,638] | 0.07062 [0.07058, 0.07242] | 81.109 [80.984, 81.375] |
| 고정 음성 | 기준선 | 61.239 [61.131, 61.791] | 19,857 [19,756, 19,900] | 0.12558 [0.12512, 0.12679] | 127.391 [127.172, 127.500] |
| 고정 음성 | 후보 | 61.244 [61.074, 61.430] | 19,733 [19,238, 19,831] | 0.12646 [0.12563, 0.13000] | 127.578 [127.328, 127.594] |

교정 GSD의 처리량 중앙값은 +0.19%, p95는 −0.82%다. 고정 음성은
각각 −0.62%, +0.70%였다. 두 입력에서 처리량과 p95의 관측 범위는
겹친다.
