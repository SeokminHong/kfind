# 선택 연결형 든·든지의 검색 범위

표준국어대사전과 한국어기초사전에서 `-든/-든지` 예문 9건을 점검했다.
용언·지정사와 높임·과거 활용, 회상의 `-던지`를 확인했다.
붙어 쓰인 관형사 `모든`이 뒤 명사의 수식어인 경우와 동사 `모다`의
`서류를 모든 찢든`도 함께 대조했다.
[표준국어대사전 -든](https://stdict.korean.go.kr/search/searchView.do?word_no=94881&searchKeywordTo=3) ·
[-든지](https://stdict.korean.go.kr/search/searchView.do?word_no=417515&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
표적의 계약 검토는 0건이다. 전체 사전은
[앞선 보정 8건](2026-11-14-interrogative-geona.md#품질)을 유지한다.

사전의 다른 예문 3건에서도 `하든`, `낫든지`, `맑든지`를 추가로
반환했다. 초기 후보에 생긴 음성 오탐 두 건은 앞 어절에 붙은 관형사
`모든`이 바로 뒤 명사를 수식하는 사례였다. 최종 후보에서 두 오탐을
제거했고, 고정 GSD 9,298건과 음성 53,308건, KAIST dev 2,532건과
test 2,592건의 검색 범위는 기준선과 일치했다. Raw·계약 보정 지표는
[고정 입력 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `ba56e542`, 후보 `2a57aeb7`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `a37f54c0`와
`a54fb946`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서는 순환했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접
순위, RSS는 최대 상주 메모리다.
