# 띄어 쓴 정도 부사의 동사 검색

GSD test의 `그 사이 한 층 더 업그레이드 된`에서 `한 층`은 정도 부사
`한층`의 띄어쓰기 오류다. 한국어기초사전에도 `한층 더`의 용례가 있다.
원본의 `하다` 검색에서 `한` [11, 14)가 사라지고 `하고` [96, 102)가
남았다. 교정문에서는 `하고` [94, 100)가 두 버전에서 모두 검출됐다.
관형절의 `도배를 한 층`과 실제 층수를 세는 `한 층`은 정확한 바이트 범위로
따로 검사했다. [한국어기초사전 한층](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=89052)

UD 고정 원본의 `하다` 동사 질의 405행에서 독립된 `한`이 있는 양성 8행과
음성 62행을 확인했다. 원본 GSD 전체 9,335행에서 반환 범위가 달라진 행은
위 한 행이다. 교정 GSD 9,298행과 고정 12세트의 Smart·Token·Any 반환
목록 249,243개는 모두 같았다. 수 관형사와 동사 관형형이 경쟁하는 다른
문형은 이 변경에서 판정하지 않는다.

| Smart 입력 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 검토 / 제외 |
| --- | --- | --- | ---: |
| 원본 GSD | 8,290, 0, 0, 1,045 / 100, 88.81, 94.07 | 원본과 같음 | 0 / 0 |
| 교정 GSD | 9,288, 0, 0, 10 / 100, 99.89, 99.95 | 9,288, 0, 10, 0 / 100, 100, 100 | 10 / 0 |
| 고정 음성 | 0, 3,155, 50,153, 0 / 0, 0, 0 | 1,413, 1,631, 50,123, 0 / 46.42, 100, 63.41 | 1,555 / 141 |

위 혼동 행렬은 기준선과 후보에서 같다. 원본 GSD의 미판정 반환 범위는
1,034행 1,127개에서 1,033행 1,126개로 줄었다. 교정 GSD는 두 버전 모두
144행 155개가 미판정이다. 고정 음성의 계약 양성 중 1,366행은 전체 정답
범위가 미확정이다. 원본 진단의 미판정 감소를 고정 음성 FPc 감소로 집계하지 않는다.

## 네이티브 형태 판정

`951c7db8`과 `cea89e15`의 release runner를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다.
후보의 기준 커밋 `7eb7014c`와 기준선 사이에는 runner와 제품 코드 차이가 없다.
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
동일 입력과 리소스를 읽는 새 프로세스를 워밍업 1회와 교대 측정 5회 실행했다.
고정 음성, 교정 GSD 및 리소스의 체크섬은 [수량 부사 비교](2026-11-22-quantity-adverb-genitive.md)와
같다. 값은 중앙값 [최솟값, 최댓값]이다.

| 입력 | 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS KiB |
| --- | --- | --- | --- | --- | --- |
| 고정 음성 | 기준선 | 63.872 [63.467, 65.047] | 18,460 [18,176, 18,524] | 0.1321 [0.1315, 0.1333] | 130,880 [130,768, 131,040] |
| 고정 음성 | 후보 | 63.144 [62.813, 63.987] | 18,227 [17,839, 18,438] | 0.1333 [0.1326, 0.1336] | 130,816 [130,576, 131,680] |
| 교정 GSD | 기준선 | 63.139 [62.876, 151.849] | 26,970 [18,053, 27,291] | 0.0809 [0.0794, 0.1168] | 84,128 [83,792, 84,320] |
| 교정 GSD | 후보 | 62.429 [62.189, 63.113] | 26,719 [18,741, 27,183] | 0.0821 [0.0800, 0.1401] | 83,600 [83,488, 83,744] |

고정 음성 처리량은 1.26% 낮고 p95는 0.91% 높았다. 교정 GSD 처리량은
0.93% 낮고 p95는 1.48% 높았다. 교정 GSD의 느린 실행을 포함해 두 입력의
측정 범위가 겹쳤다.

## 위치 표현 앞 관형형 보존

`지난번에 직접 한 층 더 위에는 분전반이 있다`에서 `한` [20, 23)은
목적어를 생략한 관형형으로 읽을 수 있다. `더` 뒤에 용언 구조가 확인되는
경우에만 정도 부사로 판정하니 이 범위가 다시 검출됐다. 후속 용언은
`좋아지게`처럼 한 어절이거나 `업그레이드 된`처럼 어근과 파생 활용을
띄어 쓴 구조일 수 있다. 원본 GSD 9,335행, 교정 GSD 9,298행과 고정
12세트의 반환 범위는 앞서 수정한 제품과 같다. 위 적중 행렬도 같다.
같은 고정 음성에서 이후 확정한 PUD 추가 반환 2건을 포함한 FPc는
양쪽 1,633이며 FNc는 0이다. [PUD 범위 검토](2026-11-22-reviewed-range-scoring.md#pud에서-정답과-함께-반환한-두-오탐)
