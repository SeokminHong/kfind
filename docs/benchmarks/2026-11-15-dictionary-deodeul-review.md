# 떠드는지 예문의 표제어

아이들이 소란스럽게 말하는 문장의 표제어는 `떠들다`다.
기존 의문형 검증에는 이 표제어가 적용돼 있다. 전체 사전 평가의 계약
입력에도 같은 표제어를 적용하고 원문, 품사, 범위 23..35를 유지했다.
[의문형 검증](2026-11-12-nieun-interrogative-endings.md#품질) ·
[표준국어대사전 -는지](https://stdict.korean.go.kr/search/contentViewOne.do?word_no=409801)

## 품질

`는지` 예문 중 `뜨다`가 표제어인 1건을 보정했다. 코드와 검색 옵션은 동일하다.
행렬은 TP, FP, TN, FN 순서이고 비율은 precision, recall, F1 순서다.
후보의 Raw도 고정 원본 사전을 사용한다.

| 입력 | 경계 | 버전 | Raw 행렬 / 비율 (%) | 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- | --- |
| 해당 예문 1건 | Smart | 양쪽 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 해당 예문 1건 | Any | 보정 전 | 0, 0, 0, 1 / 0.00, 0.00, 0.00 | 0, 0, 0, 1 / 0.00, 0.00, 0.00 |
| 해당 예문 1건 | Any | 보정 후 | 0, 0, 0, 1 / 0.00, 0.00, 0.00 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | Smart | 양쪽 | 4387, 0, 0, 71 / 100.00, 98.41, 99.20 | 4458, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | Any | 보정 전 | 4294, 0, 0, 164 / 100.00, 96.32, 98.13 | 4367, 0, 0, 91 / 100.00, 97.96, 98.97 |
| 사전 4,458건 | Any | 보정 후 | 4294, 0, 0, 164 / 100.00, 96.32, 98.13 | 4368, 0, 0, 90 / 100.00, 97.98, 98.98 |

Smart는 원래 보정 입력의 `뜨다` 질의에서도 해당 범위를 반환했다.
이는 다른 표제어의 검색 결과가 원래 양성 채점과 일치한 경우다.
