## 성능

Apple M1 Max arm64, macOS 26.6.2, Darwin 25.6.0, Rust와 Cargo 1.97.0에서
full-POS release runner를 사용했습니다. 새 프로세스에서 warm-up 1회 뒤 5회
측정했고 실행 순서는 교대했습니다. p95는 nearest-rank로 산출했습니다.
