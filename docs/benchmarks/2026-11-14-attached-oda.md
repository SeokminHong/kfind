# 붙여 쓴 보조 용언 오다의 검색 범위

교정 GSD에서 `-아/-어` 뒤에 보조 용언 `오다`가 붙은 어절은
`해온`과 `있어왔다` 두 행이다. 관형형 `온`과 과거형
`왔-` 뒤의 어미를 기존 활용 경로로 처리한다. `해온` 전체를
반환하고 `있어왔다`의 범위는 유지했다. 새 회귀 3행은 통과했고
기존 `verify-gold` 불일치 8행은 재현됐다.

고정 음성 53,308행의 반환 범위는 동일했다. #421의 불일치
1,113행 중 정확 1,047행, 부분 23행, 누락 43행이다.
행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1이다.
계약 검토는 양성 0건, 음성 31건이다.
