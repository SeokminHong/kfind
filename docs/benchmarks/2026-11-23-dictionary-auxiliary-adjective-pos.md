# 사전에서 확인한 보조 형용사의 검색 품사

full POS 리소스의 `VX`는 보조 동사와 보조 형용사를 함께 담는다.
core에서 두 국어사전으로 품사를 확정한 용언은 해당 분석을 사용한다.
기존 어미 문형 자료에서 보조 형용사로 쓰이는 후보 9개를
표준국어대사전과 우리말샘에 대조했다.

일곱 표제어는 보조 형용사만 확인됐다. `성하다`에는 동사와
형용사가 있고 `뻔하다`에는 본용언 형용사와 보조 형용사가 있다.
두 표제어의 분석은 기존 경로를 유지했다.

## 반환 범위와 평가

새 예문에서 희망·추측 용법과 앞 관형형의 결합을 검증했다.
Smart, Any에서 정상 형용사 범위 아홉 개를 보존했고, 기준선에서
재현된 동사 오반환을 제거했다. 동사와 형용사가 모두 등재된
`성하다`는 `요즘 바다에 멸치가 성한다` [27, 36)과
`옷이 아직 성하다` [14, 23)를 검증했다.
[정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

고정 음성 53,308행, 원문 GSD 9,335행, 등록 교정 GSD 9,298행에서
일곱 표제어의 질의를 전수 비교했다. 고정 음성은 0행, 원문은
`싶다` 동사 8행이고 교정에는 형용사 9행이 있었다. 원문 동사
질의 8건의 오반환을 제거했고 교정의 형용사 반환을 보존했다.
겹치는 GSD 문장 두 행은 원문 ID에 따라 각각 채점했다.
과거 비교 258,541행에서 KAIST 개발 세트가 보조 용언 `px`를
동사로 취급한 `자랑할 만한` [185, 191)의 결과 한 건이 세
경계에서 달라졌다.

## WASM

`wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release`의
원본은 2,845,136 → 2,851,221 B (+6,085), `gzip -9nc`는
967,210 → 970,112 B (+2,902), `brotli -q 11 -c`는
713,715 → 713,518 B (−197)였다. Node 26.11.1에서 기본 API의
Token과 같은 사전을 장착한 Smart를 NFC·NFD에서 비교했다.
양성 36회 모두 정확히 반환했고, 음성 36회 중 34회의 기준선
오반환이 후보에서 사라졌다.
