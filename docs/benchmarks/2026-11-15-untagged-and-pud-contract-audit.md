# KAIST 품사 미지정 음성과 PUD 보조 용언 범위

## KAIST 품사 미지정 표본

고정 1,000행의 원문, 질의, 품사, 원본 레이블과 SHA-256으로 계약 검토를
확인했다. 양성 500행과 음성 500행의 원본 채점은 유지했다. Smart의 원본
음성 적중 두 건은 서로 다른 근거로 계약 양성이다.

- `강하다`는 형용사 `강하다`와 명사 `강하(降下)`에 모음 뒤 지정사
  `다`가 결합한 형태가 겹친다. 원문과 대조문에 모두 주어·서술어가 있고,
  원문의 형용사 해석을 고르려면 문장의 의미를 판단해야 한다.
  [한국어기초사전 강하](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=22708) ·
  [한국어기초사전 강하다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=64002)
- `대규모로`는 고정 MeCab-ko 2.1.1 사전이 `대/NNG + 규모/NNG`로
  정렬한 `대규모`에 방향 조사 `로`가 붙은 형태다. `규모로`의 범위가
  같은 성분에 정렬된다.

원본 행렬과 이전 계약 결과, 기존 검토 2건에 위 두 건을 추가한 결과를
같은 반환 범위에 적용했다. 행렬은 TP, FP, TN, FN 순서다. 비율(%)은
precision, recall, F1 순서다.

| 모드 | 원본 행렬 / 비율 (%) | 이전 계약 행렬 / 비율 (%) | 검토 적용 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 498, 2, 498, 2 / 99.60, 99.60, 99.60 | 498, 2, 498, 0 / 99.60, 100.00, 99.80 | 500, 0, 498, 0 / 100.00, 100.00, 100.00 |
| Any | 498, 14, 486, 2 / 97.27, 99.60, 98.42 | 498, 14, 486, 0 / 97.27, 100.00, 98.61 | 500, 12, 486, 0 / 97.66, 100.00, 98.81 |
| Token | 403, 0, 500, 97 / 100.00, 80.60, 89.26 | 403, 0, 500, 95 / 100.00, 80.92, 89.46 | 403, 0, 498, 97 / 100.00, 80.60, 89.26 |

## PUD 정확 범위

Smart 양성 798건에 대해, 각 행의 원문과 PUD CoNLL-U 문장이 일치하는지
확인하고 골드 끝점 바로 뒤가 해당 본용언에 의존하는 `AUX/VX`인지
전수 대조했다. 해당 사례는 아래 여섯 건이다. 반환 시 그 보조 용언을
포함하는 [제품 범위 계약](../../specs/matching.md#06-구조-기반-국소-형태-판정)을 적용해
원문의 바이트로 시작과 끝을 독립적으로 계산했다.

| PUD 행 | 원본 표적 | 보조 용언 | 원본 범위 | 계약 범위 |
| --- | --- | --- | --- | --- |
| `w01074088:21` | 만들어 | 냈다 | 166..175 | 166..181 |
| `w01133014:13` | 만들어 | 내기 | 108..117 | 108..123 |
| `w01140032:10` | 만들어 | 냈다 | 94..103 | 94..109 |
| `w02005027:7` | 되어 | 준다 | 75..81 | 75..87 |
| `w03005013:15` | 만들어 | 냈다 | 175..184 | 175..190 |
| `w04002055:15` | 타 | 버렸고 | 97..100 | 97..109 |

원본 범위 기준 Smart는 792, 0, 0, 6 / 100.00, 99.25, 99.62다.
별도의 제품 범위 대조에서는 여섯 반환이 위 계약 범위와 정확히 일치해
798, 0, 0, 0 / 100.00, 100.00, 100.00이다. 입력 골드와 원본 비교는
그대로 보존하며, 제품 계약 확인에는 798건 전부를 포함했다.

## 나머지 고정 입력

`38c5707b`와 동일한 런타임에서 조회 결과를 원본과 기존 계약 보정본으로
채점했다. KAIST 품사 지정은 골드와의 겹침, 사전과 교정 GSD 양성은
바이트 범위 일치, hard-negative는 반환 여부를 사용했다.
사전 원본과 보정본 4,458건은
[기존 정렬 검토](2026-11-15-smart-source-context-batch.md#품질)를 적용했고,
GSD 9,298건은 계약 검토 0건이다. 다른 입력에는
[KAIST 품사 미지정 test와 고정 음성](2026-11-15-nominal-prefix-competition.md#품질)이
있다. 원본과 보정본 및 전체 집합과 표본은 각각의 분모로 집계했다.

| Smart 입력 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- |
| KAIST 품사 지정 dev 2,532 | 1265, 1, 1266, 0 / 99.92, 100.00, 99.96 | 1266, 0, 1266, 0 / 100.00, 100.00, 100.00 |

| KAIST 품사 지정 dev 표본 1,000 | 493, 0, 500, 7 / 100.00, 98.60, 99.30 | 491, 0, 504, 0 / 100.00, 100.00, 100.00 |
| KAIST 품사 지정 test 표본 1,000 | 499, 0, 500, 1 / 100.00, 99.80, 99.90 | 497, 0, 501, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458 | 4424, 0, 0, 34 / 100.00, 99.24, 99.62 | 4458, 0, 0, 0 / 100.00, 100.00, 100.00 |

품질 실행은 [체언 경계 비교](2026-11-15-nominal-prefix-competition.md#재현)의
Full POS 리소스와 동일하다. PUD 양성 SHA-256은
`d09a58d14dbee0ceda070e3968aa66d1c1480216d1630c134179d6190abaa7aa`,
원문 CoNLL-U SHA-256은
`55f9c8d465400e070664c5319091d31ce35a16ec220b0bebc5e3c9b12f530948`이다.
계약 검토와 문서만 변경해 성능 측정은 생략했다.
