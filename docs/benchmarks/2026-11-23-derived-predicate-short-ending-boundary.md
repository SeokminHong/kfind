# 파생 용언 안의 짧은 조건형과 명사형

Smart에서 `제기했다` [105, 117) 안의 `제기` [105, 111)가
`제다`의 명사형으로, `사면하였다` [169, 184) 안의 `사면`
[169, 175)가 `사다`의 조건형으로 반환됐다. 사전에서 명사 `제기`와
`사면` 뒤에 동사 파생 접미사와 어미가 붙는 구조를 확인했다.
기존 완결 파생 용언 판정에 조건형과 `-기` 명사형을 적용했다.
`빵을 사면`과 같은 문장의 `사면했다`는 각각 [14, 20),
[78, 90)의 별도 동사 범위다.
