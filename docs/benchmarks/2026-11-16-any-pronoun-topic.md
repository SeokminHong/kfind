# Any의 대명사와 주제 보조사 축약

compact 리소스를 사용할 때 대명사와 주제 보조사의 축약형 `전·난·넌`을
완결된 어절에서 검색한다. 관형사 분석이 경쟁하면 뒤 어절과의 연결을
확인한다. `전 정권`, `전 세계적으로`, `심사 전 과정`과 `운전` 내부를
대조하고 지정사가 이어지는 `전 마니아입니다`와 부사가 꾸미는 용언이
이어지는 `전 약간 비린 느낌이어서`를 회수했다.

## 품질

기준선 `f3d1a412`와 후보 `d56dc602`를 같은 입력 12세트의 세 모드에서
실행해 249,243개 결과의 전체 UTF-8 범위를 비교했다. 변경된 범위는
Any 교정 GSD 두 행의 `전`이다. 고정 음성 53,308행과 hard negative
45행에 새 반환 범위가 없다. compact 없이 실행한 Any 83,081행의
반환 범위도 같다. Smart의 고정 평가 11세트에서 계약 FN은 0건이다.

처음 축약형을 활성화했을 때 Any의 27행이 달라졌고, 25행에서
`운전`, `지난해` 같은 내부 위치나 경쟁 체언에 일치가 추가됐다.
완성된 어절과 경쟁 품사를 확인하는 후보는 이 범위들을 제거했다.
CLI에서는 교정 GSD 961문장 전체에 `저·나·너`를 각각 검색했다.
새로 반환된 두 범위는 모두 대명사 `저`의 축약형이었다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.
교정 GSD의 별도 계약 검토는 0건, 고정 음성은 543건이다.

| Any 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 교정 GSD 9,298행 | 기준선 | 9253, 0, 0, 45 / 100.00, 99.52, 99.76 | 9253, 0, 0, 45 / 100.00, 99.52, 99.76 |
| 교정 GSD 9,298행 | 후보 | 9255, 0, 0, 43 / 100.00, 99.54, 99.77 | 9255, 0, 0, 43 / 100.00, 99.54, 99.77 |
| 고정 음성 53,308행 | 양쪽 | 0, 17622, 35686, 0 / 0.00, —, 0.00 | 543, 17079, 35686, 0 / 3.08, 100.00, 5.98 |

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
새 프로세스 워밍업 1회, 측정 5회를 순서를 교대하며 실행했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.
