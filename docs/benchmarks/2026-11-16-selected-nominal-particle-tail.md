# 선택된 체언 뒤 조사의 명사 오탐

관형사로 시작하는 합성 명사 후보를 확인하려고 어절 전체를 다시 분석할 때,
이미 선택한 체언 바로 뒤에 붙은 조사의 범위가 명사 성분으로 재사용됐다.
같은 범위에 조사 분석이 있고 앞말에 결합할 수 있는 조사 형태까지 확인되면
이 경로에서 해당 명사 후보를 제외한다.

고정 입력 12세트의 세 모드에서 반환 범위 249,243행을 대조했다. Smart의 PUD
음성 7행에서 `지출금은`, `은행 고객은`, `대변인은`, `기업은`의
`은`과 `그녀가`, `타이가가`, `모두가`의 `가`가 각각 빠졌다. 네 행은
적중이 사라졌고 세 행에는 다른 반환 범위가 남았다. 새로 추가된 반환 범위는 없다.
`이민자가`의 `자가`, `칠월에`의 `월에`를 검증했다. 기존 `어느날`
테스트는 사전 태그만으로 `날`을 제외하는 회귀를 잡는다.

## 품질

고정 음성 53,308행에 양쪽 모두 기존 계약 검토 171건을 적용했다.
행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
양성 분모가 0인 원본 recall은 `—`로 표기한다.

| 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |

| Smart | 기준선 | 0, 4030, 49278, 0 / 0.00, —, 0.00 | 171, 3859, 49278, 0 / 4.24, 100.00, 8.14 |
| Smart | 후보 | 0, 4026, 49282, 0 / 0.00, —, 0.00 | 171, 3855, 49282, 0 / 4.25, 100.00, 8.15 |

이전 고정 평가 11세트에서 Smart 계약 FN은 0건이다. 별도로 비교한
보정 전 사전 양성 입력 4,458행의 계약 FN 33건은 양쪽에서 같다.
Workspace 테스트 640건, gold 925건과 walk/hang 스트레스, 포맷과
Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
기준선 `626c4926`과 후보 `97795f58`을 비교했다. 기준선 러너는
`b0c250fa` 빌드를 사용했으며 workspace crate와 러너 소스 및 잠금 파일이
`626c4926`과 일치한다. 양쪽에 같은 입력과 리소스를 지정하고 새 프로세스로
워밍업 1회와 측정 5회를 실행했다. 실행 순서를 교대했고 p95는 최근접 순위다.
표는 중앙값 [최솟값, 최댓값]이다.
