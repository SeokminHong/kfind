# 붙여 쓴 결과 상태 보조 동사의 검색 품사

Smart의 형용사 `있다` 질의는 `남아있게`의 `있게`와 `열려있다`의
`있다`를 독립 형용사로 반환했다. 어절의 처음부터 선행 동사의 모음
연결형과 뒤의 보조 동사 활용이 완성되면 해당 형용사 후보를 제외한다.
`지불할 돈이 있다`와 `할 수 있는 일이 남아있다`의 독립 형용사 범위를
고정 회귀에서 검증했다.
[한국어기초사전 보조 동사 있다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62595) ·
[국립국어원 살아 있다의 띄어쓰기](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6460) ·
[국립국어원 파생 용언과 보조 용언의 붙여쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?qna_seq=331002)

UD 2.18 GSD·PUD test에서 한글 토큰 내부에 `있`이 있는 102곳을
찾았다. 해당 원문 97문장의 NFC·NFD 전체 바이트 범위를 대조했다.
형용사 질의의 오반환 7곳이 사라졌다. 동사와 자동 품사 질의의 전체 반환
범위는 같았다. 띄어 쓴 보조 동사와 어절 전체의 용언 경로를 확인할 수
없는 표면형은 이 측정의 변경 대상에 포함되지 않았다.

고정 12세트의 Smart·Token·Any 반환 목록 249,243개 중 바뀐 두 건은

macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
