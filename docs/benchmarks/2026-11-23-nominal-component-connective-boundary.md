# 명사 성분 내부의 모음 연결형 오탐

원문 GSD에서 `지진해일로`의 `해` [37, 40)이 동사 `하다`로
반환됐다. `지/용언+진/연결 어미`와 뒤의 `해/용언+일/관형형 어미`를
조합하는 경로가 열려 있었다. 두 명사 `지진·해일` 뒤에 조사 `로`가
이어진 분석을 확인했다. 같은 문장의 실제 보조 용언 `하였다`
[139, 148)도 확인해 두 GSD 채점에 동일한 정답 범위를 등록했다.
[국립국어원 지진해일](https://kli.korean.go.kr/term/trgtWord/indexTrgtWord.do?trgtWordNo=225283)

완성된 명사·조사 경로에서 검색 기준점보다 긴 명사 성분이 선호되는
경우에 모음 연결형 후보를 검사한다. 붙어 있는 용언과 끝까지 이어지는
활용 근거를 보호한다. 명사 경로 하나만으로 판정한 후보는
`말해준다`, `출발하기는어렵다`, `회복하기위해서는`의 정상 반환도
제거했다. 최종 후보는 이 세 회귀와 `수리를 해 봤다`의 반환을 유지했다.
`지진해일이 밀려와서 구조 작업을 하였다`에서도 실제 동사 [46, 55)와
주격 조사까지의 명사 `해일이` [6, 15)를 보존했다.
[범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)
