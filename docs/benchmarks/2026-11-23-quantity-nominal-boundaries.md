# 수량 뒤 비교 명사와 어림 접미사의 경계

`9a1a8b7b`는 `정·도·정도·어느`를 직접 연결했다. 그 규칙은
`군에 속한 어느 정도 참여하지 않았다`의 지명 `정(町)+도`를
누락시켰고, `미만으로` 내부의 `미`, `시간쯤` 내부의 `쯤`,
`시간가량은` 내부의 `가량`을 남겼다. 네 예문에서 원래 구현의
실패를 확인했다.

기존 `COMPARATIVE_NOMINALS`의 비교 명사와 선택적 조사, 기존
`QUANTITY_APPROXIMATION_SUFFIXES`의 어림 접미사와 선택적 조사를
각각 검사한다. 숫자와 단위, 수사와 단위, 기간 명사를 같은 수량
확인 경로에서 판정한다. `has_object_counter`는 개수를 세는 용언
대조에서 사용하므로 기존 날짜·가격·기간 제외 조건을 유지한다.
`has_comparative_nominal_surface`의 지정사 경로와 `더·덜`의 비교
부사 경로도 확인했다. `불과`와 경과 시간의 `만`에는 표면형을
직접 확인하는 별도 경로가 있다. 인접 규칙을 같은 줄, 줄바꿈 및
쉼표의 여덟 예문으로 대조했고 두 실행 파일의 전체 범위가 일치했다.
