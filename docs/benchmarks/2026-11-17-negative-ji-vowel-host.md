# 모음 어간과 부정 연결형 지의 체언 경계

`소리가 나지 않았다`의 `나지`는 `나다`의 연결형 뒤에 부정 보조
용언이 이어지는 구성이다. Smart는 체언과 같은 범위에서 시작하는
용언 어간과 `-지`, 뒤 부정 보조 용언을 모두 확인해 짧은 체언
후보를 제외한다. `이 사진을 찍은 사람은 나지.`의 생략 지정사는
종결형이며, 다음 문장이 `않았으면`으로 시작해도 대명사 범위를
반환한다. [국립국어원 ‘문법 범주’의 장형 부정 설명](https://www.korean.go.kr/nkview/news_pdf/2020_11.pdf)

## 품질

이전 조사에서 확인한 모음 뒤 `지`의 체언 잔여 7범위를 모두
원문에 대조했다. GSD `test-s878`, `test-s969`에서 `나지 않고`,
`나지 않은데`의 명사·대명사 4범위, PUD `n01083013`에서
`해가 가지 않도록`의 명사 1범위를 제거했다. `유지 가능성`과
`어떻게 가지?`에는 부정 보조 용언이 없어 반환이 유지됐다.

고정 12세트 83,081행의 세 모드 반환 249,243개를 비교했다.
바뀐 것은 위 다섯 Smart 반환뿐이다. 직접 대조 13질의에서
`나다·가다·서다·집다`의 연결형, 생략·명시 지정사, 통째 명사
`가지`를 정확히 반환했다. 고정 음성 계약 검토 1,357행 및 제외
67행은 동일하며, 목표 11세트 Smart FNc는 0, FPc는 2,061에서
2,056이다. NFD로 바꾼 직접 대조 13질의도 CLI에서 기대한 바이트
범위와 종료 상태를 모두 확인했다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
직접 대조에는 계약 검토가 없다.

## 성능

각 값은 중앙값 [최솟값, 최댓값]이다. p95는 실행별 질의 시간의
nearest-rank 95백분위수를 집계했다.

| Smart 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | 최대 RSS (MiB) |
| --- | --- | ---: | ---: | ---: | ---: |
| GSD | 기준선 | 60.811 [60.391, 61.026] | 30,398 [30,354, 30,480] | 0.07129 [0.07100, 0.07158] | 81.234 [81.047, 81.500] |
| GSD | 후보 | 60.475 [60.168, 60.969] | 30,427 [29,193, 30,540] | 0.07067 [0.07046, 0.07338] | 81.141 [81.078, 81.422] |
| 고정 음성 | 기준선 | 60.784 [60.502, 61.058] | 19,858 [19,821, 19,912] | 0.12504 [0.12458, 0.12579] | 127.500 [127.141, 127.547] |
| 고정 음성 | 후보 | 61.079 [60.640, 62.170] | 19,812 [19,621, 19,884] | 0.12583 [0.12463, 0.12792] | 127.563 [127.250, 127.609] |

중앙값 변화는 표의 지표 순서로 GSD −0.55%, +0.09%, −0.88%, −0.12%,
고정 음성 +0.48%, −0.23%, +0.63%, +0.05%다. 각 지표의 측정 범위가
겹쳤으며 바이너리 크기는 양쪽 5,177,216바이트였다.

## 재현

- 기준선 `e25a2b4d`의 검색 코드 `f0986cc2`와 후보 `fd06bc4f`를 Apple M1 Max arm64,
  macOS 26.6.2 (25G83), Rust/Cargo 1.97.0에서 `cargo build --release --locked
  --manifest-path tools/morph-compare/runner/Cargo.toml`로 빌드했다.
- GSD `gsd-saint-determiner.jsonl`과 고정 음성 `negatives.jsonl`을
  `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로 실행했다.
  실행마다 새 프로세스를 만들고 각각 예열 1회 후 측정 5회를 번갈아 수행했다.
- 고정 반환 비교는 `morph-benchmark-runner boundary full-pos MODE INPUT OUTPUT`을 사용했다.
  두 비태그 세트에는 `boundary` 대신 `untagged`를 사용했다.
