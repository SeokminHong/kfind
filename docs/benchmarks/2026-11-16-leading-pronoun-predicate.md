# 용언 첫머리와 대명사의 검색 범위

`이끌어`, `나타나기`, `이용할`, `저조한`에서 어절 첫머리는 뒤까지 이어지는
용언 경로에 속한다. Smart는 같은 위치에서 조사를 소비하지 않은 runtime
대명사 후보를 제외한다. `이 역시`의 독립 대명사와 `이들은`의 조사 결합을
각각 확인한다.

## 품질

고정 12세트 83,081행을 Smart, Any, Token에서 비교했다. 바뀐 24행은
모두 Smart의 `이`, `나`, `저` 대명사 질의였다. 용언과 파생 용언 앞부분에
반환되던 24범위가 제거됐고 새 반환은 없었다. 교정 GSD 양성에서는
`이동하였다` 내부의 `이`만 사라졌고 해당 문장의 정답 `이에`는 유지됐다.
독립 대명사와 조사 결합, 단일·파생 용언을 포함한 대조 9건을 검증했다.

고정 평가 11세트에서 Smart FNc는 0건이다. 초기 사전 정렬 대조본의
raw FN 33건은 양쪽에서 같다. 고정 음성 53,308행에 같은 계약 검토
1,199건을 적용했다. 행렬은 TP, FP, TN, FN 순서이고 비율(%)은
precision, recall, F1 순서다.

| 리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- |
| 기준선 | 0, 3727, 49581, 0 / 0.00, —, 0.00 | 1199, 2528, 49581, 0 / 32.17, 100.00, 48.68 |
| 후보 | 0, 3706, 49602, 0 / 0.00, —, 0.00 | 1199, 2507, 49602, 0 / 32.35, 100.00, 48.89 |

## 성능

각 셀은 중앙값 [최솟값, 최댓값]이다. 새 프로세스에서 워밍업 1회 후
기준선과 후보의 실행 순서를 번갈아 바꿔 5회 측정했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.500 [60.370, 61.741] | 31,191 [31,010, 31,205] | 0.06950 [0.06933, 0.07017] | 80.953 [80.859, 81.094] |
| 교정 GSD | 후보 | 60.345 [60.231, 60.998] | 31,135 [30,870, 31,210] | 0.06979 [0.06933, 0.07046] | 81.016 [81.000, 81.047] |
| 고정 음성 | 기준선 | 61.101 [60.368, 61.624] | 19,924 [19,549, 19,992] | 0.12496 [0.12475, 0.12883] | 127.563 [127.453, 127.625] |
| 고정 음성 | 후보 | 60.713 [60.471, 62.335] | 19,936 [19,567, 20,082] | 0.12483 [0.12371, 0.12871] | 127.656 [127.250, 127.734] |

교정 GSD의 처리량은 −0.18%, p95는 +0.42%다. 고정 음성은 각각
+0.06%, −0.10%다. 두 입력에서 관측 범위가 겹쳤다.
