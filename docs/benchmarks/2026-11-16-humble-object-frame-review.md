# 목적격 성분과 겸양 종결형의 동형 활용

`-나이다` 앞의 동사 어간에서 ㄹ이 탈락하면 서로 다른 동사의 활용이
같아질 수 있다. 바로 앞 어절의 목적격 조사로는 해당 성분이 서술어의
목적어인지, 기간이나 동작 범위를 나타내는지 확정할 수 없다.
사전에 목적격 문형이 확인되지 않은 사실도 다른 해석을 문법적으로
배제할 근거가 되지 않는다.
[국립국어원 목적격 조사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=327634)

`비나이다`에서 `빌다`의 목적어가 있는 문장과 `비다`의 기간 성분이
있는 문장을 함께 검토했다. 기존 수량 판정은 `닷새를`에서 후보를
유지했고 `주말을`, `여름을`이 앞서는 경우에는 후보를 제외했다.
종결형 판정에서 목적격 표지만으로 후보를 제외하는 경로를 제거했다.
지원 리소스로 구별할 수 없는 기존 음성 7건은 원본 음성을 보존하고
계약 양성으로 검토했다.
[예문 쌍](../../tools/morph-compare/humble-context-cases.jsonl)
[계약 근거](../../tools/morph-compare/humble-contract-reviews.tsv)

## 품질

기존 문형 자료의 여섯 동사 쌍 12개 표제어에 해당하는 범위 회귀와
기간 변형을 점검했다. 아래 20행은 예문 쌍 18행과 새로운 기간
대조 2행이다. 두 버전에 동일한 계약 검토 9건을 적용했다. 원본
오탐 증가 7건은 겸양 활용이 겹치는 음성 회귀 7행의 반환이고,
원본 누락 감소 2건은 기간 대조문이다.

고정 입력 12세트의 세 모드 249,243행에서는 모든 UTF-8 반환 범위,
입력 ID와 리소스 체크섬이 같았다. 11개 고정 평가의 Smart 계약 FN은
0건이며 고정 음성 53,308행의 원본·계약 FP는 3,910·3,739건이다.
Workspace 테스트 644건, gold와 walk/hang, 포맷, Clippy,
평가 Python 테스트 82건과 계약 대조 테스트 2건을 통과했다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.

| Smart 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 겸양 대조 20행 | 기준선 | 9, 2, 7, 2 / 81.82, 81.82, 81.82 | 11, 0, 0, 9 / 100.00, 55.00, 70.97 |
| 겸양 대조 20행 | 후보 | 11, 9, 0, 0 / 55.00, 100.00, 70.97 | 20, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | 양쪽 | 0, 3910, 49398, 0 / 0.00, —, 0.00 | 171, 3739, 49398, 0 / 4.37, 100.00, 8.38 |

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
기준선 `d0f4342f`와 후보 `e26ec4c9`를 비교했다. 새 프로세스에서
워밍업 1회 뒤 5회씩 실행하고 기준선과 후보의 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| Smart 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 62.408 [60.877, 64.306] | 29,361 [28,811, 30,996] | 0.07492 [0.07104, 0.07529] | 81.063 [80.906, 81.422] |
| 교정 GSD | 후보 | 61.441 [60.732, 63.006] | 30,137 [28,354, 30,876] | 0.07371 [0.07158, 0.07663] | 81.297 [80.828, 81.641] |
| 고정 음성 | 기준선 | 61.545 [61.258, 63.423] | 19,715 [17,260, 19,845] | 0.12708 [0.12608, 0.13571] | 127.797 [127.469, 128.031] |
| 고정 음성 | 후보 | 61.681 [61.593, 61.815] | 19,986 [19,689, 20,025] | 0.12458 [0.12413, 0.12829] | 127.766 [127.406, 127.813] |

교정 GSD와 고정 음성의 처리량 중앙값은 각각 +2.64%, +1.38%,
p95 중앙값은 −1.61%, −1.97%다. 네 지표 모두 기준선과 후보의
측정 범위가 겹쳤다.
