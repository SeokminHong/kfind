## 배포 크기와 WASM 반환 범위

`c0f97f57`과 `a85ee914`에서 wasm-pack 0.15.0의
`wasm-pack build --target bundler --release --out-dir OUTPUT crates/kfind-wasm --locked`
로 만든 기본 WASM은 2,827,464 B, gzip -9 953,319 B, Node 기본 Brotli
702,405 B이며 SHA-256은
`1ee8e6ffbf912c8734d375c0bcd2d6f35f52ec2feab1f2de6484d9cc710240d4`로 같았다.

Node 26.11.1에서 `일왕` 항목 도입 직전과 교정 후의 component를 사용해
예문 6개를 NFC·NFD에서 비교했다. 기본 생성자의 Any·Token·Smart 결과
36개는 같았고 Smart 12개는 component 필요 진단을 반환했다. component를
장착한 생성자와 full POS 및 보강 용언도 장착한 API는 각각 네 입력에서
`왕의`와 국명 성분 `일`을 회수했다. 같은 교정 입력의 `독일 왕` 대조군은
두 API에서 같았다. component는 기준선 37,441,441 B에서 37,441,397 B로
44 B 줄었다.
