# 강조 종결형 다마다·고말고의 검색 범위

표준국어대사전과 한국어기초사전의 `-다마다/-고말고` 예문 13건을
점검했다. 동사·형용사·지정사에 결합하고 과거와 높임 뒤에도 붙는다.
`읽고 말고는`은 어절 경계를 보존한다. 사전 예문 중 `미인이고말고`와
`일이고말고`의 지정사 정답 범위는 두 예문 모두 `이고말고`다.
[표준국어대사전 -다마다](https://stdict.korean.go.kr/search/searchView.do?word_no=74103&searchKeywordTo=3) ·
[-고말고](https://stdict.korean.go.kr/search/searchView.do?word_no=395908&searchKeywordTo=3)

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.

## 성능

시작점 `70a5d2d4`, 기준선 `7efa7ec6`, 후보 `58766970`를 비교했다.
측정 빌드는 기준선 `caaf3a7e`, 후보 `4c82bd60`으로 각 버전과
제품 파일이 같다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서는 순환했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접
