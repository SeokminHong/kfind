# 명사 뒤 수량 표현의 용언 오탐

명사 뒤 수량을 확인해 `가지 두 개`, `가지 약 두 개`,
`가지 어림잡아 서 너 개 쯤`의 용언 후보를 제거했습니다. 두 명사
(`가지`, `돼지`), 어림 표현 여덟 종과 생략형, 수량 54종,
단위 뒤 표현 다섯 종의 조합 4,860건과 회귀 22건을 확인했습니다.
GSD·PUD 원문 1,989문장에서 두 명사 뒤 수량 표현을 검색해 해당
구성 0건을 확인했고, 어림 표현이 포함된 문장 15건을 검토했습니다.
[수량 명사 용례](https://www.korean.go.kr/nkview/news_pdf/2020_04.pdf) ·
[접미사 -쯤](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=329660)

적중 여부를 검사했습니다. 두 버전의 GSD·PUD 63,441행은 반환 범위까지
