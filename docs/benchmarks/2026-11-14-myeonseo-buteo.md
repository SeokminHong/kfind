# 연결 어미 면서 뒤 시작점 조사

GSD·PUD 양성과 고정 음성에서 `면서부터`를 포함한 문장을
대조했다. 한 문장에서 `받으면서부터다`의 전체 범위가 누락됐다.
연결 어미 뒤의 시작점 조사와 평서형 서술격 조사를 이어서 소비한다.
`받으면서부터`, `받으면서부터다`, `가면서부터이다`를 확인했다.
`받으면서도`는 기존 범위를 유지하고 `받으면서부터다리`는 거부한다.

고정 GSD 양성 9,306행에서 해당 한 행을 복구했고 고정 음성
53,308행의 반환 범위는 동일했다. #421의 불일치 1,113행은 정확
1,044행, 부분 23행, 누락 46행이다. 행렬은 TP, FP, TN, FN 순서이며
비율은 precision, recall, F1이다. 계약 검토는 양성 0건, 음성 31건이다.
