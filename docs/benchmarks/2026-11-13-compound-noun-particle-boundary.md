## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Rust·Cargo 1.97.0에서
동일 release 설정과 사전으로 새 프로세스 워밍업 1회 후 5회 측정했습니다.
시작점 `70a5d2d4`, 기준선, 후보의 실행 순서를 순환했습니다. 처리량은 평가
시간 기준, p95는 nearest-rank, RSS는 최대 상주 메모리입니다. 값은 중앙값
[최솟값, 최댓값]입니다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
node tools/morph-compare/apply-gsd-positive-corrections.mjs "$fixed_input" \
  --explicit-copula-noun-spans > "$positive_input"
KFIND_FULL_POS_LEXICON="$lexicon" KFIND_COMPONENT_RESOURCE="$components" \
KFIND_ENRICHED_PREDICATES="$enriched" \
  /usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
