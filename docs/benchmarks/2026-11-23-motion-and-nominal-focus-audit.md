# 이동 논항과 명사 초점의 문법 경계

`53338a37..7be578cd`의 14개 변경에서 제품 판정, GSD 정답 범위,
교정문 재사용 조건과 성능 입력 검증을 함께 대조했다.

- 문장 끝의 `가`는 `에`, `(으)로`, `에게`, `한테`, `께`가 붙은
  체언과 결합한다. 부사어가 없어도 해당 논항을 확인하고, 같은 절의
  수식어가 이어질 때도 확인한다. `도로 가`의 명사와 쉼표 뒤 호격을 보존했다.
  [국립국어원 가다의 문형](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=317656)
- 소지 연결형 뒤에서 부사어·부사격 성분을 확인한 뒤 이동 서술어로
  이어지는지 확인한다. 사전 용언 어간과 `가다`·`오다` 활용이
  일치하는 이동 합성어, 목적격 소지 대상을 취하고 보조 동사 `있다`로
  이어지는 구조도 확인한다. `책을 가지고 학교에 먼저 빠르게 갔다.`는
  `가지다` [7, 16), `가다` [44, 50)이다.
  [국립국어원 가지다의 연결형과 보조 동사](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=331761)
- `가게도`·`가게만은`·`가게까지`에 사전의 보조사 경로를 적용했다.
  `제 소유다`, `우리 동네의 명소예요`의 관형어와 명사 술어도 확인한다.
  `아이를 혼자 가게만 한 일이었다.`에서 동사 `가다`의 [17, 23)을
  보존했다. [국립국어원 지정사 어간 생략](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=314291&searchCondition=&searchKeyword=)

여섯 부사격 표기와 네 가지 부사 구성, 일곱 보조사·조사 연쇄와 세 가지
명사 술어를 교차하고 정상 대조군을 더한 143건을 전체 UTF-8 범위로
검증했다. 기준선의 오반환 63건이 제거됐고 고정 회귀 18건을 추가했다.
별도 탐색 38건에서 범위가 바뀐 15건을 확인했다.
`가 가지고`처럼 띄어 쓴 보조 용언과 동형 후보의 경계는
[소지·이동 판정의 기존 범위](2026-11-23-possession-motion-sequence.md#원문교정문과-품질)에
