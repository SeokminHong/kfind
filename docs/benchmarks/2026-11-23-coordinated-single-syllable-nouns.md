# 나열한 한 음절 명사의 검색 범위

`수, 목에 근무한다.`와 `일·월에 출근한다.`에서 다음 체언이 관형사
판정에 쓰여 앞의 요일 명사가 누락됐다. 쉼표나 가운뎃점 뒤에 한 음절
체언이 조사와 함께 또는 홀로 오면 인접 관형사 구조의 근거에서 뺀다.
`수 시간`의 관형사와 `두 사람`의 수량 구조는 그대로 판정한다.
[국립국어원 문장 부호 규정](https://www.korean.go.kr/kornorms/m/m_regltn.do)
· [한국어기초사전 수](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=89523)

요일 일곱 개를 쉼표·가운뎃점·반복 범위에 대입한 NFC 21행을
동일 리소스로 실행했다. 기준선은 `수`와 `일`의 6행 8범위를 놓쳤고
후보는 21행 28범위를 모두 반환했다. 각 요일의 NFD 입력 7행도 CLI의
`--unicode-normalization canonical`에서 원문 범위를 정확히 반환했다.
`전, 후기의 두 우승 팀이 결승전을 치렀다.`는 `전을` [39, 45)만 반환한다.
`전·후기`에 줄여 쓴 `전`은 반환하지 않는다. `보건, 노동`의 `보다`와
`사실, 믿기`의 `사다` 음성도 확인했다. 회귀 문장의 띄어쓰기와 문장 부호를
확인했고 예문 교정이 필요한 항목은 없었다.

## 네이티브 형태 판정

기준선 `e14c673a`와 검색 코드가 같은 `1ec80a10`의 release 러너와 후보
`81f3cc7a`를 Apple M1 Max 32 GiB, macOS 26.6.2 arm64,
Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다. 워밍업 1회 뒤 새 프로세스에서
두 빌드를 교대로 5회씩 실행했다. 값은 중앙값 [최솟값, 최댓값]이며
p95는 실행별 최근접 순위다.
