# 동사 관형형 판정의 체언 성분 경계

기준선은 `0f79da30`, 후보 코드는 `7b8a7801`이다. `숙성을 거친`에서
목적격 성분이 동사 `거치다`의 관형형을 지지한다. 이 판정에서도 추론한
체언 성분은 위치와 조사 소비를 검증한다. `거친`의 `거`는 사전 어절의
일부에 해당하고, `내 거는`의 `거`는 독립 의존 명사다.
[한국어기초사전 `거치다` 문형](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=15853)

## 품질

UD 2.18 GSD·PUD 원문에서 `거친`으로 시작하는 어절 두 곳의 명사·동사·형용사
질의 여섯 건을 실행했다. `test-s719`에서 명사 `거` 62..65가 제거됐고 동사
`거치다` 62..68은 유지됐다. `n01063048`에서 형용사 `거칠다` 130..136은 그대로다.
새 gold 회귀는 목적격을 받는 다른 동사 문장, 형용사 관형형, 독립 의존 명사에
대해 전체 반환 범위를 검사한다.

고정 평가 12세트의 Smart·Any·Token 전체 범위 249,243개를 대조했다.
위 오탐 한 범위만 달라졌다. 목표 11세트 Smart의 FNc는 0, FPc는 1,741→1,740이다.
고정 음성의 원본 양성 분모는 0이며 양쪽 계약 제외는 110행이다. 행렬은 TP,
FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.
