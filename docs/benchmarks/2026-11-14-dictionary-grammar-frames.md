# 사전 문형과 활용에 따른 형태 검색

원인과 비교를 나타내는 명사구, 수량과 기간 명사의 결합, 관형형과
의문형에 뒤따르는 보조 용언, 사전에 기록된 현재 관형형을 확인했다.
범위 의존 명사 `내`는 앞 체언이 범위를 정하는 경우를 확인한다.
`학교 내 시설`의 범위와 소유 대조 두 행에서는 양쪽 리비전이 모두
소유 후보를 반환했다. 그 대조의 계약 검토 1건은 기존 판정을 유지한다.
[대조 예문](../../tools/morph-compare/possessive-inner-scope-context-cases.jsonl)

행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.
신규 대조, 교정 GSD와 사전 입력은 계약 검토 0건이다.

| 입력 | 리비전 | Raw 행렬 | Raw P/R/F1 (%) | 보정 행렬 | 보정 P/R/F1 (%) |
| --- | --- | --- | --- | --- | --- |
| 신규 대조 | 기준선 | 9, 10, 0, 3 | 47.37, 75.00, 58.06 | 9, 10, 0, 3 | 47.37, 75.00, 58.06 |
| 신규 대조 | 후보 | 12, 0, 10, 0 | 100.00, 100.00, 100.00 | 12, 0, 10, 0 | 100.00, 100.00, 100.00 |
| 교정 GSD | 양쪽 | 9298, 0, 0, 0 | 100.00, 100.00, 100.00 | 9298, 0, 0, 0 | 100.00, 100.00, 100.00 |
| 사전 | 양쪽 | 3970, 0, 0, 488 | 100.00, 89.05, 94.21 | 3970, 0, 0, 488 | 100.00, 89.05, 94.21 |
| 고정 음성 | 기준선 | 0, 4092, 49216, 0 | 0.00, 0.00, 0.00 | 3, 4089, 49216, 0 | 0.07, 100.00, 0.15 |
| 고정 음성 | 후보 | 0, 4088, 49220, 0 | 0.00, 0.00, 0.00 | 3, 4085, 49220, 0 | 0.07, 100.00, 0.15 |
| 범위·소유 대조 | 양쪽 | 1, 1, 0, 0 | 50.00, 100.00, 66.67 | 2, 0, 0, 0 | 100.00, 100.00, 100.00 |

고정 음성에는 기존 계약 검토 3건을 적용했다. 줄어든 네 건은 PUD의
`달성할`, `달성하기에는`에서 동사·형용사 `달다`가 반환된 사례다.
`verify-gold`는 신규 대조를 모두 통과했으며 기준선과 같은 기존
불일치 8건을 반환했다.

## 성능

기준선 `bd0d5d0d`와 후보 `ed251e23`을 Apple M1 Max arm64,
Darwin 25.6.0, Rust/Cargo 1.97.0 release에서 비교했다. 입력마다
워밍업 1회 후 새 프로세스로 5회씩 순서를 교대했다. 표는
중앙값 [최솟값, 최댓값]이다. p95는 nearest-rank이며 RSS는 최대
상주 메모리다.

기준선 대비 사전·GSD·음성 처리량은 −1.11%, −1.05%, −0.44%이며
p95는 +3.64%, +1.56%, −0.12%다. 각 처리량과 p95의 관측 범위가
겹친다. 초기화는 +1.76%, +1.95%, +0.79%다.
