# 형용사 상태 변화 구문의 비교 부사

PUD `n01112014`에서 `물고기보다 플라스틱이 더 많아질`의
`더` [216, 219)는 부사로만 반환한다. 원문은 이 구문의 조사와
띄어쓰기가 바르다. `많아질`은 형용사 `많다`의 모음 연결형에
상태 변화의 보조 동사 `지다`가 붙은 활용이다.
[PUD 주석](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L6270)
· [한국어기초사전 지다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=77247)
· [국립국어원 많아지다 답변](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=313503)

`더`·`덜` 자료와 주격 체언, 주격 수량, 목적격 체언, 인용 제목을
처리하는 인접 경로를 확인했다. 명시된 주격 성분 뒤에서 기존 사전의
형용사·형용사 파생 품사와 모음 연결형을 확인하고 기존 `지다` 활용
검증기로 오른쪽 어절을 끝까지 검증한다. 이름에 조사가 붙은 범위와
인용 제목, 앞에 주격 성분이 확인되지 않은 `형보다 더 차가워졌다`의
명사 후보를 유지한다. 고정 회귀에서 기준선은 명사 오반환 세 범위를
냈다. 후보의 부사 반환 범위는 세 문장 모두 일치한다.

고정 음성에서 `더`·`덜` 명사 질의 77행을 골랐다. PUD의
교정 주석과 인접 대조를 더해 134개 문장에 명사·부사 268개
질의를 실행했다. SHA-256은
`890736ec7c8989fe6acb37a005bd20db10d4b12d94580ed85008d741fffa61f0`다.
범위가 바뀐 질의는 PUD 1행과 직접 대조 1행이다.
`기온은 더 낮아질`과 같은 보조사 문형과 주격 성분이 생략된
`점점 더 매워지는`도 비교했고 이 형태의 오반환은 남아 있다.
이전 입력의 정확한 범위 258,541건을 비교했을 때
반환 차이는 PUD 1행이었다. WASM의 NFC·NFD, 리소스 장착 Smart·Any,
기본 Token에서는 빌드별 고정 회귀 54개 결과를 검증했다.
