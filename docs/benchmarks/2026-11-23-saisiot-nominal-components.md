# 사이시옷 앞 명사 성분의 검색 범위

표준국어대사전의 붙임표를 사용한 합성 명사 가운데 첫 성분 끝에 받침
ㅅ이 있고 이를 뗀 표면과 뒷성분에 명사 등재가 있는 3,855개 표제어
항목을 조사했다. 뜻풀이가 첫 명사와 뒷성분을 직접 관계 짓는 항목에서
34개 합성어를 확인했다. `들깻가루`와 `고춧가루`는 재료를 빻은 가루이고
`나뭇잎`은 나무의 잎이다. `햇빛`의 해와 `햇곡식`의 접두사 `햇-`를
대조했다. MeCab-ko-dic의 분절만 이용하면 `솟대`의 `솟`을 명사 `소`로
잘못 연결할 수 있다. 3,821개 항목은 이 기준으로 첫 명사를 확정하지 못했다.
[국립국어원 들깻가루 표제어 선정](https://www.korean.go.kr/nkview/nklife/2015_1/25_01.pdf)

## 정확한 반환 범위

34개 표제어를 인용, 목적격, 보조사, 인용형 지정사 문맥에서
검증했다. 첫 명사의 136개 누락이 복원됐고 합성 명사 전체 136개와
`햇곡식`, `솟대`, 단독 `들깨`의 대조 결과를 보존했다. 동일 입력의
SHA-256은 `b090931a031216173f75cb9b917cdea7e740d513a7170ad5b54b3ab408236659`이다.
[정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

원문의 `들깨가루 같은 것도 원하는대로 …`와 교정문
`들깻가루 같은 것도 원하는 대로 …`에 같은 64개 질의를 각각
적용했다. 교정문의 명사 `들깨`에서 [0, 6) 하나가 추가됐다.
합성 명사 `들깻가루` [0, 12)와 다른 질의의 범위는 유지됐다.
이 대조 입력의 SHA-256은
`4ccdb776c94dbf05274f5a12710274e7152d29bcedc1c13d813bb549599732c5`다.

고정·등록 비교 세트에서 기존 표기의 258,541개 반환과 원문
9,335개의 반환을 유지했다. 새 등록 교정문 9,298행에서는
`gsd:test-s66:1`의 한 범위만 달라졌다. 같은 기준선에서 등록 교정에
사이시옷을 반영하면 FNc는 0에서 1이 되고, 제품 후보에서 다시
0이 된다. 원문 주석의 FNc 617 → 616은 비표준 표기 [0, 12)만
계약에서 제외한 효과다. 원문과 같은 문장의 다른 질의는 계속 채점한다.

## WebAssembly

wasm-pack 0.15.0 release bundler에서 기본 WASM은 2,840,676 →
2,843,841바이트였다. `gzip -9nc`는 963,793 → 966,578바이트,
`brotli -q 11 -c`는 710,713 → 714,880바이트였다. 사전 리소스는
양쪽에서 동일했다. Node 26.11.1에서 기본 API의 명시적 Smart 검색에
필요한 component를 확인했고, 장착 API의 canonical NFC·NFD에서
단독과 합성 성분의 복수 일치, `햇곡식`, `솟대`와 Any·Token 범위를
검증했다.
