# 회상 어미 러이다 계열

표준국어대사전 XML 2026-07-05에서 표제 7개의 결합 조건과 예문 8개를 대조했다.
지정사와 `아니다`, 주체 높임, 회상 `-더-`, 전망 `-(으)리-`가 허용된다.
`선비러니라`는 모음으로 끝나는 체언 뒤에서 지정사가 생략된 예다.
[우리말샘 -러니](https://opendict.korean.go.kr/dictionary/view?sense_no=493264) ·
[표준국어대사전 -러이다](https://stdict.korean.go.kr/search/searchView.do?word_no=100106&searchKeywordTo=3)

자동 정렬이 명사 뒤 `이러-`를 동사 `이러다`로 분류한 5건의 질의를
`이다`로 교정했다. 이 5건과 이미 지정사로 분류된 명시형 2건은
`이-`부터 어절 끝까지를 정답으로 삼았다. 생략형 1건은 원래 범위를 보존했다.
직전 입력을 그대로 사용하면 기준선과 후보의 `smart` 표적 일치는 0/8과 1/8이며,
`any`는 양쪽 모두 0/8이다.

행렬 순서는 TP, FP, TN, FN이며 비율 순서는 precision, recall, F1이다.
교정 사전의 계약 검토는 0건으로 raw와 보정이 동일하다.

| --- | --- | --- | --- | --- |
| 표적 8건 | smart·any | 기준선 | 0, 0, 0, 8 | 0.00, 0.00, 0.00 |
| 표적 8건 | smart | 후보 | 8, 0, 0, 0 | 100.00, 100.00, 100.00 |
| 표적 8건 | any | 후보 | 7, 0, 0, 1 | 100.00, 87.50, 93.33 |
| 사전 4,458건 | smart | 기준선 | 4162, 0, 0, 296 | 100.00, 93.36, 96.57 |
| 사전 4,458건 | smart | 후보 | 4170, 0, 0, 288 | 100.00, 93.54, 96.66 |
| 사전 4,458건 | any | 기준선 | 3722, 0, 0, 736 | 100.00, 83.49, 91.00 |
| 사전 4,458건 | any | 후보 | 3729, 0, 0, 729 | 100.00, 83.65, 91.10 |

교정 GSD 9,298건, 고정 음성 53,308건, KAIST 5,124건의 반환 범위는
동일했다. 해당 입력의 raw 및 계약 보정 지표는
[이유 연결형 지라 측정](2026-11-14-causal-jira.md)과 같다.

Apple M1 Max arm64, RAM 32 GiB, 로컬 APFS SSD, Darwin 25.6.0,
Rust/Cargo 1.97.0 release에서 비교했다. full POS `smart`에서

 | if ($row.ending|IN("러니","러니이까","러니이다","러라","러이까","러이다"))
   then ($row | .query="이다" | .pos="adjective" | .surface=("이"+.ending) | .gold_byte_start=(.gold_byte_end - (.surface|utf8bytelength)) | tojson)
   else . end
' "$prior" > "$dictionary"
