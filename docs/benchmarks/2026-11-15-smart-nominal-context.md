# Smart의 명사구와 지정사 생략형

`정신문화의 일대 전환`에서는 관형격 명사구와 성상 관형사 `일대`가
뒤의 명사를 수식한다. 위치 명사 목록 14개를 component 원본의
`MM.csv`와 대조했다. 전체 표면의 관형사 분석이 있는 `사이·속·일대`
중 국립국어원 자료에서 성상 관형사로 확인된 `일대(一大)`의
관형사 분석을 보존했다. `서울 일대`의 위치 명사와
`두 나무의 사이 통로`의 명사 구조를 대조했다.
[국립국어원 성상 관형사 목록](https://www.korean.go.kr/nkview/nklife/2005_1/2005_0113.pdf) ·
[한국어기초사전 사이](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=61187) ·
[한국어기초사전 속](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=71278)

지정사 `이-`가 생략된 `-다`는 모음으로 끝나는 체언에 붙는다.
`뭐든 다 좋은 거라고`의 독립 부사 `다`를 제외하고, 한 어절 안에서는
완결된 용언·조사구와 경쟁할 때 독립 체언 근거를 확인한다.
[국립국어원 -다의 결합 조건](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=332679)

## 품질

교정 KAIST dev에서 관형사 `일대` 1건이 정확한 범위 52..58로
바뀌었다. 사전 원본·보정본 각 4,458건에서 기존 `이다` 결과의
`다` 반환 30건을 전수 검토했다. `다 좋은`, `필요하다`, `생각보다` 등
23건의 표적 밖 반환을 제거했다. 나머지 7건에는 `아니다` 5건과
`오래다`, `나보다`가 포함된다. KAIST dev/test에서도 표적 밖
반환을 한 건씩 제거했다. 사전과 KAIST에서 기존 정답을 잃은 행은 없다.
교정 GSD 9,298건과 GSD·PUD 음성 53,308건의 반환 범위는 동일했다.
이 두 입력과 사전·KAIST test의 행렬은
[고정 입력 보고서](2026-11-15-fused-copula-question.md#품질)와 같다.
위치 대조 22건에서 기존 FP 1건은 `안`의 명사 질의다.
골드 925건과 walk/hang, workspace 테스트 634건과 Clippy를 통과했다.

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
위치와 생략형 대조는 검토 0건이다. KAIST 양성은 표적 겹침으로 채점했다.
생략형 대조는 표적 범위의 정확한 반환을 채점했다. 후보의 FP 1건은
`거짓은 아니다`에 해당한다.

| 입력 (Smart) | 버전 | Raw 행렬 / 비율 (%) | 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 위치 대조 22건 | 양쪽 | 17, 1, 4, 0 / 94.44, 100.00, 97.14 | 17, 1, 4, 0 / 94.44, 100.00, 97.14 |
| 생략형 대조 12건 | 기준선 | 5, 6, 1, 0 / 45.45, 100.00, 62.50 | 5, 6, 1, 0 / 45.45, 100.00, 62.50 |
| 생략형 대조 12건 | 후보 | 5, 1, 6, 0 / 83.33, 100.00, 90.91 | 5, 1, 6, 0 / 83.33, 100.00, 90.91 |
| 교정 KAIST dev 2,532건 | 기준선 | 1262, 1, 1266, 3 / 99.92, 99.76, 99.84 | 1263, 0, 1266, 3 / 100.00, 99.76, 99.88 |
| 교정 KAIST dev 2,532건 | 후보 | 1263, 1, 1266, 2 / 99.92, 99.84, 99.88 | 1264, 0, 1266, 2 / 100.00, 99.84, 99.92 |

## 성능

기준선 `f268d7ba`와 두 기능 커밋을 포함한 후보 `1e12283b`를 Apple M1 Max arm64,
macOS 26.6.2, Rust/Cargo 1.97.0 release의 Full POS Smart로 비교했다.
워밍업 1회 뒤 새 프로세스로 5회씩 실행 순서를 교대했다.
값은 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위, RSS는 최대 상주 메모리다.

| dev | 기준선 | 61.335 [60.855, 61.484] | 35011 [34749, 35137] | 0.07179 [0.07104, 0.07208] | 66.109 [66.063, 66.156] |
| dev | 후보 | 61.120 [60.819, 61.632] | 35078 [34654, 35190] | 0.07163 [0.07142, 0.07204] | 66.266 [66.109, 66.313] |
| GSD | 기준선 | 61.027 [60.672, 64.332] | 31859 [30362, 31962] | 0.06863 [0.06829, 0.07137] | 80.641 [80.609, 80.719] |

dev·GSD·음성 처리량은 각각 +0.19%, −0.04%, −0.15%이고
p95는 −0.23%, −0.12%, +0.64%다. 처리량과 지연의 측정 범위는 겹친다.
