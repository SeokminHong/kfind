# 사전 성분 경로의 반문형과 명사

Smart에서 종결 어미 `-람/-으람`과 통째 명사가 겹치면 다음
어절의 명사 성분이나 관형형과 명사 결합을 확인한다. 생성한
활용은 이 판정을 통과했지만 사전 성분에서 확인한 같은 어미
경로가 별도로 살아남았다. 두 경로에 같은 구문 판정을 적용했다.
[한국어기초사전 -람](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=73885&nation=eng)
· [한국어기초사전 사람](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=58161)
· [한국어기초사전 보람](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=58725)

`사람 셋`, `사람 뼈`, `사람 많은 곳`과 `보람 있는 일`의
동형 동사 범위를 비교했다. `사람 셋 몫의 표를 어디서 사람?`의
양쪽 범위를 대조했다. 처음 명사 [0, 6)의 동사 오반환을 제거하면서
반문의 `사람` [35, 41), 인용문에서의 `사람` [13, 19)을 유지했다.
같은 경로의 모음·받침·ㄹ 탈락·높임 및 독립 명사를 고정 회귀로 검증했다.

## 품질

고정 음성 145행, 원문 GSD 9행, 교정 GSD 10행에서
`람`으로 끝나는 어절이 포함된 동사 질의를 확인했다.
258,541건의 기존 반환 범위에서 Smart 3행이 달라졌다.
GSD s93, s370, s864 각각의 명사 `사람` [0, 6)을 보존했고
동사 `사다`의 같은 범위만 제거했다. s93과 s370은 문장
부호를 보완했고 `정구지`와 구어 종결은 보존했다. s864는 원문을 사용했다.
세 문장의 원문과 표준문을 각각 명사와 동사 두 개로 검색한
18행의 SHA-256은
`b527bdfadf9cae51c9f2d1a3914d8b9e42412ad275e9c112c0d2f0a0440dbcd8`다.

고정 회귀 7행은 리소스 장착 WASM Smart·Any, 기본 Token의
NFC·NFD를 빌드별 42건 비교했다. Smart의 오반환 10개가
사라졌고 다른 경계의 결과는 일치했다.

행렬 순서는 TP, FP, TN, FN이며 정밀도·재현율·F1 단위는 %다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 기준선 | 0, 3,034, 50,274, 0 / 0, 0, 0 | 1,430, 1,490, 50,240, 0 / 48.97, 100, 65.75 | 1,492 | 0 |
| 고정 음성 후보 | 0, 3,031, 50,277, 0 / 0, 0, 0 | 1,430, 1,487, 50,243, 0 / 49.02, 100, 65.79 | 1,489 | 0 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 592 / 99.93, 93.60, 96.66 | 13 | 592 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

미판정 추가 반환은 원문 GSD 553행 613범위, 교정 GSD 104행
110범위다. 고정 음성 계약 양성 1,207행의 전체 정답과 제외
42행의 37범위도 검토가 남아 있다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0,
Python 3.14.8에서 기준선 `e6866914`와 후보 `9f527999`의
release 빌드를 비교했다. 빌드별 워밍업 1회 뒤 새 프로세스에서
실행 순서를 교대해 5회 측정했다. 실행별 p95는 최근접 순위다.
[고정 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
· [리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "directive-ram-structural-latest-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" e6866914 "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 9f527999 "$lexicon" "$component" "$predicates"
```

집중 입력은 고정 음성·원문 GSD·교정 GSD 순서로 뽑은 동사
질의 164행, 원문·표준문 대조 18행, 이 경로의 회귀 7행을
연결한 189행이다. ID에는 순서대로 `fixed:`, `raw:`,
`corrected:`, `paired:`, `regression:`을 붙였다.
