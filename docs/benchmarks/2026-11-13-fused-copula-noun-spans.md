# 축약 지정사 앞 명사 정답 범위

`7648744f`의 full POS `smart` 반환 범위를 두 입력의 정답으로 평가했습니다.
한국어 GSD의 명사·지정사·어미 주석과 원문이 일치하는 `인` 27건,
`입니다` 22건, 모음 뒤 지정사가 생략된 `다` 17건의 명사 끝을 교정했습니다.
예를 들어 `개조인`에서 명사 질의 `개조`의 끝은 지정사 활용 앞입니다.
[검색 사양](../../specs/matching.md) · [이전 교정 입력](2026-11-13-compound-noun-partial-particle.md)

행렬은 TP, FP, TN, FN 순서이고 비율은 precision, recall, F1입니다.
양성은 정확한 UTF-8 범위로 평가했습니다. 별도 계약 검토는 0건입니다.

| 입력 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- |
| 기존 교정 9,335건 | 8372, 0, 0, 963 | 100.00, 89.68, 94.56 | 8372, 0, 0, 963 | 100.00, 89.68, 94.56 |
| 축약 지정사 범위 교정 9,335건 | 8438, 0, 0, 897 | 100.00, 90.39, 94.95 | 8438, 0, 0, 897 | 100.00, 90.39, 94.95 |

66건의 정답 끝 바이트만 바뀌었습니다. 교정 후 부분 일치는 694건, 겹치는 반환이
없는 사례는 203건입니다. 제품 성능은 기존 고정 입력과 같은 실행 파일로 평가합니다.

```sh
node tools/morph-compare/apply-gsd-positive-corrections.mjs "$fixed_input" \
  --explicit-copula-noun-spans --fused-copula-noun-spans > "$noun_span_input"
```

교정 입력 SHA-256은 `3deff66d4fea6cafd64d65cf1c5453fc95a49afd548fd83907836cb7c009c455`입니다.
