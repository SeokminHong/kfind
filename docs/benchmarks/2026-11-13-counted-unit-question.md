오탐을 제거했습니다. `이불을 벌써 개냐`에서는 동사만 반환합니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Rust·Cargo 1.97.0에서 같은 release 설정과
사전 리소스를 사용했습니다. 기준선의 실행 파일은 문서 변경 전과 소스가 동일합니다.
새 프로세스에서 워밍업 1회 후 실행 순서를 교대하며 5회 측정했습니다.
값은 중앙값 [최솟값, 최댓값]이며 p95는 nearest-rank입니다.

처리량 중앙값은 양성에서 1.02%, 음성에서 0.21% 증가했고 p95는 각각 1.09%,
0.08% 감소했습니다.
