# 관형사 뒤의 체언과 조사·지정사

부사와 관형사 분석이 겹치는 어절은 다음 어절에 용언 분석이 있어도
그 어절이 체언과 조사 또는 체언과 표기에 남은 지정사 활용으로 끝나면
관형사 분석을 유지한다. `멋진 한 해를`, `멋진 한 해였고`의 `한`을 반환하며
불완전한 지정사 활용은 이 근거로 인정하지 않는다.
[국립국어원의 수 관형사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=322072)

## 원문 대조

고정 음성 53,308행의 PUD 부분을 CoNLL-U 원문과 대조했다. 원문 전체가
같은 문장에서 토큰을 순서대로 바이트 범위에 정렬하고, 관형사는 질의와
같은 `DT/det` 표면, 대명사는 같은 표제어의 `PRON`을 찾았다. 검색 결과를
참조하기 전에 관형사 336행과 대명사 237행의 범위가 정해졌다. 그중
관형사 37행과 대명사 18행은 기존 Smart가 원문 토큰과 같은 범위를
반환하지 않았다. 54행은 원문 토큰의 한쪽 이상이 문자·숫자에 닿아 있고,
세 대명사 범위는 PUD가 조사의 일부를 별도 토큰으로 분리한 경우다.
이 54행의 표기·분절은 개별 계약 검토가 남아 있다.

양쪽이 분리된 나머지 한 행은 `한/DT`가 `해/NNB`를 수식하고
`였고/VC`가 `해`에 붙는 `n01115013`이다. 원문의 범위는 `35..38`이다.
같은 체언에 관형격 조사가 붙은 `n02044008`도 확인했다. 두 행은
동사 관형형과 대조한 뒤 별도의 계약 양성으로 기록했다. 원본 음성표는 보존했다.
`n01115013`의 회귀 문장은 출처의 `ToDoOrigText`에 따라 뒤 절의
`합류할준비`를 `합류할 준비`로 교정했으며 표적 바이트 범위는 동일하다.

## 품질

고정 입력 12개를 세 모드로 실행한 249,243행에서 입력 ID, 리소스 해시와
반환 범위를 대조했다. 원본 음성표의 `n01115013`에 Smart 범위
`35..38`이 추가됐고, 나머지 입력과 두 모드의 반환은 같았다.

아래 표는 고정 음성의 행 단위 결과다. 행렬은 TP, FP, TN, FN 순이고
비율(%)은 precision, recall, F1 순이다. 양쪽 실행에 같은 계약 검토
158건을 적용해 코드 효과를 비교했다.

| 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 4028, 49280, 0 / 0.00, 0.00, 0.00 | 157, 3871, 49279, 1 / 3.90, 99.37, 7.50 |
| Smart | 후보 | 0, 4029, 49279, 0 / 0.00, 0.00, 0.00 | 158, 3871, 49279, 0 / 3.92, 100.00, 7.55 |
| Any | 양쪽 | 0, 17622, 35686, 0 / 0.00, 0.00, 0.00 | 158, 17464, 35686, 0 / 0.90, 100.00, 1.78 |
| Token | 양쪽 | 0, 2864, 50444, 0 / 0.00, 0.00, 0.00 | 120, 2744, 50406, 38 / 4.19, 75.95, 7.94 |

기존 검토 156건만 고정하면 Smart FPᶜ는 3,872건에서 3,873건으로
증가한다. 새로 반환된 `한`을 원문이 관형사로 정렬하고 있으므로 위
표에서는 두 버전에 같은 검토를 적용했다. Any와 Token의 표는 반환
유무를 나타내며 원문 범위 일치와 별개다.

골드 925건과 walk/hang, workspace 테스트, 포맷과 Clippy,
benchmark Python 82건과 계약 대조 2건이 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`9d261610`과 `384ee0ba`를 비교했다. 각 입력과 버전에 대해 새
프로세스로 워밍업 1회와 측정 5회를 실행하고 두 버전의 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.
