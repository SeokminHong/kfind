# GSD 양성 문장의 추가 정답 범위

원문과 교정 GSD에서 각각 미판정 523행과 95행을 검색했다. 명사 질의와
같은 명사가 문장 내 파생 용언의 첫 성분으로 주석된 경우는 원문 7행,
교정문 6행이었다. 모두 같은 문장의 별도 GSD 토큰에 있는
`NNG+XSV+어미` 분절을 대조했다. 접속 부사 `또는`의 미판정 행은
입력별 1행이었다. GSD s565의 두 `또는`은 모두 선택 대상을 연결한다.
XPOS 주석 `MAG`와 `MAJ`를 한국어기초사전의 부사 분류와 대조했다.
[GSD r2.18 원문](https://github.com/UniversalDependencies/UD_Korean-GSD/blob/r2.18/ko_gsd-ud-test.conllu)
· [한국어기초사전 부사 분류](https://krdict.korean.go.kr/eng/dicMarinerSearch/search?mainSearchWord=-%EB%8A%94)
· [명사 성분 검색 사양](../../specs/matching.md#36-확장-경계와-품사를-분리한다)

교정문의 미판정 동사 `하다` 2행은 모두 검토했다. s958은 원문의
`가야합니다`를 `가야 합니다`로 고친 경우다. s988에서는 배달할 능력이
부족하다는 뜻이 아니라 문장 앞부분에서 제시한 이유로 배달할 수 없다는
뜻이므로 `못 한다고`로 쓴다. 두 교정문의 독립 동사 범위를 추가했다.
원문 채점은 기존 범위를 유지했다.
[필요를 나타내는 보조 용언](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=333847)
· [`-어야 하다` 띄어쓰기](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6204)
· [`못 하다` 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=320246)
· [인용 문형 `-고 하다`](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=73277)

s369는 `이동 통신 요금`, `170만 건`, `연체 금액은`으로 고쳤다.
원문 22번은 `연체금액은` 전체를 정답으로 잡았으나 GSD 주석은
`연체+금액+은`이다. 명사 `연체`의 정확한 범위를 확인했다.
같은 문장의 `의원` 내 `원` 반환은 원문과 교정문 양쪽의 미판정 범위에
남겼다. s57, s403, s769는 기존 교정 이력의 공백과 전체 문장을 대조했다.
[단위 명사 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=27&pageIndex=1&qna_seq=336528)

아래 범위는 원문의 UTF-8 바이트 위치이며 오른쪽에 교정문의 위치를 함께
적었다. 같은 문장과 질의의 두 행에는 전체 정답 범위를 공통으로 적용했다.

| GSD 행과 질의 | 원문 범위 | 교정 범위 |
| --- | --- | --- |
| s57:9 명사 지원 | 46..55, 197..203 | 47..56, 198..204 |
| s369:10·22 명사 연체 | 91..97, 152..158, 182..188 | 93..99, 154..160, 185..191 |
| s403:9 명사 조정 | 89..95, 142..148 | 91..97, 144..150 |
| s552:15 명사 출전 | 76..82, 117..123 | 76..82, 117..123 |
| s565:6 부사 또는 | 28..34, 66..72 | 28..34, 66..72 |
| s622:4 명사 주차 | 24..30, 51..57 | 24..30, 51..57 |
| s769:8 명사 결혼 | 35..41, 58..64 | 35..41, 58..64 |
| s958:4 동사 하다 | 32..38 | 32..38, 63..72 |
| s988:11 동사 하다 | 85..94 | 76..85, 86..95 |

## 평가

기준 리비전 `17e81bac`의 Smart full-pos release에서 같은 리소스로
두 교정 입력을 실행했다. 교정본 9,298행 가운데 s369의 17행만 입력이
바뀌었고 그중 반환 좌표가 달라진 11행은 공백에 따른 이동을 확인했다.
원문 GSD와 고정 음성은 입력과 제품 코드가 같아 기존 출력에 새 계약을
적용했다. 실행 입력은 v2.18 고정 원본과 다음 명령으로 생성한 교정본이다.
교정 입력 SHA-256은 `5231c0e7c4d3c72de2982e0c38fc5420f01dcbecd764428e993b903e56dc8308`에서
`ae694ce3309045bbe892bd151a51cb3bcc00ae0d0bf545b9014cc9664e274a5b`로 바뀌었다.
[입력과 러너 재현](../../tools/morph-compare/README.md#gsdpud-고정-감사-입력)

```sh
node tools/morph-compare/replay-gsd-audit-positives.mjs positives.jsonl > corrected-positives.jsonl
runner boundary full-pos smart corrected-positives.jsonl corrected-result.json
python3 tools/morph-compare/score-ud-audit.py --residual corrected-positives.jsonl corrected-result.json
```

행렬 순서는 TP, FP, TN, FN이며 뒤의 세 값은 정밀도·재현율·F1(%)이다.

| 입력 | 원본 행렬 및 지표 | 계약 행렬 및 지표 | FPc / FNc | 검토 / 제외 |
| --- | --- | --- | ---: | ---: |
| 원문 GSD 기존 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,647, 9, 86, 559 / 99.90, 93.93, 96.82 | 20 / 559 | 594 / 34 |
| 원문 GSD 후보 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,648, 9, 86, 558 / 99.90, 93.94, 96.83 | 20 / 558 | 602 / 34 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 6 / 0 | 140 → 149 / 0 |
| 고정 음성 양쪽 | 0, 3,028, 50,280, 0 / 0, 0, 0 | 1,430, 1,483, 50,246, 0 / 49.09, 100, 65.85 | 1,485 / 0 | 1,589 / 149 |

원문 FNc 1건 감소는 s369:22의 전체 어절 주석을 명사 성분 범위로
확정한 효과다. 제품 검색 동작은 동일하다. 양성의 미판정은 원문
523행 583범위에서 515행 573범위로, 교정 95행 101범위에서 86행
92범위로 줄었다. 사전과 원문이 근거를 제공한 위 범위만 이번에 판정했다.
