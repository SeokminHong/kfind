# 청유 인용 관형형과 종결 보조사 경계

청유 인용 관형형 `-자는`은 주체 높임을 포함해 `살자는`, `읽으시자는`처럼
관형형 끝까지 반환한다. 경쟁하는 체언과 주제 보조사 분석이 있으면 Smart는
동작 용언 어간의 출처와 앞뒤 성분을 확인한다. 같은 어절 내부에서 `은/는·도`로
일치를 승인하는 일반 보조사 경로는 종결형에 적용하지 않는다. 명시된 인용, 연결
어미와 보조사의 결합, `모르다`의 `몰라도` 전체 활용을 대조했다.
[국립국어원 인용 어미](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=332600) ·
[국립국어원 보조사 는](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=320810) ·
[국립국어원 보조사 도](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=335082)

## 품질

앞선 [종결 어미 연쇄 검증](2026-11-17-final-source-continuation.md)의
잔여 5범위는 `남자는`, `피자도`, `거라는`, `몰라도` 두 곳이다. 고정
12세트 83,081행의 세 모드 반환 목록 249,243개를 비교했고 Smart에서는
해당 5범위가 사라졌다. 고정 음성의 기존 검토 1,399행을 적용한 목표 11세트에서
Smart FNc는 0, FPc는 1,953→1,948이다.

GSD·PUD CoNLL-U 원문에서 표면이 `자는` 또는 `자도`로 끝나는 27토큰을
모두 찾았다. 앞부분에 `다`를 붙인 동사 질의로 `살자는`의 전체 범위 한 곳과
체언·조사 26곳을 검사했다. 원문상의 `살자는`은 별도 직접 대조이며 고정 양성
질의의 일부가 아니다. 직접 대조에는 같은 표면을 쓰는 청유 인용 `조금 더 남자는
제안을 했다`, 주제어 `그 남자는 진실을 말했다`, 그리고 인용 부호 뒤의
보조사 `‘활짝 피자’도`가 들어 있다. CLI NFC 및 canonical NFD에서 직접 대조
17질의의 반환 목록 34개를 확인했다. 두 직접 입력의 계약 검토는 0건이다.

Any와 Token은 `바꿔보자는`의 전체 범위를 반환한다. 같은 KAIST 문장이
고정 개발 세트와 개발 표본 양쪽에 포함된다. `그 남자는`의 `v:남다`는 Any에서
기존 부분 반환이 전체 어절로 늘었고 Token에서 오탐 1건이 생겼다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.

## 성능

각 값은 중앙값 [최솟값, 최댓값]이다. p95는 질의 시간의 nearest-rank
95백분위수다.

| Smart 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | 최대 RSS (MiB) |
| --- | --- | ---: | ---: | ---: | ---: |
| GSD | 기준선 | 62.196 [61.483, 63.878] | 29,040 [28,082, 29,582] | 0.07446 [0.07329, 0.07633] | 81.391 [81.063, 81.484] |
| GSD | 후보 | 62.038 [61.826, 62.271] | 29,588 [28,680, 29,650] | 0.07325 [0.07254, 0.07683] | 81.531 [81.250, 81.578] |
| 고정 음성 | 기준선 | 62.106 [61.848, 62.523] | 19,142 [16,735, 19,226] | 0.12892 [0.12800, 0.13975] | 127.563 [127.484, 127.797] |
| 고정 음성 | 후보 | 62.136 [61.853, 62.482] | 19,138 [18,932, 19,185] | 0.12925 [0.12904, 0.13100] | 127.609 [127.578, 128.547] |

GSD 처리량·p95 중앙값은 +1.89%·−1.62%, 고정 음성은
−0.02%·+0.26%였다. 두 입력 모두 기준선과 후보의 처리량 및 p95 범위가
겹쳤다. 러너 크기는 5,198,576에서 5,198,880바이트로 늘었다.

## 재현

- 기준선 `ea615024`와 후보 `a3f35f20`을 Apple M1 Max arm64,
  macOS 26.6.2 (25G83), Rust/Cargo 1.97.0에서 `cargo build --release --locked
  --manifest-path tools/morph-compare/runner/Cargo.toml`로 빌드했다.
- GSD `gsd-saint-determiner.jsonl`과 고정 음성 `negatives.jsonl`은
  `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로
  실행했다. 실행마다 새 프로세스를 만들고 예열 1회 후 측정 5회를 번갈아 수행했다.
- 고정 반환 비교는 `morph-benchmark-runner boundary full-pos MODE INPUT OUTPUT`을
  사용했다. 두 비태그 세트에는 `boundary` 대신 `untagged`를 사용했다.
  [고정 입력, 공통 자원 및 SHA-256](2026-11-16-nominal-predicate-path.md#재현)
