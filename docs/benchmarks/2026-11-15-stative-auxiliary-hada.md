# 형용사에 붙은 어하다의 검색 범위

형용사에 붙는 `-어하다`의 `하여/해`와 과거 `하였-/했-` 활용을
어절 끝까지 반환한다. `힘들어하여`, `가여워하였다`, `힘들어했다`와
문장 부호 뒤에 별도로 오는 `하여튼`을 대조했다.
[국립국어원 힘들어하다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=316071)

## 품질

고정 사전의 `-여` 예문 13건을 비교했다. 형용사에 붙은
`-어하여`는 1건이며 추가 계약 보정은 0건이다.
전체 사전에는 [보정 입력](2026-11-15-dictionary-deodeul-review.md#재현)을 사용했다.
행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.

| 입력 | 경계 | 버전 | Raw 행렬 / 비율 (%) | 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- | --- |
| 여 13건 | Smart | 양쪽 | 13, 0, 0, 0 / 100.00, 100.00, 100.00 | 13, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 여 13건 | Any | 기준선 | 12, 0, 0, 1 / 100.00, 92.31, 96.00 | 12, 0, 0, 1 / 100.00, 92.31, 96.00 |
| 여 13건 | Any | 후보 | 13, 0, 0, 0 / 100.00, 100.00, 100.00 | 13, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | Smart | 양쪽 | 4387, 0, 0, 71 / 100.00, 98.41, 99.20 | 4458, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | Any | 기준선 | 4295, 0, 0, 163 / 100.00, 96.34, 98.14 | 4369, 0, 0, 89 / 100.00, 98.00, 98.99 |
| 사전 4,458건 | Any | 후보 | 4296, 0, 0, 162 / 100.00, 96.37, 98.15 | 4370, 0, 0, 88 / 100.00, 98.03, 99.00 |

GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
반환 범위는 직전 기준선과 동일했다. Any 불일치 88건에는 지정사 질의
83건과 다른 용언 질의 5건이 포함된다.
