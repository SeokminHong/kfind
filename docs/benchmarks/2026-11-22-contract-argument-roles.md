# 문형 판별과 WASM 리소스 크기

기준선은 `1aec53cb`, 후보는 `4908f8b5`다. Smart full POS에서
감사 질의 1,747행의 반환 범위 36행이 바뀌었다. 등록 사례 32행과
변형·대조 4행이다. KAIST 테스트 2,604행의 반환 범위는 일치했다.

`듣다`는 `방으로 들어갔다`의 이동 동사를 반환하지 않는다. `교실로 급히 들어갔다`와
`마을로 들어가면`도 같은 판정을 적용한다. `이어폰으로 들어갔다`와
`강의를 … 들어갔다`의 진행형은 반환한다. `늦다`는 약속·면접·마감·회의와
등교·수업 시간 보어에 동사형으로 일치한다. 일반 시간 부사어 뒤의 형용사와
`수업 시간에 시계가 늦죠`도 일치한다.
[들어가다 문형](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=67877)
· [듣다 문형](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=74104)
· [늦다 동사 문형](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=61181)

GSD의 `한` 4행과 외국어 제목의 부사 `더` 2행에서 표적 오탐이 사라졌다.
`공연 중 한 곡`의 동사와 수 관형사, `내가 그중 한 곳`의 동사 관형형,
인용 안의 `더 멀리 간다`는 각 대조 범위를 유지한다.
겸양형의 목적격 소요 기간·수량도 보존했다.

UD 2.18 GSD·PUD 원문에서 독립 표면 `한·더`와 `들어가/들어갔`, `늦-`,
`-라는/-라면/-라도/-랴/-렷다`, 동형 의지 종결형을 검색해 양쪽에 348개
질의를 실행했다. 반환이 바뀐 9행을 확인했다. GSD는 5행이며 나머지 4행은
PUD의 `여성들/친구/조종사 중 한 명`과 `지중해를 중심으로 한`이다.
`n02066010`에서 `한 명`의 동사 오탐만 빠지고 `조사하는`의 동사 성분은 남았다.
GSD `test-s22`는 제목 닫는 부호를 복원한 교정본에서 부사 오탐을 확인했다.

## 배포 산출물

macOS arm64, Rust 1.97.0, wasm-pack 0.15.0의 같은 최적화 bundler 빌드로
측정했다. 압축 크기는 Node.js 26.11.1의 gzip level 9와 Brotli 기본 설정이다.

| 산출물 | 기준선 bytes | 후보 bytes | 증감 bytes |
| --- | ---: | ---: | ---: |
| 최적화 WASM | 2,780,973 | 2,793,467 | +12,494 |
| WASM gzip | 938,143 | 941,525 | +3,382 |
| WASM Brotli | 690,242 | 694,032 | +3,790 |
| 외부 component | 37,103,633 | 37,206,905 | +103,272 |

명사 역할 TSV 115,569 bytes는 component의 정렬된 표면·역할 섹션으로 변환한다.
용례 및 표제어 ID와 전체 TSV는 WASM에 싣지 않는다. full POS의 해시와 크기는 같다.
Node에서 bundler 산출물을 실행해 schema 5와 6 리소스를 각각 로드하고
`듣다`의 검색 결과가 schema 6에서 바뀌는 것을 확인했다.

## 네이티브 성능

Apple M1 Max, Darwin 25.6.0, Rust/Cargo 1.97.0의 release 실행 파일을 사용했다.
각 입력에서 양쪽으로 한 번 워밍업한 뒤 새 프로세스에서 5회 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 감사 질의 | 기준선 | 63.94 [63.48, 64.37] | 28,935 [28,429, 29,562] | 0.11333 [0.10863, 0.11875] | 66.59 [66.27, 66.66] |
| 감사 질의 | 후보 | 64.94 [64.38, 65.75] | 29,320 [27,590, 29,579] | 0.11538 [0.10904, 0.11900] | 66.92 [66.92, 66.94] |
| KAIST | 기준선 | 62.40 [62.11, 62.93] | 28,637 [28,155, 28,916] | 0.08892 [0.08742, 0.09133] | 67.09 [67.06, 67.16] |
| KAIST | 후보 | 63.10 [62.24, 63.51] | 28,675 [28,047, 29,315] | 0.09033 [0.08708, 0.09500] | 67.45 [67.19, 67.53] |

처리량 중앙값은 감사 질의 +1.33%, KAIST +0.13%다. p95는 각각 +1.80%,
+1.59%다. 처리량과 p95는 관측 범위가 겹친다.

```sh
CARGO_TARGET_DIR="$PWD/target" cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
KFIND_FULL_POS_LEXICON="$pos" KFIND_COMPONENT_RESOURCE="$component" \
  KFIND_ENRICHED_PREDICATES="data/enriched/predicates.tsv" \
  /usr/bin/time -l morph-benchmark-runner boundary full-pos smart "$input" "$output"
wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release --locked
```
