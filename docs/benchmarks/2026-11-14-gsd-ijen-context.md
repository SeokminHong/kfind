# GSD 이젠의 문맥 품사

`이젠 삼겹살도 판다`와 `이젠 집에서 만들어 먹어요`에서 `이젠`은
뒤 서술어가 가리키는 행동의 시간을 나타냅니다. 원문의 표기와 바이트 범위를
보존하고 주석을 부사 `이제`와 보조사 `는`의 결합으로 교정했습니다.
[주석 교정 목록](../../tools/morph-compare/gsd-ijen-context-annotations.tsv) ·
[축약 분석 계약](../../specs/matching.md) ·
[부사와 보조사 결합 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=317746)

독립 어절 `이제`, `이제는`, `이젠`을 GSD 양성 9,314행, PUD 양성
798행, GSD·PUD 음성 53,308행과 사전 양성 4,458행에서 검색했습니다.
해당 문장은 각각 2개, 4개, 7개, 69개이며 `이젠`이 있는 문장은 각각
2개, 0개, 2개, 3개입니다. GSD 두 문장의 품사와 범위를 모두 점검했습니다.

`4af9c526` full POS 실행 파일에서 같은 9,314행을 교정 전후로 비교했습니다.
행렬은 TP, FP, TN, FN 순이며 비율은 precision, recall, F1 순입니다.
계약 검토는 0건입니다.

| 경계 | 입력 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- | --- |
| smart | 교정 전 | 9111, 0, 0, 203 | 100.00, 97.82, 98.90 | 9111, 0, 0, 203 | 100.00, 97.82, 98.90 |
| smart | 교정 후 | 9113, 0, 0, 201 | 100.00, 97.84, 98.91 | 9113, 0, 0, 201 | 100.00, 97.84, 98.91 |
| any | 양쪽 | 8938, 0, 0, 376 | 100.00, 95.96, 97.94 | 8938, 0, 0, 376 | 100.00, 95.96, 97.94 |

`any`에서는 부사 축약형을 생성하지 않아 두 행이 계속 누락됩니다. #421에서
남은 1,113행의 `smart` 결과는 정확 일치 926행, 부분 일치 86행, 겹치는
반환 없음 101행입니다.

```sh
node tools/morph-compare/apply-gsd-sentence-edits.mjs "$input" --ijen-context > "$corrected"
"$runner" boundary full-pos "$boundary" "$corrected" "$output"
```
