# GSD 구어 어휘의 품사 주석

교정 GSD 9,306행에서 표면형이 `짱` 또는 `존나`로
시작하거나 `입니다요`로 끝나는 6행을 문맥과 대조했다.
`짱입니다요`에서 ‘으뜸’을 뜻하는 `짱`은 명사이며, 두
`존나`는 뒤의 형용사를 꾸미는 정도 부사다. `짱 좋아요`와
`짱 많아서`의 부사 주석 및 `짱뚱어탕이`의 명사 주석을
유지했다. 원문, 표면형과 UTF-8 정답 범위는 모두 유지했다.
[국립국어원 ‘짱’의 의미](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=327003) ·
[교정 주석](../../tools/morph-compare/gsd-colloquial-pos-annotations.tsv)

검색 실행 파일은 a32c6998에서 빌드했다. 양성 계약 검토
0건으로 raw와 계약 보정 값이 같다. 행렬은 TP, FP, TN, FN,
비율은 precision, recall, F1 순서다.

#421 비교군 1,113행은 교정 후 `smart` 정확 1,068행,
부분 17행, 누락 28행이다. `any`는 정확 944행, 부분 162행,
누락 7행이다. `짱입니다요`는 교정 후에도 전체 범위를 찾지
못했다. 평가 주석만 바뀌어 검색 성능 측정은 생략했다.

```sh
node tools/morph-compare/apply-gsd-sentence-edits.mjs "$input" --colloquial-pos > "$corrected"
"$runner" boundary full-pos "$boundary" "$corrected" "$output"
```

교정 SHA-256은 `5e5b16769d5489b5589e1aceb5980ab726e6cdd3aab55fad4cb628e1da844f62`다.
