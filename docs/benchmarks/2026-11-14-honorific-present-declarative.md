# 주체 높임 현재 평서형 신다 검색

고정 사전에서 주체 높임 현재 평서형 `-(으)신다` 표적 2건을 점검했다.
모음·받침 있는 어간과 ㄹ 탈락을 확인했다. `쓰신 다짐`에서는 관형형만 검색한다.

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
표적의 신규 계약 보정은 0건이다. 전체 사전의
[앞선 보정 10건](2026-11-14-honorific-request-sipsa.md#품질)을 유지한다.

| --- | --- | --- | --- | --- |
| 표적 2건 | smart·any | 기준선 | 0, 0, 0, 2 / 0.00, 0.00, 0.00 | 0, 0, 0, 2 / 0.00, 0.00, 0.00 |
| 표적 2건 | smart·any | 후보 | 2, 0, 0, 0 / 100.00, 100.00, 100.00 | 2, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | smart | 기준선 | 4295, 0, 0, 163 / 100.00, 96.34, 98.14 | 4304, 0, 0, 154 / 100.00, 96.55, 98.24 |
| 사전 4,458건 | smart | 후보 | 4297, 0, 0, 161 / 100.00, 96.39, 98.16 | 4306, 0, 0, 152 / 100.00, 96.59, 98.27 |
| 사전 4,458건 | any | 기준선 | 4160, 0, 0, 298 / 100.00, 93.32, 96.54 | 4170, 0, 0, 288 / 100.00, 93.54, 96.66 |
| 사전 4,458건 | any | 후보 | 4162, 0, 0, 296 / 100.00, 93.36, 96.57 | 4172, 0, 0, 286 / 100.00, 93.58, 96.69 |

`거나:7`의 `오시거나` 표적은 유지됐다. 뒤 절 `오신다`도 독립된
`오다` 활용으로 두 경계에서 반환했다.

GSD 9,298건, 음성 53,308건과 KAIST dev/test 2,532/2,592건의 범위가
같았다. Raw·계약 보정 혼동행렬과 비율은
[고정 입력 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `dda4eab9`, 후보 `d0904d8a`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `5533d195`와
`4d9d7b5f`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다.
p95는 최근접 순위, RSS는 최대 상주 메모리다.
