# PUD 날짜·시간 단위의 원문 정렬

고정 음성에서 PUD의 `년·월·일·시·분·초·주` 명사 질의 436행을
CoNLL-U 원문과 대조했다. 숫자 바로 뒤에 독립 `NNB` 토큰이 있고
수사가 `nummod`로 분석된 날짜·시간 단위를 확인했다. 연월일의
복합 주석에서는 원문의 단위 토큰과 바이트 범위를 직접 맞췄다.
[국립국어원 한글 맞춤법 제43항](https://www.korean.go.kr/kornorms/regltn/regltnView.do)

원문에 실제 단위가 있는 55행의 58범위를
[계약 검토](../../tools/morph-compare/pud-noun-label-corpus-reviews.tsv)에
기록했다. `월`은 35행 37범위, `일`은 17행 18범위, `시`는 1행
1범위, `주`는 2행 2범위다. 원문에서 같은 글자가 별도로 나온
`일본`과 `10개월`도 확인했다. 날짜 단위 외에 `월마·토요일에·목요일`의
일부를 반환한 3행과 `발견하기3일`이 함께 나온 1행은 기존 집계에 남겼다.

원문 55행과 네 종류의 대조문에 단위 명사와 대조 분석의 질의를 각각
실행했다. 총 220개 실행에서 단위 질의는 원문의 58범위를 정확히
반환했다. 대조문에서 단위 질의는 반환이 없었고, 각 대조 분석은 표적
전체를 반환했다. 원문에서 대조 분석이 단위 범위와 겹치는 곳은 없었다.

## 품질

`104734b2`의 동일한 반환 범위를 이전 계약 검토 1,200건과 새 계약
검토 1,255건으로 각각 채점했다. 합의한 고정 11세트의 Smart FNc는
0건이며 FPc는 2,469건에서 2,414건으로 줄었다.
