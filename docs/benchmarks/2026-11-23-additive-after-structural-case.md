# 문법격 조사와 보조사 도의 경계

문법격 조사 `이/가`, `을/를`, `의`와 보조사 `도`는 하나의 조사
연쇄에서 결합하지 않는다. 명사에 바로 붙는 `도`와 `에도`,
`에서도`, `께서도`, `로도`, `만을`의 정상 결합을 양쪽
검증기에서 확인했다. [국립국어원 조사 결합 순서](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=320510) ·
[한국어 조사의 하위 부류와 결합 유형](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART001093772)

## 정확한 반환 범위

등록 평가의 Smart·Any·Token 반환 258,541개와 원문 GSD의 Smart
반환 9,335개에서 체언 질의 바로 뒤의 `이/가/을/를/의`와
`도/만/까지/조차/마저`를 점검했다. 해당 형태를 가진 기준선 Smart
반환은 `나가도`와 `여의도` 두 건이었고 둘 다 검토했다.

| 표적 | 원문과 점검한 표기 | 제거한 명사 오반환, UTF-8 | 보존한 양성, UTF-8 |
| --- | --- | --- | --- |
| 나가도 | 원문 `서울 시내 차 가지고 나가도 되겠니` | [28, 37) | 동사 나가다 [28, 37) |
| 나가도 | 조사와 물음표를 명시한 대조문 `서울 시내에 차를 가지고 나가도 되겠니?` | [34, 43) | 동사 나가다 [34, 43) |
| 여의도 | 원문 `여의도 한강고수부지에서` | [14, 23) | 명사 여의도 [14, 23) |
| 여의도 | `한강 고수부지`로 띄어 쓴 등록 교정문 | [14, 23) | 명사 여의도 [14, 23) |

두 문장의 질의 28개와 65개를 각 표기에 동일하게 적용한 186개
Smart 결과에서 위 네 범위만 달라졌다. 입력 SHA-256은
`8aea65d01148bedbcf84c7a2c94ec8ebffed0e9f0c715401d7fbf6cc278f5a0d`다.
등록 평가에서도 Smart와 Token에서 `나가도` [28, 37)이 제거됐다.
Any에서는 이전 범위가 [28, 34)로 줄었다.

원문 GSD의 `gsd:test-s7:21`은 `여회사원과` [204, 219)를 명사
`여`의 정답으로 표시했다. `여회사원`과 `여고생`의 첫 성분은
접두사이고 앞의 `여의도`는 지명이다. 이 근거로 원문은 보존하고
음성 판정을 기록했다. 같은 기준선에서 이 주석만 반영하면 원문
FPc는 11 → 12, FNc는 621 → 620이다. 아래 표의 제품 비교는

## 네이티브 형태 판정

Apple M1 Max 32 GiB, macOS 26.6.2 arm64, Rust·Cargo 1.97.0,
Python 3.14.8에서 기준선 `a531f6a9`와 후보 `d547a848`를
release로 비교했다. 각 조건을 한 번 가동한 뒤 순서를 교대하며 새
프로세스로 5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는
실행별 최근접 순위다. 두 러너에 동일 리소스를 장착했다.
[사전·입력 체크섬](2026-11-23-native-nominal-prefix-examples.md#네이티브-형태-판정)

| 입력 | 실행 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS KiB |
| --- | --- | --- | --- | --- | --- |
| 고정 음성 | 기준선 | 61.883 [61.583, 65.442] | 19,635.0 [16,703.9, 19,808.6] | 0.1259 [0.1245, 0.1371] | 130,864 [130,736, 131,152] |

처리량과 p95는 고정 음성에서 −1.07%와 +0.56%, 등록 교정 GSD에서
−0.50%와 +1.26%였다. 최대 RSS 중앙값은 각각 304 KiB와 48 KiB 늘었다.
직전 기준선 `1273b5f2`에서 같은 조사 변경을 측정했을 때 교정 GSD의
처리량과 p95가 −1.61%와 +1.96%, 재측정에서 +0.99%와 −0.14%였다.
최신 기준선에서 관측한 차이의 재현 여부는 유보한다.

```sh

  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" a531f6a9 "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" d547a848 "$lexicon" "$component" "$predicates"
```

## WebAssembly

`wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release`
와 wasm-pack 0.15.0에서 기본 WASM은 2,839,856 → 2,839,864바이트다.
`gzip -9nc`는 964,920 → 965,144바이트, `brotli -q 11 -c`는
711,222 → 710,871바이트다. Node 26.11.1에서 component가 없는 기본 API의
명시적 Smart 명사 질의가 거부되는 것을 확인했다. 동일 리소스를 장착한
API에서는 `나가도`의 잘못된 명사 범위가 사라지고 동사와
`학교에서도`, `선생님께서도`, `책만을`의 정확한 범위가 유지됐다.
