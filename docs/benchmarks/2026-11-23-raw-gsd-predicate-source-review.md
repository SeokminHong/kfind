# GSD 원문의 인명과 이어진 용언 주석

같은 Smart full-pos 빌드(`13d6f6b3`)로 GSD 원문 9,335행과
등록 교정본 9,298행을 평가했다. 원문은
`eaafbae7757dbb62c9a0ca6b370dadf0f41b53c3e3d044f21b191c2aab8e3682`,
후보 교정본은
`3e5a4c75efa08d2bacb3a01e2e038151335c6a59b9f9dce7f307403f5b91eb76`다.
[실행 설정과 사전 체크섬](2026-11-23-comparative-measure-subject.md#네이티브-형태-판정)

- `test-s188`의 `내쉬와`는 존 내쉬와 그의 딸을 잇는 명사와 접속
  조사다. 명사 질의에서 원문 [150, 159), 교정문 [159, 168)이
  반환됐다. 동사 `내쉬다`는 두 문장 모두 빈 결과였고
  `숨을 깊이 내쉬었다`에서 [14, 26)이 반환됐다.
  [서울문화재단 공연 자료](https://www.sfac.or.kr/upload/archive/2010/11/05/001/20101105134936C13599_ORG.pdf)
- `test-s436`의 원문 `따라한` [92, 101)은 `따르다`의 연결형과
  본용언 `하다` 사이의 띄어쓰기가 빠졌다. `무료 추천 종목을 따라 한`에서
  명사 `무료`는 [70, 76), 동사 `따르다`는 [94, 100)이다.
  원문 [10, 16)의 명사 `슈퍼` 오반환은 동일 위치에서 계속 발생한다.
  [국립국어원 따라 하다의 형태와 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=335337)
- 동사 `따다`는 교정문에서도 [94, 100)을 반환했다. 명령 인용
  `아버지는 병뚜껑을 따라 하셨다` [26, 32)와 직접 인용
  `아버지는 “병뚜껑을 따라!”라고 하셨다` [29, 35)도 반환한다.
  인용 표지 `고` 없이 쓰이는 명령형이 있으므로 `따라+하다`만으로
  동사 후보를 배제할 수 없다.
  [국립국어원 명령형의 간접 인용](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=330712)

원문 양성·고정 음성과 교정 양성에서 `따라`와 `하다` 활용이
이어지는 조건을 검색했다. 해당 문장은 `test-s436` 하나였고
원문 양성 13행, 고정 음성 33행, 교정 양성 13행이었다.
기존 술어 재분석 표의 11행을 원문과 대조했다. `난방식`은 기존
원문 검토에 반영되어 있고, `그래도`의 두 주석과 `분양한다`,
`필요하시다면`의 원문 누락은 남아 있다. `두말 할`과 `불어 넣었다는`
등은 원문 오탐·누락을 이번 검토에서 재분류하지 않았다.

두 문장의 관련 질의 133개를 원문과 교정문에 적용하고 대조 예문
4개를 확인했다. 반환 표면이 바뀐 질의는 `쓰이다`, `따다`,
`따르다` 세 건이었다. 입력 SHA-256은
`bc138d77ca87c7296627e1bf1cc3be84f8c7b823e29d173aeb4f7c7a699e6dd6`다.
등록 교정본 전체에서 기존 교정본과 반환 표면이 모두 같았고 띄어쓰기
위치 뒤의 6행만 반환 오프셋이 이동했다.

| 입력 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 원문 기존 주석 | 8,291, 0, 0, 1,044 / 100, 88.82, 94.08 | 8,696, 3, 19, 616 / 99.97, 93.38, 96.56 | 11 | 616 |
| 원문 이번 주석 | 8,291, 0, 0, 1,044 / 100, 88.82, 94.08 | 8,697, 3, 20, 613 / 99.97, 93.42, 96.58 | 11 | 613 |
| 기존 교정본 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,287, 0, 11, 0 / 100, 100, 100 | 2 | 0 |
| 이번 교정본 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,286, 1, 11, 0 / 99.99, 100, 99.99 | 3 | 0 |

원문 FNc 세 건은 원문의 인명 주석, 명사 범위, 철자 경계를
검토한 결과다. 원문의 계약 제외 범위는 한 곳 늘어 2행이다.
교정본 FPc 한 건은 기존 독립 명사 오반환을 주석에 반영한 결과다.
추가 반환 미판정은 원문 578행 640범위, 교정본 119행 125범위다.
고정 음성의 품질 입력, 검색 빌드와 조회 자원은 비교 전후 동일하다.
