# 괄호와 인용부호 뒤의 조사

Smart에서 닫는 부호에 붙은 조사를 독립 어휘로 반환하던 경로를 검증했다.
`해(1446년)가`, `《월보》가`와 `“기관(Agency)”과의`는 조사 연쇄다.
`“가”라고` 안의 동사, `(뛰지 말고) 가`의 독립 동사와 `오천에서 만으로`의
수사는 기존 범위를 반환했다.
[국립국어원 문장 부호 해설](https://www.korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0001) ·
[괄호 뒤 조사](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=337379)

## 품질

고정 입력 12세트를 세 모드로 실행해 249,243행의 전체 반환 범위를
대조했다. Smart에서만 59행이 달라졌다. 고정 음성에서는 GSD 29행과
PUD 29행에서 잘못된 범위를 하나씩 제거했다. GSD 한 행에는 `6.3%가`의
별도 오탐이 남아 행 단위 FP는 57건 줄었다. 닫는 부호와 조사의 경계가
확인되는 일반 조사 연쇄를 검증 대상으로 삼았다. 인용격 `고`는
일반 조사 연쇄 밖의 별도 검토 범위다.

교정 GSD의 `gsd:test-s220:8`은 상품명 `'두잇'`에 붙은 보조사
`만`을 수사로 주석했다. 수사 용법은 `입장객 수를 오천에서 만으로 높였다.`에서
대조했다. 원본 기대값을 보존하고
[계약 검토](../../tools/morph-compare/gsd-positive-corpus-reviews.tsv)를 양쪽에
같이 적용했다. 고정 평가 11세트의 Smart 계약 FN은 0건이다.

행렬은 TP, FP, TN, FN 순서이고 비율(%)은 precision, recall, F1 순서다.
교정 GSD의 계약 검토는 1건이고 고정 음성의 계약 검토는 1,052건이다.

| 입력 | 리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 교정 GSD 9,298행 | 기준선 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 9297, 1, 0, 0 / 99.99, 100.00, 99.99 |
| 교정 GSD 9,298행 | 후보 | 9297, 0, 0, 1 / 100.00, 99.99, 99.99 | 9297, 0, 1, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | 기준선 | 0, 3867, 49441, 0 / 0.00, —, 0.00 | 1052, 2815, 49441, 0 / 27.20, 100.00, 42.77 |
| 고정 음성 53,308행 | 후보 | 0, 3810, 49498, 0 / 0.00, —, 0.00 | 1052, 2758, 49498, 0 / 27.61, 100.00, 43.27 |

## 성능

각 셀은 중앙값 [최솟값, 최댓값]이다. fresh process에서 워밍업 1회 후
기준선과 후보의 실행 순서를 교대로 바꿔 5회 측정했다. 처리량은
행 수를 `evaluation_seconds`로 나눴고 p95는 실행별 질의 지연의
nearest-rank 95백분위다. RSS는 `/usr/bin/time -l`의 최대값이다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 61.292 [61.102, 61.420] | 30,803 [30,469, 30,889] | 0.07146 [0.07129, 0.07221] | 81.031 [80.969, 81.109] |
| 교정 GSD | 후보 | 61.623 [61.082, 63.016] | 30,499 [28,189, 30,872] | 0.07217 [0.07167, 0.07704] | 81.031 [80.984, 81.219] |
| 고정 음성 | 기준선 | 61.589 [61.137, 61.672] | 19,663 [19,463, 19,924] | 0.12750 [0.12583, 0.12971] | 127.719 [127.594, 128.406] |
| 고정 음성 | 후보 | 61.639 [61.332, 63.969] | 19,728 [19,028, 19,851] | 0.12742 [0.12696, 0.13179] | 127.656 [127.250, 127.828] |

교정 GSD의 처리량은 −0.99%, p95는 +0.99%다. 고정 음성은 각각
+0.33%, −0.07%다. 두 입력 모두 처리량과 p95의 관측 범위가 겹쳤다.
