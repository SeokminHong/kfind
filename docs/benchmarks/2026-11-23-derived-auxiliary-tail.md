# 붙여 쓴 파생 본용언 뒤 보조 용언의 반환 범위

Smart에서 두 음절의 파생 본용언이 모음 연결형으로 끝나면,
뒤 성분이 질의한 표제어의 사전 결합 조건을 충족하며 어절
끝까지 활용되는지 확인한다. `말해준다`의 `준다`, `일해봤다`의
`봤다`, `말해버렸다`의 `버렸다`가 해당한다. `설명해 주다`처럼
세 음절의 파생 본용언은 띄어 쓴다. [국립국어원 말해 주다](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=308213)
· [국립국어원 파생 용언 뒤 띄어쓰기](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=3&qna_seq=309446)
· [한국어기초사전 주다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=77245)

기존 사전 결합 정보를 재사용한다. `줄다`의 활용과 겹치는
`준다`는 이 결합에서 `주다`의 범위다. `피해가`·`박해가`의
주격 조사, `항해했다`의 용언 파생 접미사, `나타난다`의
통째 용언 분석도 함께 대조했다. `물이 빠르게 준다`의
독립 `줄다`와 `비를 피해 가다가`의 독립 `가다`는 유지됐다.
[한국어기초사전 줄다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=82138)

## 원문·교정문과 품질

PUD n01022002의 27번과 n01048008의 23번 `준다`는 보조
동사로 주석돼 있다. n01048008의 `진입한새로운`,
`일치하는데이는`, `중요한역할을` 세 곳은 `ToDoOrigText`의
공백을 복원했다. 두 원문의 `말해준다`는 허용 표기다.
붙여 쓴 입력과 띄어 쓴 입력을 같은 빌드 설정으로 비교했다.
[PUD n01022002](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L1148)
· [PUD n01048008](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L2884)

두 문장과 주격·파생 접미사 대조 PUD 두 문장의 고정 질의를
원문·교정문에서 비교했다. 401개 중 위 세 누락이 복원됐으며
나머지 범위는 유지됐다. 대조 입력 SHA-256은
`b620a82c9d8c08c9d539a1ac6b8c4e2f6dcd19816b31759d056d6df922b78999`다.
역사 입력의 258,541개 조합에서는 PUD 원문 두 행의 반환만 바뀌었다.
고정 회귀 21행을 NFC·NFD와 리소스 장착 Smart·Any, 기본 Token으로
빌드당 126개 조합에서 확인했다. 기준선 Smart의 누락 12개 조합이 통과했다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0,
Python 3.14.8에서 `c0c158ae`와 `80edcb54`의 release 빌드를
비교했다. 새 프로세스로 빌드별 워밍업 1회 뒤 순서를 교대해
5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이며 각 실행에서 p95를
최근접 순위로 계산했다.
