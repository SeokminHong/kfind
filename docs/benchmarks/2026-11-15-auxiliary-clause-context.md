# 연속 보조 용언의 절 문맥

붙여 쓴 보조 동사와 명사 분할이 경쟁하는 어절에서, 앞의 목적격
성분과 뒤 보조 용언의 종결 활용을 함께 확인했다. 앞 어절에는 공통
활용으로 검증한 `-고` 연결형이 필요하다. `해오 + 고`가 각각 명사로
등록돼 있어도 `그 일을 꾸준히 해오고 있다`에서는 `해오고`를 반환한다.
같은 경로에서 진행의 높임형도 확인했다. `-어지다`의 명사 경쟁 판정은
후행 보조 동사의 완결 활용을 확인한다.
[한국어기초사전의 연결 어미](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=78583)

## 품질

12개 고정 입력을 Smart·Any·Token으로 실행해 249,243행의 ID,
리소스 해시와 반환 범위를 대조했다. 반환 범위 차이는 고정 음성의
`pud:w01144063:verb:차다` Smart 한 행이다. 해당 문장의
`차지했지만민주당이`를 반환하던 범위가 `차지`까지 줄었다. 이 행의
오탐은 남아 있어 원본·계약 혼동 행렬은 기준선과 같다.

대조문에서는 `해오고 있다`, `해오고 계신다`의 두 후보를 복구했고
지역명이 주제인 `해주시는 명부에 있다`는 제외했다. 골드 925건,
walk/hang, workspace 테스트, 포맷과 Clippy를 통과했다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.

| 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) | 계약 검토 |
| --- | --- | --- | --- | --- |
| 교정 GSD Smart 9,298건 | 양쪽 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 0 |
| PUD Smart 798건 | 양쪽 | 792, 0, 0, 6 / 100.00, 99.25, 99.62 | 798, 0, 0, 0 / 100.00, 100.00, 100.00 | 6 |
| 고정 음성 Smart 53,308건 | 양쪽 | 0, 4028, 49280, 0 / 0.00, 0.00, 0.00 | 156, 3872, 49280, 0 / 3.87, 100.00, 7.75 | 156 |
| 절 문맥 대조 3건 | 기준선 | 0, 0, 1, 2 / 0.00, 0.00, 0.00 | 0, 0, 1, 2 / 0.00, 0.00, 0.00 | 0 |
| 절 문맥 대조 3건 | 후보 | 2, 0, 1, 0 / 100.00, 100.00, 100.00 | 2, 0, 1, 0 / 100.00, 100.00, 100.00 | 0 |

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`3e40d3fb`와 `440eb99b`을 비교했다. 입력마다 새 프로세스로 워밍업
1회와 측정 5회를 실행하고 두 실행 순서를 교대했다. 표는 중앙값
[최솟값, 최댓값]이며 p95는 최근접 순위로 구했다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD Smart | 기준선 | 63.045 [62.686, 64.314] | 28,034 [27,818, 28,551] | 0.07829 [0.07625, 0.07908] | 81.422 [81.234, 81.609] |
| 교정 GSD Smart | 후보 | 62.656 [62.214, 63.181] | 27,982 [27,782, 28,511] | 0.07779 [0.07608, 0.07929] | 81.344 [81.250, 81.672] |
| 고정 음성 Smart | 기준선 | 64.429 [62.635, 65.187] | 19,163 [18,577, 19,214] | 0.12937 [0.12917, 0.13258] | 127.781 [127.594, 128.047] |
| 고정 음성 Smart | 후보 | 63.513 [62.209, 64.155] | 18,956 [18,612, 19,192] | 0.12996 [0.12896, 0.13221] | 127.781 [127.703, 128.609] |

교정 GSD와 고정 음성의 처리량 중앙값은 각각 −0.19%, −1.08%였고,
p95는 −0.64%, +0.46%였다. 네 지표의 측정 범위가 겹쳤다.
입력, 리소스와 실행 명령은
[직전 절 문형 측정](2026-11-15-verb-object-contrast-audit.md#재현)과 같다.
