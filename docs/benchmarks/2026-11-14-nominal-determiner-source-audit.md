# 관형사와 명사가 경합하는 단음절

`화보 속 박하선은`에서 압축 사전은 `속`의 관형사와 명사 분석을
모두 제공한다. `smart`의 한 음절 관형사 판정은 뒤의 `박하선은`을
체언과 조사로 확인한 뒤 명사 후보를 제거한다. 한국어기초사전의
명사 `속`은 사물의 안이나 어떤 상황의 가운데를 뜻한다.
[한국어기초사전](https://krdict.korean.go.kr/m/eng/searchResultView?ParaWordNo=71278)

MeCab 원본 `MM.csv`에서 결합 분류가 `~고유명사`인 2행
(`별`, `속`)과 `~인명명사`인 2행(`성`, `소`)을 확인했다.
교정 GSD의 해당 표제어는 `별` 2행, `속` 5행, `성` 7행,
`소` 1행이다. `별 사람이 다 있네`에서도 관형사 검색이 성립하므로
원본의 결합 분류를 후행 명사의 엄격한 품사 제한으로 해석할 수 없다.

원본 `화보 → 속 → 박하선`에서 앞뒤 접속 비용과 가운데 단어 비용의
합은 명사 경로 최솟값 3,022, 관형사 경로 7,451이다. 이 값은
세 어절의 국소 비교다. 제품의 압축 사전에는 접속 비용과 결합 분류가
없다. [압축 사전 사양](../../specs/matching.md#06-구조-기반-국소-형태-판정)

기준선 35bef322의 full POS `smart`에서 [대조 8건](../../tools/morph-compare/nominal-determiner-source-context-cases.jsonl)을
실행했다. `화보 속`, `책 속`, `밤하늘 별 하나`의 명사 누락과
`화보 속`의 관형사 오탐을 재현했다. 행렬은 TP, FP, TN, FN
순서이며 비율은 precision, recall, F1이다. 계약 검토는 0건이다.

| Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 보정 비율 (%) |
| --- | --- | --- | --- |
| 4, 1, 0, 3 | 80.00, 57.14, 66.67 | 4, 1, 0, 3 | 80.00, 57.14, 66.67 |

```sh
"$runner" boundary full-pos smart tools/morph-compare/nominal-determiner-source-context-cases.jsonl "$output"
```
