# 국명과 왕의 합성 명사 분절

Korean-PUD의 `일왕`·`독일왕` 세 문장, 네 위치를 원문 주석으로 확인했다.
기존 component에서 두 합성 명사의 명사 분절이 없었다. 일반 합성어
자료에 국명과 직함 명사를 등록해 `일왕의`, `독일왕이`, `독일왕과`의
조사까지 반환한다. `일왕` 질의의 내부 `독일왕의` 오탐도 제거했다.
[PUD 원문](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/e942f9c5e9351f37bcb8f202bb9df70f78c60d35/ko_pud-ud-test.conllu)

고정 12세트의 Smart·Token·Any와 교정 GSD의 전체 반환 목록 258,541개를
대조했다. 고정 음성에서 명사 `왕` 3행과 국명 성분 `일` 2행의 정답
6개를 회수했다. 네 행은 원문의 명사 분절에 따라 계약 양성으로 기록했다.
원본 GSD 양성 9,335행의 반환은 같다.

| 고정 음성 53,308행 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 기준선 | 0, 3,127, 50,181, 0 / 0, 0, 0 | 1,417, 1,598, 50,145, 5 / 47.00, 99.65, 63.87 | 1,603 | 5 |
| 후보 | 0, 3,131, 50,177, 0 / 0, 0, 0 | 1,422, 1,598, 50,145, 0 / 47.09, 100, 64.03 | 1,603 | 0 |

두 실행에 같은 정답 범위를 사용했다. 계약 양성의 전체 범위 검토는
182행을 마쳤고 1,240행이 미확정이다. 교정 GSD의 원본·계약 행렬과
확정 FPc·FNc는 [대명사 내부 명사 비교](2026-11-23-atomic-pronoun-nominal-tails.md)의
후보와 같다.

## 네이티브 형태 판정

`c0f97f57`과 `2dd06b94`를 Apple M1 Max 32 GiB, macOS 26.6.2 (25G83),
Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다. 두 실행군은 같은 release
runner를 사용했다. [교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
`boundary full-pos smart INPUT OUTPUT`을 새 프로세스에서 워밍업 1회와
교대 측정 5회 실행했다. 입력, full POS, 보강 용언의 체크섬은
[공통 component 비교](2026-11-23-source-aligned-nominal-prefixes.md)와 같다.
Component는 `f9530d384a375ce5d9d9cce4cac5b48efbd928c0b0ed24011d20f7afee570dec`
37,441,353 B에서 `9b4e96eccf9b50e2b4c9b8fe6272d13a3229ee137075fe4f532293c575d91dd8`
37,441,441 B로 바뀌었다. 값은 중앙값 [최솟값, 최댓값]이다.

| 입력 | 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS KiB |
| --- | --- | --- | --- | --- | --- |
| 고정 음성 | 기준선 | 64.201 [63.519, 64.624] | 18,375 [18,287, 18,505] | 0.1323 [0.1314, 0.1328] | 130,816 [130,768, 131,568] |
| 고정 음성 | 후보 | 64.356 [64.056, 65.500] | 18,378 [17,929, 18,493] | 0.1322 [0.1318, 0.1337] | 131,664 [130,752, 131,760] |
| 교정 GSD | 기준선 | 62.932 [62.715, 63.164] | 26,899 [26,857, 27,142] | 0.0805 [0.0788, 0.0812] | 83,872 [83,584, 84,256] |
| 교정 GSD | 후보 | 63.282 [62.631, 63.585] | 27,213 [27,082, 27,295] | 0.0798 [0.0797, 0.0810] | 83,840 [83,760, 84,272] |

고정 음성 처리량은 0.02% 높고 p95는 0.08% 낮았다. 최대 RSS 중앙값은
848 KiB 늘었다. 교정 GSD 처리량은 1.17% 높고 p95는 0.87% 낮았다.
두 입력의 처리량·p95·RSS 측정 범위는 각각 겹쳤다.
