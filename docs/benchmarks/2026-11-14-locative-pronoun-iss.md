# 있다와 합쳐진 장소 대명사 검색

`어딨-`과 `여깄-` 뒤에 `있다`의 활용이 이어지면 해당 장소
대명사의 검색에서 축약 어절을 반환한다. 고정 GSD에서
`어딨|여깄|거깄|저깄`에 해당하는 표면형 1건을 확인했고
`어딨어`의 정확 범위를 복구했다. 실제 발화의 의문형과
감탄형, 존댓말 활용, 미완성 어간과 어절 내부를 검증했다.
[국립국어원 발화 자료](https://www.korean.go.kr/nkview/nklife/1997_1/7-7.html)

b1f0dd6f와 bd8ef979의 full POS `smart`를 비교했다. 양성은 정확 범위,
음성은 반환 여부로 채점했다. 행렬 순서는 TP, FP, TN, FN이다. 양성
계약 검토는 0건이며 음성은 기존 3건을 적용했다. 음성 53,308건의
반환 범위와 전체 정답 검증의 기존 불일치 8건은 동일하다.

| 양성 | 기준선 | 9291, 0, 0, 9 | 100.00, 99.90, 99.95 | 9291, 0, 0, 9 | 100.00, 99.90, 99.95 |
| 양성 | 후보 | 9292, 0, 0, 8 | 100.00, 99.91, 99.96 | 9292, 0, 0, 8 | 100.00, 99.91, 99.96 |

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 같은 release
설정, 입력과 사전 리소스를 사용했다. 시작점 70a5d2d4, 기준선, 후보를
워밍업 1회 뒤 새 프로세스로 5회씩 측정하고 실행 순서를 교대했다.
p95는 nearest-rank이며 RSS는 `/usr/bin/time -l`의 최대 상주 메모리다.
표는 중앙값 [최솟값, 최댓값]이다.

기준선 대비 양성·음성 처리량은 +0.62%, −0.19%이며 p95는 −1.23%,
+0.44%다. 초기화는 −0.53%, −1.84%, RSS는 −0.18%, −0.11%다.
시작점 대비 양성·음성 처리량은 +5.20%, +10.51%이고 p95는 −10.40%,
+12.21%다.
