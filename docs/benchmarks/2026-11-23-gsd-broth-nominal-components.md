# 음식 명사 국물의 국 성분

고정 GSD 음성에서 질의가 명사 `국`이고 문장에 `국물`이 있는 5행을
확인했다. 한국어기초사전은 음식의 `국물`을 국이나 찌개의 건더기를
뺀 물로 풀이하며 MeCab은 `국/NNG+물/NNG`로 정렬한다. 이미 `국물`과
`진국`의 두 명사 범위를 확인한 s853 외에 원문 4행을 검토에 추가했다.
`청국`, `국서` 등 `國`의 결합은 기존 잔여에 남아 있다.
[한국어기초사전 국물](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=64512)
· [한자어 의존 형태소 연구](https://www.korean.go.kr/nkview/nklife/1998_1/8-3.html)

| 원문 GSD | 원문 UTF-8 범위 | 교정문 범위 |
| --- | --- | --- |
| s32 | [10, 13) | [10, 13) |
| s844 | [0, 3) | [0, 3) |
| s878 | [38, 41) | [38, 41) |
| s938 | [33, 36) | [33, 36) |

s32의 `넘`을 표준문에서 `너무`로 바꿨다. 원문과 교정문의 153개
질의 쌍을 `06f77ce9`와 검색 코드가 같은 Smart full-pos 러너에서
비교했다. 전체 목록에서 명사로 질의한 `넘`의 원문 반환만 달라졌으며
`국물`의 네 범위와 이전에 검토한 s853의 두 범위는 일치했다.
[국립국어원 너무의 용법](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=310938)
· [원문과 범위 근거](../../tools/morph-compare/contract-contrast-evidence.jsonl)

같은 고정 음성 출력에 정확한 정답 범위를 추가했다. 검토를 마친 범위는
221행에서 225행으로 늘었으며 양성 1,208행의 전체 정답 범위가 미확정이다.
원문·교정 GSD 양성의 결과는 이 검토 전과 같다.
