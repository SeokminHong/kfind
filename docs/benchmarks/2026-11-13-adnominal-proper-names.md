## 품질

GSD에서 `알린`과 `오른`을 놓친 문장을 확인했습니다. 두 형태 모두 원본 사전에서 동사
관형형과 고유명사로 분석됩니다. 앞 어절의 목적격이나 `까지` 결합이 관형형을 지지하면
동사 후보를 살렸습니다. 앞 목적어와 고유명사 주어·화제 뒤에 별도의 목적어와 종결
서술어가 이어지는 문장은 관형형으로 판정했습니다. 이름을 직접 인용한 문장과 관형사
`오른`도 대조했습니다. [UD 회귀](../../data/fixtures/ud_morphology_cases.tsv)

`그 사실을 알린 로페스에게 물었다.`는 앞 문장에 따라 `알린`이 `알리다`의 관형형이나
사람 이름으로 해석됩니다. 두 문장을 짝지었으며 이름 해석에서 반환한 동사 후보는 raw
FP와 계약 보정 TP로 기록했습니다. [동형이의 예문](../../tools/morph-compare/adnominal-proper-name-context-cases.jsonl) · [계약 검토](../../tools/morph-compare/adnominal-proper-name-contract-reviews.tsv)

GSD·PUD 일반 음성과 KAIST dev·test 질의 행렬은 반환 범위가 같았습니다.
행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서입니다. GSD 양성, 회귀 양성,
동형이의 양성은 정확한 범위로 채점했습니다. 회귀·동형이의 음성과 KAIST는 표적과의 겹침으로,

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Darwin 25.6.0, Rust·Cargo 1.97.0에서
동일한 리소스와 release 설정을 사용했습니다. 입력별로 새 프로세스에서 warm-up 1회 뒤
5회를 측정하고 리비전 순서를 교대했습니다. 처리량은 runner 평가 시간으로 계산했고
p95는 nearest-rank, RSS는 `/usr/bin/time -l`의 프로세스 최대 상주 메모리입니다.
셀은 중앙값 [최솟값, 최댓값]입니다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
KFIND_FULL_POS_LEXICON="$full_pos_dir/lexicon.bin" \
KFIND_COMPONENT_RESOURCE="$component_resource" \
KFIND_ENRICHED_PREDICATES="$enriched_predicates" \
  /usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```

자동 품사 품질 재산정에는 `boundary`를 `untagged`로 바꿨습니다.
