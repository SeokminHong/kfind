# GSD 못하다와 못 하다의 표기

원문 GSD의 부사 `못` 질의 9행을 모두 대조했다. 미검출 4행은
`못하고`, `못하면`, `못한다고`가 한 어절로 쓰였다. 국립국어원은
실력이나 성과가 기준에 미치지 못하는 경우 동사 `못하다`를 인정하며,
외부 조건으로 행동을 수행할 수 없을 때는 부사 `못`을 띄어 쓰도록
안내한다.
[우승 못한의 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=312943&searchCondition=&searchKeyword=)
· [능력과 외부 상황에 따른 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=320248)
· [GSD r2.18 평가 원문](https://github.com/UniversalDependencies/UD_Korean-GSD/blob/r2.18/ko_gsd-ud-test.conllu)

| 원문 ID | 원문의 표적 | 판정 및 교정본 정답 |
| --- | --- | --- |
| s26:5, s694:5 | 우승을 못하고 [40, 49) | 원문 표기를 보존하고 동사 못하다 [40, 49)를 검사 |
| s945:2 | 예약 못하면 [7, 16) | 교정본의 못 [7, 10)을 검사하고 원문 계약 미검출은 유지 |
| s988:10 | 배달을 못한다고 [72, 84) | 면이 불어 제공할 수 없다는 배달 거리 제약을 확인해 해당 원문 범위만 제외하고 교정본의 못 [72, 75)를 검사 |

s945의 예약이 성립하지 않은 이유는 원문만으로 확인할 수 없다.
예약하지 못한 경우를 뜻하는 기존 교정본과 원문 측정을 각각 유지했다.
별도 대조에서 취소된 결승전의 `못`은 [48, 51), 실력이 부족한 선수의
`못하고`는 [44, 53)으로 반환됐다. 부정 보조 용언 `배달하지 못한다고`
구성은 동사 [20, 32)를 반환했고 부사 질의는 비었다. 원문과 교정문 및
대조를 합친 12개 질의에서 행렬은 TP 7, FP 0, TN 5, FN 0이다.
정밀도·재현율·F1은 각 100%이며 별도 계약 검토 0행으로 계약 행렬도 같다.
범위는 모두 UTF-8 바이트 반개구간이다.

## 평가

제품 트리가 같은 140f118a의 Smart full-pos release에 같은 사전을 장착했다.
원문은 같은 입력과 실행 결과를 채점했다. 교정본은 이전과 현재 입력을
각각 같은 러너에서 실행했다. 두 중복 문장의 24행만 입력이 바뀌었다.
돌아온 범위가 바뀐 18행 중 두 행은 새 동사 표적과 일치했고, 나머지
16행은 복원한 공백 1바이트에 따른 이동과 일치했다. 다른 9,274행의
입력과 반환 범위, 교정 평가의 잔여 오류는 같았다. 새 교정본의 SHA-256은
`66466637b6439a7ca8553e0b493d92aeb28e55394316042850f04e3d20384cf1`이다.
[고정 입력 재생](../../tools/morph-compare/README.md#gsdpud-고정-감사-입력)
· [러너와 리소스](2026-11-23-dictionary-drug-suffix-components.md#성능)

행렬 순서는 TP, FP, TN, FN이며 뒤 세 값은 정밀도·재현율·F1(%)이다.

| 입력 | 원본 행렬 및 지표 | 계약 행렬 및 지표 | FPc / FNc | 검토 / 제외 |
| --- | --- | --- | ---: | ---: |
| 원문 GSD 기존 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,651, 9, 95, 541 / 99.90, 94.11, 96.92 | 20 / 541 | 619 / 39 |
| 원문 GSD 후보 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,651, 9, 97, 538 / 99.90, 94.15, 96.94 | 20 / 538 | 622 / 40 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 6 / 0 | 153 → 155 / 0 |
| 고정 음성 양쪽 | 0, 3,026, 50,282, 0 / 0, 0, 0 | 1,430, 1,481, 50,248, 0 / 49.12, 100, 65.88 | 1,483 / 0 | 1,589 / 149 |

원문 FNc 3건 감소는 기존 품사 오류 2행과 표준 입력 범위 판정 1행의
결과다. 제품 검색은 동일하다. 미판정 추가 반환은 원문 511행
569범위, 교정문 86행 92범위다.
