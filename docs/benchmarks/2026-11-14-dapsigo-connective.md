# 답시고 계열 연결 어미

사전의 `-ㄴ답시고/-는답시고/-답시고/-랍시고` 19행을 검사했다.
명시형 지정사 3행의 범위를 `이랍시고`로 교정했다. 생략형
`기자랍시고`와 `전문가랍시고`는 `smart`에서 어절 전체를 반환한다.
`any`는 명시형 지정사의 범위를 반환한다.
[국립국어원 용례](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=308340)

동사 받침과 ㄹ 탈락, 형용사, 높임·과거·전망 선어말 어미를 검사했다.
`쉬답시고`와 `살는답시고`는 동사 활용으로 반환하지 않는다.
`verify-gold`의 신규 6행은 통과했고 기존 불일치 8행이 재현됐다.
교정 GSD 9,298행과 고정 음성 53,308행의 반환 범위는 같았다.
