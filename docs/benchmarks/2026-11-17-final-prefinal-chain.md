# 독립 종결형의 선어말 어미 검증

`만족하였다`의 `-였-다`와 `지속되었습니다`의 `-었-습니다`는
선어말 어미와 종결 어미로 나뉜다. 독립 종결형을 확인할 때 기존
활용 경로와 같은 어미 연쇄 판정을 사용했다. 앞의 부사 `매우`와
`오래`에 각각 겹친 하오체 종결형과 인용 축약형을 걸러낸다.
[국립국어원 과거 선어말 어미](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=329570)
· [한국어기초사전 만족하다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=15856)

`없었다`는 동일한 연쇄에서 형용사와 보조 용언 분석이 생긴다.
`거의 없었다`는 관형격 조사가 수식할 체언이 없으므로 `거의`의
관형격 후보를 제외할 때 존재 술어 판정도 사용한다. `내 거의 뚜껑은
없었다`는 뚜껑이 관형격의 수식 대상이 되는 예문이다.

## 품질

고정 12세트의 83,081행을 세 모드로 실행해 반환 목록 249,243개를
비교했다. Smart에서 다음 기존 오탐 두 범위가 사라졌다.

| 원문 ID | 질의 | 제거한 UTF-8 바이트 범위 |
| --- | --- | --- |
| `pud:n01059025` | `v:오다` | `오래` 190..196 |
| `pud:w01081030` | `v:매다` | `매우` 33..39 |

목표 11세트의 FNc는 0, FPc는 1,801에서 1,799로 줄었다.
기존 계약 검토를 동일하게 적용했다. 행렬 열은 TP, FP, TN, FN 순서이며,
비율 열은 precision, recall, F1 순서다. 고정 음성의 원본 recall은
양성 분모가 없어 정의되지 않는다. 대조의 계약 검토는 0건이다.

| Smart 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 고정 음성 | 기준선 | 0, 3267, 50041, 0 / 0, —, 0 | 1387, 1797, 50016, 0 / 43.56, 100, 60.69 |
| 고정 음성 | 후보 | 0, 3265, 50043, 0 / 0, —, 0 | 1387, 1795, 50018, 0 / 43.59, 100, 60.71 |
| 교정 GSD | 양쪽 | 9296, 0, 0, 2 / 100, 99.98, 99.99 | 9292, 4, 2, 0 / 99.96, 100, 99.98 |
| 대조 24질의 | 기준선 | 12, 9, 3, 0 / 57.14, 100, 72.73 | 12, 9, 3, 0 / 57.14, 100, 72.73 |
| 대조 24질의 | 후보 | 12, 5, 7, 0 / 70.59, 100, 82.76 | 12, 5, 7, 0 / 70.59, 100, 82.76 |

대조에는 `감탄하였다`, `만족하셨겠지`의 선어말 어미와 함께 실제
하오체 인용·후치, `오래`의 인용 축약, `거의`의 관형격을 포함했다.
반대 방향으로 실제 하오체·인용 축약·관형격을 부사 질의가 반환하는
기존 다섯 범위가 남는다. Workspace 테스트, Clippy, gold 형태 사례
925건과 walk/hang stress를 검사했다.

## 성능

기준선 `0de97462`와 후보 코드 `5b1d9d1b`를 Apple M1 Max arm64,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Node.js 26.11.1에서 같은
release 설정으로 빌드했다. `/usr/bin/time -l RUNNER boundary
full-pos smart INPUT OUTPUT`을 입력별로 새 프로세스에서 워밍업
1회 후 두 버전을 번갈아 각 5회 실행했다. 중앙값 [최솟값, 최댓값]이다.
처리량은 초기화를 제외하고 p95는 nearest-rank로 구했다.

5,294,224에서 5,314,832바이트로 늘었다.
