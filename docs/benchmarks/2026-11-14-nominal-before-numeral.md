# 독립 수사 앞 일반 명사 검색

`일 하나는`에서 앞의 `일`에 일반 명사와 관형사 분석이 경합했다.
뒤 어절이 독립 수사에 조사 `는`이 붙은 구조이므로 일반 명사
분석을 유지한다. 단위 명사나 관형격 구조인 `한 번만`, `한
아이의`는 대조 입력으로 검증했다.

교정 GSD 9,298행의 `NR` 및 `NR+조사` 주석 21행 중
바로 앞 어절이 한 음절인 4행을 검토했다. `일 하나는`의 정확
범위를 복구했다. 음성 53,308행의 반환 범위와 정답 검증의 기존
불일치 8행은 동일하다.

35c10b86과 후보 12adf4c0의 full POS `smart`를 비교했다.
양성은 정확 범위, 음성은 반환 여부를 채점했다. 행렬 순서는
TP, FP, TN, FN이다. 양성 계약 검토는 0행이며 음성은 기존 3행을
적용했다. #421 비교군 1,111행은 정확 1,107행, 부분 0행, 누락
4행이다.

| --- | --- | --- | --- | --- | --- |
| 양성 | 기준선 | 9293, 0, 0, 5 | 100.00, 99.95, 99.97 | 9293, 0, 0, 5 | 100.00, 99.95, 99.97 |
| 양성 | 후보 | 9294, 0, 0, 4 | 100.00, 99.96, 99.98 | 9294, 0, 0, 4 | 100.00, 99.96, 99.98 |
| 음성 | 양쪽 | 0, 4092, 49216, 0 | 0.00, 0.00, 0.00 | 3, 4089, 49216, 0 | 0.07, 100.00, 0.15 |

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 같은
release 설정과 사전 리소스를 사용했다. 작업 시작점 70a5d2d4,
기준선, 후보를 워밍업 1회 뒤 새 프로세스로 5회씩 측정했다.
실행 순서는 교대했다. p95는 nearest-rank이며 RSS는 최대 상주
메모리다. 표는 중앙값 [최솟값, 최댓값]이다.

기준선 대비 양성·음성 처리량은 +0.76%, +0.49%이고 p95는
−0.95%, −1.07%다. 초기화는 −0.45%, +0.90%, RSS는
+0.06%, −0.07%다. 시작점 대비 처리량은 +7.40%, +9.95%이며
p95는 −12.08%, +13.09%다.
