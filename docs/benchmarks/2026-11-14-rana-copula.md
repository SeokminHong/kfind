# 인용 종결형 라나의 지정사 생략

`-라나` 사전 용례 12행을 대조했다. `인간뿐이라나`와
`집안이라나`의 명시적인 지정사 범위는 `이라나`로 정정했다.
`입을 거라나`와 `제외될 거라나`의 누락을 해소했다. `입을`은
목적격 분석과 경합하므로, 앞 목적어가 이어지는 타동사 관형형
경로를 확인했다. 범위 회귀는 의존 명사·단위 명사와 명령 인용을
대조한다. `any`의 5건은 지정사 생략형이다.
[국립국어원 사전](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=74718)

행렬은 TP, FP, TN, FN 순서다. 표의 입력은 계약 검토 0건으로
raw와 보정 결과가 같다.
