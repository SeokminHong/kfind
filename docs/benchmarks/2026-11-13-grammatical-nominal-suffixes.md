# 복수·수량 접미사의 명사 오탐

## 품질

체언과 접미사 분석이 이어지고 뒤의 조사가 어절을 완성하면 `-들`·`-씩` 위치에 명사 성분을
합성하던 경로를 막았습니다. `사람들도`, `사건들도`, `조금씩도`와 말뭉치에서 확인한
조사 결합을 음성으로 등록했습니다. 독립 명사 `들`과 ‘살쾡이’의 방언 명사 `씩`은 양성
대조에서 각각 조사까지 회수했습니다. [국립국어원 접미사 설명](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=334021) · [UD 회귀](../../data/fixtures/ud_morphology_cases.tsv)

GSD 원본 양성에서 lemma의 `들`·`씩`과 같은 위치의 XPOS가 `XSN`인 어절을 골라, 해당
접미사 위치에 대한 명사 질의 음성 120건을 만들었습니다. 전부 `-들`이었고, 원문에서
표적 byte 범위와 접미사 표기가 일치하는지 검증했습니다. 표적 겹침 기준 오탐 22건이
사라졌습니다. GSD·PUD 일반 음성, GSD 교정 양성, KAIST dev·test 질의 행렬에서 반환 범위는
같았습니다.

행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서입니다. GSD 교정 양성과 회귀
양성은 정확한 범위로, GSD 접미사 표적과 KAIST·회귀 음성은 겹침으로 채점했습니다. 범위가
없는 일반 음성은 반환 여부로 채점했습니다. 검토 0건인 행은 raw와 계약 보정 결과가 같습니다.

동일한 리소스와 release 설정으로 새 프로세스를 실행했습니다. 입력별로 warm-up 1회 뒤
5회를 측정하고 기준선과 후보의 순서를 교대했습니다. 처리량은 평가 시간으로 계산했고 p95는
