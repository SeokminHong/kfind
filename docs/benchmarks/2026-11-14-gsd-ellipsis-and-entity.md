# GSD 공통 성분 생략과 상호 주석

교정 GSD 9,300행에서 한 음절 표면형 직후에 가운뎃점 계열 부호
또는 쉼표와 공백이 오는 12행을 검토했다. `지•정체`의 `지`와
`전, 후기`의 `전`은 각각 `지체·정체`와 `전기·후기`에서
공통 성분을 생략하고 남은 조각이다. 독립 명사로 부여된 두 주석을
제거했다. `주수사` 표면형 또는 `주+수사` 주석을 가진 1행은
상호 전체와 관형격 조사로 교정했다. 문장과 유지된 행의 UTF-8 범위는
같다. [문장 부호 규정](https://www.korean.go.kr/kornorms/m/m_regltn.do) ·
[하월곡동 인허가 기록](https://opengo.kr/5601fb040e887edf2cd57382) ·
[교정 주석](../../tools/morph-compare/gsd-ellipsis-and-entity-annotations.tsv)

763320a4와 검색 코드가 같은 full POS 실행 파일로 두 입력을 비교했다.
양성 정확 범위 기준이며 행렬은 TP, FP, TN, FN 순서다. 계약 검토는
0건이다. 검색 코드 변경이 없어 성능 측정을 생략했다.

정확 1,106행, 부분 0행, 누락 5행이며 `any`는 정확 968행, 부분
138행, 누락 5행이다.
