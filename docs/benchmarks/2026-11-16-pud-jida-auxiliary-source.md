# PUD 피동·변화 구성의 보조 동사 지다

`밝혀졌다`는 `밝히다`의 연결형 `밝혀` 뒤에 보조 동사와 과거·종결
어미가 붙은 활용이다. `커지는`은 형용사 `크다`의 연결형 `커`와
변화를 나타내는 보조 동사 `지다`의 결합이다. 대조문 `선수가 한 점
차로 졌다`와 `꽃은 지는 중이다`에서는 같은 표면이 단독 본용언이다.
[국립국어원 ‘이루어지다’와 ‘만들어지다’](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5986) ·
[한글 맞춤법 제47항](https://korean.go.kr/kornorms/m/m_regltn.do)

## 원문 조사

기준선 `7dc52b6f`의 GSD·PUD 고정 음성에서 `verb:지다`로
남은 36행의 반환 41범위를 원문 CoNLL-U에 대조했다. PUD의
피동·변화 용언 중 12행 14범위에서 독립적인 문법 근거로
보조 동사 경계를 확인했다. CoNLL-U의 통째 `VV` 어절과
`-아/-어` 연결형 경계를 사용해 원문 UTF-8 범위를 정렬했다.
원문과 대조문에서 `지다`와 원문의 본용언을 각각 검색한
48개 Smart 질의에서 `지다`의 원문 14범위와 대조문 12범위가
정확했다. 본용언은 원문 12행에서 해당 어절을 반환하고
대조문의 표적 위치에서는 반환하지 않았다.

`pud:w01144056:verb:지다`에는 피동 `치러졌다`의 `졌다`와 명사
`인질`의 `질`이 함께 반환됐다. 이 행은 원래 평가에 유지한다.
`벌어진`, `퍼진`, `떨어졌고`, `틀어져` 같은 어휘화된 동사의
성분 검색 계약은 해당 쓰임의 사전 분석이 확인될 때 적용한다.

적용했다. 고정 음성 53,308행의 계약 검토는 1,341행에서 1,353행으로
늘었고, 비표준 입력 제외는 67행이다. 목표 11세트에서 Smart FNc는
