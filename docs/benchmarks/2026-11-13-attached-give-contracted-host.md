# 축약 연결형 해 뒤의 붙임 보조 동사 주다

`해주었다`와 `해주었어요`에서 어절 첫머리의 `해`를 `하다`의 축약
연결형으로 확인하고 뒤의 보조 동사와 어미를 함께 반환합니다. 지명
`해주`를 대조군으로 검사했습니다.

GSD 양성 9,314행을 검색해 어절 첫머리 `해` 뒤에
`주/줘/줬/준/줄/줌/줍`이 오는 문장 8개, 89행을 찾았습니다. 이 가운데
동사 `하다` 질의와 해당 표적이 일치하는 8행을 모두 대조했습니다.
두 행이 정확 일치로 바뀌었습니다. 음성 53,308행 중 같은 표기가 있는
202행을 포함해 반환 범위가 동일했습니다. PUD 양성 798행과 사전 양성
4,458행에는 해당 표기가 없었고 사전 양성의 반환 범위도 같았습니다.
`해주기도`, `해주시네요`, `해주세요`, `해주신`, `해주시는`의 누락은
남아 있습니다. 신규 회귀 3건은 통과했고 기존 `verify-gold` 불일치 8건은
같았습니다.

행렬은 TP, FP, TN, FN이며 비율은 precision, recall, F1입니다. 양성
계약 검토는 0건이며 음성에 기존 판정 27건을 적용했습니다.

코드를 같은 Apple M1 Max, macOS 26.6.2, rustc 1.97.0 release 환경에서
비교했습니다. 실행 순서를 순환하며 새 프로세스에서 워밍업 1회, 측정 5회를
실행했습니다. 값은 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위입니다.
