# 인칭 대명사의 주제 보조사 축약

교정 GSD 9,306행과 고정 음성 53,308행의 표면형에서 `전·난·넌`을
검색했다. 양성 12행과 음성 182행에 해당한다. 후보는 `전 마니아입니다`와
`전 약간 비린 느낌이어서`에서 대명사 `저`의 정확한 범위를 복구했다.
고정 음성 전체의 반환 범위는 동일했다. [국립국어원 어휘 자료](https://www.korean.go.kr/common/download.do%3Bfront%3DACDCBFD78E8867C4BAB9F602C8E74EF5?c_file_name=5fd59448-6389-4d1e-874a-d17b2d8b42e4_0.pdf&file_path=reportData&o_file_name=%EA%B5%AD%EC%96%B4%EA%B5%90%EC%9C%A1_%EC%96%B4%ED%9C%98_%EB%82%B4%EC%9A%A9_%EA%B0%9C%EB%B0%9C%282%EB%8B%A8%EA%B3%84%29_%EC%B5%9C%EC%A2%85%EB%B3%B4%EA%B3%A0%EC%84%9C.hwp)

`박근혜 전 대표`의 관형사와 `이괄의 난`의 명사는 선행 성분으로
구별한다. 문두 `전 세계가 주목했다`와 `전 사람이 좋아요`는 모두
`전 + 명사 + 주격 조사 + 서술어` 구조다. 첫 문장의 `전`은 전체를
뜻하고 두 번째는 화자를 가리킨다. 후보는 두 문장에서 `전`을
반환한다.

#421의 비교군 1,113행 중 정확 1,055행, 부분 22행, 누락 36행이다.
행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1이다.
양성 검토는 0건이고 고정 음성의 계약 보정은 32건이다.
