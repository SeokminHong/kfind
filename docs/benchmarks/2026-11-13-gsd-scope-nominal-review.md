# GSD 범위 의존 명사 주석

GSD `test-s435:6`의 `한국 내 개신교선교사들`에서 `내`는 한국의
범위를 나타냅니다. 원문의 문장과 UTF-8 범위 44..47을 보존하고
`나+의/NP+JKG`를 `내/NNB`로 교정했습니다. [국립국어원 범위 의존 명사 설명](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=9201&mn_id=97&pageIndex=1)

GSD·PUD와 사전 양성, GSD·PUD 음성에서 글자·결합 부호·숫자에 붙지 않은
`내` 99곳을 전수 대조했습니다. 명사 검색 점검에서 범위 의존 명사 13곳을
확인했습니다. 이 수에는 GSD에서 양성 질의가 생성되지 않은 `시설 내`가
포함됩니다. 기준선의 명사 질의는 범위 의존 명사 1/13곳을 반환했습니다.
범위 의존 명사 검색의 누락과 대명사 질의의 오탐은 별도 수정 대상입니다.

`학교 내 시설을 확인했습니다`에는 학교 안의 시설과 학교에 있는 화자의
시설이라는 해석이 모두 성립합니다. 앞 문장으로 뜻을 지정한 양성·음성
대조를 등록했습니다. 이 한 쌍에서만 범위 해석의 음성을 계약 양성으로
평가합니다. [대조 입력](../../tools/morph-compare/possessive-inner-scope-context-cases.jsonl) ·
[계약 검토](../../tools/morph-compare/possessive-inner-scope-contract-reviews.tsv)

행렬은 TP, FP, TN, FN 순이며 비율은 precision, recall, F1 순입니다.
full POS `smart`에서 기준선 `330a7f8e`의 같은 실행 파일로 두 GSD
입력을 비교했습니다. 교정으로 GSD `smart` 일치는 9,101/9,314에서
9,100/9,314로 바뀌었고 검색 누락 한 건이 드러났습니다.

| 입력 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) | 검토 |
| --- | --- | --- | --- | --- | --- |
| GSD 교정 전 | 9101, 0, 0, 213 | 100.00, 97.71, 98.84 | 9101, 0, 0, 213 | 100.00, 97.71, 98.84 | 0 |
| GSD 교정 후 | 9100, 0, 0, 214 | 100.00, 97.70, 98.84 | 9100, 0, 0, 214 | 100.00, 97.70, 98.84 | 0 |
| 범위 명사 대조 99곳 | 1, 8, 78, 12 | 11.11, 7.69, 9.09 | 1, 8, 78, 12 | 11.11, 7.69, 9.09 | 0 |
| 대명사 문맥 대조 | 1, 1, 0, 0 | 50.00, 100.00, 66.67 | 2, 0, 0, 0 | 100.00, 100.00, 100.00 | 1 |

```sh
node tools/morph-compare/apply-gsd-sentence-edits.mjs "$input" --scope-nominals > "$corrected"
"$runner" boundary full-pos smart "$corrected" "$output"
```
