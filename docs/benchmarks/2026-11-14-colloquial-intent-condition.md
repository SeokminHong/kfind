# 구어 의도 조건 어미 검색

GSD에서 `실라면/을라면/갈라면/할라면/볼라면`과 명사 뒤
`이+라면` 주석을 대조한 2행 중 `가실라면`에 구어 조건형이
쓰였다. `갈라면`, `먹을라면`, `먹으실라면`, `살라면`과
표준형·서술격 조사 대조문도 검사했다.
[대조 입력](../../tools/morph-compare/colloquial-intent-condition-cases.jsonl)

기준선 b8e92e21과 후보 37a77c69의 검색 코드를 비교했다.
교정 양성 9,306행은 정확 범위, 음성 53,308행은 적중 여부로
판정했다. 계약 검토는 0건이다. 행렬은 TP, FP, TN, FN,
비율은 precision, recall, F1 순서다.

| 경계 | 입력 | 버전 | Raw 및 계약 보정 행렬 | Raw 및 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- |
| smart | 양성 | 기준선 | 9258, 0, 0, 48 | 100.00, 99.48, 99.74 |
| smart | 양성 | 후보 | 9259, 0, 0, 47 | 100.00, 99.49, 99.75 |
| any | 양성 | 기준선 | 9067, 0, 0, 239 | 100.00, 97.43, 98.70 |
| any | 양성 | 후보 | 9068, 0, 0, 238 | 100.00, 97.44, 98.70 |
| smart | 음성 | 양쪽 | 0, 4088, 49220, 0 | 0.00, 0.00, 0.00 |
| any | 음성 | 양쪽 | 0, 17563, 35745, 0 | 0.00, 0.00, 0.00 |

`any`에서 `갈다`가 `가실라면`에 기존부터 적중했고 후보에서 그
범위가 길어졌다. `smart` 음성 반환 범위는 모두 같았다.
#421 비교군 1,113행의 후보 결과는 `smart` 정확 1,071행,
부분 15행, 누락 27행과 `any` 정확 947행, 부분 159행, 누락 7행이다.

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0의 동일
릴리스 빌드로 시작점 70a5d2d4도 비교했다. 새 프로세스에서 워밍업
1회 후 5회 측정하고, 시작점·기준선·후보와 그 역순을 교대했다.
