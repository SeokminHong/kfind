# 수량과 정도 표현의 명사 범위

`어느 정도`와 `열 명 정도`에서 명사 `정` 질의가 `정도`를 반환했다.
이 경우 `정도` 전체가 분량이나 수준을 나타낸다. 앞의 관형사 `어느`
또는 단위가 확인된 수량을 근거로 `정`에 첨가 보조사 `도`를 붙인
후보를 제외한다. `열 명 정도 왔고 서로 정도 들었다`에서는 뒤의
`정도` [39, 45)만 `정`의 일치로 보존한다.
[한국어기초사전 어느](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62822) ·
[한국어기초사전 정도](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=70876&nation=eng&nationCode=6)

## 네이티브 형태 판정

기준선 `f5f58843`의 실행 소스는 `168728af`과 같다. 후보 `54a32880`과
같은 Cargo target에서 `cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml`로
빌드했다. 입력, 리소스 체크섬, 기기, 도구와 교대 실행은
[실행 조건](2026-11-23-embedded-alternative-connectives.md#네이티브-형태-판정)과
같다. 각 입력을 별도 프로세스로 워밍업 1회 및 교대 측정 5회 실행했다.
아래는 중앙값 [최솟값, 최댓값]이다.
