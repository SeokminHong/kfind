# 이유 연결형 지라

사전의 `ㄴ지라/은지라/는지라` 표제 예문 7행을 전수 확인했다.
지정사 질의 한 행의 범위를 `친구인지라`의 `인지라`로 정렬했다.
완료 동작, 상태, 높임 어간과 지정사를 확인하고, 띄어 쓴
의존 명사 `지`와 의문형 `-는지`를 대조했다.
[국립국어원 말뭉치 연결 어미 지침](https://korean.go.kr/common/download.do?c_file_name=35c6ff74-7598-438d-ab4c-a7d91a5908d9.pdf&file_path=reportData)
