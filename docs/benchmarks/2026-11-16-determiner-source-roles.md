# GSD·PUD 관형사의 원문 수식 관계

고정 평가의 Smart 관형사 잔여 41행을 원문에 대조했다. GSD 10행과
PUD 31행의 문장 ID를 맞추고, 반환 범위를 원문 토큰의 품사와 의존
관계에 대조했다. 교정 GSD 한 행은 교정 전후의 오프셋을 따로 확인했다.
세 행의 기존 음성 표기에 관형사 양성 네 범위를 복원했다.

| 원문 ID | 토큰과 범위 | 수식 관계 |
| --- | --- | --- |
| GSD `test-s238` | 9번 `전` 86..89, 13번 `전` 114..117 | 병렬로 나열된 두 인명의 직함인 국무총리와 원내대표를 수식 |
| PUD `w01009017` | 12번 `이` 99..102 | 목적격 조사를 가진 `아이디어`를 지시. PUD 세부 품사 `PRD`, 의존 관계 `det` |
| PUD `w02009002` | 4번 `그` 33..36 | `혁명`과 병렬을 이루는 명사 `심각함`을 수식. PUD 세부 품사 `DT`, 의존 관계 `det` |

원문 3개와 대조문 3개에서 양쪽 품사 질의의 전체 반환 범위를 확인했다.
Smart와 Token은 원문의 관형사 네 범위를 정확히 반환한다. Any는
네 범위 외의 세 위치도 반환한다. 원문의 `국무총리` 앞 `전`을 명사로
반환하는 Smart 오탐은 대조 검사에서 유지된다. 대조문의 `전에`,
`이는`, `그는`은 각각 명사 또는 대명사와 조사 결합으로 반환된다.

`한`·`온` 잔여 16행 가운데 15행에서 동사 관형형 활용 또는 수식 관계를
확인했다. 한 행의 `온`은 외국어 제목의 음역이다. 이 범위와 나머지
관형사 잔여는 원문 판정에 따른 기존 채점을 유지했다. `몇 안 되는`의
`몇`과 `그 누구`의 `그`는 품사 태그만으로 판정하지 않았다.
