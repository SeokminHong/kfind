# 범위 의존 명사 내 검색

`학교 내`처럼 조사 없는 체언 뒤에 오는 범위 의존 명사 `내`를 독립
범위로 반환합니다. 앞 어절에 완결된 연결형이나 격·보조사 결합이 있으면
범위의 근거로 쓰지 않습니다. [정답 교정과 대조 입력](2026-11-13-gsd-scope-nominal-review.md) ·
[범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

글자·결합 부호·숫자에 붙지 않은 `내` 99곳을 GSD·PUD와 사전에서
전수 대조했습니다. 범위 명사 13곳을 모두 찾았고, 명사 질의의 기존 오탐
8곳 중 연결형 `보니` 뒤의 한 곳을 제거했습니다. 남은 명사 오탐 7곳과
대명사 질의의 범위 의존 명사 오탐은 별도 판정이 필요합니다. 신규 회귀는
모두 통과했고 기존 `verify-gold` 불일치 8건은 재현됐습니다.

교정한 GSD 양성 9,314건에서 `test-s435:6` 한 건만 반환 범위가
달라졌습니다. 사전 양성 4,458건은 동일합니다. 원본 음성 53,308건의
새 반환 12건은 모두 원문에서 지역·공간 범위를 나타내는 명사 `내`입니다.
고정 음성 입력에서의 raw 결과를 보존했습니다.

행렬은 TP, FP, TN, FN 순이며 비율은 precision, recall, F1 순입니다.
