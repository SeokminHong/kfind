# 수량 단위 뒤의 조사와 지정사

숫자에 붙은 단위 명사 뒤에 조사와 지정사가 이어지면 Smart가
`50개뿐이었다`에서 `개뿐`, `3곳까지였다`에서 `곳까지`를 반환한다.
기존 조사와 지정사 검증을 재사용하며, 지정사는 별도 범위로 검색된다.
수량과 단위의 경계, 조사 두 개가 이어지는 형태, 붙임과 띄어쓰기,
천 단위 구분자, 불완전한 지정사 활용을 대조했다.
[국립국어원 한글 맞춤법 제42항과 제43항](https://korean.go.kr/kornorms/regltn/regltnView.do)

## 품질

고정 입력 12개와 세 모드 249,243행에서 ID, 리소스 해시, 반환 범위를
대조했다. PUD 원문 `n01094014`의 2번 수량 `50`, 3번 `개뿐/NNB+AP`,
4번 `이었다/VC`가 이어지는 한 행에서만 Smart 범위 `12..18`이 추가됐다.
기존 지정사 범위 `18..27`은 동일했다. CLI의 canonical 정규화에서도
분해형 입력의 원문 범위 `27..42`가 반환됐다.

고정 음성 53,308행의 행 단위 행렬은 TP, FP, TN, FN 순이고
비율(%)은 precision, recall, F1 순이다. 두 실행에 같은 계약 검토
160건을 적용했다. 새 검토의 근거는 PUD 원문의 단위와 조사 범위이며
원본 음성표를 보존했다.

| 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 4030, 49278, 0 / 0.00, 0.00, 0.00 | 159, 3871, 49277, 1 / 3.95, 99.38, 7.59 |
| Smart | 후보 | 0, 4031, 49277, 0 / 0.00, 0.00, 0.00 | 160, 3871, 49277, 0 / 3.97, 100.00, 7.64 |
| Any | 양쪽 | 0, 17622, 35686, 0 / 0.00, 0.00, 0.00 | 160, 17462, 35686, 0 / 0.91, 100.00, 1.80 |
| Token | 양쪽 | 0, 2864, 50444, 0 / 0.00, 0.00, 0.00 | 120, 2744, 50404, 40 / 4.19, 75.00, 7.94 |

골드 925건과 walk/hang, workspace 테스트 639건, 포맷, Clippy,
benchmark Python 82건과 계약 대조 2건을 통과했다.

[오탐 증가 검토](README.md#오탐-증가-검토)에서 추가 반환 한 건을
원문과 대조했다. 종전 계약 검토 159건만 적용하면 Smart 계약 FP가
3,871건에서 3,872건으로 늘어난다. 원문의 수량·단위·조사·지정사
경계가 새 범위를 확인하므로 계약 양성을 추가해 양쪽에 적용했다.
검토 결과 추가 반환 중 제품 오탐과 미판정은 각각 0건이다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`da73ff11`과 `7377e3f6`을 비교했다. 각 입력과 버전에 대해 새
프로세스로 워밍업 1회와 측정 5회를 실행하고 두 버전의 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD Smart | 기준선 | 60.614 [60.181, 61.557] | 30,720 [28,323, 31,144] | 0.07175 [0.07062, 0.07721] | 81.125 [81.031, 81.375] |
| 교정 GSD Smart | 후보 | 60.908 [60.487, 62.036] | 30,260 [29,161, 30,992] | 0.07242 [0.07079, 0.07583] | 80.984 [80.844, 81.422] |
| 고정 음성 Smart | 기준선 | 60.726 [60.516, 61.599] | 19,948 [19,825, 20,020] | 0.12488 [0.12404, 0.12608] | 127.844 [127.516, 127.969] |
| 고정 음성 Smart | 후보 | 60.839 [60.278, 61.880] | 20,070 [20,003, 20,201] | 0.12450 [0.12292, 0.12463] | 127.656 [127.453, 127.828] |

교정 GSD와 고정 음성의 처리량 중앙값은 각각 −1.50%, +0.61%,
p95 중앙값은 +0.93%, −0.30%였다. 네 지표의 측정 범위가 겹쳤다.
