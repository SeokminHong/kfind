# 원인 의존 명사 앞의 지시 대명사

`이 때문에`의 `때문`은 앞의 명사·대명사나 용언 활용을 받아 원인을 나타낸다.
`이 때문에 늦었다`의 `이`는 대명사이며, `그 이유 때문에 늦었다`의 `그`는
`이유`를 꾸미는 관형사다. `이 때문에 치과에 갔다`에는 명사 `이` 분석도
성립한다. 앞말의 체언 분석을 유지하고 `때문` 뒤의 조사·지정사 활용까지 확인했다.
[국립국어원 문형 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=313417)

UD 2.18 Korean-GSD·PUD test에서 `이·그·저` 다음에 `때문`으로 시작하는
토큰을 검색했다. GSD 2건, PUD 0건이며 두 원문 모두 `이 때문에`였다.
고정 음성에서 대명사 범위 132..135와 0..3을 검증하고 교정 GSD 양성의
기존 관형사 품사 두 건을 계약 채점에서 바로잡았다. 원본 입력과 정답은 보존했다.

별도로 `이에·이로·이로써·이와` 토큰 18개를 GSD·PUD에서 대조했다.
고정 음성에 해당하는 13행 중 GSD 8행에서 대명사와 조사 범위를 기록했다.
PUD 4행은 이미 대명사로 검토되어 있었고, 한 행은 앞말과의 공백을 복원한
`ToDoOrigText`에서 정확한 범위를 확인해 기존 비표준 입력 제외를 적용했다.
조사 없이 `이 역시`로 쓰인 GSD 한 행의 대명사 범위도 기록했다.
[한국어기초사전 지시 대명사 이](https://krdict.korean.go.kr/m/eng/searchResultView?ParaWordNo=27527&mainSearchWord=%EC%9D%B4)

같은 독립 검토를 기준선과 후보에 적용했다. 고정 음성의 정렬된 계약 양성 46행은
후보에서 누락·추가 범위가 각각 0건이다. 고정 12세트와 세 경계 모드의
반환 목록 249,243개 중 차이는 두 문장의 Smart 대명사·관형사 질의 네 행이다.

## 네이티브 형태 판정

`e95d9495`와 `0600f11d`의 release runner를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
비교했다. 입력과 리소스 체크섬은
[앞선 비교](2026-11-22-embedded-question-object.md#네이티브-형태-판정)와 같다.
새 프로세스로 워밍업 1회 후 교대 측정 5회를 실행했다. 표는 중앙값 [최솟값, 최댓값]이다.
