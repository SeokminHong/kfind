# 목적어가 있는 절의 부사 내부 명사 오탐

`색깔을 정말 좋아했어요`의 `정말`은 목적어 `색깔을`을 취하는
`좋아했어요`를 수식한다. 어절 전체에 부사와 명사 분석이 공존하고
앞 목적격 명사구와 뒤 용언의 결합이 확인되면 어절 내부의 명사
후보를 제외한다. `참말 믿었다`, `잘못 이해했다`, 부사가 이어진
`정말 많이 배웠습니다`에서 문형과 범위를 확인했다.
[한국어기초사전 정말](https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=61174) ·
[한국어기초사전 잘못](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=62478&nation=eng)

명사와 부사가 함께 등재된 어절을 확인하지 않은 초기 후보는
`소홀히`의 어기 `소홀`을 네 목록에서 누락시켰다. `상자를 통째로 들었다`의
명사 `통`도 누락됐다. 어절 전체의 두 분석을 요구하고 사전의 명사 어기와
파생 접미사 경로를 보존한 후보에서 해당 반환을 복원했다. `통째`,
`통째로`, `껍질째`, `껍질째로`와 `정이 들었다`의 정상 반환을 확인했다.
[회귀 예문](../../data/fixtures/ud_morphology_cases.tsv)
