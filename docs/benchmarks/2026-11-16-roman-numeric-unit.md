# 로마 숫자와 단위 명사의 결합

Smart는 `XVI세`, `ⅩⅥ세`, `제IV장`의 로마 숫자와 단위 명사를
확인한다. 뺄셈 표기와 자릿수 순서를 검증해 영문 단어 `CIVIC`이나
반복이 잘못된 `IIIII`를 로마 숫자로 처리하지 않는다. 숫자를 확인한 뒤
기존 단위·조사·지정사 검증을 적용한다. `IV장이다`의 `장`과
`XVI세뿐이었다`의 `세뿐`을 같은 경로로 확인했다.
[국립국어원 한국 점자 규정의 로마 숫자 표기 예](https://korean.go.kr/common/download.do?c_file_name=korean_finger_alphabet.pdf&file_path=about&o_file_name=%ED%95%9C%EA%B8%80%EC%A0%90%EC%9E%90%EA%B7%9C%EC%A0%95%ED%95%B4%EC%84%A4%EC%84%9C_%EC%B5%9C%EC%A2%85%EC%9D%B8%EC%87%84%EB%B3%B8.pdf)

## 품질

고정 입력 12개와 세 모드 249,243행에서 ID, 리소스 해시와 반환 범위를
대조했다. Smart는 고정 음성의 PUD 10행에서 범위 13개를 추가했다.
원문 CoNLL-U의 로마 숫자 `NUM`이 바로 뒤 의존 명사 `NNB`를
수식하는지 확인하고 단위·조사 토큰을 원문에 다시 정렬했다. 13개
범위가 모두 계승 순서 단위 `세(世)`와 일치했다.
[계약 검토](../../tools/morph-compare/roman-numeric-unit-corpus-reviews.tsv)

8행은 반환이 새로 생겼고 2행은 기존 반환에 올바른 범위가 추가됐다.
두 행의 기존 반환 `투트모세`의 끝 음절 `89..92`와 `세실리가`의 첫
음절 `41..44`는 인명 내부의 오탐이다. 두 범위는 그대로 관측되어
행 단위 양성 판정과 별도로 남긴다. [오탐 증가 검토](README.md#오탐-증가-검토)

고정 음성 53,308행의 행 단위 행렬은 TP, FP, TN, FN 순이다.
비율(%)은 precision, recall, F1 순이며 양쪽 실행에 같은 검토
170건을 적용했다. 원본 음성표는 보존했다.

골드 925건과 walk/hang, workspace 테스트, 포맷, Clippy,
benchmark Python 82건과 계약 대조 2건을 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`4bd7e873`과 `a5b460af`를 비교했다. 각 입력과 버전에 대해 새
프로세스로 워밍업 1회와 측정 5회를 실행하고 두 버전의 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.
