# 소요 시간 구문의 관형형 경계

`병원까지 가는 데 걸리는 시간`에서 `데`는 소요 시간을 묻는
구문의 의존 명사다. Smart는 `걸리는 시간`이나 `시간이 걸렸다`처럼
시간 명사와 `걸리다`가 이어질 때 앞 관형형과 경쟁하는 명사·화제
조사 분석을 제외한다. `데`에 붙은 부사격 조사도 확인한다.
[국립국어원 ‘-는데’와 ‘-는 데’](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6792) ·
[한국어기초사전 ‘걸리다’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=86940)

고정 GSD·PUD의 명사·대명사·수사 질의에서 `은/는`으로 끝나는
어절 뒤의 `데`와 조사 결합을 검색했다. 고정 음성 75행·9문장과
교정 GSD 양성 59행·8문장에 해당했으며 PUD 양성에는 없었다.
`걸리다`와 `시간`이 이어지는 표적 문장은 한 문장으로, 고정 음성
5행과 교정 GSD 양성 4행에 있다. 이전 잔여의 `n:가`에서 `가는`
11범위를 확인했다. `가는 길`, `가는 방법`과 합성 명사
`전문가는`의 반환도 확인했다.

`가는 데에게 편지를 보냈다`와 `둑의 가는 데가 칠했다`에서 `데`는
인명으로 쓰일 수 있고 `가는`은 명사와 화제 조사로 반환된다.
`버스로 가는 방법`의 명사 오탐이 대조군에 남아 있다.

## 품질

고정 12세트 83,081행에서 세 모드의 반환 목록 249,243개 중
`gsd:test-s556:noun:가`의 Smart 30..36만 사라졌다.
`v:가다`는 같은 범위를 유지했다. 목표 11세트의 Smart FNc는
0이고 FPc는 1,813→1,812다. 새 계약 검토는 0건이며 기존 고정
음성 제외는 108행이다.

`집에 가는 데 걸리는 시간을 쟀다`의 정규형 CLI에서 NFC와 NFD의
동사 범위(7..13, 16..31)를 확인했고 후보에서 명사 범위는 사라졌다.
NFD에는 기준선과 후보 모두 구조 검증 미완료 진단과 종료 코드 2가
있다.

행렬의 순서는 TP, FP, TN, FN이고 비율(%)은 precision, recall, F1
순서다. 대조 질의에 계약 보정은 없다.

## 재현

기준선 `5715d66e`, 후보 코드 `a1c3e62b`를 Apple M1 Max arm64,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Node.js 26.11.1에서
같은 release 설정으로 실행했다. 성능은 새 프로세스에서 입력별
워밍업 1회 후 두 버전을 번갈아 각 5회 측정했다. 첫 두 지표의
방향이 반복되는지 같은 설정으로 한 회차 더 측정했다.
`/usr/bin/time -l RUNNER boundary full-pos smart INPUT OUTPUT`으로
실행했다. [빌드 명령과 입력 체크섬](2026-11-17-gun-initial-component.md#재현)
