# 붙여 쓴 부사와 동사 연결형

목적격 체언 다음의 어절에서 사전 부사와 동사의 `-고` 연결형이 붙고,
뒤에 독립 용언이 이어지면 Smart는 동사 연결형의 경계를 찾는다.
`마주보고`와 `똑바로보고`에서 `보고`를 검색하고, 한 동사인
`돌보고`의 내부는 검색하지 않는 대조를 확인했다.

## 품질

[앞선 비교의 12개 입력](2026-11-15-joined-predicate-chain.md#품질)을
Smart·Any·Token으로 실행해 249,243행의 ID, 리소스 해시, 반환 범위를
대조했다. 변경은 Smart의 `pud:n01144038:12` 한 건이다. `보다`에서
`보고`의 바이트 범위 `100..106`이 반환됐다. PUD Smart의 798건 모두
정답과 겹쳤다. 정확 범위 불일치 6건은 붙여 쓴 보조 용언을 포함하는 반환
범위와 본용언까지만 지정한 정답 범위의 차이다.

고정 음성 53,308행과 PUD·교정 GSD 양성을 원문·질의·품사로 연결했을 때
123행이 겹쳤다. 이 가운데 PUD 양성·음성의 형용사 태그, 표면형, 문장 ID가
같은 `큰` 22행과 `긴` 1행은 원문의 관형 관계와 양성 바이트 범위를
확인했다. 원본 음성 레이블은 보존하고 기존 `aligned-source-component`
계약 검토를 등록했다. 나머지 100행은 이번 계약 검토에 포함하지 않았다.
같은 음성 입력에서 저장소에 기록된 기존 34건과 이번 23건을 ID·질의·
품사·원본 레이블·원문 SHA-256으로 검증해 기준선과 후보에 똑같이 적용했다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1 순서다.
PUD 양성은 정확한 바이트 범위로 채점하며 계약 검토는 0건이다.
GSD·PUD 음성은 반환 범위 존재 여부로 채점한다.

골드 925건과 walk/hang, workspace 테스트, Clippy, 포맷,
benchmark Python 테스트 82건과 계약 대조 테스트 2건을 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release,
Full POS Smart에서 `69e8a173`과 `01e47e64`를 비교했다.
기준선 실행 파일은 `24942bf7`에서 빌드했으며 `69e8a173`과 Git tree가
같다. 워밍업 1회 후 새 프로세스로 5회씩 실행하고 순서를 교대했다.
표는 중앙값 [최솟값, 최댓값]이다. p95는 최근접 순위, RSS는 최대 상주 메모리다.

PUD, 교정 GSD, 음성 순으로 처리량 중앙값은 +0.58%, −0.12%, +0.36%,
p95는 −0.13%, +1.01%, −1.61%다. 세 입력에서 처리량과 p95 범위는
각각 겹쳤다.

```sh

scripts/benchmark-run.sh run --name joined-adverb-connective -- \
  /usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
