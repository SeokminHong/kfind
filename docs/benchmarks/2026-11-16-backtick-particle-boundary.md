# 백틱으로 둘러싼 표기 뒤의 조사

GSD `test-s316`의 `현답(贤答)` 뒤 133..136은 주격 조사 `이`다.
짝이 맞는 백틱으로 둘러싼 표기 바로 뒤에 조사가 붙을 때, 표기 안의
끝말이나 병기 괄호 앞말을 기준으로 기존 조사 판정을 적용한다.
같은 길이의 백틱 연쇄를 짝지을 때 왼쪽 문맥 범위를 사용한다.
[CommonMark의 백틱 연쇄와 코드 범위](https://spec.commonmark.org/0.31.2/#code-spans)

## 품질

고정 12세트 83,081행에서 백틱이 있는 서로 다른 원문 5개를
확인했다. 백틱 바로 다음에 한글이 있는 원문은 4개다. 기준선에서
백틱 바로 뒤로 시작하는 Smart 반환은 6개였다. 여는 쪽의 `큰`,
`현답`, `외환` 네 범위를 유지하고, 닫는 쪽에서 대명사와 관형사로
반환한 조사 `이` 두 범위를 제외했다. 세 모드의 반환 범위
249,243개를 비교했으며 이 두 범위만 바뀌었다.

회귀 13개에서 주격·조사 연쇄, 여러 쌍, 길이가 같은 백틱 연쇄,
수식어가 표기 안에 오는 경우를 확인했다. 짝이 안 맞는 부호와
이스케이프된 부호, 띄어 쓴 관형사, 받침 조건이 맞지 않는 표적은
기존 반환을 유지했다. 고정 음성의 계약 검토 1,357행과 제외
67행을 유지했다. 목표 11세트에서 Smart FNc는 0, FPc는
2,079에서 2,077이다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
회귀의 계약 검토는 0행이다.

## 성능

입력마다 새 프로세스에서 워밍업 1회 후 두 러너를 교대로 5회
실행했다. 표는 중앙값 [최솟값, 최댓값]이다. p95는 실행별 최근접
순위를, RSS는 `/usr/bin/time -l`의 최대 상주 메모리를 사용했다.

| Smart 입력 | 리비전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.901 [60.650, 62.576] | 30,514 [29,219, 30,610] | 0.07071 [0.07042, 0.07275] | 81.219 [81.094, 81.250] |
| 교정 GSD | 후보 | 60.923 [60.599, 62.837] | 30,475 [28,373, 30,614] | 0.07108 [0.07079, 0.07463] | 81.109 [81.031, 81.438] |
| 고정 음성 | 기준선 | 60.463 [60.229, 62.025] | 19,705 [17,037, 19,790] | 0.12633 [0.12508, 0.13600] | 127.672 [127.266, 127.750] |
| 고정 음성 | 후보 | 60.646 [60.369, 61.394] | 19,620 [19,489, 19,887] | 0.12717 [0.12433, 0.12879] | 127.609 [127.281, 128.406] |

| 백틱 반복 | 후보 | 60.780 [60.380, 60.989] | 96,143 [95,989, 97,123] | 0.01583 [0.01554, 0.01588] | 80.156 [80.125, 80.281] |

교정 GSD 처리량·p95 중앙값은 −0.13%·+0.53%, 고정 음성은
−0.43%·+0.66%다. 두 입력의 관측 범위는 각각 겹친다.
백틱 반복은 +22.58%·−7.09%이며 후보에서 반환하는 범위가 줄어드는
작업량이다. 러너는 5,179,024바이트에서 5,179,456바이트로 늘었다.

## 재현

기준선은 `41bf4dbe`, 후보 코드는 `14aefd10`이다. 기준선의 검색
코드와 같은 `d35eeefa`에서 검증한 러너를 사용했다. Apple M1 Max
arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
`/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로
측정했다. 고정 평가의 명시 품사는 `boundary full-pos MODE INPUT OUTPUT`,
자동 품사는 `untagged full-pos MODE INPUT OUTPUT`으로 실행했다.
[고정 입력과 리소스 체크섬](2026-11-16-nominal-predicate-path.md#재현)

백틱 반복 입력은 `data/fixtures/ud_morphology_cases.tsv`의
`regression.particle.enclosed.backtick-` 13행을 원래 순서대로
1,000번 반복한 13,000행이다. JSONL 필드는 순서대로 `id`,
`query`, `pos`, `text`, `expected`, `gold_byte_start`,
`gold_byte_end`이며 ID는 fixture 접두사를 뗀 이름에 콜론과
0..999 반복 번호를 붙였다. SHA-256은
`43213d36885df270ecbab997e8f6379b40a7c3211095b2e776731fd2ceba28f5`다.
