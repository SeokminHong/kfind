# GSD의 곡명 지와 지정서 주석

소녀시대의 곡을 찾는 두 문장에서 `지`를 곡명으로 분류했습니다. 발화에
나온 한글 표기와 바이트 범위를 보존했습니다. `지정서를 수여하고`는 문서를
수여하는 문장이므로 `지정서+를`과 어절 전체 범위를 정답으로 삼았습니다.
[SMTOWN의 공식 뮤직비디오](https://www.youtube.com/watch?v=U7mPqycQ0tQ) ·
[지정서 사용례](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000192425) ·
[주석 교정 목록](../../tools/morph-compare/gsd-ji-nominal-annotations.tsv)

독립된 `지`, `지정서`, `소녀시대`를 GSD 양성 9,314행, PUD 양성 798행,
GSD·PUD 음성 53,308행과 사전 양성 4,458행에서 검색했습니다. 해당 문장은
각각 5개, 0개, 5개, 3개입니다. GSD의 `지` 질의 4행을 모두 검토했고
`지•정체`의 표기와 범위는 원출처 확인 대상으로 남겼습니다.

`3e8763c2` full POS로 교정 전후를 비교했습니다. 행렬은 TP, FP, TN, FN이며
비율은 precision, recall, F1입니다. 계약 검토는 0건입니다.

| 경계 | 입력 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- | --- |
| smart | 교정 전 | 9101, 0, 0, 213 | 100.00, 97.71, 98.84 | 9101, 0, 0, 213 | 100.00, 97.71, 98.84 |
| smart | 교정 후 | 9102, 0, 0, 212 | 100.00, 97.72, 98.85 | 9102, 0, 0, 212 | 100.00, 97.72, 98.85 |
| any | 교정 전 | 8933, 0, 0, 381 | 100.00, 95.91, 97.91 | 8933, 0, 0, 381 | 100.00, 95.91, 97.91 |
| any | 교정 후 | 8934, 0, 0, 380 | 100.00, 95.92, 97.92 | 8934, 0, 0, 380 | 100.00, 95.92, 97.92 |

`지정서`는 두 경계에서 정확히 일치했습니다. 곡명 두 건은 `smart`에서
계속 누락됩니다. #421의 불일치 1,113행 중 교정 전 `smart` 정확 일치는
914행, 부분 일치는 86행, 겹치는 반환 없음은 113행이었습니다. 교정 후
각각 915행, 86행, 112행입니다.

```sh
node tools/morph-compare/apply-gsd-sentence-edits.mjs "$input" --ji-nominals > "$corrected"
"$runner" boundary full-pos "$boundary" "$corrected" "$output"
```

교정 입력 SHA-256은 `1552fa35dfc7e06dd49e8e79208755f84fefb2e4a7e4673dba8b256194c3c1e6`입니다.
검색 코드 변경이 없어 성능 측정을 생략했습니다.
