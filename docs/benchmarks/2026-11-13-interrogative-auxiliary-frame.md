## 품질

`물이 찬가 보다`와 `차가 단가 보다`에서 주격 체언과 추측 보조 형용사 사이의 표적은
의문형입니다. 두 문장의 명사 검색을 음성으로 검증했습니다. 명사에 목적격 조사가
붙는 `찬가를 본다`와 수량 명사구 `찬가 한 곡을`의 반환 범위도 확인했습니다.
[국립국어원 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=327262) ·
[범위 회귀](../../data/fixtures/interrogative_span_cases.tsv)

독립 인용 `‘단가?’`는 단맛을 묻는 의문형과 가격을 되묻는 명사 양쪽으로 성립합니다.
인용문은 동일하게 두고 앞 문장으로 의미를 가르는 대조를 사용했습니다.
[대조 예문](../../tools/morph-compare/interrogative-context-cases.jsonl) ·
[계약 검토](../../tools/morph-compare/interrogative-contract-reviews.tsv)

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Darwin 25.6.0, Rust·Cargo 1.97.0에서
동일한 리소스와 release 설정을 사용했습니다. 새 프로세스에서 입력별로 warm-up 1회 후
5회 측정하고 실행 순서를 교대했습니다. 처리량은 runner 평가 시간, p95는 nearest-rank,
RSS는 `/usr/bin/time -l`의 최대 상주 메모리를 사용했습니다. 셀은 중앙값 [최솟값, 최댓값]입니다.

양성·음성 처리량은 각각 0.24%, 0.51% 늘고 p95는 각각 0.56%, 1.08% 줄었습니다.
초기화 중앙값은 각각 0.48%, 3.18% 늘었으며 측정 범위가 겹칩니다. RSS는 각각 0.24%,
0.22% 줄었습니다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
KFIND_FULL_POS_LEXICON="$full_pos_dir/lexicon.bin" \
KFIND_COMPONENT_RESOURCE="$component_resource" \
KFIND_ENRICHED_PREDICATES="$enriched_predicates" \
  /usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
