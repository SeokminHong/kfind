# 대명사의 복수 접미사와 원문 범위

`이들이`와 `그들의`는 대명사에 복수 접미사 `-들`과 조사가 붙은
형태다. `이 들에는`과 `그 들의`는 관형사가 독립 명사 `들`을
수식한다. 앞 형태에 대한 대명사 질의의 반환 범위는 복수 접미사와
조사까지 포함한다.
[국립국어원 복수 접미사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=326975)

고정 음성 53,308행에서 `이`, `그`, `저` 대명사 질의와 대응하는
`-들` 표면을 모두 검색했다. 34행(`이` 12행, `그` 22행, `저` 0행)을
문장 ID와 원문으로 CoNLL-U에 연결했다. 정상 경계의 31행에서
`PRON` 어절 33개의 바이트 범위를 확인했다. GSD 1개는 `이+들+은`으로
분절돼 있다. PUD 30개는 `이들`·`그들` 표제어와 복수 표지를 갖고,
나머지 2개는 표제어 없이 복수로 표기된 `이들`이다.

앞 어절과 붙어 기록된 `선호했으며이들은`, `말해그들은`,
`등장하고그들의`의 3행은 원본 `ToDoOrigText`에 공백이 있어
계약 평가에서 제외했다. 원문과 범위는 보존했다.
[계약 검토](../../tools/morph-compare/plural-pronoun-source-corpus-reviews.tsv)

## 품질

정상 원문 31개, 원본의 띄어쓰기를 복원한 3개, 관형사 대조문 2개에
각각 대명사와 관형사 질의를 실행했다. Smart는 대명사 범위 36개와
대조문의 관형사 범위 2개를 모두 정확히 반환했다. 경쟁 질의가
표적 범위와 겹친 사례는 Smart 0개, Any 38개, Token 2개다.

고정 평가에는 `74e9e2ec`에서 저장한 동일한 반환 목록을 사용했다.
목표 11세트의 Smart FNc는 0이고 FPc는 1,900에서 1,869로 줄었다.
행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
계약 제외는 고정 음성의 기존 72행과 신규 3행이다.
대조 질의는 계약 검토 0건이다.

## 재현

대명사와 관형사 질의의 `pos`를 각각 `pronoun`과 `determiner`로
지정하고 `morph-benchmark-runner boundary full-pos MODE INPUT OUTPUT`을
세 모드에서 실행했다. 원문과 대조문은 계약 검토의 예문 자료에 있다.
대명사 양성은 조사까지 포함한 어절 범위, 관형사 양성은 첫 음절 범위를
검사했다. 같은 원문에 표적이 둘이면 양쪽의 정확 범위를 모두 검사했다.
