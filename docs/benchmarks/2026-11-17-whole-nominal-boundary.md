# 통째 명사와 내부 체언의 경계

`선전`은 구조 사전에 성분 정렬이 없는 일반 명사와 고유 명사로
등록돼 있다. 두 분석은 같은 어절 범위를 차지한다. 어절 전체의 분석이
이 두 품사에 한정되면, Smart는 통째 명사의 경계를 내부 성분 판정에
사용한다. `선전 교통 경찰은 전에`에서 `전`은 `전에`만 반환한다.
`자동차상`의 `차`처럼 사전에 정렬된 성분은 계속 검색한다.

## 품질

잔여 음성에서 명사 질의와 반환 문자열이 일치하고 앞에 한글이 붙은
어절 말미 범위 130개를 조사했다. 65개의 전체 어절이 compact 사전에서
일반 명사 또는 고유 명사로만 분석됐다. 고정 12세트 83,081행의 세 모드
249,243개 반환 목록을 모두 비교했다. Smart의 고정 음성 다섯 행에서
각 한 범위가 제거됐다.

- `선전`의 `전`이 사라지고 같은 문장의 `전에` 범위는 남았다. 해당
  평가 행은 기존 계약의 원문 양성이다.
- `절차`의 `차`, `일상`의 `상`, `지불`의 `불`, `이중`의 `중`이 사라졌다.
  `이중 대부분`에 공백 하나를 넣은 `이 중 대부분`에서는 의존 명사 `중`을
  153..156으로 반환한다. `이중 확인`의 전체 명사 `이중`은 보존했다.
  [국립국어원 ‘이 중’의 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?qna_seq=329898)

평가 계약을 양쪽에 동일하게 적용했다. 목표 11세트 Smart의 FNc는 0,
FPc는 1,919에서 1,915다. 행렬은 TP, FP, TN, FN 순이며 비율(%)은
precision, recall, F1 순이다. 고정 대조 8개에 계약 검토는 0건이고,
고정 음성의 계약 평가에는 기존 제외 72행을 적용했다.

| 고정 대조 | 기준선 | 4, 4, 0, 0 / 50.00, 100, 66.67 | 4, 4, 0, 0 / 50.00, 100, 66.67 |
| 고정 대조 | 후보 | 4, 0, 4, 0 / 100, 100, 100 | 4, 0, 4, 0 / 100, 100, 100 |

## 성능

각 값은 중앙값 [최솟값, 최댓값]이다. p95는 질의 시간의 nearest-rank
95백분위수다.

| Smart 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | 최대 RSS (MiB) |
| --- | --- | ---: | ---: | ---: | ---: |
| GSD | 기준선 | 60.597 [60.490, 60.866] | 30,464 [30,283, 30,510] | 0.07129 [0.07079, 0.07142] | 81.188 [81.109, 81.266] |
| GSD | 후보 | 60.671 [60.273, 60.934] | 30,451 [29,854, 30,580] | 0.07088 [0.07075, 0.07325] | 81.344 [81.234, 81.641] |
| 고정 음성 | 기준선 | 60.570 [60.413, 61.596] | 19,600 [19,314, 19,853] | 0.12737 [0.12450, 0.12962] | 127.609 [127.344, 127.781] |
| 고정 음성 | 후보 | 60.579 [60.403, 61.081] | 19,770 [19,358, 19,845] | 0.12508 [0.12471, 0.12904] | 127.641 [127.547, 127.703] |

GSD 처리량·p95 중앙값은 −0.04%·−0.58%, 고정 음성은
+0.87%·−1.80%다. 각 지표의 관측 범위는 겹쳤다.
