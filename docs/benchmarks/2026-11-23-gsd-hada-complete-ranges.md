# GSD 동사 하다의 명사형과 보조 용언 범위

원문 GSD의 `하다` 미판정 반환 9행을 대조했다. 네 행에 해당하는 세
문장에서 독립 `하다`의 모든 범위를 확인했다. `없게 함`은 명사형
어미로 종결되는 사동 구성이다. `해줬으면 한다`의 `한다`는 바람을
나타내고 `해야 한다`의 두 번째 `한다`는 필요를 나타낸다. 두 GSD에
같은 원문과 정답 범위를 등록했다.
[한국어기초사전 하다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=73277)
· [국립국어원 하다의 보조 동사 쓰임](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=304402)
· [원문과 대조 예문](../../tools/morph-compare/contract-contrast-evidence.jsonl)

두 문장에서 기존 116개 질의를 원문과 대조문에 각각 실행했다.
`해줬으면 한다`는 보조 동사를 붙여 쓸 수 있는 형태다. 띄어 쓴 원칙
표기에서 `하다`는 `해` [138, 141)와 `한다` [152, 158)를 반환했다.
`감액 부분`과 `합의 처리`를 띄어 쓴 교정문에서 `해야` [196, 202)와
`한다` [203, 209)를 확인했다. 띄어 쓴 `해 줬으면`의 `해` [138, 141)를
명사 질의도 반환했다. 이 범위의 명사 분석은 문장 안에서의 목적격
조사 생략 가능성을 검토할 때까지 미판정으로 남겼다.
[보조 용언 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=312171)

같은 `97762583` 실행 결과에서 네 행이 모두 새 정답과 일치했다.
앞서 확인한 아홉 행 가운데 두 행은 별도 제품 수정으로 범위를 확인했다.
나머지 세 행의 추가 반환은 파생 어휘 경계나 띄어쓰기 오류와 겹친다.
해당 범위는 이번 검토에서 확정하지 않았다.

채점은 같다.
