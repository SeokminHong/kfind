# 분해형에서 붙임 보조 용언의 반환 범위

Smart의 canonical 검색에서 붙임 보조 용언을 판정할 때 사전
표면과 분할 지점을 NFC로 맞춘다. 결과는 원문 바이트 범위다.
`문 앞에 서있었다`의 [11, 23)은 NFD 원문에서 [26, 56)로
반환된다. 붙임이 허용되는 `열어뒀다`, `꺼져있었다`와,
띄어 쓴 `서 있었다`, `생각해 보자`에서 각 원문의 범위를 확인했다.

모음 연결형 뒤에 오는 보조 용언의 완결 활용과 본용언 경계를
확인한다. `가지에`의 동사 `가다`, `사하라`의 동사 `사다`,
`고쳐주셨다`의 내부 동사 `치다`를 제외하고, `가지`의
독립 활용, `사두었다`, `고쳐주셨다`의 정확한 범위를 보존한다.
어절 안에서 시작하는 후보는 파생 연결형 또는 어절 전체의
보조 용언 경로에 맞는 용언 성분을 확인한다.
사전에서 확인한 합성 동사 후행 성분은 기존 구조 근거와
결합해 `걷어붙이고`, `걷어붙였으며`, `몰아붙였다`를
그대로 검색한다. `말해준다`의 파생 성분은 기존 검색 계약을 따른다.
[한글 맞춤법 제47항](https://www.korean.go.kr/kornorms/regltn/regltnView.do)
· [국립국어원 합성 동사 -어붙이다](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=325015)
· [파생 연결형의 기존 회귀](2026-11-17-derived-ha-nominalizer.md)

## 원문·교정문 대조

정규화와 반환 범위를 확인한 질의는 고정 음성 37,923행,
원문 GSD 2,922행, 등록 교정 GSD 2,904행의 동사·형용사다.
채점은 등록 입력을 그대로 사용했다. 달라진 문장의 띄어쓰기와
철자를 확인해 원문·교정문에서 NFC·NFD 질의를 각각 실행했다.
보조 용언 붙여쓰기가 규범상 허용되는 `알려줘`, `고쳐주신다`는
유지했다. 별도 입력 3,296건의 SHA-256은
`1d1f4bd33bcee131273aedf5da0f75dea1ea0aa2b5769d25b35ea26efb1c56dc`이다.

| 문장 | 표기 교정 | 확인한 표적 |
| --- | --- | --- |
| GSD s262 | 골라먹을 → 골라 먹을 | 고르다 원문 [61, 73), 교정 [61, 67) |
| GSD s436 | 무료 추천 종목을, 따라 한 | 따르다 원문 [92, 101), 교정 [94, 100) |
| GSD s446 | 떨어지내요 → 떨어지네요 | 떨어지다 [31, 46) |
| GSD s667 | 단정 지어, 들어와 있음을 | 들어오다의 [279, 288) 보존, 들다 오반환도 같은 범위에 남음 |
| GSD s874·s918·s980 | 배달해 주시더군요, 검안해 주신, 설명해 주네요 | 각각 [33, 42), [37, 46), [34, 43) |
| GSD s923 | 비벼먹으면 → 비벼 먹으면 | 비비다 원문 [47, 62), 교정 [47, 53) |

| PUD w01027007 | 건조하기 때문에 | 사하라 내부 사다 |

고정 사전 진단의 `떠드는지`와 `가져다주게`는 예전 표제어
`뜨다`, `가지다`로 검색할 때의 오반환이 없어졌다. 현행 표제어
`떠들다`, `가져다주다`는 각각 [23, 35), [11, 26)을 반환했다.

## 검색 품질

고정 음성의 FPc는 1,512 → 1,502다. 독립적인 `차지` 범위가
남은 원문은 FPc에 계속 포함된다. 원문 GSD에서 `골라먹을`,
`비벼먹으면`, `떨어지내요`의 검색이 사라져 FNc 3건이
늘었다. 교정문의 올바른 활용은 모두 검색된다.

기존 평가 258,541건의 반환 범위를 대조해 Smart 20행의
변경을 확인했다. 전체 범위 미검증 계약 양성은 1,207행이며,
제외 42행에서 37범위의 판정이 남았다. 추가 반환 미판정은
원문 GSD 576행 638범위, 교정 GSD 116행 122범위다.
[평가 입력과 리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

WASM canonical 검색에서 원문 GSD 45행, 교정 GSD 38행의
NFD 반환 범위가 NFC와 일치했다. 고정 음성의 NFD 변화
한 건은 `말해준다`의 [200, 209)에 해당하는 기존 파생 성분이다.
등록 음성의 판정은 그대로 계수했다. `나타나는데` 안의 기존
NFD 동사 `타다` 오반환은 [61, 64)에 대응하며 남았다.
직접 회귀 54건의 후보 반환은 모두 정확한 NFC·NFD 범위와
일치했다.

출시용 WASM은 `wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release`로
빌드했다. 원본은 2,858,176 → 2,860,360 B (+2,184), gzip은
972,678 → 972,960 B (+282), Brotli는 716,963 → 716,340 B
(−623)였다.

## 성능

Apple M1 Max, macOS 26.6.2 arm64, Rust 1.97.0, Python
3.14.8과 Node 26.11.1에서 기준선 `dd3e3d4c`와 후보
`24772db6`을 같은 리소스로 측정했다. 새 프로세스에서 버전별
워밍업 1회 뒤 순서를 교대해 5회 측정했다. 중앙값 [최솟값,
최댓값]을 사용했고 p95는 각 실행의 최근접 순위다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name canonical-contract -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" dd3e3d4c "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 24772db6 "$lexicon" "$component" "$predicates"
node tools/morph-compare/measure-smart-nfd-wasm.mjs \
  "$corrected_gsd" "$wasm_package_dir" "$lexicon" "$component" "$predicates"
```

WASM은 교정 GSD에서 동사·형용사 2,904행을 원래 순서로 추출해
NFD로 실행했다. 변환 입력 SHA-256은
`d3c4b4392bec08cb60a8aa1ba50519e1770e9bf5516fad74e706c8349a393997`이다.
