# 관형절 뒤 수 관형사 한의 검색 범위

Smart에서 동사 `하다`를 검색할 때, 앞 어절의 용언 관형형과 뒤
명사 성분을 확인해 `생일을 맞은 한 신입사원`, `믿지 못할 한 해`의
수 관형사를 거른다. 바로 앞 어절에 목적격 조사를 가진 명사 분석이
있으면 `그 일을 한 때`의 `한`처럼 본동사 후보를 유지한다.
수 관형사 `한`의 결합 범위와 같은 명사를 꾸미는 두 용언의
연결형·관형형 순서를 근거로 삼았다.
[한국어기초사전 한](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=73278)
· [국립국어원 관형어 순서](https://korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=8883&mn_id=&pageIndex=40)

## 반환 범위와 품질

동사 `하다` 질의를 고정 음성 273행, 원문 GSD 132행, 교정
GSD 124행에서 비교했다. 이 중 독립 어절 `한`이 있는 행은
각각 62, 8, 7행이다. 기존 258,541개 검색 결과 비교에서는
Smart 3행의 반환이 달랐다. 고정 범위 회귀 6행을 NFC·NFD와
리소스 장착 Smart·Any 및 기본 Token으로 실행해 빌드당 36개
결과를 검사했다.

변경된 두 문장에서 원문·교정문을 대상으로 질의 206개를
비교했다. GSD s243의 `사장이(오른쪽 네 번째)`, `감사행사`,
`이 날`은 각각 `사장(오른쪽 네 번째)이`, `감사 행사`,
`이날`로 교정했다. 동사 검색은 양쪽에서 `한`의 [142, 145)를
거르고 `하고`의 [195, 201)을 보존했다. PUD n02044008의
`믿지 못할 한 해`는 원문 표기가 그대로 유효하며 양쪽 실행에서
`한`의 [80, 83)이 사라졌다. 대조 입력 SHA-256은
`923e567cf41345f6270d66238cc125e39a86aadb9b00215816f1753ea3a79d40`이다.

GSD s283에는 `한 유닛`과 `한 턴`의 추가 범위 두 개가
남아 있다. 고정 음성 계약 양성 1,207행은 전체 범위가 미검증이며
제외 42행에서 37범위의 판정이 남았다. 추가 반환 미판정은
원문 GSD 576행 638범위, 교정 GSD 116행 122범위다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0, Python
3.14.8에서 기준선 `4d90ee7d`와 후보 `ab48c291`을 비교했다.
같은 리소스를 장착했다. 빌드마다 새 프로세스로 워밍업 1회,
순서를 교대하며 5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이며
p95는 각 실행의 최근접 순위다. [평가 리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "han-adnominal-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 4d90ee7d "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" ab48c291 "$lexicon" "$component" "$predicates"
```

입력은 고정 음성 53,308행(`482e55d417516e8db503dbd421725fcc7affc6c6afcf5b5d42cec3bbd4d35d54`),
교정 GSD 9,298행(`5231c0e7c4d3c72de2982e0c38fc5420f01dcbecd764428e993b903e56dc8308`),
동사 `하다` 529행(`84420b58530ad56f1efd19e44c8edfe497a50cb0b708508e35b6c50bccc78ce9`)이다.
529행은 고정 음성, 원문 GSD, 교정 GSD 순서로 연결했고 각
입력의 질의 순서를 유지했다.
