# 변화 연결형 뒤 결과 상태 보조 동사의 검색 품사

`켜져 있어요`에서 `있어요`는 결과 상태를 나타내는 보조
동사다. Smart는 앞 어절에서 동사나 형용사의 모음 연결형과
`-어지다`의 마지막 모음 연결형을 각각 확인한다. 첫 용언이
어간과 어미로 나뉘는 `넓어져`도 같은 판정을 거친다. 같은
문장에 `작업할 수 있었다`가 있으면 가능성의 형용사 범위는
유지한다. [한국어기초사전 있다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62595)
· [국립국어원 한국어교육 문법·표현 내용 개발 연구](https://www.korean.go.kr/common/download.do?book_seq=275&c_file_name=dd56408d-ba84-49d8-8343-8a9b33bf79c1_0.pdf&downGubun=bookDataView&file_path=bookData&o_file_name=%ED%95%9C%EA%B5%AD%EC%96%B4%EC%A7%84%ED%9D%A5-01-20.pdf)

## 원문·교정문과 품질

PUD의 `있는`과 `있다`는 각각 12번과 17번의 `VX`다.
`ToDoOrigText`에 따라 `결정한 이후`와 `일본식 정원`의 공백을
복원했다. 첫 문장은 이중 피동을 줄인 `쓰여 있는`으로도 대조했다.
원문과 교정문에서 동사 범위는 모두 유지됐다.
[PUD n04007018](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L19494)
· [PUD w02005026](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L20485)

184개 원문·교정 질의에서 형용사 오반환 네 건이 제거됐다.
고정 음성과 GSD에서 `져`와 띄어 쓴 `있-`가 이어지는
`있다` 질의 14행을 골라 40개 대조 질의와 함께 확인했다.
`켜져\n있어서`와 보조 용언을 두 번 붙인 `켜져있어서`의 품사
동형은 여전히 반환된다. 존재의 `사전이 있어서`와 범위의
`정하는 데 있어서`는 형용사 반환을 보존했다.
대조 입력 SHA-256은 각각
`fb9310f377252357bb7175ed6dbad697d31816383743e82559f62db1da4db304`,
`5abc9ec02c0caa6bdcf210adacaeb2d19136cab79c170e2d10aaec28ee2d47a1`다.
역사 입력 258,541개 조합에서는 PUD 원문 두 행만 달라졌다.
고정 회귀 9행은 NFC·NFD와 리소스 장착 Smart·Any, 기본 Token으로
빌드당 54개 조합에서 확인했다.

행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.
두 빌드에 같은 입력과 정답을 적용했다.

미판정 추가 반환은 원문 GSD 553행 613범위, 교정 GSD 104행
