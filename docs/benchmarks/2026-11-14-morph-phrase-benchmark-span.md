# 형태 검색 평가의 구 범위

교정 GSD 9,306행에서 공백을 포함하는 질의는 방송 제목
`나름 가수다` 두 건이다. 제품은 각 문장에서 `19..35`를
반환한다. 평가 러너가 결과를 두 원자 범위 `19..25`, `26..35`로
기록하면서 정확 일치가 부분 일치로 집계됐다. 러너는 각 검색
결과의 전체 범위를 기록하며 정답과 검색 코드는 동일하다.
회귀는 별개인 두 구 결과를 각각 하나의 범위로 기록하는지 검사한다.
러너 테스트 10건이 통과했다.

두 경계에서 제목 두 건만 범위가 달라졌으며 고정 음성 53,308건의
반환 범위는 동일했다. #421의 비교군 1,113행 중 `smart`는 정확
1,057행, 부분 20행, 누락 36행이다. 행렬은 TP, FP, TN, FN
순서이며 비율은 precision, recall, F1이다. 양성 계약 검토는
0건이고 고정 음성 계약 보정은 32건이다.
