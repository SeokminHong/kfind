## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Rust·Cargo 1.97.0에서 같은
release 설정과 리소스로 새 프로세스 워밍업 1회 뒤 5회 측정했습니다.
작업 시작점 `70a5d2d4`, 기준선, 후보의 실행 순서를 순환했습니다.
값은 중앙값 [최솟값, 최댓값]입니다. p95는 nearest-rank, RSS는 최대 상주
메모리입니다.

기준선 대비 양성 처리량은 2.46% 늘고 p95는 3.88% 줄었습니다. 음성
처리량은 0.45% 늘고 p95는 0.50% 줄었습니다. 양성 처리량은 이번 측정에서
후보의 최솟값이 기준선의 최댓값을 넘었고, 음성 처리량과 양쪽 p95의 측정
범위는 겹쳤습니다. 시작점 대비 처리량은 양성 10.21%, 음성 13.11% 늘었고
p95는 양성 13.11% 감소, 음성 8.45% 증가했습니다.
