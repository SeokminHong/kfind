# 고유명사 내부 명사 범위

Smart는 독립 품사가 고유명사뿐인 어절을 하나의 체언으로 확인한다.
사전의 성분 경계나 앞부분 전체와 끝 명사를 각각 덮는 독립 명사 분석이
있으면 명사 성분을 유지한다. 단위 명사 `세` 질의는 `투트모세 III세가`에서
`III` 뒤에 붙은 `세가`만 반환한다. `동아프리카`의 `동`은 사전 성분이고
`후베이성`의 `성`은 앞의 지명과 결합한 행정 단위다.
[중국 행정구역 자료](https://www.kiep.kr/galleryDownload.es?bid=0001&list_no=1724&seq=1)

## 품질

PUD 원문의 `PROPN/NNP`와 조사 결합형 내부 반환 32행 36범위를 추출했다.
고정 입력 12세트와 세 모드 249,243행에서 ID, 리소스 해시, 반환 범위를
비교했다. 범위 차이 5건은 모두 Smart 고정 음성에서 발생했다.

| 원문 형태 | 제거된 범위 | 근거 |
| --- | --- | --- |
| 투트모세 III세가 | `세` 89..92 | 인명 내부의 임의 분절이다. 왕의 계승 순서를 나타내는 `세가` 96..102는 유지했다. |
| 강혜정 | `정` 13..16 | 고유명사 전체에 내부 명사 경계가 없다. |
| 아이티 | `아` 199..202 | 음역 지명에 독립 명사 경계가 없다. |
| 음주운전 | `전` 37..40 | 사전 성분은 `음주 + 운전`이다. |
| 대한민국 | `국` 9..12 | 사전 성분은 `대한 + 민국`이다. |

PUD 이름 내부 후보 36범위 중 `투트모세` 한 곳이 바뀌었다. 나머지
35범위에는 실제 성분과 리소스의 성분 분석을 추가 확인할 사례가 섞여 있다.
예를 들어 MeCab 원자료에는 `Colorado`의 음역인 `콜로라도`를
`콜로라 + 도`로 분리한 항목이 있다. 이 분석에 따른 반환은 남아 있다.

고정 음성 53,308행의 행렬은 TP, FP, TN, FN 순서이고 비율은 precision,
recall, F1 순서다. 양쪽에 기존 계약 검토 170건을 같은 기준으로 적용했다.

| 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 4039, 49269, 0 / 0.00, 0.00, 0.00 | 170, 3869, 49269, 0 / 4.21, 100.00, 8.08 |
| Smart | 후보 | 0, 4035, 49273, 0 / 0.00, 0.00, 0.00 | 170, 3865, 49273, 0 / 4.21, 100.00, 8.09 |
| Any | 양쪽 | 0, 17622, 35686, 0 / 0.00, 0.00, 0.00 | 170, 17452, 35686, 0 / 0.96, 100.00, 1.91 |
| Token | 양쪽 | 0, 2864, 50444, 0 / 0.00, 0.00, 0.00 | 120, 2744, 50394, 50 / 4.19, 70.59, 7.91 |

신규 범위 회귀 5건, 형태 분석 gold와 walk/hang 스트레스, workspace
테스트 639건, benchmark Python 82건, 포맷과 Clippy를 확인했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
`814f0e6e`와 `d75e457d`를 비교했다. 각 버전을 새 프로세스로 실행해
워밍업 1회 뒤 5회씩 측정하고 버전 순서를 교대했다. 표는 중앙값
[최솟값, 최댓값]이며 p95는 최근접 순위다.
