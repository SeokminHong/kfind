# 퍼센트 기호 뒤 조사 경계

`60%가 넘는다`에서 숫자와 기호는 백분율을 나타내고 `가`는
그 뒤에 붙은 주격 조사다. Smart는 숫자와 붙은 `%` 또는 `％` 뒤의
조사 연쇄를 기호의 읽기 `퍼센트`를 기준으로 확인한다. 공백으로
나뉜 `집에 가`는 동사 활용형으로 반환한다.
[국립국어원 퍼센트 표기 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=27&pageIndex=1&qna_seq=326976)

## 품질

고정 12세트 83,081행에서 숫자·퍼센트 기호 다음에 글자가 붙는
595행을 모두 검색했다. 기준선 Smart가 기호 뒤에서 반환한 완결 범위는
GSD `test-s575`의 `6.3%가`와 `test-s832`의 `60%가`에 있는 세 범위다.
두 문장의 `가다` 두 범위와 `test-s832`의 명사 `가` 한 범위를 제거했다.
세 모드의 249,243개 반환 비교에서 이 세 범위만 바뀌었다.

직접 대조 7질의는 소수점과 전각 기호를 포함한 `가`, 보조사 `도`,
떨어져 쓰인 동사·명사 `가`, 기호 뒤 지정사 `였다`를 확인한다.
CLI의 NFC와 canonical 모드 NFD에서 14개 반환 범위가 모두 일치했다.
NFD `60%였다`는 양쪽이 같은 범위를 반환하면서 기존 구조 검증 미완료
진단과 종료 코드 2를 냈다.
고정 음성 계약 검토 1,357행과 제외 67행은 동일하다. 목표 11세트의
Smart FNc는 0이고 FPc는 2,056에서 2,053이다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
직접 대조에는 계약 검토가 없다.

GSD 처리량·p95 중앙값은 1차 −0.32%·+0.88%, 2차 −0.82%·+1.00%였고
두 차수 모두 측정 범위가 겹쳤다. 고정 음성은 1차 −1.61%·+2.51%,
2차 +0.82%·−1.99%로 변화 방향이 반대였고 2차에는 측정 범위가 겹쳤다.
러너 크기는 5,177,216에서 5,177,696바이트로 480바이트 증가했다.

## 재현

- 기준선 `86dc3913`의 검색 코드 `fd06bc4f`와 후보 `4f622cbf`를 Apple M1 Max arm64,
  macOS 26.6.2 (25G83), Rust/Cargo 1.97.0에서 `cargo build --release --locked
  --manifest-path tools/morph-compare/runner/Cargo.toml`로 빌드했다.
- GSD `gsd-saint-determiner.jsonl`과 고정 음성 `negatives.jsonl`을
  `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로 실행했다.
  실행마다 새 프로세스를 만들고 각 차수에서 예열 1회 후 측정 5회를 번갈아 수행했다.
- 고정 반환 비교는 `morph-benchmark-runner boundary full-pos MODE INPUT OUTPUT`을 사용했다.
  두 비태그 세트에는 `boundary` 대신 `untagged`를 사용했다.
