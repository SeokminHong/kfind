# 추측 종결형 ㄹ레라·을레라 검색

표준국어대사전의 `-ㄹ레라/-을레라` 예문 2건을 전수 점검했다.
주체 높임과 과거 뒤의 결합, 띄어 쓴 뒤 낱말, 명사 `올레`에
인용격 조사 `라`가 붙은 대조군을 확인했다.
[표준국어대사전 -ㄹ레라](https://stdict.korean.go.kr/search/searchView.do?word_no=98941&searchKeywordTo=3) ·
[표준국어대사전 -을레라](https://stdict.korean.go.kr/search/searchView.do?word_no=266471&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
표적의 신규 계약 보정은 0건이다. 전체 사전은
[앞선 보정](2026-11-14-dictionary-anhta-pos-review.md#품질)을 적용한다.

| --- | --- | --- | --- | --- |
| 표적 2건 | smart·any | 기준선 | 0, 0, 0, 2 / 0.00, 0.00, 0.00 | 0, 0, 0, 2 / 0.00, 0.00, 0.00 |
| 표적 2건 | smart·any | 후보 | 2, 0, 0, 0 / 100.00, 100.00, 100.00 | 2, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 사전 4,458건 | smart | 기준선 | 4301, 0, 0, 157 / 100.00, 96.48, 98.21 | 4330, 0, 0, 128 / 100.00, 97.13, 98.54 |
| 사전 4,458건 | smart | 후보 | 4303, 0, 0, 155 / 100.00, 96.52, 98.23 | 4332, 0, 0, 126 / 100.00, 97.17, 98.57 |
| 사전 4,458건 | any | 기준선 | 4168, 0, 0, 290 / 100.00, 93.49, 96.64 | 4198, 0, 0, 260 / 100.00, 94.17, 97.00 |

Smart는 `올레라 불리는 길`에서 명사를 찾고 동사 후보를 제외한다.
Any는 부분 문자열 계약에 따라 동사 후보도 반환한다.

GSD 9,298건, 음성 53,308건과 KAIST dev/test 2,532/2,592건의 범위가
같았다. Raw·계약 보정 혼동행렬과 비율은
[고정 입력 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `4afd9301`, 후보 `eb37baa4`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `9967f0fa`와
`cc2c9477`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다.
p95는 최근접 순위, RSS는 최대 상주 메모리다.
