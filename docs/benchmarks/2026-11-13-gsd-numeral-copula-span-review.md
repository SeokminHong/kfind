# GSD 수사 뒤 지정사의 정답 범위

GSD 양성 9,314건에서 수사 질의와 수사·지정사 품사 조합을 검색했습니다.
수사 질의 30건 가운데 지정사가 있는 5건을 모두 교정했습니다.
`하나이기도`와 `하나이다`는 수사에서 범위를 끝냈습니다. `일흔이라는`은
중복 주석된 `이/NNB`를 제거하고 수사에서 범위를 끝냈습니다.
`하나뿐임`과 `하나뿐이라는`의 `뿐`은 수사에 붙은 한정 보조사이므로
`하나뿐`까지 범위에 포함했습니다. 전체 자료에서 `뿐`이 들어간 나머지 두 주석도
대조했습니다. `실적뿐`은 보조사, `지불했을 뿐만`의 `뿐`은 의존명사입니다.
원문과 나머지 9,309건의 주석은 동일합니다.

수사 질의 대조군 25건 중 `일회용` 2건과 `일주일에` 1건은 두 경계 모두
불일치하며, 복합어 내부의 수사 검색과 정답 주석은 별도 판정이 필요합니다.
두 경계의 전체 반환 범위는 교정 전후 동일합니다. 같은 검색 실행 파일을 사용해
성능 측정을 생략했습니다.

```sh
node tools/morph-compare/apply-gsd-copula-span-review.mjs "$input" --numerals > "$corrected"
"$runner" boundary full-pos "$boundary" "$input" "$baseline"

```
