# 군복무의 명사 성분 범위

우리말샘의 전문 용어 `군^복무`는 띄어쓰기와 붙여쓰기를 모두
허용한다. 국립국어원 형태 분석 자료에서도 `군복무`를 허용 표기의
예로 든다. 기존 component에 일반 명사 `군(軍)`과 `복무(服務)`의
범위를 기록했다.
[우리말샘 군 복무](https://opendict.korean.go.kr/dictionary/view?sense_no=840051),
[국립국어원 형태 분석 자료](https://www.korean.go.kr/common/download.do%3Bfront%3DFC6FB396D396C95CC85B68ECDCB03CD3?c_file_name=35c6ff74-7598-438d-ab4c-a7d91a5908d9.pdf&file_path=etcData&o_file_name=2025%EB%85%84+%ED%95%9C%EA%B5%AD%EC%96%B4+%EA%B5%AC%EC%A1%B0+%EB%B6%84%EC%84%9D+%EB%B0%8F+%EB%AC%B4%ED%98%95+%EB%8C%80%EC%9A%A9%EC%96%B4+%EB%B3%B5%EC%9B%90+%EB%A7%90%EB%AD%89%EC%B9%98+%EA%B5%AC%EC%B6%95+%EC%97%B0%EA%B5%AC+%EA%B2%B0%EA%B3%BC%EB%B3%B4%EA%B3%A0%EC%84%9C.pdf)

표준국어대사전과 우리말샘에서 `군` 뒤에 성분 또는 단어 경계가
표시된 표제어 및 `육군` 237개를 고정 음성 53,308행과 두 GSD 입력의
명사 `군` 질의에 대조했다. 붙여 쓴 표제어가 나타난 행은 원문의
`군복무`와 `육군`, 등록 교정문의 `육군`, 고정 음성의 `군고구마`다.
`군 생활`과 `군 입대`는 띄어 쓴 표제어로 확인했다.

원문 GSD `gsd:test-s782:5`에서 `군` [40, 43)을 복원했다. 띄어 쓴
`군 복무`의 같은 범위는 기존에도 반환됐다. 목적격·보조사·지정사가
이어지는 예문, 두 표기가 함께 있는 문장의 [0, 3)과 [24, 27),
전체 명사 [0, 12)와 뒤 성분 `복무를` [3, 12)를 확인했다.
`군고구마`의 굳어진 `군`과 `구운 고구마`에서는 명사 `군`이 없다.
접두사 `군-`이 붙은 `불필요한 군일을 줄였다`에서는 두 리소스 모두
`군` [13, 16)을 반환한다. 별도 파생어 오류로 남는다.
[국립국어원 군고구마 형태](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=321212),
[표준국어대사전 군일](https://stdict.korean.go.kr/search/searchView.do?word_no=400185)

원문 GSD 9,335행 외에 고정·등록 평가 258,541개를 비교했다.
목적격 합성 명사의 원문과 교정 표기에 각각 같은 721개 질의를 실행했다.
붙여 쓴 `군복무`에 대한 `군` [40, 43) 한 범위만 달라졌다.
원문 양성 추가 반환은 582행 644범위가 미판정이다.

배포용 component를 장착했다. 러너 SHA-256은
`8dd489f960c1428bc6f4e6109e9d6f0c8454d9f834345508bc6b1e7756ed0f5a`,
후보 component는
`373cc47978828b7763b085dde771520607e2cb53e597a92822bb990f341a4a7e`다.
