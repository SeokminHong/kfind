# 건대 연결형 검색

사전과 어문 규범에 확인된 동사 8개의 `-건대` 결합을 정확 활용
경로에 등록했다. `생각건대`의 `하` 탈락과 `회상컨대`의 거센소리
결합을 같은 형태 규칙에서 생성한다. 기존 겸양형 `받자옵건대`,
명사 `건대`, 비표준 축약 `생각컨대`를 대조했다.
