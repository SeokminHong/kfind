# Any의 관형 대명사 축약

component 리소스가 있는 Any는 독립 어절 `울` 뒤에 명사 머리가 성립하면
`우리`의 축약으로 반환한다. Smart와 같은 검증을 사용한다. `울 아이`를
회수하고 `울 것 같다`와 `울타리`를 대조했다.

## 품질

고정 입력 12세트의 세 모드 249,243행을 검증했다. 변경된 두 범위는
교정 GSD의 `울 꼬맹이도`와 `울 아들`에 있는 `울`이다. 리소스가 없는
Any와 모든 Smart·Token 결과는 기준선과 같다. 고정 평가 11세트에서
Smart 계약 FN은 0건이다.

교정 GSD의 고유 문장 961개에 `우리`, `저`, `나`, `너`를 각각
별도 CLI 질의로 실행해 추가 반환 범위도 전수 비교했다. 최종 후보의
새 범위 두 개는 모두 위의 정답과 일치한다. 주제 조사 축약을 함께
적용한 실험은 `전`의 정답 두 개 외에 `전 정권`, `심사 전 과정`,
`전 세계적으로`, `전 정권의`, `전, 후기`에서 다섯 범위를 추가했다.
관형사와 대명사가 겹치는 문형은 기존 대조에 기록돼 있다.
[주제 조사 축약의 경합 문형](2026-11-14-pronoun-topic-shortening.md)

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
교정 GSD의 아래 질의에는 별도 계약 검토가 없다. 음성 53,308행에는
양쪽에 기존 계약 검토 171건을 적용했다. 양성 분모가 0인 raw recall은
`—`로 표기한다.

| Any 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 교정 GSD 9,298행 | 기준선 | 9095, 0, 0, 203 / 100.00, 97.82, 98.90 | 9095, 0, 0, 203 / 100.00, 97.82, 98.90 |
| 교정 GSD 9,298행 | 리소스 후보 | 9097, 0, 0, 201 / 100.00, 97.84, 98.91 | 9097, 0, 0, 201 / 100.00, 97.84, 98.91 |
| 고정 음성 53,308행 | 양쪽 | 0, 17622, 35686, 0 / 0.00, —, 0.00 | 171, 17451, 35686, 0 / 0.97, 100.00, 1.92 |

Workspace 테스트 643건, gold 925건과 walk/hang 스트레스, 포맷,
Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
기준선 `4b0980f1`과 후보 `d0714b86`을 비교했다. 기준선 실행 파일의
코드와 빌드 설정은 제품 머지 `46fc66cd`와 같다. 같은 리소스로 새
프로세스 워밍업 1회, 측정 5회를 실행 순서를 교대하며 수행했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.

GSD 처리량은 0.22% 감소했고 p95는 0.43% 감소했다. CLI에서
`우리`는 리소스 검증을 포함한 벽시계 중앙값이 16.467ms,
RSS 중앙값이 35.797MiB 증가했다. `저`의 벽시계 중앙값은
0.030ms 증가했다.
