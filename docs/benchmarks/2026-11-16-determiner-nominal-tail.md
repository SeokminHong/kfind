# 관형사와 명사·조사 연쇄

`전체회의를`은 `전체+회의+를`, `전쟁영화`는 `전쟁+영화`로
분석된다. 런타임 관형사 뒤의 명사와 조사는 각 품사가 정렬된 범위로
어절 끝까지 이어져야 한다. `전쟁영화를`에서 `화/NNG+를/JKO`
분석 전체를 단일 명사처럼 세면 `전+쟁영+화를` 분할이 살아남는다.
품사 범위를 확인한 뒤, 더 긴 명사로 시작하는 경로가 더 적은 명사
성분으로 어절을 완성할 때 내부 관형사를 제거한다.
[한국어기초사전 전쟁의 명사 용례](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=29551)

후속 명사·조사 경로의 비용은 어절 끝에서 한 번 계산한다. 관형사 뒤
경로와 경쟁하는 첫 명사 뒤 경로가 이 계산을 공유한다. `전과정을`은
관형사 `전`과 명사 `과정`의 경로가 유지된다. `두번째`에는 기존
차례 표현의 붙임쓰기 판정을 적용한다.
[국립국어원 차례 표현의 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=327795)
