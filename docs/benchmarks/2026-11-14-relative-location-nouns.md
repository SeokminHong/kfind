# 기준 체언 뒤의 위치 명사

국립국어원 교재의 장소 위치 표현 `앞·뒤·위·아래·밑·옆·안·속·밖`
아홉 개를 검사했다. 앞의 기준 체언과 뒤의 독립 체언을 확인한다.
뒤 어절에 용언 분석이 경합하면 목적격 조사 결합을 확인한다.
[국립국어원 교사용 지도서](https://korean.go.kr/common/downloadPreview.do?c_file_name=24f3c676-5593-4567-9f72-63a152ee00d5_0.pdf&file_path=reportData)

교정 GSD에서 아홉 표제어의 질의 54행을 확인했다. `화보 속`의
정확 범위 1행을 회복했고 #421 비교군 1,111행도 모두 정확하다.
음성 53,308행의 반환 범위는 같았다. `책 속 이야기를`의 명사
누락과 `화보 속`의 관형사 오탐도 해소했다. 별도 대조에서
`친구는 안 먹었다`의 명사 오탐과 `verify-gold`의 기존 불일치
8건이 남았다.

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 동일한
release 설정과 사전을 사용했다. 작업 시작점 70a5d2d4, 기준선,
후보를 워밍업 1회 뒤 새 프로세스로 5회씩 교대 실행했다.
p95는 nearest-rank이며 RSS는 최대 상주 메모리다. 표는 중앙값
[최솟값, 최댓값]이다.
