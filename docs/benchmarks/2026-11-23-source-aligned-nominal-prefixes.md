# 공통 component의 명사 접두사 분절

표준국어대사전에서 붙임표와 첫 성분의 원어가 접사 표제어와 일치하고,
붙여 쓴 동형 명사의 첫 성분 경계도 같은 표제어 5,641개를 추출했다.
접두사 표면은 83개다. 공통 component의 정렬된 `XPN`은 후보 명사의 범위와
같아야 하며, 뒤에 붙은 조사는 체언의 끝소리와 허용 전이를 확인한다.
`중무장포`는 별도 사료에서 쓰임을 확인하고 `중-·무장·포`를 정렬했다.
`재무장관으로서` 안의 `재무장(再武裝)` 뒤에 남는 `관으로서`는 이 체언에
붙는 조사 연쇄로 판정하지 않는다.
[표준국어대사전 중무장](https://stdict.korean.go.kr/search/searchView.do?word_no=310049) ·
[국사편찬위원회 FRUS 사료](https://db.history.go.kr/contemp/level.do?itemId=frus&levelId=frus_006r_0010_0530)

고정 12세트의 Smart·Token·Any와 교정 GSD Smart에서 258,541개 반환 목록을
비교했다. 새 component를 장착했을 때 고정 음성 22행의 23개 범위가
사라졌다. `중무장포`의 `중` [21, 24)은 빠졌고 같은 문장의 의존 명사
`중` [34, 37)은 검출됐다. 원본 GSD 9,335행과 교정 GSD 9,298행의 전체
반환 목록은 일치했다. 후보에 기존 component를 장착한 비교에서도 전체
반환 목록이 기준선과 같았다.

| 고정 음성 Smart 53,308행 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 기준선 | 0, 3,155, 50,153, 0 / 0, 0, 0 | 1,413, 1,631, 50,123, 0 / 46.42, 100, 63.41 | 1,633 | 0 |
| 후보, 새 component | 0, 3,134, 50,174, 0 / 0, 0, 0 | 1,413, 1,610, 50,144, 0 / 46.74, 100, 63.71 | 1,611 | 0 |

계약 제외는 141행이다. 비교 양쪽에 같은 정답을 적용했다. 계약 양성 중
70행의 전체 정답 범위를 검증했고 1,343행은 전체 범위가 미확정이다.
원본과 교정 GSD의 행렬은 [정도 부사 보고서](2026-11-22-spaced-degree-adverb.md)와 같다.

## WASM과 리소스 크기

`76bfcccd`와 `95f3420a`를 `wasm-pack 0.15.0`에서
`wasm-pack build crates/kfind-wasm --target bundler --release --locked`로
빌드했다. Node 26.11.1에서 WASM을 gzip 레벨 9와 Brotli 기본 설정으로
압축했다. 단위는 바이트다.

| 빌드 | WASM | gzip | Brotli | component |
| --- | ---: | ---: | ---: | ---: |
| 기준선 | 2,825,356 | 953,492 | 703,385 | 37,235,765 |
| 후보 | 2,826,360 | 953,646 | 703,549 | 37,441,353 |

WASM gzip은 154바이트, component는 205,588바이트 늘었다. 기존 component
SHA-256은 `8928bce4a6d57ed85ef0d0243240c0735d84bf68db737ac6935dde2eb3757e30`,
새 component SHA-256은 `f9530d384a375ce5d9d9cce4cac5b48efbd928c0b0ed24011d20f7afee570dec`다.

대조 25개를 각각 NFC와 NFD로 실행했다. `new Kfind()`의 Any·Token 반환과
품사 지정 Smart의 component 필요 오류가 두 빌드에서 같았다. 기존 component를
장착한 `new Kfind(component)`와 `Kfind.withResources`도 각 빌드에서 같은 범위를
반환했다. 두 장착 API는 새 component에서 `중무장포`·`중무장`·`남동생`·`재무장`의
첫 성분 오탐 네 곳을 동일하게 제거했다. `대나무`와 단위 명사 `대`는 두 리소스에서
같은 범위를 반환했고, 사전 분절이 없는 `대실패`의 첫 음절 오탐은 남았다.

## 네이티브 형태 판정

`76bfcccd`와 `95f3420a` release runner를 Apple M1 Max 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다.
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
워밍업 1회와 새 프로세스 교대 측정 5회를 실행했다. 입력, full POS와 보강
용언 자료의 체크섬은 [정도 부사 보고서](2026-11-22-spaced-degree-adverb.md)와
같다. 각 runner는 위 표의 component를 읽었다. 값은 중앙값 [최솟값, 최댓값]이다.

| 입력 | 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS KiB |
| --- | --- | --- | --- | --- | --- |
| 고정 음성 | 기준선 | 62.768 [62.218, 64.065] | 18,347 [17,601, 18,753] | 0.1312 [0.1303, 0.1348] | 130,976 [130,816, 131,568] |
| 고정 음성 | 후보 | 64.967 [63.736, 65.670] | 18,659 [17,680, 19,027] | 0.1308 [0.1290, 0.1333] | 131,008 [130,880, 131,904] |
| 교정 GSD | 기준선 | 63.561 [62.937, 63.769] | 27,012 [26,583, 27,263] | 0.0795 [0.0789, 0.0835] | 83,696 [83,664, 84,208] |
| 교정 GSD | 후보 | 64.042 [63.322, 66.427] | 26,958 [26,149, 27,661] | 0.0800 [0.0774, 0.0838] | 84,352 [83,728, 84,432] |

고정 음성 처리량은 1.70% 높고 p95는 0.30% 낮았다. 교정 GSD 처리량은
0.20% 낮고 p95는 0.63% 높았다. 초기화 중앙값은 각각 2.199 ms,
0.481 ms 늘었다. 처리량과 p95의 측정 범위는 두 입력에서 겹쳤다.
