# 형태 문맥과 계약 표적 검증

기준선은 8780efc6, 후보는 b089ec30이다. Smart full POS에서 감사 질의와
복원한 KAIST 테스트 질의 행렬을 양쪽에 동일하게 입력했다.

## 품질

비교 부사의 앞 부사, 목적 연결형과 이동 동사 사이의 부사, 성씨 호칭 뒤의 병렬
인용, 추측어 뒤의 서술어, 소요 시간 표현을 바꿔도 같은 구조가 검증된다.
`주요 생산지`의 `주`를 제거하고 `캐나다의 주요, 밀 생산지`의 `주`는 유지했다.
PUD `w01044010`의 `네바다주의 주요 산업`에서 `주의` 9..15가 남고
`주요`의 첫 음절 16..19가 사라졌다. `학교 내 내 시설`의 대명사는
두 번째 `내`만 반환한다. `통상 시`, `황혼 시`는 독립 의존 명사로 검색되며
`통상시(通常視)`, `황혼시(黃昏視)` 내부에서 `시`를 반환하지 않는다.
[국립국어원 `시` 띄어쓰기](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6480&mn_id=46)

감사 입력 1,747행 중 18행의 반환 범위가 바뀌었다. 등록 판정 4행과
변형·대조 14행이 바뀌었다. KAIST 테스트 행렬 2,604행의 반환 범위는 모두 같았다.
KAIST 문장 제외는 테스트 57→52건, 개발 64→63건으로 줄었다.
복원한 문장에는 `바람이 세차`, `본관동은 … 화장실 등이 있다`, `상술 배워갔다`가 포함된다.
[국립국어원 `세차` 활용](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=317902)

행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.
KAIST 테스트의 계약 검토는 25행이고 제외는 4행이다.

| 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| KAIST 테스트 2,604행 | 양쪽 | 1297, 2, 1300, 5 / 99.85, 99.62, 99.73 | 1296, 0, 1304, 0 / 100, 100, 100 |

`사람들이 방으로 들어갔다`의 `듣다`는 검색 기준선에서 원본과 계약 모두 음성으로
채점한다. 대조문 `학생은 녹음된 강의를 첫 회부터 한 편씩 들어갔다`에서는 진행 보조
용언 `가다`와 `듣다`의 목적어가 성립한다. 현재 매처의 원문 반환은 남아 있다.

일정 보어 `늦다`, 종결형과 겹치는 `-다오`·`-ㅁ세`·겸양형, `-서야`,
`-랴/-렷다`, `-(이)라도`는 원문에서 경쟁 서술어가 취하는 논항이나 생략을
입증해야 한다. `한`의 부분 수량은 시간 구문에서 성립하는 동사 관형형을 함께 보존해야
한다. 외국어 제목의 `더`는 인용된 표제의 구성 성분을 식별할 근거가 필요하다.
[부분 수량 구문의 동사 대조](2026-11-16-partitive-grammar.md)

## 성능

Apple M1 Max arm64, macOS 26.6.2(Darwin 25.6.0), Rust/Cargo 1.97.0의
release 빌드로 측정했다. 입력별로 각 버전을 한 번 워밍업하고 새 프로세스에서
5회씩 순서를 교대했다. 처리량은 평가 시간 기준이며 p95는 최근접 순위다.
표는 중앙값 [최솟값, 최댓값]이다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 감사 질의 | 기준선 | 62.42 [62.30, 63.30] | 29,290 [28,992, 29,594] | 0.11017 [0.10775, 0.11296] | 66.73 [66.50, 66.83] |
| 감사 질의 | 후보 | 63.01 [62.02, 63.43] | 29,256 [28,648, 29,998] | 0.10879 [0.10750, 0.11454] | 66.56 [66.52, 66.66] |
| KAIST | 기준선 | 62.03 [61.38, 62.55] | 29,699 [28,942, 30,172] | 0.08475 [0.08346, 0.08742] | 67.09 [66.97, 67.27] |
| KAIST | 후보 | 61.64 [61.38, 61.92] | 28,864 [28,396, 30,302] | 0.08829 [0.08533, 0.08983] | 67.11 [66.84, 67.27] |

처리량 중앙값은 감사 입력 −0.12%, KAIST −2.81%다. p95는 각각 −1.25%,
+4.18%다. 두 입력의 처리량과 p95 관측 범위가 겹친다.

## 재현

```sh
CARGO_TARGET_DIR="$PWD/target" cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT
```

KAIST 입력은 후보의 `sentence-reviews.json`을 사용하여 `tools/morph-compare/Dockerfile`의
테스트용 `dataset.py`, `apply_fixture_contract.py`, `query_matrix.py` 순서로 생성한다.
감사 입력은 검토 TSV와 인라인의 원문을 SHA-256으로 대조하여 명시 품사 질의를
모은 뒤 변형·대조 55행을 추가한 감사 스냅샷이다.
