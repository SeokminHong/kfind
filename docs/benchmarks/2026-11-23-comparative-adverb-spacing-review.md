# 정도 부사 문장의 띄어쓰기

고정 음성에서 명사 `더`를 반환한 42행을 확인했다. GSD는
등록 교정문을 사용하고 PUD는 빠진 공백을 확인해 대조문을
만들었다. Smart full-pos `bee71aad`가 원문 42행에서 45범위를,
교정한 문장과 원문을 포함한 같은 42행에서 43범위를 반환했다.
26행의 문장이 달랐으며 교정 쪽에서는 40행에서 반환이 남았다.
대조 입력의 SHA-256은
`4497514785825ea431b65e12716bc5d82cfcece092e55f7c4102046378b4f256`다.

- PUD n01120010에서 연결형 `특별해서`와 독립 부사 `더욱더`를
  띄어 썼다. 공백이 빠진 원문 `특별해서더욱더 [51, 72)`에서
  명사 `더 [69, 72)`를 잘못 반환했다. 교정문은 명사 `더`를
  반환하지 않고 부사 `더욱더 [64, 73)`를 반환한다. 원문 계약
  제외를 공백이 빠진 범위에 한정했다.
- 같은 PUD 문장의 모든 고정 음성 질의 35개를 원문과 교정문에서
  대조했다. 의존 명사 `수 [30, 33)`는 양쪽에서 반환된다.
  다른 명사·대명사·용언 질의의 반환 범위도 확인했다.
  이 입력의 SHA-256은
  `da150aedb933a9966c022f7b78baa78ab09f1242b63f7c5440a5a1b3c2aa8272`다.
- GSD s95의 등록 교정문에서도 명사 `더` 반환이 사라졌다.
  원문의 `더 [19, 22)`는 이미 독립 어절이므로 원문 계약의
  오탐으로 유지했다. 두 문장의 표기는 `한 층 더 업그레이드
  된`과 `한층 더 업그레이드된`이다.
