# 부분 수량의 어림 접미사와 단위 검색

575041d7 이후 8dc62b03까지 첫 부모 이력 41개 중 `crates`를 바꾼 19개의
품사 판정과 인접 회귀, 고정 UD 채점 변경을 검토했다. #1040의 부분 수량 판정은
비율 접미사 `-꼴`을 처리했으나 기존 어림 접미사 `-쯤`과 `-가량`을 함께
확인하지 않았다.

독립 어절 `중 한`으로 고정 음성 342행의 문장 9개와 원본·교정 GSD
각 32행의 문장 2개를 확인했다. 두 어림 접미사가 단위에 붙은 문장은
이 입력에 없었다. 어림 접미사 두 가지와 서로 다른 단위, 조사 이형태를
독립 입력에서 검증했다.

`두 권 중 한 권쯤 빌리고 내용은 직접 설명하기로 했다`에서
동사 `하다`의 오반환 `한` [12, 15)를 제거하고 실제 동사 [66, 72)를
유지한다. `한 상자가량을`의 수 관형사 `한`도 동사로 반환하지 않는다.
`한 권쯤은`의 단위 명사 `권` [4, 7)을 반환하며, 잘못된 조사 이형태가
붙은 `한 권쯤는`에는 이 범위를 반환하지 않는다. 비율 표현과 실제
관형형 `서평을 한 권`의 범위는 유지된다.
[국립국어원 어림 접미사](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=325406) ·
[고정 회귀](../../data/fixtures/ud_morphology_cases.tsv)

## 고정 입력의 품질

고정 음성과 원본·등록 교정 GSD의 전체 반환 범위는 양쪽에서 일치했다.
표의 행렬은 TP, FP, TN, FN 순서이며 지표는 precision, recall, F1 순서다.

| 입력 | 원본 행렬 / 지표 (%) | 계약 행렬 / 지표 (%) | FPc | FNc | 계약 검토 / 제외 |
| --- | --- | --- | ---: | ---: | ---: |
| 고정 음성 53,308행 | 0, 3,081, 50,227, 0 / 0, 0, 0 | 1,426, 1,540, 50,194, 0 / 48.08, 100, 64.94 | 1,541 | 0 | 1,584 / 148 |
| 원본 GSD 9,335행 | 8,290, 0, 0, 1,045 / 100, 88.81, 94.07 | 8,695, 3, 16, 621 / 99.97, 93.33, 96.54 | 11 | 621 | 450 / 0 |
| 교정 GSD 9,298행 | 9,287, 0, 0, 11 / 100, 99.88, 99.94 | 9,287, 0, 11, 0 / 100, 100, 100 | 2 | 0 | 34 / 0 |

## 네이티브 형태 판정

1273b5f2와 554dcfe7을 Apple M1 Max 32 GiB, macOS 26.6.2
(25G83), Rust 1.97.0, Python 3.14.8에서 같은 release 설정으로
빌드했다. 양쪽에 동일한
[고정 입력 및 체크섬](../../tools/morph-compare/README.md#gsdpud-고정-감사-입력)과
[배포용 리소스](2026-11-23-native-nominal-prefix-examples.md#네이티브-형태-판정)를
사용했다. `boundary full-pos smart INPUT OUTPUT`을
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
워밍업 1회와 새 프로세스 5회 실행했다. 값은 중앙값 [최솟값, 최댓값]이다.

| 입력 | 실행 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS KiB |
| --- | --- | --- | --- | --- | --- |
| 고정 음성 | 기준선 | 64.719 [63.511, 68.357] | 17,858.9 [15,822.1, 18,281.3] | 0.1357 [0.1336, 0.1426] | 131,072 [122,704, 131,280] |
| 고정 음성 | 후보 | 64.905 [63.796, 136.765] | 17,984.6 [7,351.2, 18,404.6] | 0.1355 [0.1336, 0.1789] | 131,040 [111,136, 131,296] |
| 교정 GSD | 기준선 | 65.186 [64.443, 85.031] | 24,509.3 [21,608.4, 26,605.8] | 0.0852 [0.0811, 0.0908] | 84,000 [83,872, 84,512] |
| 교정 GSD | 후보 | 65.639 [64.959, 66.489] | 26,678.9 [24,884.9, 26,933.1] | 0.0810 [0.0800, 0.0852] | 83,840 [83,840, 84,016] |

고정 음성 처리량·p95 중앙값은 +0.70%와 −0.15%,
교정 GSD는 +8.85%와 −4.93%다. 두 입력의 측정 범위가 겹쳤고
고정 음성 후보 한 번의 처리량이 다른 실행보다 낮았다.
