# 용언 연결형 주변의 정도 부사

`잠깐 나오고 거의 생략되는데`의 `거의`는 다음 용언을 꾸민다.
Smart는 앞 어절이 절의 성분이거나 연결형이고, 뒤에 용언 연결형이나
기존 수량·관형형·보조 용언 조건이 있으면 관형격으로 해석한 명사
후보를 제외한다. 앞에 관형사·관형격·현대 관형형이 성립하면 명사
분석을 보존한다. MeCab-Ko 어미 자료에 `-고`의 ETM 표지가 있으므로
앞 연결형과 겹치는 관형형 분석은 현대 관형 어미의 ㄴ·ㄹ 받침을
확인한다.
[국립국어원 -고와 관형형](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=311587)

`네 거의`, `네가 고른 거의`의 관형격 범위와 한 문장의
`걸 [14, 17)`, 부사 `거의 [62, 68)`를 전체 반환 목록에서 검사했다.

12조합에 있었다. 네이티브 형태 테스트와 `verify-gold` 927행 및
walk/hang을 통과했다.

## 품질

행렬은 TP, FP, TN, FN 순서이며 뒤 세 값은 정밀도·재현율·F1(%)이다.
32문장 대조는 검토·제외 0행으로 원본과 계약 행렬이 같다. FNc와 FPc는
유효 범위를 찾은 행에서도 누락 또는 추가 반환을 각각 집계한다.

| 입력 | 원본 행렬 및 지표 | 계약 행렬 및 지표 | FPc / FNc |
| --- | --- | --- | ---: |
| 32문장 대조 기준선 | 34, 24, 6, 0 / 58.62, 100, 73.91 | 원본과 동일 | 25 / 0 |
| 32문장 대조 후보 | 34, 21, 9, 0 / 61.82, 100, 76.40 | 원본과 동일 | 21 / 0 |
| 고정 음성 양쪽 | 0, 3,026, 50,282, 0 / 0, 0, 0 | 1,430, 1,481, 50,248, 0 / 49.12, 100, 65.88 | 1,483 / 0 |
| 원문 GSD 양쪽 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,651, 9, 97, 538 / 99.90, 94.15, 96.94 | 20 / 538 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 6 / 0 |

고정 입력별 검토 / 제외는 순서대로 1,589 / 149, 622 / 40,
155 / 0행이다. 고정 입력 71,941행과 별도 과거 비교 258,541행의
전체 반환 범위가 일치했다. 고정 음성 계약 양성 1,176행 및 제외
39행 37범위, 원문 양성 511행 569범위, 교정 양성 86행 92범위는
미판정이다.
