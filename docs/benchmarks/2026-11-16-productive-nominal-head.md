# 합성 명사 끝의 값

Smart에서 `값`의 앞부분 전체가 독립 일반 명사로 확인되면 붙여 쓴
합성 명사의 끝 성분을 반환한다. 별도의 합성어 사전 항목이 없어도
`연료값을`, `기름값이`에서 조사까지 반환한다. `연룟값을`의 앞부분은
사이시옷을 걷어 사전과 대조하고, `연료값이었다`에서는 지정사 앞의
`값`까지 반환한다. [값의 결합](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=8209&mn_id=217&pageIndex=4) · [연료값과 연룟값](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=321595)

## 품질

고정 입력 12세트와 세 모드 249,243행에서 ID, 리소스 해시, 반환 범위를
비교했다. 달라진 범위는 PUD `w01113074:noun:값`의 Smart 반환 한 건이다.
원문에서 `값을` 93..99가 연료 가격을 뜻함을 확인했다. 고정 음성 원본은
보존하고 기존 검토 170건에 이 행을 추가해 양쪽 결과에 적용했다.
[원문과 대조 근거](../../tools/morph-compare/final-nominal-component-corpus-reviews.tsv)

고정 음성 53,308행의 행렬은 TP, FP, TN, FN 순서다. 비율(%)은
precision, recall, F1 순서다.

신규 범위 회귀 4건과 기존 구조 음성 `빙원옆에`를 포함해 gold 및
walk/hang, workspace 639건, Clippy, 포맷, benchmark Python 82건과
계약 대조 2건을 통과했다. `노무삿값`은 앞말 `노무사`의 일반 명사
항목을 리소스에서 확인할 수 없어 누락이 남았다.

## 성능

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
`4d128e4b`와 `8123e602`를 비교했다. 입력별로 양쪽 버전의 실행 순서를
교대하고 각각 새 프로세스 워밍업 1회와 측정 5회를 사용했다. 표는
중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위다.
