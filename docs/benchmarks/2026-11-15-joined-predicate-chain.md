# 붙여 쓴 용언 연쇄의 검색 범위

한 어절 안의 형용사 관형형은 왼쪽 용언의 완결 관형형·연결형과 오른쪽
명사구를 확인한다. 어절 전체가 명사와 조사로 분석되거나 후보가 사전
고유명사의 내부에 있으면 이 경로를 사용하지 않는다.

`-게 되다`, `-기 위하다` 앞의 용언은 완결 연결 어미를 기준으로 이어
분석한다. `-기는`과 `-긴`은 명사형·보조사 분석으로 뒤 독립 용언과 구분한다.

## 품질

PUD 양성 798건, GSD·PUD 음성 53,308건, 교정 GSD 9,298건, 사전
원본·보정본 각 4,458건, hard-negative 45건, KAIST dev 2,532건과
test 품사 지정·미지정 각 2,592건 및 1,000건 표본 세 종의 ID와
반환 범위를 Smart·Any·Token에서 비교했다.

PUD Smart에서 형용사 관형형 9건, 목적 구문 2건, 결과 구문 1건,
명사형 주제 뒤 형용사 1건이 정확히 반환됐다. 한 문장에 있는 두 `된`을
함께 찾으면서 이미 적중한 행에도 반환 범위가 하나 늘었다.
남은 정확 범위 불일치는 7건이다. `마주보고`의 `보다` 질의는 반환이 없고,
나머지 6건은 붙여 쓴 보조 용언을 포함한 반환 범위가 기존 정답과 겹친다.

GSD·PUD 음성표에서 새로 반환된 `pud:w01105053:adjective:크다`는 같은
문장·질의·품사의 양성 `pud:w01105053:20`과 반환 범위가 일치한다.
`pud:w01103022:verb:되다`에는 이미 반환이 있었고 같은 문장의 다른 `된`이
추가됐다. 기존 레이블과 채점 기준을 사용했다. 나머지 세트와 Any·Token의
전체 반환 범위는 동일했다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1 순서다.
PUD 양성은 정확한 바이트 범위로 채점했다. 계약 검토는 0건이다.
음성표는 반환 유무로 채점하고 기존 계약 양성 35건을 적용했다.

| 입력 (Smart) | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| PUD 양성 798건 | 기준선 | 778, 0, 0, 20 / 100.00, 97.49, 98.73 | 778, 0, 0, 20 / 100.00, 97.49, 98.73 |
| PUD 양성 798건 | 후보 | 791, 0, 0, 7 / 100.00, 99.12, 99.56 | 791, 0, 0, 7 / 100.00, 99.12, 99.56 |
| GSD·PUD 음성 53,308건 | 기준선 | 0, 4073, 49235, 0 / 0.00, 0.00, 0.00 | 35, 4038, 49235, 0 / 0.86, 100.00, 1.70 |
| GSD·PUD 음성 53,308건 | 후보 | 0, 4074, 49234, 0 / 0.00, 0.00, 0.00 | 35, 4039, 49234, 0 / 0.86, 100.00, 1.70 |

골드 925건, walk/hang, workspace 테스트 636건, Clippy와 포맷 검사를
통과했다. [품사 미지정 KAIST 결과](2026-11-15-automatic-predicate-and-quantity.md#품질)

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release의
Full POS Smart에서 `a1484602`와 `d7fe8653`을 비교했다. 기준선 실행
파일의 소스 `05870bb3`은 `a1484602`와 런타임과 리소스가 동일하다.
워밍업 1회 후 새 프로세스로 5회씩 실행하고 순서를 교대했다. 표는 중앙값
[최솟값, 최댓값]이며 p95는 최근접 순위, RSS는 최대 상주 메모리다.

각각 겹쳤다.
