# 붙여 쓴 보조 용언의 경합과 부정 구문의 반환 범위

Any는 본용언과 보조 용언 각각의 경계가 맞아야 붙여 쓴 어절 전체를
반환한다. 어절 전체를 덮는 보조 용언 분석은 같은 구성을 뒷받침한다.
별개의 통째 용언 분석이 성립하는 `따라간`은 기존의 짧은 범위를 유지한다.

`-지`에 붙은 조사 뒤에서는 부정 보조 용언의 활용을 어절 전체에서 검사한다.
어간 뒤의 연속 활용만 확인하던 검증에 일반 용언 컴파일러의 완성형을 사용해
`맵지도 않고`, `아무렇지도 않네요`, `같진 않네요`의 조사까지 반환한다.
`먹질 말이 안 된다`의 주격 명사구를 음성 대조군으로 확인했다.
[한국어기초사전의 보조 형용사 `않다`](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=71583&nation=eng)

## 품질

기준선과 후보를 같은 고정 입력 12세트에서 실행해 249,243개 검색 결과의
입력 ID·리소스 체크섬·전체 UTF-8 범위를 대조했다. 변경된 결과는 Any 11개와
Token 5개다. 기존에 적중하던 `먹을지언정 죽을 먹지는 않겠다`에서 추가된
`먹지는`도 검색한 동사의 활용이다. 고정 음성 53,308행과 hard negative 45행은
어느 모드에서도 범위가 바뀌지 않았다. 새 잘못된 반환 범위는 0건이며,
원본과 계약 검토를 같은 상태로 채점했다. Smart는 사전 원본 진단을 제외한
고정 평가 11세트에서 계약 FN이 0건이다.

PUD 원본은 `타버렸고`의 `타`만 정답으로 표시하고 기존 계약 검토는 어절 끝까지
요구한다. 후보가 어절을 완결하면서 raw FN은 1건 늘고 계약 FN은 1건 줄었다.
compact 리소스가 없는 Any에서도 비교한 83,081행 가운데 부정 구문 5행의 범위를
복구했다.

행렬은 TP, FP, TN, FN 순이고 비율(%)은 precision, recall, F1 순이다.
교정 GSD와 사전 원본 진단의 계약 검토는 0건, PUD는 6건,
고정 음성은 321건이다.

## 재현

기준선은 `0d2caeeb`, 후보는 `780bd593`이다. 기준선 러너는 실행 코드가
같은 `7c342492`에서 빌드했다. 두 버전 모두 Apple M1 Max arm64,
macOS 26.6.2, Rust/Cargo 1.97.0의 release 빌드다.
[교정 GSD와 고정 음성 입력](2026-11-16-any-noun-before-copula.md#재현)의
SHA-256은 각각 `1040ed9371fa5ca3a223dfacba83f07765c99b901b41a675701d851a8c130c21`,
`482e55d417516e8db503dbd421725fcc7affc6c6afcf5b5d42cec3bbd4d35d54`다.
같은 lexicon·enriched 파일을 사용했다. compact의 SHA-256은
`da0cb23a2f85941932a7c431d2a8446563a49c48e8215dac2dd7e1a790a0eb5c`다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml --target-dir "$runner_build"
KFIND_FULL_POS_LEXICON="$data/lexicon.bin" KFIND_COMPONENT_RESOURCE="$data/morphology-component-compact.kfc" KFIND_ENRICHED_PREDICATES="data/enriched/predicates.tsv" \
  /usr/bin/time -l "$runner_build/release/morph-benchmark-runner" boundary full-pos "$mode" "$input" "$output"
```
