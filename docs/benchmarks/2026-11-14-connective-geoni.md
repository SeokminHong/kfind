# 어미 거니·거니와의 검색 범위

표준국어대사전과 한국어기초사전의 두 어미 표제에 해당하는 예문 21건을 확인했다.
`먹었겠거니`에서는 과거·추측 선어말 어미 뒤의 `-거니`를, `정리하거니와`와
`학생이거니와`에서는 어간의 뒤에 붙은 `-거니와`를 포함한다.
주체 높임과 별도 어절도 대조했다.

## 성능

시작점 `70a5d2d4`, 기준선 `29766606`의 검색 코드 `e3ff5b8f`,
후보 `3be7221b`와 트리가 같은 `bb6efccb`를 비교했다.
Apple M1 Max arm64, macOS 26.6.2와 Rust/Cargo 1.97.0 release를
사용했다. full POS `smart`에서 워밍업 1회 후 새 프로세스로 5회 실행하고
순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다. p95는 최근접 순위,
RSS는 최대 상주 메모리다.
