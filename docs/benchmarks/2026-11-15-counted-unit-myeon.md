# 수량 단위 뒤의 지정사 조건형

`몸이 두 개면`의 `개면`은 수량 단위 명사 뒤에 지정사 어간이
생략된 조건형이다. Smart는 수량과 단위 명사의 결합을 확인해
해당 범위를 검색한다. 따로 등재된 `개면` 때문에 생략형을 제외하던
경로를 수정했다. 다른 단위와 붙여 쓴 숫자, 별도 동사 활용을 고정 회귀로 대조했다.
[한국어기초사전 -면](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=80259&nation=eng)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
사전의 `면` 예문 26건을 전수 대조했다. 추가 계약 보정은 0건이며,
전체 사전에는 [기존 보정](2026-11-15-copula-polite-honorific.md)을 적용했다.
