# 체언 접미사와 겹치는 용언 검색 범위

`건물주들은`은 명사 `건물주`, 복수 접미사 `-들`, 보조사 `은`으로
어절을 이룬다. 런타임 분해가 `들은`에 동사 `듣다`의 관형형을 추가한
경우, 기존 체언·문법 접미사·조사 경로를 판정에 사용한다. 어절 전체에
용언 분석이 있거나 해당 위치에 합성 용언의 구성 성분이 확인되면 후보를
유지한다. 컴포넌트 사전과 기존 접미사 목록은 그대로 썼다.
[국립국어원 복수 접미사와 보조사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=313594)

기준선은 `건물주들은`의 [9, 15)를 `듣다`로 반환했다. 새 회귀의
`상점주들은 안내를 들은 뒤 나갔다`에서는 같은 오탐 [9, 15)와
정상 관형형 [26, 32)를 모두 반환했다. 후보는 정상 관형형만 반환했다.
명사 `건물주`의 조사 포함 범위 [0, 15)와 `알아듣다`의 관형형
[27, 39)는 양쪽에서 일치했다. 같은 경로에 있는 `-씩`과 조사 및
대조 어미가 포함된 기존 회귀도 통과했다.
[정확한 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

`모래 주머니`를 `모래주머니`로 교정한 GSD 문장을 원문과 함께
기준선과 후보에 넣었다. 각 표기에서 기존 30개 질의를 실행했다.
두 표기에서 모두 기준선의 같은 오탐 [9, 15)만 빠졌다. 맞춤법 교정
판정은 `모래 주머니` 표적에만 적용한다.
[원문과 교정 내역](../../tools/morph-compare/gsd-proofreading-edits.tsv)

고정 음성, 원문 GSD 양성, 교정 GSD 양성에서 어절 중간의 `들/씩`과
조사로 이어지는 용언 반환 범위를 대조했다. 해당 형태의 반환은 고정
음성의 `건물주들은` 한 건이었다. 고정 12세트와 교정 GSD의
258,541개 반환 목록을 비교했으며 이 한 건만 달랐다. 별도로 원문 GSD
양성 9,335행의 반환 목록이 모두 일치했다.
