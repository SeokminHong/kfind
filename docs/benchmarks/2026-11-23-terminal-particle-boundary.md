# 종결 조사의 어절 경계

Smart는 조사 연결 규칙상 다음 조사가 허용되지 않는 위치에
어절의 문자가 남으면 부분 조사 연쇄를 제외한다. `우리나라의`에서
`우리나`를 반환하던 경로를 이 조건에 포함한다. 사전에 정렬된
`배나무`의 `배`와 `가시나무`의 `가시` 및 독립적인
`우리나 너희나`, `누구나`의 조사 결합은 유지한다.
[국립국어원 우리나라의 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=325853)
· [한국어기초사전 배나무](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=58766)

## 원문·교정문과 품질

`gsd-whole-noun-context-review.tsv`의 문맥과 사전 근거를 대조했다.
등록 원문에서 한국을 뜻하는 명사 `우리나라`를 대명사 `우리`로
태깅한 네 행을 재분류했다. 원래 입력과 채점 행은 보존했다.
원문과 교정문에서 동형 명사를 포함한 네 문장의 모든 등록
질의와 명시적 명사·대명사 질의를 같은 조건으로 비교했다.
122개 질의 중 두 입력에서 `우리`의 오반환 8개가 사라졌고
명사 `우리나라` 범위는 유지됐다.

역사 입력 258,541개 조합에서는 KAIST `종교도서`의 명사
`종교`가 [0, 9)의 `종교도`를 반환하던 중복 행 두 개가 바뀌었다.
붙여 쓴 원문에서는 `종교`의 반환이 사라지고 명사 `도서`
[6, 12)가 유지됐다.
`종교 도서`로 띄어 쓴 대조문에서 두 빌드의 명사 범위는
각각 `종교` [0, 6), `도서` [7, 13)였다. 대조 입력의
SHA-256은 `c39704aa936ac2333d361ff62bc604339c97efe2859dc03e3dfcfc0d25d848da`다.

행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.
각각 같은 정답 기준으로 기준선과 후보를 채점했다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 양쪽 | 0, 3,038, 50,270, 0 / 0, 0, 0 | 1,426, 1,498, 50,236, 0 / 48.77, 100, 65.56 | 1,499 | 0 |
| 원문 GSD 기준선 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,639, 10, 78, 605 / 99.88, 93.46, 96.56 | 17 | 605 |
| 원문 GSD 후보 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,639, 6, 82, 605 / 99.93, 93.46, 96.58 | 13 | 605 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

원문 FNc 609 → 605는 품사 검토의 효과다. 같은 검토를 양쪽에
적용했을 때 FPc 17 → 13은 제품 수정의 효과다. 남은 추가 반환
미판정은 원문 GSD 568행 630범위, 교정 GSD 104행 110범위다.
고정 음성 계약 양성 1,207행의 전체 정답과 제외 42행의 37범위도
검토가 남아 있다.

고정 회귀 12행의 NFC·NFD와 리소스 장착 Smart·Any, 기본 Token을
빌드당 72개 조합으로 확인했다. Smart의 오반환 8개가 사라졌고
유효 범위는 유지됐다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0과
Python 3.14.8에서 `9083957b`와 `18817a6e`를 비교했다.
새 프로세스로 빌드별 워밍업 1회 뒤 순서를 교대해 5회 측정했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 각 실행의 최근접 순위다.
[고정 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
· [리소스 체크섬](2026-11-23-state-auxiliary-pos.md#네이티브-성능)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name "terminal-particle-$workload" -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 9083957b "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 18817a6e "$lexicon" "$component" "$predicates"
```

집중 입력은 고정 음성, 원문 GSD, 교정 GSD에서 대명사 `우리`와
명사 `우리나라`, `배`, `가시`, `종교` 질의를 원래 순서로 뽑고
ID에 각각 `fixed:`, `raw:`, `corrected:`를 붙인 142행이다.

처리량·p95 변화는 고정 음성 +0.77%·−1.09%, 교정 GSD
