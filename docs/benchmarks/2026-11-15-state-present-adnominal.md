# 상태 형용사의 현재 관형형

어간 뒤에 `-는`을 붙이는 형용사도 현재 관형형으로 검색한다.
`끊임없는`, `난데없는`처럼 사전에 표제어는 있고 해당 활용이 보강 사전에
개별 등록되지 않은 경우도 포함한다. Smart는 붙임 어절 내부에서 시작하는
형용사 후보의 품사와 위치를 소스 분석과 대조한다.
[국립국어원 어휘 교육 자료의 «끊임없다» 활용](https://www.korean.go.kr/common/download.do?c_file_name=6e11f481-61a6-4b57-a6cd-4ece612af57c_0.pdf&file_path=reportData&o_file_name=%ED%95%9C%EA%B5%AD%EC%96%B4+%EC%96%B4%ED%9C%98+%EA%B5%90%EC%9C%A1%EB%82%B4%EC%9A%A9+%EA%B0%9C%EB%B0%9C%2820141201%29.pdf)

## 품질

형용사 질의 가운데 `있다/없다` 계열 또는 사전에 `-는` 활용이 등록된
표제어를 찾아, 본문에 어간과 `-는`이 이어지는 행을 확인했다.
KAIST dev 11건, test 7건, 사전 원본과 보정본 각 8건, 교정 GSD 28건,
GSD·PUD 음성 14건, hard-negative 0건이다. 전체 입력의 ID와 반환 범위도
세 경계 모드에서 비교했다.

Any와 Token에서 KAIST dev의 `끊임없는` 두 건이 정확하게 반환됐다.
KAIST test의 붙여 쓴 `국경없는`, `권위있는`은 세 모드 모두 원본 정답
범위를 반환했다. 기존 계약은 두 입력을 비표준 표기로 처리한다.
Smart의 구조 검증은 `인기있는`에서 형용사 `있다`가 반환되는 것을
막으며 독립 활용 `뜻이 있는`을 유지한다. 사전·GSD·고정 음성·
hard-negative의 모든 반환 범위가 기준선과 같았다.
골드 925건과 walk/hang, workspace 테스트 634건, Clippy를 통과했다.

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
KAIST 양성은 정답 범위와의 겹침으로 채점했다.
음성은 반환 범위의 유무로 채점했으며 ID·질의·품사·원문 해시가
일치하는 양성 검토 35건을 적용했다.
