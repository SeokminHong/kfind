# 청유형 세와 으세

한국어기초사전과 표준국어대사전에서 수집한 `-세/-으세` 14행을
검사했다. 모음·ㄹ·그 밖의 받침과 ㄷ 불규칙 활용을 대조했다.
붙인 보조 용언 `읽어보세`는 검색하고, 어절 내부의 지명 `몰리세`는
청유형으로 검색하지 않는다.
[한국어기초사전 `-세`](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=78404) ·
[`-으세`](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=78434)

행렬은 TP, FP, TN, FN 순서다. 표의 입력은 계약 검토 0건으로
raw와 보정 결과가 같다.

| 입력 | Raw 및 보정 행렬 | Raw 및 보정 P/R/F1 (%) |
| --- | --- | --- |
| 세 계열 smart · 기준선 | 7, 0, 0, 7 | 100.00, 50.00, 66.67 |
| 세 계열 any · 기준선 | 0, 0, 0, 14 | 0.00, 0.00, 0.00 |
| 세 계열 smart·any · 후보 | 14, 0, 0, 0 | 100.00, 100.00, 100.00 |
| 사전 smart · 기준선 | 3957, 0, 0, 501 | 100.00, 88.76, 94.05 |
| 사전 smart · 후보 | 3964, 0, 0, 494 | 100.00, 88.92, 94.13 |
| 사전 any · 기준선 | 3453, 0, 0, 1005 | 100.00, 77.46, 87.30 |
| 사전 any · 후보 | 3467, 0, 0, 991 | 100.00, 77.77, 87.50 |
| 교정 GSD smart · 양쪽 | 9298, 0, 0, 0 | 100.00, 100.00, 100.00 |

고정 음성의 raw 행렬과 P/R/F1은 양쪽 모두 0, 4092, 49216, 0과
0.00%, 0.00%, 0.00%다. 기존 계약 검토 3건을 적용하면
3, 4089, 49216, 0과 0.07%, 100.00%, 0.15%다. 교정 GSD와
고정 음성의 반환 범위는 동일하다. 신규 `verify-gold` 회귀가
통과했고 기존 불일치 8건이 재현됐다.

## 성능

시작점 `70a5d2d4`, 기준선 `77adec12`, 후보 `1405cd07`을
Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0 release에서
비교했다. 입력마다 워밍업 1회 후 새 프로세스로 5회씩 교대하고
실행 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다. p95는
nearest-rank이며 RSS는 최대 상주 메모리다.
