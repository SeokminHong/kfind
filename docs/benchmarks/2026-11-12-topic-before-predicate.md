## 품질

`돼지는 자랐다`, `돼지는 영리하다`, `가지는 맛있다`에서 `-는`의
관형형 분석에는 수식 대상이 없습니다. `가지는 맛있다`에서는 부정 연결형
`가지`도 성립하지 않습니다. 세 용언 질의는 원문 음성으로 채점합니다.
대조 11건에는 각 문장의 명사 질의 3건, 관형형 뒤에 `건`과 `게`가 오는 용언
질의 2건, `가지는` 뒤에 `않았다·못했다·마라`가 오는 용언 질의 3건을 포함했습니다.
대조와 GSD에서 양성은 표적 범위와 정확히 일치해야 하며, 음성은 표적과 겹치는
범위가 없어야 합니다. KAIST는 기존 겹침 기준을 사용했습니다.

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust와 Cargo 1.97.0에서 full-POS 릴리스
runner를 사용했습니다. 입력과 모드마다 각 revision을 새 프로세스에서 warm-up 1회
후 5회 측정하고 revision 실행 순서를 번갈아 바꿨습니다. 각 실행의 p95는
nearest-rank로 계산했습니다. 표는 중앙값 [최솟값, 최댓값]입니다.

GSD `smart` 처리량은 1.03% 감소했고 p95는 1.36% 증가했습니다. 대조
`smart` 처리량은 2.92% 증가했고 p95는 19.84% 감소했습니다. `any`의

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos "$boundary" "$input" "$output"
```

입력은 위 fixture의 질의, 품사, 문장, 기대값과 바이트 범위를 JSONL로 전달했습니다.
두 실행에 같은 `KFIND_FULL_POS_LEXICON`, `KFIND_COMPONENT_RESOURCE`,
`KFIND_ENRICHED_PREDICATES`를 사용했습니다.
