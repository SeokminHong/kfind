# 붙임 보조 용언의 명사형 뒤 조사

교정 GSD 9,306행에서 연결 어미 `아/어` 뒤에 한 형태소와
명사형 어미 `ㅁ/음/기` 및 후속 형태소가 이어지는 분석을 검색했다.
해당하는 `해주기도`와 `보여줌으로써` 두 행을 확인했다.
`보여줌으로써`의 UTF-8 범위 `90..108`을 복구했다. 보조 용언까지
명사형으로 이어지는 구조와 조사의 이형태를 검증하고, 사전 피·사동
관계만으로 생성된 경로에는 기존 완성형 요건을 유지했다.
새 회귀 5행은 통과했고 기존 `verify-gold` 불일치 8행은 재현됐다.

#421의 불일치 1,113행 중 정확 1,049행, 부분 23행, 누락 41행이다.

TN, FN 순서다. 비율은 precision, recall, F1이다. 계약 검토는
양성 0건, 음성 31건이다.
