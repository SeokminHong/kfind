# 감탄형 누먼의 검색 범위

동사 어간과 높임 `-(으)시-` 뒤의 `-누먼`을 소비한다.
표준국어대사전의 두 용례 `가누먼`, `트누먼`과 높임형,
별도 어절 대조군에서 반환 범위 전체를 검사했다.
[표준국어대사전 -누먼](https://stdict.korean.go.kr/search/contentViewOne.do?word_no=409393)

## 품질

고정 사전에는 `트누먼` 1건이 수록되어 있다. 이 어미의 계약 보정은
0건이다. 전체 사전은 [보정 입력](2026-11-15-honorific-directive-report.md#재현)을 사용했다.
행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.

| 누먼 1건 | Smart | 양쪽 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 |
| 누먼 1건 | Any | 기준선 | 0, 0, 0, 1 / 0.00, 0.00, 0.00 | 0, 0, 0, 1 / 0.00, 0.00, 0.00 |
| 누먼 1건 | Any | 후보 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 |

| 사전 4,458건 | Any | 기준선 | 4270, 0, 0, 188 / 100.00, 95.78, 97.85 | 4343, 0, 0, 115 / 100.00, 97.42, 98.69 |

GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
