# 진행·결과 상태 보조 동사 있다의 검색 품사

Smart에서 `-고 있다`와 `-아/어 있다`의 완결된 동사 문형을
확인했다. 앞 어절이 명사인 경우에는 목적격 조사 또는 경계를
가로지르는 동사 어간 분석이 있어야 보조 동사 판정을 선택한다.
`차고`와 책 이름 `잡고`의 독립 명사는 그대로 검색된다.
앞 관형형과 의존 명사가 이루는 `읽는 데 있어서`의 형용사
범위도 보존한다.
[한국어기초사전 보조 동사 있다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62595)
· [정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

## 네이티브 성능

Apple M1 Max, macOS 26.6.2 arm64, Rust 1.97.0과 Python 3.14.8에서
기준선 `00923a97`과 후보 `0857561a`를 대조했다. 같은 full POS,
component와 확장 용언을 사용했다. 집중 입력은 고정 음성·원문
GSD·교정 GSD의 `있다` 질의에 정확 범위 대조군 21건을 더한
1,083건이다.
집중 입력 SHA-256은
`e20dcd59c3cf0cbf949b0e790d2752b7232420436a12284dce93c72007f116c1`이다.
[고정 입력·리소스 체크섬](2026-11-23-possibility-predicate-pos.md#원문과-교정문)

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
scripts/benchmark-run.sh run --name state-auxiliary -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 00923a97 "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 0857561a "$lexicon" "$component" "$predicates"
```

입력마다 양쪽을 한 번 가동한 뒤 새 프로세스로 교대하며 5회
측정했다. 최근접 순위 p95와 나머지 지표의 중앙값 [최솟값,

## WASM

`wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release`로
기준선 `00923a97`과 후보 `0857561a`를 빌드했다.
원본은 2,854,385 → 2,857,780 B (+3,395), `gzip -9nc`는
970,767 → 972,620 B (+1,853), `brotli -q 11 -c`는
715,106 → 716,197 B (+1,091)였다. Node 26.11.1에서 기본 Token과
full POS·component를 장착한 Smart·Any의 NFC·NFD 입력을 각각
대조했다. 빌드당 138건 중 Smart의 추가 반환 20범위가 제거됐고
동사와 독립 명사·형용사 양성 및 Any·Token 결과는 유지됐다.
