# 고유어 접두사의 사전 용례와 명사 경계

표준국어대사전에서 고유어 접두사의 용례로 제시한 한 단어와 유일한
명사 표제어의 붙임표가 같은 경계를 나타내면 기존 component에
접두사 성분을 기록한다. `말벌`, `한겨울`, `날고기`에서 명사 질의가
접두사를 반환하던 오류를 확인했다. `군일`은 `군-`(40278)과
`군일`(400185)의 표기와 뜻을 대조해 같은 component의 성분으로
기록했다. 자동 추출 238개와 어휘 검토 1개를 확인했다.
[표준국어대사전 말벌](https://stdict.korean.go.kr/search/searchView.do?word_no=420141),
[국립국어원 한겨울 형태](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=320164),
[표준국어대사전 군일](https://stdict.korean.go.kr/search/searchView.do?word_no=400185)

접두사에 실린 용례의 표기가 같아도 동형 명사에서 두 형태가 나올 수
있다. `날-`의 용례는 날것이나 서투른 사람을 뜻하는 `날짜02`다.
달력의 `날짜01`은 명사 `날`과 접미사 `-짜`로 된 말이다. 출생증명서
문장의 `날` [42, 45)을 독립 근거로 정답에 기록했다. 동형 표제어를
구분하지 않은 추출에서 그 범위가 사라지는 것을 확인했다.
[표준국어대사전 날짜01](https://stdict.korean.go.kr/search/searchView.do?word_no=407607),
[날짜02](https://stdict.korean.go.kr/search/searchView.do?word_no=60044),
[국립국어원 날짜 형태](https://www.korean.go.kr/nkview/nklife/1987_4/11_24.html)

239개 어휘를 각각 맨어절, 보조사, 목적격, 부사격, 지정사 문맥에서
실행했다. 접두사와 동형인 명사 질의 1,195개 중 시작 위치의
오반환은 1,137개에서 0개로 줄었다. 전체 명사 질의 1,195개의 정확한
반환은 모두 유지됐다. `말은 말벌을 보고 뒤로 물러났다`에서
`말은` [0, 6)만 남았고, 수 관형사 `한`의 `한 겨울`, 명사 `한을`과
`군복무`의 `군`도 확인했다. 이 대조 입력의 SHA-256은
`4e00ac2ae1f8c93aad6cd151c6ecedce29f625bed9863897f7170a0e3afa5277`다.
[정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

고정·등록 평가 258,541개와 원문 GSD 9,335행에서 달라진 범위는
고정 음성의 `말벌`과 `한겨울` 두 건이다. 세 문장의 원문과 교정문에
같은 116개 질의를 각각 실행했다. `6시30분-10시` → `6시 30분~10시`,
`전진하던독일군` → `전진하던 독일군`, `기재하며그 후` →
`기재하며 그 후`를 적용했다. 명사 `말`은 원문 [76, 79)와 교정문
[77, 80)에서, 명사 `한`은 두 표기의 [57, 60)에서 제거됐다.
`날짜01`의 `날` [42, 45)은 양쪽 표기에서 유지됐다.
원문·교정 쌍 SHA-256은 `9a1fd370063f9b9af2f2fb61e81a0e3be6318ff52f3d4748597ccb2b09eb35c8`이다.

`날짜01`의 명사 범위를 채점에 반영하면 같은 기준선의 FPc는
1,544에서 1,543으로 바뀐다. 정답을 고정한 제품 비교에서
FPc는 1,543 → 1,541, FNc는 0이다. 고정 음성의 양성 범위
1,207행, 제외 문장 42행의 반환 38범위는 미검증이다. 원문과 등록

## 네이티브 형태 판정

기준선 `8dc62b03`과 후보 `74fcfdd2`의 component를 같은 release
러너에 교대 장착했다. 러너 SHA-256은
`8dd489f960c1428bc6f4e6109e9d6f0c8454d9f834345508bc6b1e7756ed0f5a`,
후보 component는
`83915ef08f6718146e5210027e0ff42a4dccaf11fbb3e1d4c6d0461064b076f6`이다.
크기는 37,441,441 → 37,450,453바이트, `gzip -9nc`는
11,692,022 → 11,693,399바이트였다.
[입력·기준선 사전 체크섬](2026-11-23-military-service-nominal-component.md#네이티브-형태-판정)

Apple M1 Max 32 GiB, macOS 26.6.2 arm64, Rust·Cargo 1.97.0,
Python 3.14.8에서 각 조건을 한 번 가동한 뒤 순서를 교대하며 새
프로세스로 5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는
실행별 최근접 순위다.
