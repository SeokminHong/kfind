# 체언 뒤 지정사의 어미 완결성

`나이`와 `아이`의 마지막 `이`에는 사전에서 어간과 어미를
한 음절에 정렬하지 못한 지정사 분석이 겹친다. 후보는 이런 복합
분석을 어간·어미 연쇄에 쓰지 않는다. 선어말 품사를 지난 상태도
뒤에 별도의 어미가 와야 완결된다. `나이다`, `누구입니까`,
`나이었다`, `나이었지만`, `의사이셨습니다`, `결과이긴`의 체언
반환을 확인했다. CLI의 canonical 정규화에서 NFD `나이`의
대명사 오탐이 사라지고 분해형 `나이다`와 `의사이셨습니다`의
체언은 유지됐다.

## 품질

기준선 `88e5703e`의 Smart 잔여 1,780행 중, 어절 시작 체언
반환 뒤 꼬리가 `이·입·이시·이었` 하나로 끝나는 6행 7범위를
찾았다. 세 모드로 실행한 고정 12세트의 반환 목록 249,243개를
비교했다. Smart의 해당 7범위와 `길이보다` 안의 `길` 한 범위가
사라졌다.

| 입력 | 제거한 범위 수 | 표적 |
| --- | --- | --- |
| GSD `test-s270` | 2 | `나이`의 명사·대명사 `나` 7..10 |
| GSD `test-s381` | 2 | `아이` 두 곳의 명사 `아` 110..113, 121..124 |
| GSD `test-s479` | 1 | `아이`의 명사 `아` 0..3 |
| PUD `n01070017` | 2 | `나이`의 명사·대명사 `나` 10..13 |
| PUD `n04002020` | 1 | `길이보다`의 명사 `길` 70..76 |

PUD 원문 주석에서 `길이보다`는 `길이-보다`, `길이가`는
`길이-가`다. `길이` 질의는 두 곳에서 조사까지 반환한다.
`길` 질의의 `길이가` 범위 30..36은 다른 어미 후보로 여전히
반환되므로 이 행의 계약 오탐은 남는다. 잘린 `누구입`, `나이었`,
`나이었도`도 실제 사전으로 실행하면 체언 반환이 남는다.

목표 11세트 Smart FNc는 0, FPc는 1,780→1,774다. 계약 보정은
양쪽에 동일하게 적용했고 고정 음성의 계약 제외는 109행이다.
다른 평가 세트의 반환은 일치했다. 행렬은 TP, FP, TN, FN 순서이고
비율은 precision, recall, F1 순서다. 원본의 recall은 고정 음성에
양성 분모가 없어 정의되지 않는다.

| 고정 음성 모드 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| Smart | 기준선 | 0, 3262, 50046, 0 / 0, —, 0 | 1404, 1774, 50021, 0 / 44.18, 100, 61.28 |
| Smart | 후보 | 0, 3256, 50052, 0 / 0, —, 0 | 1404, 1768, 50027, 0 / 44.26, 100, 61.36 |
| Any | 양쪽 | 0, 17616, 35692, 0 / 0, —, 0 | 1404, 16103, 35692, 0 / 8.02, 100, 14.85 |
| Token | 양쪽 | 0, 2850, 50458, 0 / 0, —, 0 | 1188, 1661, 50134, 216 / 41.70, 84.62, 55.87 |

Workspace 테스트, Clippy, gold 925건과 walk/hang stress가
통과했다.

## 성능

기준선 `88e5703e`와 후보 코드 `be1f5517`을 같은 release 설정으로
빌드했다. Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust·Cargo
1.97.0, Node.js 26.11.1에서 `/usr/bin/time -l RUNNER boundary
full-pos smart INPUT OUTPUT`을 사용했다. 입력과 버전별로 새
프로세스에서 워밍업 1회 뒤 교대로 각 5회 측정했다. 중앙값
[최솟값, 최댓값]을 기록하고 p95는 최근접 순위로 계산했다.
[빌드 명령과 입력 체크섬](2026-11-17-gun-initial-component.md#재현)
