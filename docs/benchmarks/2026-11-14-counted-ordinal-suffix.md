# 단위 명사와 차례 접미사

`네 번째`, `첫 번째`, `네 해째`에서 단위 명사와 차례 접미사가
이어지는 범위를 반환합니다. 원본 GSD·PUD에서 `째`가 포함된 문장
14개를 모두 점검했습니다. 띄어 쓴 수량 구성 10곳과 숫자에 붙인
`3일째에`, `5년째`의 범위를 회복했습니다. `첫째`와 붙여 쓴
`두번째로`의 범위는 그대로입니다. [국립국어원 형태 분석 지침](https://www.korean.go.kr/common/download.do?c_file_name=313036ed-dca8-473e-9ab9-e0bd7bf07565_0.pdf&file_path=reportData)

GSD 9,314행에서 정확 일치가 세 건 늘었습니다. PUD 양성 798행과 사전
양성 4,458행의 범위는 같습니다. GSD·PUD 음성 53,308행에서는
`3일째에` 한 행의 기존 반환이 `일`에서 `일째에`로 확장됐습니다.
해당 행의 원본 기대값을 보존하고 검색 계약상 실제 날짜 단위를 포함함을
기록했습니다. 기존 계약 검토 28건의 ID와 문장 해시를 대조했습니다.
[계약 검토](../../tools/morph-compare/counted-ordinal-corpus-reviews.tsv)

행렬은 TP, FP, TN, FN 순서이고 비율은 precision, recall, F1입니다.
GSD의 계약 검토는 0건입니다. 음성의 계약 검토 29건을 양쪽에 적용했습니다.

## 성능

순환하고 새 프로세스에서 워밍업 1회와 측정 5회를 수행했습니다.

최근접 순위입니다. [입력과 리소스](2026-11-14-directional-genitive.md#성능)

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
