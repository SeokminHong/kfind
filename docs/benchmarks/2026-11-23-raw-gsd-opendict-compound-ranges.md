# 우리말샘에서 확인한 원문 GSD 합성 명사의 범위

표준국어대사전에 해당 전체 표제어가 없던 `NNG+NNG` 103행을
우리말샘 2026년 7월 snapshot과 대조했다. 39행의 전체 표제어를
찾았다. `경기부양`, `금융위기`, `원내대표` 등 20행에서 사전의
성분 경계와 원문의 명사 용법을 확인했다. `변호사시험`과
`대한변호사협회`, 독립 `유통`과 `유통업체`처럼 한 질의에
해당하는 범위가 둘인 경우 모두 기록했다.
[표제어 번호와 원문·대조 범위](../../tools/morph-compare/contract-contrast-evidence.jsonl)

`트위터` 내부의 `트위`, `아이웨어`의 `아이`, `슈퍼개미`의
`슈퍼` 세 범위를 명사 정답에서 제외했다. 첫째는 서비스 이름의
일부이고, 둘째의 원어는 눈을 뜻하는 `eye`다. 셋째는 투자자의
규모를 나타내는 `super`이고 소매점 명사 `슈퍼`의 원어는
`supermarket`이다. 실행 결과는 원문에서 세 범위를 모두 반환했다.
다른 80행은 첫 성분을 독립 명사로 확정할 근거가 부족하거나
띄어 써야 하는 구의 판정이 남아 기존 점수를 유지했다.
[우리말샘 트위터](https://opendict.korean.go.kr/dictionary/view?sense_no=979539)
· [아이웨어](https://opendict.korean.go.kr/dictionary/view?sense_no=773473)
· [슈퍼개미](https://opendict.korean.go.kr/dictionary/view?sense_no=616994)

`이때`로 교정한 두 대명사 질의에서 `이` [0, 3)이 사라졌다.
`따라 한`으로 띄우면 `따르다`의 반환은 `따라` [94, 100)로
바뀐다. 같은 범위를 동사 `따다`도 반환하는 오류가 교정문에서
드러났다. 종목을 모방하는 문맥에서 `따라`는 `따르다`의 활용이다.
교정한 위치와 독립적인 검색 오류를 함께 기록했다.
