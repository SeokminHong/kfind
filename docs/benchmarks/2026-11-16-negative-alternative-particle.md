# 부정 연결형 내부의 선택 조사 판정

`지나지 않아`에서 `지+나`가 소비한 뒤 같은 어절에 `-지`가 남는다.
용언 활용과 다음 부정 보조 용언이 확인되면 선택 조사를 붙여 추정한
부분 명사 분석을 제외한다. `일어나지 않았다`와 `일어나 영어로`의
`일어` 질의로 같은 판정과 실제 조사 결합을 확인했다.
[한국어기초사전 ‘지나다’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=82142) ·
[한국어기초사전 조사 ‘나’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=89218)

## 품질

GSD·PUD 원문에서 `나지` 뒤에 부정 보조 용언이 오는 7문장과,
고정 음성의 잔여 결과 중 질의보다 긴 명사 범위가 `나`로 끝나는
5행을 검토했다. 이 가운데 PUD `w03010100`의 `지나지 않아`에서
명사 `지`가 반환한 81..87이 제거됐다. `나지` 자체의 명사 질의
두 행과 별도 어절 `지나` 세 행에는 반환이 남는다. `코로나`의
고유명사 경로도 별도 검토 대상이다.

고정 12세트 83,081행의 세 모드에서 반환 249,243개를 비교했다.
다른 반환 범위는 같다. Smart 목표 11세트의 FNc는 0, FPc는
2,147에서 2,146으로 줄었다. 고정 음성의 계약 검토는 1,340행,
제외는 66행으로 같다. 회귀는 계약 검토 0행이다. 행렬은 TP, FP,
TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.

## 성능

기준선 `ba270575`와 후보 코드 `5130ba1c`를 동일한 장치에서
비교했다. 첫 비교와 재측정 각각 새 프로세스로 워밍업 1회 뒤
실행 순서를 바꾸며 5회 측정했다. 표는 중앙값 [최솟값, 최댓값]이다.

고정 음성의 첫 비교에서 처리량은 2.34% 감소했고 p95는
3.12% 증가했다. 재측정에서 처리량은 0.45% 증가했고 p95는
0.90% 감소했다. RSS 중앙값은 두 비교에서 0.39 MiB와
0.36 MiB 높았다. 러너 파일은 5,158,416바이트에서
5,158,560바이트로 늘었다.

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo
1.97.0 release에서 측정했다. 각 revision에서 다음 명령으로
러너를 만들고 같은 입력과 리소스로 실행했다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
