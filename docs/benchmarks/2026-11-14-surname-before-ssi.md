# 호칭 씨 앞의 성씨 검색

교정 GSD 9,300행의 문장 중 한글 한 음절 뒤에 `씨`가
오는 표기를 검색했다. 직접 결합 4곳(`이` 2곳, `신`과 `구`
각 1곳)과 인접 대조 `이 모 씨` 1곳을 확인했다.
`이` 2곳과 `신` 1곳의 정확한 범위를 회복했고, `구`와
`모`의 범위는 유지했다. 영문 익명 표기와 `오 시장`처럼
직함이 붙는 구조는 이번 판정 범위 밖이다.

`씨`는 호칭 의존 명사와 씨앗을 뜻하는 일반 명사로 모두 쓰인다.
`이 씨`의 성씨와 관형사 해석을 보존하고, `이 씨앗`은
호칭 구조로 판정하지 않는다.
[호칭 씨](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=58145) ·
[일반 명사 씨](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=65937) ·
[대조 입력](../../tools/morph-compare/surname-before-ssi-cases.jsonl)

기준선 cefd5a99와 후보 f819a6ca의 full POS `smart`를 비교했다.
PR 기준선 ec65cc2d와 후보 14c051ee는 각각 동일한 실행 코드와
검색 리소스를 사용한다.
양성은 정확 범위, 음성은 반환 여부로 평가했다. 음성의 반환 범위는
53,308행 모두 일치했다. 양성 계약 검토는 0건이고, 음성에는
기존 검토 1건을 적용했다. 행렬은 TP, FP, TN, FN 순서다.
[음성 계약 검토](../../tools/morph-compare/nominal-before-coordinate-corpus-reviews.tsv)

| 입력 | 버전 | Raw 행렬 | Raw P/R/F1 (%) | 계약 보정 행렬 | 보정 P/R/F1 (%) |
| --- | --- | --- | --- | --- | --- |
| 양성 | 기준선 | 9261, 0, 0, 39 | 100.00, 99.58, 99.79 | 9261, 0, 0, 39 | 100.00, 99.58, 99.79 |
| 양성 | 후보 | 9264, 0, 0, 36 | 100.00, 99.61, 99.81 | 9264, 0, 0, 36 | 100.00, 99.61, 99.81 |
| 음성 | 양쪽 | 0, 4090, 49218, 0 | 0.00, 0.00, 0.00 | 1, 4089, 49218, 0 | 0.02, 100.00, 0.05 |

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 동일한
release 빌드 설정과 리소스를 사용했다. 시작점 70a5d2d4, 기준선,
후보를 같은 입력으로 비교했다. 워밍업 1회 후 5회, 각 회차를
새 프로세스에서 실행했으며 버전 순서를 교대했다. p95는 nearest-rank,
RSS는 최대 상주 메모리다. 표는 중앙값 [최솟값, 최댓값]이다.

직전 기준선 대비 처리량 변화는 양성 −1.20%, 음성 −3.36%이고
p95는 양성 +0.77%, 음성 +3.70%다. 두 입력 모두 직전 기준선과
후보의 처리량 측정 범위가 겹친다. 시작점 대비 처리량은 양성 +6.75%,
음성 +7.92%이고 p95는 양성 −11.32%, 음성 +15.06%다.
