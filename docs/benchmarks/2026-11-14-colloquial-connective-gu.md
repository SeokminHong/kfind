# 구어 연결 어미 구의 검색

용언 어간과 높임·시제 선어말 어미 뒤의 구어 연결 어미 `-구`를
검색한다. `smart`에서 같은 표면의 체언이 있으면 앞 문맥을 검사한다.
[국립국어원 용례](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=320203)

GSD의 어절 표면형이 `구`로 끝나는 25행(명사 23, 대명사 1, 형용사 1)을
확인했다. `좋구`의 정확 범위 1행을 회복했다. 같은 문장의 `좋아요`
질의도 두 활용을 함께 반환한다. GSD·PUD 음성 53,308행의 반환 범위는
모두 같다. 어간과 선어말 어미 조합, 같은 표면의 명사, 어절 내부를
11행의 회귀로 확인했다. 전체 정답 검증의 기존 불일치 8행은 동일하다.

기준선 c199d3eb와 후보 e0dbbe0e의 full POS `smart`를 비교했다.
양성은 정확 범위, 음성은 반환 여부를 채점했다. 행렬 순서는 TP, FP,
TN, FN이다. 양성 계약 검토는 0행이며 음성은 기존 검토 3행을 적용했다.

| 입력 | 버전 | Raw 행렬 | Raw P/R/F1 (%) | 계약 보정 행렬 | 보정 P/R/F1 (%) |
| --- | --- | --- | --- | --- | --- |
| 양성 | 기준선 | 9290, 0, 0, 10 | 100.00, 99.89, 99.95 | 9290, 0, 0, 10 | 100.00, 99.89, 99.95 |
| 양성 | 후보 | 9291, 0, 0, 9 | 100.00, 99.90, 99.95 | 9291, 0, 0, 9 | 100.00, 99.90, 99.95 |
| 음성 | 양쪽 | 0, 4092, 49216, 0 | 0.00, 0.00, 0.00 | 3, 4089, 49216, 0 | 0.07, 100.00, 0.15 |

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0에서 같은 release
설정, 입력과 사전 리소스를 사용했다. 시작점 70a5d2d4, 기준선, 후보를
워밍업 1회 뒤 새 프로세스로 5회씩 측정하고 실행 순서를 교대했다.
p95는 nearest-rank이며 RSS는 `/usr/bin/time -l`의 최대 상주 메모리다.
표는 중앙값 [최솟값, 최댓값]이다.

기준선 대비 양성·음성 처리량은 −0.47%, −0.16%이며 p95는 +0.83%,
−0.52%다. 초기화는 +0.76%, +0.80%, RSS는 +0.06%, +0.11%다.
시작점 대비 양성·음성 처리량은 +7.35%, +10.80%이고 p95는 −11.59%,
+11.29%다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```

입력과 사전 리소스의 체크섬은 [건으로 끝나는 부사 측정](2026-11-14-adverb-before-geon-conflict.md#성능)과 같다.
