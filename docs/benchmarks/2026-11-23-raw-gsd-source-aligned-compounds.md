# 원문 GSD 합성어 첫 명사의 정답 범위

원문과 교정 GSD에서 문장, 질의, 품사, 시작점이 같고 끝점이 다른
미검토 `NNG+NNG` 계열 224행을 대조했다. 질의 표면이 한 번만 나오며
MeCab-ko-dic 2.1.1의 합성어 분절도 첫 성분을 같은 명사로 분석한
일곱 행의 문맥과 UTF-8 정답 범위를 확인했다. `바늘잎`, `중학부`,
`종묘사직`, `선제골`, `생산직`, `제육볶음`, `고등어조림`이 해당한다.
다른 217행은 그 조건에서 독립 정답을 확정할 수 없었다.
[원문 품사열과 정답 범위](../../tools/morph-compare/raw-gsd-source-corpus-reviews.tsv) ·
[국립국어원 제육볶음](https://www.korean.go.kr/front/roman/romanView.do?mn_id=98&pageIndex=1&roman_seq=11683) ·
[국립국어원 고등어조림](https://www.korean.go.kr/front/roman/romanView.do?mn_id=98&pageIndex=1&roman_seq=11240)

`지적 장애`, `특수 교육 기관`, `특별 보너스`를 띄어 쓴 두 문장을
원문과 함께 같은 `81d66c28` 실행 파일로 대조했다. 음성 36질의와
양성 14질의를 양쪽에서 실행했다. `중학`의 원문 [77, 83)과 교정문
[80, 86), `생산`의 [0, 6)은 모두 반환됐다. 교정문에서 명사 `지`
질의가 `지적` 내부 [0, 3)을 추가로 반환했으며 이 범위는 미판정이다.
[원문과 교정문](../../tools/morph-compare/contract-contrast-evidence.jsonl)
