# GSD 명사 수식 표현의 띄어쓰기

복합 고유명사 검토에서 남은 15건을 문장별로 점검했습니다. `강남 지역`,
`경남 도지사`, `청국 공사`처럼 장소나 소속을 나타내는 명사와 수식을 받는
일반명사를 띄어 썼습니다. `중국 시장`의 병렬 표현 `국내 시장`도 같은 문장에서
교정했습니다. 10개 문장의 띄어쓰기 11곳을 수정하고, 관련 질의 11건의
정답 범위를 첫 명사로 교정했습니다. 동일 문장을 공유하는 122개 행에 같은 원문
교정과 UTF-8 바이트 위치를 적용했습니다.
[문장 교정 목록](../../tools/morph-compare/gsd-nominal-modifier-edits.tsv) ·
[국립국어원의 명사구 띄어쓰기 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=331097) ·
[경상남도 직함 용례](https://www.gyeongnam.go.kr/governor/index.gyeong?menuCd=DOM_000002807002000000) ·
[조선왕조실록 직함 용례](https://sillok.history.go.kr/id/kza_14202007_001)

경기 상대를 나타내는 `대만전`과 `일본전`, 대회·상 이름이 포함된
`유럽여자프로골프`와 `대구광역시교육감상`, 분야명 `현대미술`의 다섯 건은
별도 주석 판정 대상으로 남겼습니다. `경남도지사` 원문 대조에서는 `경남도`가
반환됐고 `경남 도지사`에서는 `경남`이 반환됐습니다.

기준선과 교정본에 같은 full POS 실행 파일 `8581bac664494819874fd78381ac0030879e71c5`를
사용했습니다. 행렬은 TP, FP, TN, FN 순이며 비율은 precision, recall, F1입니다.
계약 검토는 0건입니다.

| 경계 | 입력 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) |
| --- | --- | --- | --- | --- | --- |
| smart | 기준선 | 9072, 0, 0, 242 | 100.00, 97.40, 98.68 | 9072, 0, 0, 242 | 100.00, 97.40, 98.68 |
| smart | 교정 | 9082, 0, 0, 232 | 100.00, 97.51, 98.74 | 9082, 0, 0, 232 | 100.00, 97.51, 98.74 |
| any | 기준선 | 8913, 0, 0, 401 | 100.00, 95.69, 97.80 | 8913, 0, 0, 401 | 100.00, 95.69, 97.80 |
| any | 교정 | 8923, 0, 0, 391 | 100.00, 95.80, 97.86 | 8923, 0, 0, 391 | 100.00, 95.80, 97.86 |

두 경계에서 10건의 정확 일치를 회복했습니다. 기존에 정확 일치했던
`국내시장` 행은 `국내 시장`으로 교정한 뒤에도 정확 일치했습니다.
수정 문장 밖 9,192건의 반환 범위는 동일합니다. 제품 검색 코드가 동일해
성능 측정을 생략했습니다.

```sh
node tools/morph-compare/apply-gsd-sentence-edits.mjs "$input" --nominal-modifiers > "$corrected"
"$runner" boundary full-pos "$boundary" "$input" "$baseline"
"$runner" boundary full-pos "$boundary" "$corrected" "$output"
```
