# 보조 용언의 연결형과 활용 검증

한국어기초사전 XML의 보조 용언 항목 54개에서 결합 주석을 확인했다.
이 중 활용 전체가 가능한 `-어` 구성의 보조 동사 24개를 선행 품사와
함께 등록했다. 일부 선행 용언에 한정된 뜻풀이나 후행 형태가 고정된
구성은 별도 근거가 필요하다. `-고 싶다`와 `-지 않다`는 이 표의
`-아/-어` 연결 조건을 충족하지 않는다.

Smart의 파생 용언 뒤 연결형 판정은 사전의 결합 조건, 보조 동사의
완결 활용, 성분 리소스의 보조 용언·어미 분석을 함께 확인한다.
본용언 연결형과 같은 범위에서 체언이 끝나고 뒤가 조사로 분석되는
`지난해와`도 대조했다. `말해버리더라`는 어절 끝까지 반환하고,
지역명과 주제 조사가 결합한 `해주시는`은 제외했다.

## 품질

Smart·Any·Token에서 [고정 입력 12개](2026-11-15-joined-predicate-chain.md#품질)의
249,243행을 비교했다. 입력 ID, 리소스 체크섬과 모든 반환 바이트 범위가
같았으므로 각 세트의 원본·계약 지표도 기준선과 같다. 아래는 변경 경로와
직접 관련된 Smart 입력이다. 대조문은 목표 질의가 한 번이라도 반환되면
적중으로 셌다. 행렬은 TP, FP, TN, FN 순이고 비율은 precision, recall,
F1 순이다.

| 입력 | 버전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) | 계약 검토 |
| --- | --- | --- | --- | --- |
| 교정 GSD 9,298건 | 양쪽 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 9298, 0, 0, 0 / 100.00, 100.00, 100.00 | 0 |
| PUD 798건 | 양쪽 | 792, 0, 0, 6 / 100.00, 99.25, 99.62 | 798, 0, 0, 0 / 100.00, 100.00, 100.00 | 6 |
| GSD·PUD 음성 53,308건 | 양쪽 | 0, 4028, 49280, 0 / 0.00, 0.00, 0.00 | 156, 3872, 49280, 0 / 3.87, 100.00, 7.75 | 156 |
| 보조 용언 대조문 11건 | 기준선 | 8, 0, 2, 1 / 100.00, 88.89, 94.12 | 8, 0, 2, 1 / 100.00, 88.89, 94.12 | 0 |
| 보조 용언 대조문 11건 | 후보 | 9, 0, 2, 0 / 100.00, 100.00, 100.00 | 9, 0, 2, 0 / 100.00, 100.00, 100.00 | 0 |

대조문은 `해 주세요`의 붙임형, `신청해주시는`, `해주시는` 지역명,
`해가며 달이며`, `타버렸고`, `말해버리더라`, `읽어내기는`,
`밝혀냈다`, `먹어치웠다`, `좋아죽겠는데`, `읽어 내고`다.
양성의 반환 범위에는 같은 어절의 보조 용언까지 포함하고, 띄어 쓴
`읽어 내고`는 본용언 어절 끝까지 반환했다. 골드 925건과 walk/hang,
workspace 테스트, 포맷과 Clippy를 통과했다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`935f06e9`와 `dc69055d`를 비교했다. 각 입력·버전에서 별도 프로세스로
warm-up 1회와 측정 5회를 실행하고 순서를 교대했다. 표는 중앙값
[최솟값, 최댓값]이고 p95는 최근접 순위다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 62.149 [61.371, 63.374] | 28,505 [25,751, 29,352] | 0.07708 [0.07471, 0.08292] | 81.125 [80.969, 81.469] |
| 교정 GSD | 후보 | 61.550 [61.167, 63.739] | 28,774 [27,808, 29,205] | 0.07621 [0.07492, 0.07913] | 81.188 [80.828, 81.203] |
| GSD·PUD 음성 | 기준선 | 62.793 [61.950, 64.696] | 19,319 [16,800, 19,426] | 0.12908 [0.12842, 0.13571] | 127.578 [127.359, 128.328] |
| GSD·PUD 음성 | 후보 | 63.445 [62.649, 64.255] | 19,173 [18,699, 19,315] | 0.12988 [0.12888, 0.13075] | 127.594 [127.547, 128.594] |

교정 GSD의 처리량은 +0.94%, p95는 −1.14%였다. 고정 음성의 처리량은
−0.76%, p95는 +0.61%였다. 네 지표의 기준선·후보 측정 범위가 겹쳤다.

기준선·후보의 각 소스에서 같은 러너 잠금 파일로 다음 명령을 실행한다.
위 리소스 경로를 `KFIND_FULL_POS_LEXICON`, `KFIND_COMPONENT_RESOURCE`,
`KFIND_ENRICHED_PREDICATES`에 각각 지정한다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml --target-dir "$build"
/usr/bin/time -l "$build/release/morph-benchmark-runner" boundary full-pos smart "$input" "$output.json" 2>"$output.time"
```

품사 미지정 품질 입력은 `boundary` 대신 `untagged`를 사용한다.
