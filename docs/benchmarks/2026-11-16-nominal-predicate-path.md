# 명사와 조사 경계의 부분 용언 판정

`기네스` 내부의 `기네`는 형용사 질의에서 부정 지정사 품사로도
시도되므로 완성 명사와의 경합을 같은 조건으로 검증한다.
`미시마는`에서는 선택된 명사 `미시마`와 주제 조사 `는`의 경계를
유지한다. 관형형 파생 또는 수사열 분석이 겹쳐도 합성 용언을
선택하기 전에 해당 명사와 조사 경계를 적용한다.

## 품질

고정 12세트 83,081행의 세 모드에서 전체 반환 249,243개를
비교했다. 바뀐 Smart 21행의 원문과 표적을 확인했다. 고정 음성
16행의 오탐이 없어졌고, 기존 양성에서는 PUD 한 행과 KAIST 한
원문을 공유하는 네 평가 행의 추가 오탐만 없어졌다.

- `기네스`의 `기네`와 `검은색` 내부의 `검은`이 형용사로 반환되던 경로를 닫았다. `검은색`은 한 단어인 명사이며 compact의 두 내부 성분도 명사로 기록돼 있다. [한국어기초사전 ‘검은색’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=31663)
- `기대감은`, `사람들은`, `해운대는`, `미시마는`, `마그마는`, `타이가는`의 부분 활용과 `아니든`의 `든`을 제외했다.
- PUD `w01002013`의 실제 동사 `가게` 24..30은 남겼고 `타이가는` 내부의 80..86을 제외했다. KAIST `MH2_0190-s531`의 `늘어도` 40..49를 유지했고 `차리는` 내부 86..89를 제외했다.

회귀 11행에서 기존 오탐 6범위가 사라졌고 실제 `마는`, `아니네`,
`검은`, `들은`, `든`의 정답 범위를 확인했다. 기존 회귀의 `사달라`와
`사달라고`는 연결형 `사` 뒤에 오는 요청 보조 동사의 범위를 유지했다.
고정 음성 계약 검토
1,354행과 제외 67행을 유지했다. 목표 11세트의 Smart FNc는 0,
FPc는 2,098에서 2,082로 줄었다.

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.

## 성능

입력마다 새 프로세스에서 워밍업 1회 후 두 러너를 교대로 5회
실행했다. 표는 중앙값 [최솟값, 최댓값]이다. p95는 실행별 최근접
순위를, RSS는 `/usr/bin/time -l`의 최대 상주 메모리를 사용했다.

| Smart 입력 | 리비전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.797 [60.410, 61.355] | 30,295 [29,539, 30,522] | 0.07133 [0.07088, 0.07288] | 81.125 [81.031, 81.531] |
| 교정 GSD | 후보 | 60.769 [60.669, 62.493] | 30,162 [28,499, 30,375] | 0.07133 [0.07088, 0.07563] | 81.375 [81.172, 81.516] |
| 고정 음성 | 기준선 | 60.605 [60.126, 60.893] | 19,806 [19,706, 19,886] | 0.12608 [0.12521, 0.12729] | 127.594 [127.016, 127.688] |
| 고정 음성 | 후보 | 60.530 [60.374, 60.591] | 19,711 [19,202, 19,952] | 0.12633 [0.12408, 0.13075] | 127.609 [127.266, 127.656] |

교정 GSD 처리량·p95 중앙값은 −0.44%·0.00%, 고정 음성은
−0.48%·+0.20%다. 두 입력의 관측 범위가 각각 겹친다. 러너는
양쪽 모두 5,179,024바이트다.

## 재현

기준선은 `cdc6534e`, 후보 코드는 `e37286bf`다. Apple M1 Max
arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0 release에서
`/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로
측정했다. 고정 평가의 명시 품사는 `boundary full-pos MODE INPUT OUTPUT`,
자동 품사는 `untagged full-pos MODE INPUT OUTPUT`으로 실행했다.
