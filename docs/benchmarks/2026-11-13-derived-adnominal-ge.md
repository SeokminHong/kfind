# 파생 용언 관형형 뒤의 게

`7d9e5640`과 `ccfdfff9`의 full POS `smart`를 비교했습니다. `전환하는 게`에서는
사전의 명사 `전환`, 용언 파생 접미사 `하`, 관형 어미 `는`을 이어서 확인합니다.
`전환해 게 두 마리`의 갑각류 명사와 대조했습니다.
[회귀 입력](../../data/fixtures/ud_morphology_cases.tsv)

행렬 순서는 TP, FP, TN, FN이며 비율은 precision, recall, F1입니다.

| 입력 | 리비전 | Raw 행렬 | Raw 비율 (%) | 계약 보정 행렬 | 계약 보정 비율 (%) | 검토 |
| --- | --- | --- | --- | --- | --- | ---: |
| GSD 교정 양성 9,335건 | 기준선 | 8442, 0, 0, 893 | 100.00, 90.43, 94.98 | 8442, 0, 0, 893 | 100.00, 90.43, 94.98 | 0 |
| GSD 교정 양성 9,335건 | 후보 | 8443, 0, 0, 892 | 100.00, 90.44, 94.98 | 8443, 0, 0, 892 | 100.00, 90.44, 94.98 | 0 |
| GSD·PUD 음성 53,308건 | 양쪽 | 0, 4080, 49228, 0 | 0.00, 0.00, 0.00 | 26, 4054, 49228, 0 | 0.64, 100.00, 1.27 | 26 |

양성은 정확한 UTF-8 범위, 음성은 반환 여부로 채점했습니다. 양성 한 건을
회수했고 다른 양성·음성의 반환 범위는 같았습니다. 남은 불일치는 부분 일치
694건과 겹치는 반환이 없는 198건입니다. `verify-gold`의 기존 오탐 5건이 남았습니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Rust·Cargo 1.97.0에서
동일 release 설정과 사전으로 새 프로세스 워밍업 1회 후 5회 측정했습니다.
작업 시작점 `70a5d2d4`, 기준선, 후보의 실행 순서를 순환했습니다. 값은
중앙값 [최솟값, 최댓값]이며 p95는 nearest-rank, RSS는 최대 상주 메모리입니다.

직전 기준선 대비 처리량은 양성 0.07%, 음성 0.17% 늘고 p95는 각각
