# 목적·이유 연결형 느라·느라고의 검색 범위

사전의 `-느라/-느라고` 예문 10건을 점검했다. 일반 동사, 높임과
`살다 → 사느라고`의 ㄹ 탈락을 확인했다. `읽고 라디오를`에서는
별도 단어를 포함하지 않는다.
[표준국어대사전 -느라](https://stdict.korean.go.kr/search/searchView.do?word_no=410258&searchKeywordTo=3) ·
[-느라고](https://stdict.korean.go.kr/search/searchView.do?word_no=409975&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
사전 계약 검토 0건으로 raw와 보정이 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `a8fbe091`의 검색 코드 `340475bd`,
후보 `28ceba4c`와 제품 파일이 같은 `caaf3a7e`를 비교했다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
