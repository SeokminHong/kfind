# 예스러운 높임 연결형과 명사구

`조사 권한`의 `조사`는 명사구의 앞 성분이다. 어미를 직접 생성하는 경로는
이 구조를 확인했으나, 어간과 어미를 소스 품사 경로로 결합하는 경로는
같은 검사를 거치지 않았다. 두 경로에 명사구 검사를 적용했다.
`조사 및 탐험`이나 `검사 및 관리`처럼 접속 부사가 잇는 두 체언도 확인한다.
[연결형 -사와 -으사](2026-11-14-archaic-honorific-sa.md)

## 품질

고정 Smart GSD·PUD 음성 53,308건을 ID와 반환 바이트 범위로 비교했다.
기준선에서 동사·형용사 질의에 `사`로 끝나는 범위를 반환한 10행의
11개 범위를 확인했다. 명사구 오탐이 9행에서 사라졌으며,
일반 명사구 검사가 7행, 병렬 명사구 검사가 2행을 처리했다.
다른 범위 변경은 없었다. 닫는 따옴표 뒤에 조사가 붙은
`‘수 년간 조사’를`의 반환 1건이 남았다.

띄어쓰기 교정 KAIST dev 2,532건, 계약 검토 KAIST test 2,592건,
사전 보정본 4,458건, 교정 GSD 9,298건, hard-negative 45건은
반환 범위가 기준선과 같다. `도우사 또한 살 길을 열어 주셨다`와
기존 사전 용례의 연결형 활용을 유지했다. 골드 925건과 walk/hang,
workspace 테스트 634건, Clippy를 통과했다.
[다섯 고정 입력의 기준선 행렬](2026-11-15-smart-source-context-batch.md#품질)

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
음성의 계약 평가는 ID·질의·품사·원문 SHA-256이 일치하는 기존 양성
검토 35건을 적용했다.

| 입력 (Smart) | 버전 | Raw 행렬 / 비율 (%) | 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| GSD·PUD 음성 53,308건 | 기준선 | 0, 4088, 49220, 0 / 0.00, 0.00, 0.00 | 35, 4053, 49220, 0 / 0.86, 100.00, 1.70 |
| GSD·PUD 음성 53,308건 | 후보 | 0, 4079, 49229, 0 / 0.00, 0.00, 0.00 | 35, 4044, 49229, 0 / 0.86, 100.00, 1.70 |
| 높임 연결형 대조 16건 | 기준선 | 5, 3, 8, 0 / 62.50, 100.00, 76.92 | 5, 3, 8, 0 / 62.50, 100.00, 76.92 |
| 높임 연결형 대조 16건 | 후보 | 5, 0, 11, 0 / 100.00, 100.00, 100.00 | 5, 0, 11, 0 / 100.00, 100.00, 100.00 |

높임 연결형 대조는 `ud_morphology_cases.tsv`의
`regression.archaic-honorific-sa.` 16건이다. 계약 검토는 0건이다.

## 성능

기준선 `978ffd0a`와 후보 `c20390d9`를 Apple M1 Max arm64,
macOS 26.6.2, Rust/Cargo 1.97.0 release의 Full POS Smart로 비교했다.
워밍업 1회 뒤 새 프로세스로 5회씩 실행하고 측정 순서를 교대했다.
값은 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위, RSS는 최대 상주 메모리다.

| 입력 | 버전 | 초기화 ms | 처리량 cases/s | p95 ms | RSS MiB |
| --- | --- | --- | --- | --- | --- |
| KAIST test | 기준선 | 60.917 [60.495, 62.629] | 33415 [32013, 33842] | 0.07733 [0.07600, 0.07858] | 66.469 [66.328, 66.594] |
| KAIST test | 후보 | 61.301 [60.717, 62.706] | 33591 [32964, 33746] | 0.07642 [0.07600, 0.07813] | 66.391 [66.313, 66.516] |
| GSD | 기준선 | 61.067 [60.198, 64.218] | 31833 [30707, 31960] | 0.06837 [0.06817, 0.07038] | 80.766 [80.719, 80.984] |
| GSD | 후보 | 60.890 [60.747, 61.472] | 31335 [30943, 31715] | 0.06917 [0.06867, 0.07088] | 80.875 [80.750, 81.453] |
| 음성 | 기준선 | 60.985 [60.741, 61.784] | 20050 [17434, 20321] | 0.12558 [0.12304, 0.13167] | 127.453 [127.094, 127.625] |
| 음성 | 후보 | 61.863 [60.681, 62.889] | 20032 [19612, 20224] | 0.12475 [0.12333, 0.12858] | 127.344 [127.328, 127.531] |

test·GSD·음성 처리량은 각각 +0.53%, −1.57%, −0.09%이며
p95는 −1.19%, +1.16%, −0.66%다. RSS 중앙값은 각각 −0.12%, +0.14%,
−0.09%다. 세 지표 모두 기준선과 후보의 측정 범위가 겹친다.
