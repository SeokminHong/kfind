# 수량 명사구 앞의 요 분석

어절 끝 `요`에서 짧은 명사와 보조사 분석이 경합하면 뒤에
이어지는 명사구로 어절 전체의 분석을 확인한다. 단위 명사 앞의
아라비아 숫자도 같은 경로에서 확인한다. `8개`, `3 편을`,
`4개국이`처럼 단위와 조사가 있는 붙임·띄움 예문을 대조했다.
기존의 `가요`와 일반 명사구, 수량 단위, 지정사 활용,
보조사가 붙은 질문과 열거 구문의 반환을 확인했다.
[한글 맞춤법 제43항](https://www.korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0001)

고정 음성에서 질의한 명사 바로 뒤에 `요`가 붙어 어절을 완성하는
17행을 확인했다. 원문과 등록 교정 GSD에는 해당 명사 질의가 없었다.
고정 음성에서 오른쪽 어절이 숫자로 시작한 경우는 GSD s322의
`주요 20개국` 한 행이었다. `주` [0, 3)의 오반환만 제거했고
수식어 `주요` [0, 6)와 단위 명사 `개국` [9, 15)를 보존했다.
단위를 띄어 쓴 표기의 정답 범위는 각각 [0, 6), [10, 16)이다.

GSD s1의 붙여 쓴 원문 `주요20개국`과 등록 교정문의
`주요 20개국`을 같은 설정에서 비교했다. 교정문에서 `주`
[106, 109)의 오반환이 사라졌다. `주요` [106, 112)와
`개국` [115, 121)을 보존했다. 원문의 세 질의는 두 빌드에서
빈 결과였다. 원문·교정문과 줄바꿈 대조 15행의 SHA-256은
`d6797127618d19286c125d56ebba8eae45fd6a976115959a218bf70bfc8a7b2c`다.

## 품질

기존 입력 258,541개 검색의 전체 범위를 비교했을 때
고정 음성 Smart 1행만 달라졌다. 고정 회귀 8행은 WASM의
리소스 장착 Smart·Any와 기본 Token, NFC·NFD에서 빌드별
48건을 비교했다. Smart의 오반환 6개가 사라졌다.

행렬 순서는 TP, FP, TN, FN이며 정밀도·재현율·F1 단위는 %다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 기준선 | 0, 3,031, 50,277, 0 / 0, 0, 0 | 1,430, 1,487, 50,243, 0 / 49.02, 100, 65.79 | 1,489 | 0 |
| 고정 음성 후보 | 0, 3,030, 50,278, 0 / 0, 0, 0 | 1,430, 1,486, 50,244, 0 / 49.04, 100, 65.81 | 1,488 | 0 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 587 / 99.93, 93.65, 96.69 | 13 | 587 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

미판정 추가 반환은 원문 GSD 549행 609범위, 교정 GSD 104행
110범위다. 고정 음성 계약 양성 1,207행의 전체 정답과 제외
42행의 37범위도 검토가 남아 있다.

## 성능

Apple M1 Max 32 GB, macOS 26.6.2 arm64, Rust 1.97.0,
Python 3.14.8에서 기준선 `251e4956`과 후보 `aa97aa1d`의
release 빌드를 비교했다. 빌드별 워밍업 1회 뒤 새 프로세스에서
실행 순서를 교대해 5회 측정했다. 실행별 p95는 최근접 순위다.
[고정 입력 체크섬](2026-11-23-han-adnominal-chain.md#성능)
