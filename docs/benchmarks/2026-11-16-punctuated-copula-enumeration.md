# 열거형 지정사와 후속 술어 검색

쉼표와 뒤 지정사 술어로 열거를 확인한 `앨버타는 캐나다의 주요, 밀
생산지이기도 하다.`에서 Smart의 `adj:이다`는 `주요`(26..32)와
`이기도`(47..56)를 반환한다. 뒤 술어의 `-기`, 보조사와 보조 용언
`하다`를 확인하며 `하다`의 `다`(60..63)는 지정사에서 제외한다.
[국립국어원 보조 용언 ‘하다’의 문법 정보](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=324942)

## 품질

기준선 `d64f0c62`와 후보 `d66cca6c`의 고정 12세트 83,081행에서
Smart·Any·Token 반환 범위 249,243개를 대조했다. 모든 범위가 같았다.
고정 11세트에서 Smart FNc는 0건, FPc는 2,477건이다.
[변경 없는 전체 입력의 품질 기준](2026-11-16-bound-nominal-prefix.md#품질)

추가 대조에서는 같은 열거 뒤에 일반 지정사 술어를 쓰거나 첫 술어를
`소요`로 바꾼 두 범위를 더 회수했다. 쉼표가 없는 기존 `작가요`,
관형어 `주요`, 높임 보조사가 붙은 `해요`, 목적격 명사구 뒤
`해요`의 반환 범위를 확인했다.

행렬은 TP, FP, TN, FN 순서이고 비율(%)은 precision, recall, F1
순서다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 지정사 대조 7행 | Smart 기준선 | 1, 0, 3, 3 / 100.00, 25.00, 40.00 | 1, 0, 3, 3 / 100.00, 25.00, 40.00 |
| 지정사 대조 7행 | Smart 후보 | 4, 0, 3, 0 / 100.00, 100.00, 100.00 | 4, 0, 3, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 양쪽 | 0, 3676, 49632, 0 / 0.00, —, 0.00 | 1199, 2477, 49632, 0 / 32.62, 100.00, 49.19 |
| 고정 음성 53,308행 | Any 양쪽 | 0, 17616, 35692, 0 / 0.00, —, 0.00 | 1199, 16417, 35692, 0 / 6.81, 100.00, 12.75 |
| 고정 음성 53,308행 | Token 양쪽 | 0, 2847, 50461, 0 / 0.00, —, 0.00 | 1069, 1778, 50331, 130 / 37.55, 89.16, 52.84 |

추가 대조에는 계약 검토가 0건이다. 고정 음성에는 두 리비전에 기존
계약 검토 1,199건을 동일하게 적용했다.

## 성능

입력별로 새 프로세스에서 기준선과 후보를 워밍업 1회 후 5회 측정했다.
실행 순서는 교대했다. 각 셀은 중앙값 [최솟값, 최댓값]이며 p95에는
최근접 순위를 사용했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 61.285 [60.274, 62.319] | 30,670 [28,567, 31,029] | 0.07071 [0.07029, 0.07438] | 81.047 [80.922, 81.094] |
| 교정 GSD | 후보 | 60.628 [60.440, 61.133] | 30,772 [29,685, 30,841] | 0.07042 [0.07021, 0.07271] | 81.141 [81.063, 81.359] |
| 고정 음성 | 기준선 | 61.374 [60.583, 63.148] | 19,503 [18,991, 19,755] | 0.12900 [0.12638, 0.13129] | 127.547 [127.281, 127.766] |
| 고정 음성 | 후보 | 61.603 [61.237, 62.291] | 19,899 [19,717, 19,940] | 0.12529 [0.12508, 0.12763] | 127.313 [127.266, 127.656] |

교정 GSD의 처리량은 +0.33%, p95는 −0.41%, RSS 중앙값은
+0.094 MiB다. 고정 음성은 각각 +2.03%, −2.87%, −0.234 MiB다.
두 입력에서 처리량과 p95 관측 범위는 겹친다.

## 재현

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0,
Node.js 26.11.1을 사용했다. 기준선과 후보를 같은 리소스에서
`cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml`로
빌드했다. 각 실행은 `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`을
사용했다. 입력과 리소스 SHA-256은
[괄호 뒤 조사 범위 비교와 연결된 재현 절차](2026-11-16-enclosed-particle.md#재현)에
기록된 값과 같다.
