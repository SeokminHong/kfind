# 구어 어미 걸랑의 검색 범위

한국어기초사전의 `-걸랑` 예문 10건을 점검했다. 조건이나 말의 근거를
밝히는 어미를 어절 끝까지 반환한다. 높임과 과거, 지정사, 긴 형태
`-거들랑`도 확인했다. [한국어기초사전 -걸랑](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=66936)

## 품질

행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서다.
사전 계약 검토 0건으로 raw와 보정이 같다.

| 입력 | 경계 | 버전 | Raw·보정 행렬 | Raw·보정 비율 (%) |
| --- | --- | --- | --- | --- |
| 표적 10건 | smart | 기준선 | 9, 0, 0, 1 | 100.00, 90.00, 94.74 |
| 표적 10건 | any | 기준선 | 0, 0, 0, 10 | 0.00, 0.00, 0.00 |
| 표적 10건 | smart·any | 후보 | 10, 0, 0, 0 | 100.00, 100.00, 100.00 |
| 사전 4,458건 | smart | 기준선 | 4263, 0, 0, 195 | 100.00, 95.63, 97.76 |
| 사전 4,458건 | smart | 후보 | 4264, 0, 0, 194 | 100.00, 95.65, 97.78 |
| 사전 4,458건 | any | 기준선 | 3940, 0, 0, 518 | 100.00, 88.38, 93.83 |
| 사전 4,458건 | any | 후보 | 3950, 0, 0, 508 | 100.00, 88.60, 93.96 |

고정 GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
검색 범위가 모두 일치했다. Raw·계약 보정 지표는
[고정 입력 보고서](2026-11-14-gu-exclamative.md)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `cff8f9c3`의 검색 코드 `006d094c`,
후보 `d4840a7a`와 제품 파일이 같은 `226f4e29`를 비교했다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`를 사용했다. 워밍업 1회 후 새 프로세스로 5회씩 실행하고
버전 순서를 순환했다. 각 값은 중앙값 [최솟값, 최댓값]이다.
p95는 최근접 순위, RSS는 최대 상주 메모리다.
