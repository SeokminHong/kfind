# GSD·PUD의 한과 대 의존 명사 범위

UD 2.18 GSD·PUD test에서 표면형이 `한` 또는 `대`인 토큰을
각각 29곳, 53곳 확인했다. 토큰 주석과 앞뒤 원문을 함께 읽었다.
`가능한 한`에서는 앞 관형형이 뒤 명사의 조건·한도를 정한다.
`한 모금`과 `한 줄기`에서는 뒤 단위를 세는 수 관형사가 쓰였다.
PUD의 세 `대`는 순서, 연령대, 양쪽 점수의 대립을 나타낸다.
[국립국어원 가능한 한의 문법](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=329480)
· [한국어 어문 규범](https://www.korean.go.kr/kornorms/m/m_regltn.do)
· [국립국어원 십대의 허용 표기](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6569&mn_id=217)

| 고정 음성 원문 | 명사 질의 | 표적 바이트 |
| --- | --- | --- |
| GSD `test-s314` 가능한 한 빠른 시일 | 한 | 178..181 |
| PUD `n01034060` 제45대 대통령 | 대 | 25..28 |
| PUD `n01035004` 십대 여학생 | 대 | 99..102 |
| PUD `n01142007` 1 대 1 비긴 상황 | 대 | 15..18 |

GSD에는 품사가 관형사로 기록됐고 PUD에는 표제어가 비어 있어 고정 음성에
포함됐다. Smart는 네 행에서 위 양성 범위만 반환했다.

## 품질

고정 평가 11세트에서 FNc 0, FPc 1,708→1,704다. 고정 음성
53,308행의 원본 평가와 제품 범위는 동일하다.

| 등록부 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 제외 |
| --- | --- | --- | ---: |
| 기준선 | 0, 3,227, 50,081, 0 / 0, —, 0 | 1,428, 1,708, 50,054, 0 / 45.54, 100, 62.58 | 118 |
| 검토 후 | 0, 3,227, 50,081, 0 / 0, —, 0 | 1,432, 1,704, 50,054, 0 / 45.66, 100, 62.70 | 118 |

제품 코드와 사전 리소스는 동일하므로 기존 성능 기준선을 사용한다.
