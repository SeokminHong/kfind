# 관형격 명사구 뒤의 위치 명사와 관형사

`정신문화의 일대 전환`에서는 관형격 명사구와 성상 관형사 `일대`가
뒤의 명사를 수식한다. 위치 명사 목록 14개를 component 원본의
`MM.csv`와 대조했다. 전체 표면의 관형사 분석이 있는 `사이·속·일대`
중 국립국어원 자료에서 성상 관형사로 확인된 `일대(一大)`의
관형사 분석을 보존했다. `서울 일대`의 위치 명사와
`두 나무의 사이 통로`의 명사 구조를 대조했다.
[국립국어원 성상 관형사 목록](https://www.korean.go.kr/nkview/nklife/2005_1/2005_0113.pdf) ·
[한국어기초사전 사이](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=61187) ·
[한국어기초사전 속](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=71278)

## 품질

교정 KAIST dev에서 관형사 `일대` 1건이 정확한 범위 52..58로
바뀌었다. 기존 위치 대조 22건, 사전 원본·보정본 각 4,458건,
교정 GSD 9,298건, GSD·PUD 음성 53,308건과
계약 검토 KAIST test 2,592건의 반환 범위는 동일했다.
나머지 입력의 행렬은 [고정 입력 보고서](2026-11-15-fused-copula-question.md#품질)와 같다.
위치 대조에서 기존 FP 1건은 `안`의 비부사 질의다.
골드 925건과 walk/hang, workspace 테스트 634건과 Clippy를 통과했다.

행렬은 TP, FP, TN, FN 순서이며 비율(%)은 precision, recall, F1 순서다.
위치 대조는 검토 0건이다. KAIST 양성은 표적 겹침으로 채점했다.

| 입력 (Smart) | 버전 | Raw 행렬 / 비율 (%) | 보정 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 위치 대조 22건 | 양쪽 | 17, 1, 4, 0 / 94.44, 100.00, 97.14 | 17, 1, 4, 0 / 94.44, 100.00, 97.14 |
| 교정 KAIST dev 2,532건 | 기준선 | 1262, 1, 1266, 3 / 99.92, 99.76, 99.84 | 1263, 0, 1266, 3 / 100.00, 99.76, 99.88 |
| 교정 KAIST dev 2,532건 | 후보 | 1263, 1, 1266, 2 / 99.92, 99.84, 99.88 | 1264, 0, 1266, 2 / 100.00, 99.84, 99.92 |

## 성능

기준선 `f268d7ba`와 후보 `ec2e8f55`를 Apple M1 Max arm64,
macOS 26.6.2, Rust/Cargo 1.97.0 release의 Full POS Smart로 비교했다.
워밍업 1회 뒤 새 프로세스로 5회씩 실행 순서를 교대했다.
값은 중앙값 [최솟값, 최댓값]이며 p95는 최근접 순위, RSS는 최대 상주 메모리다.

| --- | --- | --- | --- | --- | --- |
| dev | 기준선 | 60.786 [60.721, 61.274] | 34854 [34073, 35018] | 0.07179 [0.07171, 0.07371] | 66.219 [66.156, 66.281] |
| dev | 후보 | 60.609 [60.519, 61.306] | 34465 [32889, 34960] | 0.07221 [0.07163, 0.07462] | 66.391 [66.250, 66.688] |
| GSD | 기준선 | 61.037 [60.614, 62.627] | 31686 [29379, 31787] | 0.06904 [0.06858, 0.07283] | 80.656 [80.594, 81.016] |
| GSD | 후보 | 61.146 [60.488, 61.699] | 31376 [30115, 31865] | 0.06979 [0.06842, 0.07179] | 80.844 [80.781, 81.031] |
| 음성 | 기준선 | 60.994 [60.706, 61.292] | 20027 [19985, 20195] | 0.12467 [0.12400, 0.12596] | 127.297 [126.969, 127.375] |
| 음성 | 후보 | 61.551 [61.130, 61.930] | 19973 [19820, 20227] | 0.12521 [0.12346, 0.12754] | 127.438 [127.063, 127.547] |

dev·GSD·음성 처리량은 각각 −1.11%, −0.98%, −0.27%이고
p95는 +0.58%, +1.08%, +0.43%다. 처리량과 지연의 측정 범위는 겹친다.
