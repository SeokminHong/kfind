# PUD에서 다른 위치에 있는 동사 범위

고정 음성의 `하다` 오반환을 원문에서 확인했다. `해`, `하여`,
`했`, `하`로 시작하는 실측 범위를 가진 PUD 8행을 대조했다.
`하지만`, `하나`, `하긴`만 반환한 행은 해당 문형 검토와 구분했다.
그중 두 행에는 같은 질의가 검색할 수 있는 동사 범위가 있었다.
[PUD n01022002 원문](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L1148)
· [PUD n01072021 원문](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L4088)

- n01022002의 `한참`은 부사다. 붙여 쓸 수 있는 `말해준다`에서는
  기존 붙임 보조 용언 계약에 따라 `하다`의 범위 [200, 209)를
  확인했다. PUD가 VX로 표기한 `주다`의 범위 [203, 209)는 누락으로
  남겼다. 같은 빌드의 `말해 준다` 대조문에서 `말하다`는
  [197, 203), `주다`는 [204, 210)를 반환했다.
  [한국어기초사전 말하다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62103)
  · [한국어기초사전 주다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=77245)
  · [국립국어원 말해 주다의 띄어쓰기](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=308213)
- n01072021의 `기쁘게 했을`에서 `하다`는 [190, 196)이다.
  붙여 쓴 `애도하는포스트들`의 [39, 45)와 `한 줄`의 [207, 210)은
  모두 오반환으로 남겼다. PUD의 띄어쓰기 교정문에서 `하다`는
  `했을` [191, 197)과 `한` [209, 212)를 반환했다. 수 관형사
  `한`의 오반환은 교정문에서도 재현된다.

원문과 대조문 28개 질의의 입력 SHA-256은
`4ad4c6c79ee5f7948bc52a3421da3b92690e367a49c7d7cbede1afa218325739`다.
같은 `c940ce63` 제품 출력으로 두 정답 기준을 비교했다.
고정 음성 출력 SHA-256은
`5bc3c2b9fe7ed2c5fbd446b63518f9d298bc7de9b9ab5a38d58f10b4c68666f9`다.
행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 기존 검토 | 0, 3,036, 50,272, 0 / 0, 0, 0 | 1,426, 1,496, 50,238, 0 / 48.80, 100, 65.59 | 1,497 | 0 |
| 고정 음성 추가 검토 | 0, 3,036, 50,272, 0 / 0, 0, 0 | 1,428, 1,494, 50,237, 1 / 48.87, 99.93, 65.64 | 1,496 | 1 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 592 / 99.93, 93.60, 96.66 | 13 | 592 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

같은 행에 정답이 있어도 나머지 오반환은 범위 기준으로 집계한다.
평가 근거만 바꿨으므로 제품 성능 측정을 생략했다.
