# 간접 의문절의 목적격 조사

UD 2.18 GSD·PUD test에서 ㄴ 받침 음절 뒤에 `가를`이 이어지는 두 위치를
확인했다. PUD의 `나뉘어졌는가를`과 `만들 수 있는가를`은 의문절에 목적격
조사가 붙었다. KAIST·KSL dev·test에서 같은 문자 조건으로 15곳을 확인했다.
`이루어지는가를`, `오르는가를`, `것인가를` 같은 활용 외에 `찬가를`,
`무언가를`, `뭔가를`도 있으므로 어간과 의문 어미가 완성되어야 한다.
`남겼던가를`은 회상형 `-던가`를 쓰며 이 검증의 대상인 ㄴ·은·는 계열과 구별했다.
[한국어 의문절의 목적격 결합](https://contents2.kocw.or.kr/KOCW/data/document/2020/seowon/choiyungon0805/2.pdf)

GSD·PUD의 `수(가·도·는·만) 있다` 표면을 붙여 쓴 형태까지 탐색했다.
정규식 후보는 GSD 54곳, PUD 102곳이며 형용사 `있다` 고정 음성 질의가
있는 다섯 문장에서 의존 명사 `수`와 형용사 `있다`가 결합했다. 다섯 행의
원문 바이트 범위를 기록했다. `있는가를`의 누락은 PUD `ToDoOrigText`의
표준 띄어쓰기에서도 재현했다. 수정 뒤 표준 문장 115..127과 고정 입력
114..126이 일치한다. 정렬이 확인된 계약 양성 35행의 범위 누락·추가는 모두 0건이다.
[표준국어대사전의 가능 구문 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=27&pageIndex=1&qna_seq=329797)

| 고정 음성 Smart | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 제외 |
| --- | --- | --- | ---: |
| 기준선 | 0, 3,217, 50,091, 0 / 0, 0, 0 | 1,436, 1,670, 50,061, 1 / 46.23, 99.93, 63.22 | 140 |
| 후보 | 0, 3,218, 50,090, 0 / 0, 0, 0 | 1,437, 1,670, 50,061, 0 / 46.25, 100, 63.25 | 140 |

고정 12세트 83,081행의 Smart·Token·Any 반환 목록 249,243개를 대조했다.
달라진 행은 `있는가를`이 나온 한 건이다. Smart·Token에서는 일치가 생겼고,
Any에서는 어미 뒤 목적격 조사까지 범위가 늘었다. 교정 GSD 9,298행의
Smart 반환 범위 체크섬은 같다.

## 네이티브 형태 판정

기준선 `f744bf180`과 후보 `3831c8d4`의 release runner를 Apple M1 Max,
32 GiB, macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
비교했다. 교정 GSD와 고정 음성의 입력 및 리소스 체크섬은
[동일 workload 비교](2026-11-22-whole-adverb-boundary.md#네이티브-형태-판정)와 같다.
측정군별 새 프로세스로 워밍업 1회 후 교대 측정 5회를 실행했다.
값은 중앙값 [최솟값, 최댓값]이다.

교정 GSD의 처리량·p95 중앙값은 +1.87%·−2.70%였고 실행별 범위가 겹쳤다.
고정 음성은 처리량 +7.46%, p95 −9.47%였으며, 독립 반복에서도 +7.46%·−9.19%였다.
초기화·최대 RSS 중앙값 차이는 0.57% 이내였다. 고정 음성의 차이는 이 두 실행에서
관측한 값이다.

CLI의 `canonical` 모드에서 NFC와 NFD의 전체 바이트 범위를 대조했다.
NFD `왔는가`는 목적격 조사 없이도 기준선과 후보 모두 구조 검증 미완료를 보고했다.
조사가 붙은 NFD 입력에서 후보는 정확한 범위를 반환하며 같은 진단이 남는다.
