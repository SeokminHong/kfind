# 보조 동사의 완결 활용 검증

`달라 보였다`의 `보이다`, 동사 뒤의 `-아/-어 내다`, 형용사 뒤의
`-어하다`를 기존 용언 활용기로 검증했다. `보이다`의 활용과 같은 음절로
시작하는 다른 동사를 대조했다. 완료 보조 동사의 명사형은 본용언 연결형과
함께 반환한다. `-어하다`에는 기존 모음 연결형과 과거형 경로를 사용한다.
[한국어기초사전의 완료 보조 동사 문형](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=60625)

## 품질

고정 입력 12개를 Smart·Any·Token으로 실행했다. 249,243행의 입력 ID,
리소스 해시와 반환 범위를 대조했다. Smart의 모든 반환 범위가 동일했다.
Any와 Token은 PUD의 `만들어내기`를 제품 계약 범위인 `108..123`으로
반환했다. Any는 원본 골드 `108..117`과의 정확 일치가 한 건 줄었다.
[PUD의 두 골드 범위](2026-11-15-untagged-and-pud-contract-audit.md#pud-정확-범위)

고정 음성의 원문에 있는 `지어내서`는 `짓다`의 연결형을 포함한다. 이
행의 원본 분석은 `지내+서`이고, 별도의 골드 회귀는 같은 구문을 양성으로
확인한다. 기존 156건의 계약 검토를 양쪽에 똑같이 적용했다. 이 행은
그 검토에 포함되어 있지 않아 Token의 FP와 FPᶜ가 각각 한 건 늘었다.
Any는 기존 적중 행의 반환 범위만 `62..68`에서 `62..74`로 늘었다.
[한국어기초사전의 짓다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=66585)

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.
PUD는 정확한 바이트 범위로 채점한다. 음성은 반환 유무로 채점한다.
다른 입력과 교정 GSD의 행렬은 기준선과 동일하다.

## 성능

Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
`e38625b9`와 `389c7097`을 비교했다. 입력마다 새 프로세스로 워밍업
1회와 측정 5회를 실행하고 두 실행 파일의 순서를 교대했다. 표는 중앙값
[최솟값, 최댓값]이며 p95는 최근접 순위로 구했다.

처리량은 표의 입력 순서로 +0.37%, +0.85%, +0.82%였고,

모두 겹쳤다. PUD Token 초기화 중앙값은 +3.39%였으며 범위가 겹치지 않았다.

## 재현

교정 GSD와 고정 음성 입력, 세 리소스의 체크섬은
[앞선 보조 용언 측정](2026-11-15-vowel-auxiliary-frames.md#재현)과
같다. PUD 입력 `pud-positives.jsonl`의 SHA-256은
`d09a58d14dbee0ceda070e3968aa66d1c1480216d1630c134179d6190abaa7aa`이다.
양쪽 러너에 같은 Cargo 잠금 파일을 사용했다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml --target-dir "$build"
/usr/bin/time -l "$build/release/morph-benchmark-runner" boundary full-pos "$mode" "$input" "$output.json" 2>"$output.time"
```
