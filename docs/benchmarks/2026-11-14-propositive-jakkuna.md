# 청유 종결형 자꾸나의 검색 범위

사전의 `-자꾸나` 예문 8건을 점검했다. `가자꾸나`, `놀자꾸나`와 보조
동사가 붙은 `부지런해지자꾸나`를 어절 끝까지 반환한다.
`가자. 꾸나 씨가`처럼 뒤의 원문이 별도 어절인 경우를 대조했다.
[표준국어대사전 -자꾸나](https://stdict.korean.go.kr/search/searchView.do?word_no=274632&searchKeywordTo=3)

## 성능

시작점 `70a5d2d4`, 기준선 `ca62d820`의 검색 코드 `40156860`,
후보 `40f9ac9a`와 제품 파일이 같은 `65826d92`를 비교했다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스 5회씩 실행했다.
