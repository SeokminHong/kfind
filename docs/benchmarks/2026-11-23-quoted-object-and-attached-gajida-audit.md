# 따옴표 목적어와 붙임 보조 동사

`e6866914..23ba55ad`의 13개 변경에서 형태 판정과 원문·교정문의
정답 범위를 대조했다. 새 검토 102행 중 63행은 구현 대상 확인,
7행은 원본 정렬 오류, 32행은 비표준 표기 범위였다. 제외된
원문 범위와 각 교정문을 대조했다. `사고발생시`와 함께 나온 별도
명사 `사고는`처럼 유효한 범위는 기존 범위 채점에서 누락을 센다.

- `학교에 가가지고 서류를 받았다.`에서 `가다` [10, 22)를
  반환한다. 모음 연결형과 `가지고`의 결합을 기존 붙임 용언
  판정에 적용하며 보조사가 이어지면 해당 범위도 확인한다.
  `와가지고` [17, 29), `써가지고` [10, 22),
  `가가지고도` [10, 25)를 대조했다.
  [국립국어원 보조 동사와 붙여 쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=314331)
- `그는 ‘가’를 가지고 자리에 갔다.`에서는 따옴표와 목적격
  조사가 표시한 목적어를 확인해 `가지고` [20, 29)를
  `가다`의 반환에서 제외한다. 독립 이동 동사 [40, 46),
  `“가!”라고`의 명령 [13, 16), 두 단어를 인용한 목적어의
  소지 동사 [33, 42)를 보존한다.
  [국립국어원 따옴표 뒤 조사](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=44&qna_seq=335358)

16개 탐색 입력에서 달라진 전체 반환은 5건이다. 서로 다른 따옴표,
직접 인용, 띄어 쓴 긴 파생 용언과 그 비표준 붙임, 짝이 맞지 않는
따옴표까지 대조했다. 고정 회귀 8행을 추가했다.
탐색 입력 SHA-256은
`cde0e887cd8fafed14a6dd2b7a1b9aec18e8413b45c4e7ecb84412f9331516b5`다.

`느낌이 나는 무늬를 쓰는 것도`의 대명사 [10, 16)은 남았다.
`옆집 어른이 나는 소리를 듣는 것도 방해했다`에는 같은
위치의 대명사와 안긴 관형절이 함께 성립한다. 이 구조의
경합은 기존 원문·교정 평가 기준으로 기록한다.

## 성능

Apple M1 Max 32 GiB, macOS 26.6.2 arm64, Rust·Cargo 1.97.0,
Python 3.14.8에서 `23ba55ad`와 `37c722c1`의 release를 비교했다.
빌드별로 가동 1회 뒤 순서를 교대해 새 프로세스로 다섯 번 측정했다.
표는 중앙값 [최솟값, 최댓값]이며 p95는 실행별 최근접 순위다.
고정 음성과 원문 GSD, 사전·component의 체크섬은
[이전 측정 기록](2026-11-23-measure-and-source-boundary-audit.md#네이티브-성능)과
같다. 교정 GSD SHA-256은
`ae694ce3309045bbe892bd151a51cb3bcc00ae0d0bf545b9014cc9664e274a5b`다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
node tools/morph-compare/replay-gsd-audit-positives.mjs "$raw" > "$corrected"
scripts/benchmark-run.sh run --name morphology-audit-recheck-1098 -- \
  python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline_runner" 23ba55ad "$lexicon" "$component" "$predicates" \
  --candidate "$candidate_runner" 37c722c1 "$lexicon" "$component" "$predicates"
python3 tools/morph-compare/score-ud-audit.py --residual "$input" "$output"
```
