# 어미·조사에 겹치는 의존 명사 범위

`받다가`와 `사회적동요가`의 내부 `가`는 구조 그래프에서 의존 명사 품사가
확인되지 않았다. 같은 위치의 다른 품사 범위를 대신 사용한 폴백이 의존 명사
후보를 열었다. 용언과 어미 또는 완결 체언과 조사의 분석이 확인되면 그 범위에
의존 명사를 덧붙일 때 해당 품사의 근거가 필요하다. 정렬된 `우물가`의 `가`,
`일일 이용권`의 수사열 단위 명사 범위는 유지한다.

고정 12세트 83,081행을 세 모드로 실행해 반환 범위 목록 249,243개를
대조했다. 차이는 Smart 고정 음성의 12위치였고 GSD 원문 3곳과 PUD
원문 9곳을 모두 확인했다. 어미 `받다가·세워지면서`, 조사
`비비크림이나·정부중앙청사에서·바네즈가·사회적동요가·벨링스하우센은`이
대표 사례다. 교정 GSD 9,298행의 전체 목록은 같았다.

고정 평가 11세트의 FNc는 0, FPc는 1,689→1,681이다. 일부 행은
다른 반환 범위가 남아 범위와 행 단위 감소량이 다르다.

| 고정 음성 Smart | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 제외 |
| --- | --- | --- | ---: |
| 기준선 | 0, 3,227, 50,081, 0 / 0, —, 0 | 1,432, 1,689, 50,054, 0 / 45.88, 100, 62.90 | 133 |
| 후보 | 0, 3,217, 50,091, 0 / 0, —, 0 | 1,432, 1,681, 50,062, 0 / 46.00, 100, 63.01 | 133 |

NFC·NFD CLI에서 여섯 대조 입력의 전체 범위를 비교했다. 별도로
NFD `보증기간이 끝난다`에 명사 `가`를 질의하면 양쪽 CLI 모두 구조 검증 미완료를
보고했다. 같은 문장을 포함한 입력에서도 진단이 재현됐다.

## 네이티브 형태 판정

`6d14aa17`와 `bc04f3d8` release runner를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
비교했다. 입력과 리소스는 [기존 비교](2026-11-22-whole-adverb-boundary.md#네이티브-형태-판정)와
같다. 측정군별 새 프로세스로 워밍업 1회, 교대 측정 5회를 실행했다.
표는 중앙값 [최솟값, 최댓값]이다.

| 교정 GSD | 기준선 | 63.40 [63.26, 63.92] | 28,626 [27,528, 29,189] | 0.0760 [0.0740, 0.0787] | 81.59 [81.38, 81.77] |

처리량·p95 중앙값 차이는 교정 GSD +2.30%·−2.50%, 고정 음성
−1.06%·+1.32%였다. 초기화·최대 RSS 차이는 절댓값 0.29% 이내였다.
관측 범위가 겹쳤으며 처리량·지연 시간의 작은 차이는 판정을 유보한다.
