# 이동 동사의 도착지와 결과 상태

Smart 동사 `듣다` 검색이 원문 GSD의 `가시권에 들어와있음을`과
띄어 쓴 `가시권에 들어와 있음을`을 반환했다. 한국어기초사전은
`가시권에 들어오다`를 범위 안에 포함되는 문형으로 제시한다.
`듣다` 뒤에 붙는 연속상 보조 동사 `오다`는 같은 활용을 만들지만
그 청취 행위에는 도착지나 진입 후의 결과 상태가 없다.
[한국어기초사전 들어오다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=74105)
· [한국어기초사전 듣다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=74104)
· [국립국어원 보조 동사 있다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=27&pageIndex=1&qna_seq=329941)

같은 줄에서 `에` 또는 `(으)로`가 붙은 사전 공간 명사와
`들어가다`·`들어오다`의 완결 활용을 대조한다. `에`가 붙은 체언
뒤에서 결과 상태 보조 용언까지 확인되면 공간 명사 역할이 없는
범위 표현도 판정할 수 있다. 결과 상태 보조 용언에는 명사형 어미
뒤에 조사가 붙을 수 있다. 기존 공간 명사 역할, 동사 활용,
보조 용언과 조사 분석을 사용했다.

고정 회귀 17행을 비교했다. 새 13행 중 기준선은 7행에서 이동 동사를
`듣다`로 반환했다. 후보는 `교실에 들어갔다`, `집으로 들어오고 있다`,
`통신 범위에 들어와 있음은` 등의 오탐을 제거했다. 같은 문장에
`교실에 들어와 음악을 들었다`가 있으면 `들어오다` [20, 29)와
`듣다` [40, 49)만 각각 반환했다. 목적어·도구·시간·행위 장소가
청취를 지시하는 네 문장의 `들어왔다`도 유지했다.
[정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

원문 s667의 양·음성 질의 102개를 원문과 교정문에 각각 실행했다.
앞 절의 `단정지어`를 `단정 지어`로 교정하고 `들어와 있음을`은
한글 맞춤법 제47항의 원칙 표기로 띄어 썼다. 본용언 활용형이
두 음절인 `들어와있음을`도 허용 표기다. 두 입력에서 `듣다`만
달라져 원문 [278, 296)과 교정문 [279, 288)의 오탐이 빠졌다.
같은 범위의 `들어오다`는 유지됐다. 별도 `들다` 질의의 같은
반환과 사전 역할이나 결과 상태 근거가 없는 `가시권에 들어왔다`의
`듣다` 반환은 남아 있다.
[기존 원문·교정 비교](2026-11-23-raw-gsd-classifying-nominal-suffixes.md)
· [한글 맞춤법 제47항 해설](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=336402)

고정 음성에서 `듣다` 질의 149행과 그중 계약 오탐 18행을 비교했다.
한 행이 빠졌고 나머지 17행은 잔여 목록에 있다. 고정 12세트와
등록 교정 GSD의 전체 반환 목록 258,541개 중 변화는 이 한 행이다.
원문 GSD 양성 9,335행의 반환도 비교했다. 고정 음성의 계약 제외
148행, 양성 범위 미검증 1,208행, 제외 범위 미검증 42행은 같다.
원문 양성에는 미판정 683행 751범위, 교정 양성에는 119행 125범위가
남아 있다. 동일 정답과 범위 근거를 양쪽에 적용했다.

처리량·p95 중앙값 차이는 고정 음성 −2.02%·+2.51%, 교정
GSD −2.75%·+2.57%였다. 같은 실행 파일끼리의 차이는 각각
−1.82%·+2.59%, −6.67%·+6.60%였다. 후보 재측정 차이는
각각 +1.18%·−1.60%, −0.52%·+0.13%였다. 반복 변동과
재측정을 고려해 성능 회귀 판정은 유보한다.

```sh
cargo build --locked --release --manifest-path tools/morph-compare/runner/Cargo.toml
python3 tools/morph-compare/measure-smart.py "$input" "$out" \
  --baseline "$baseline" ea71ce9f "$lexicon" "$component" "$predicates" \
  --candidate "$candidate" 52d00aee "$lexicon" "$component" "$predicates"
```

동일 기준선 비교에는 두 인수에 같은 기준선 러너와 리비전을 지정한다.
