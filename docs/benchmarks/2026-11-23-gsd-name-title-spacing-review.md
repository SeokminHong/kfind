# GSD 성명과 호칭·직함의 띄어쓰기

GSD 교정 내역에서 공백만 추가된 표기와 원문 명사 질의의 미검출
범위가 겹치는 후보 중 호칭이나 직함의 띄어쓰기에 해당하는 9행
7문장을 확인했다. 인물의 성·성명 뒤 호칭과 직함은 제48항을
적용했다. 직업이나 직함과 `선생님`은 독립 단어이므로 띄어 썼다.
성씨 자체나 가문을 나타내는 접미사 `-씨`는 붙여 쓴다.
[한글 맞춤법 총칙·제48항](https://www.korean.go.kr/kornorms/regltn/regltnView.do)
· [국립국어원 호칭 씨와 접미사 씨](https://www.korean.go.kr/nkview/nknews/200011/28_7.htm)

s531의 `이를` [10, 16)은 앞 문단의 수사 결과를 가리킨다.
원본 기사의 앞 문단과 GSD 2번의 대명사·목적격 주석을 확인했다.
명사 `이` 검색은 원문과 교정문 모두 이 범위를 오반환한다.
같은 문장의 두 질의 행에서 각각 FPc에 반영한다.
