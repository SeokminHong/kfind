# 분해형 용언의 어미 시작 음절 경계

NFD로 적은 `왔는가`에서 `오다`의 연결형 후보 `와`는 같은 음절의 끝 자모
`ᆻ` 앞에서 끝난다. 이 후보에 어미를 붙이거나 전체 NFC 어절을 후보 길이로
잘라 구조 검증에 넘기면 원문 byte 경계가 맞지 않는다. 어미 검증과 구조 분석
두 경로에서 같은 음절을 완성하는 받침 앞의 후보를 제거하고, `왔`으로 끝나는
과거형 후보의 범위를 유지한다.

UD 2.18 GSD·PUD test의 `왔·봤·됐·했·갔·줬·뒀·썼`을 포함하는 문장을
전수 추출해 각 동사 질의로 검색했다. GSD 178개, PUD 342개 질의·문장 쌍의
문자열 후보 566곳을 확인했다. 각 정규화 모드에서 기준선과 후보의 core·token
목록이 모두 같았다. NFD에서 여덟 질의 모두 종료 코드가 2에서 0으로 바뀌었다.
`왔는가`, `왔는가를`, `와서`는 정확한 범위를 반환했고 `왓슨`은 일치와
검증 미완료 진단 없이 종료했다.

고정 12세트의 Smart·Token·Any 반환 목록 249,243개와 교정 GSD 9,298행의
Smart 반환 목록은 동일했다. 고정 음성의 원본 TP/FP/TN/FN은 0/3,218/50,090/0,
precision·recall·F1은 0%다. 계약 값은 1,437/1,670/50,061/0,
precision 46.25%, recall 100.00%, F1 63.25%다. 제외는 140행이다.

## CLI 성능

기준선 `084fd8af`와 후보 `231e4a51`의 release CLI를 Apple M1 Max, 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0에서 비교했다. GSD, PUD 순서로
`# text = `가 붙은 원문 중 `왔` 또는 `갔`이 있는 55행을 추출했다.
원문 체크섬은 [UD 입력 생성기](../../tools/morph-compare/generate-ud-audit-fixtures.mjs)에
고정되어 있다. 다음 네 줄을 순서대로 붙인 뒤 줄바꿈을 포함한 59행을 300번 반복하고
각 파일을 NFC·NFD로 정규화했다.

```text
어제 왔는가?
어제 왔는가를 확인한다.
그는 이쪽으로 오는가를 확인한다.
왓슨은 현장에 가지 않았다.
```

| 입력 | 행 | 바이트 | SHA-256 |
| --- | ---: | ---: | --- |
| NFC | 17,700 | 2,190,600 | `eddae7cf34ebe5d318852009ee658106ec69067fa98370e8b345905f08775db7` |
| NFD | 17,700 | 4,967,100 | `c227d86f9c9090fbd0f958eec71cc744109ce36fca33050d33d1a1ccef1bdc47` |

```sh
/usr/bin/time -l "$runner" --data-dir "$data" --threads 1 --count --pos verb --unicode-normalization canonical -- 오다 "$input"
```

full-pos·component·enriched 리소스는
[앞선 네이티브 비교](2026-11-22-embedded-question-object.md#네이티브-형태-판정)와 동일하다.
조합별 새 프로세스로 워밍업 1회 뒤 양쪽 실행 순서를 번갈아 바꾸며 5회 측정했다.
초·RSS 값은 중앙값 [최솟값, 최댓값]이고 처리량은 입력 bytes를 시간 중앙값으로 나눈 값이다.
모든 실행에서 9,300행이 일치했다.

| 입력 | 측정군 | wall s | 처리량 MiB/s | 최대 RSS MiB |
| --- | --- | --- | ---: | --- |
| NFC | 기준선 | 0.25 [0.25, 0.25] | 8.36 | 63.83 [63.72, 63.83] |
| NFC | 후보 | 0.25 [0.25, 0.25] | 8.36 | 63.83 [63.66, 63.92] |
| NFD | 기준선 | 0.68 [0.67, 0.69] | 6.97 | 64.03 [63.94, 64.13] |
| NFD | 후보 | 0.52 [0.51, 0.52] | 9.11 | 63.92 [63.64, 63.95] |

분해형의 처리 시간 중앙값은 23.53% 줄었다. NFC는 0.01초 측정 단위에서
같았다. NFD 성능 차이는 위의 활용형이 반복되는 입력에 한정해 측정했다.
