# 비교 구문의 정도 부사 검색

Smart는 형용사 앞의 `더·덜`에 주격 주어와 `보다`가 붙은 비교
대상이 확인되면 부사로 분석한다. 비교 대상과 주어 사이의 관형형,
정도 부사 앞의 배수 표현도 확인한다. 이름의 목적격이나 제목에 속한
명사 성분은 해당 범위에서 검색할 수 있다.
[한국어기초사전 ‘더’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=26829) ·
[한국어기초사전 ‘덜’](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=48653)

## 품질

기준선 `8146775c`와 후보 `d47269fe`에서 고정 12세트 83,081행의
Smart·Any·Token 반환 범위 249,243개를 비교했다. 고정 음성의 명사
`더` 질의 77행 가운데 57행에서 62범위가 반환됐다. 그중 PUD 세 행의
오탐 범위가 사라졌다.

- `n01015036`의 `케이라가 키에라보다 3배 더 많았다`에서 238..241
- `n01035004`의 `알아낸 것보다 모르는 것이 더 많다고`에서 217..220
- `n01059054`의 `유사점보다 차이점이 더 많지만`에서 80..83

그 밖의 전체 반환 범위는 같다. 회귀 대조는 부사 질의, 주격 표시가
없는 이름, 목적격이 붙은 이름, 신문 제목과 수량을 나타낼 수 있는
`조금`을 포함한다. NFC와 NFD 입력의 부사·명사 질의도 확인했다.
고정 평가 11세트의 Smart FNc는 양쪽 0건, FPc는 2,477건에서
2,474건으로 줄었다.

행렬은 TP, FP, TN, FN 순서이고 비율(%)은 precision, recall, F1 순서다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 추가 대조 9행 | Smart 기준선 | 6, 3, 0, 0 / 66.67, 100.00, 80.00 | 6, 3, 0, 0 / 66.67, 100.00, 80.00 |
| 추가 대조 9행 | Smart 후보 | 6, 0, 3, 0 / 100.00, 100.00, 100.00 | 6, 0, 3, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3676, 49632, 0 / 0.00, —, 0.00 | 1199, 2477, 49632, 0 / 32.62, 100.00, 49.19 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3673, 49635, 0 / 0.00, —, 0.00 | 1199, 2474, 49635, 0 / 32.64, 100.00, 49.22 |
| 고정 음성 53,308행 | Any 양쪽 | 0, 17616, 35692, 0 / 0.00, —, 0.00 | 1199, 16417, 35692, 0 / 6.81, 100.00, 12.75 |
| 고정 음성 53,308행 | Token 양쪽 | 0, 2847, 50461, 0 / 0.00, —, 0.00 | 1069, 1778, 50331, 130 / 37.55, 89.16, 52.84 |

추가 대조의 계약 검토는 0건이다. 고정 음성에 기존 계약 검토
1,199건을 두 리비전에 동일하게 적용했다.

## 성능

입력별로 새 프로세스에서 기준선과 후보를 워밍업 1회 후 5회 측정했다.
실행 순서는 교대했다. 각 셀은 중앙값 [최솟값, 최댓값]이며 p95에는
최근접 순위를 사용했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.747 [60.478, 62.289] | 30,759 [28,562, 31,165] | 0.07033 [0.06958, 0.07471] | 81.203 [81.016, 81.359] |
| 교정 GSD | 후보 | 61.052 [60.918, 61.541] | 30,643 [28,480, 30,924] | 0.07137 [0.07046, 0.07562] | 81.047 [80.891, 81.281] |
| 고정 음성 | 기준선 | 62.186 [60.706, 62.546] | 19,903 [19,270, 20,092] | 0.12537 [0.12383, 0.12908] | 127.547 [127.266, 127.672] |
| 고정 음성 | 후보 | 61.002 [60.781, 61.505] | 19,656 [19,389, 19,996] | 0.12775 [0.12471, 0.12992] | 127.422 [127.094, 127.469] |

교정 GSD의 처리량 중앙값은 −0.38%, p95는 +1.48%다. 고정 음성은 각각
−1.24%, +1.89%다. 두 입력에서 처리량과 p95의 관측 범위는 겹쳤다.

## 재현

Apple M1 Max arm64, macOS 26.6.2 (25G83), Rust/Cargo 1.97.0,
Node.js 26.11.1을 사용했다. 두 리비전을
`cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml`로
빌드했다. 각 실행은 `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`을
사용했다. [입력과 리소스 체크섬](2026-11-16-auxiliary-competition.md#재현)
