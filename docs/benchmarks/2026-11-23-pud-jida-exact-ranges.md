# PUD 피동과 변화 용언의 지다 범위

고정 음성에서 보조 동사 `지다`를 양성으로 확인한 기존 PUD 검토
13행을 전수 점검했다. 원문에서 통째로 표시된 동사 어절 안에서
`-아/-어` 경계와 보조 동사의 활용을 각각 확인해 15범위를
정답으로 등록했다. `끌어당겨져 … 만들어진`과 `알려져 … 알려져`는
두 범위를 요구한다. 선거 문장의 `인질`은 명사이고 `치러졌다`의
`졌다`만 정답이다.
[붙여 쓰는 -어지다](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5986)
· [기존 본용언 대조](2026-11-16-pud-jida-auxiliary-source.md)
· [PUD r2.18 원문](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu)
· [확정한 원문 범위](../../tools/morph-compare/contract-contrast-evidence.jsonl)

PUD `ToDoOrigText`에서 `계속되던 가운데`, `겨냥한 지방`,
`진행되었다는 사실`, `형성한 파편` 등의 공백을 복원했다.
교정된 문장은 8개다. 정상적인 준말 `이뤄졌으며`를 유지했다.
같은 release 검색기로 원문·교정문 26질의의 30범위가 모두
일치했다. 원문 `치러졌다`의 `졌다 [157, 163)`는 교정문에서
`[158, 164)`, 원문 `끌어당겨져`·`만들어진`의
`[85, 88)`, `[98, 101)`는 교정문의 `[86, 89)`, `[99, 102)`다.
범위는 UTF-8 바이트 반개구간이다.

교정한 문장의 다른 고정 질의 366행을 같은 러너에서 재실행했다.
기존 잔여의 9행에 반환이 남았다. `상승하는 경우`의 `하다`,
`차지하게 된`의 `하다`·`차다`에 대한 원문 오반환은 사라졌다.
`진행되었다는 사실`에서는 인용 구성 `-다는 [122, 128)`가
동사 `달다`로 새로 반환됐다. 이 범위는 별도 제품 결함으로 남았다.
[국립국어원 간접 인용의 -다는](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=90&pageIndex=1&qna_seq=332642)

## 평가

고정 음성 53,308행은 검토 1,589행, 제외 149행이다. 행렬 순서는
TP, FP, TN, FN이고 뒤 세 값은 정밀도·재현율·F1(%)이다.

| 입력 | 원본 행렬 및 지표 | 계약 행렬 및 지표 | FPc / FNc |
| --- | --- | --- | ---: |
| 고정 음성 양쪽 | 0, 3,026, 50,282, 0 / 0, 0, 0 | 1,430, 1,481, 50,248, 0 / 49.12, 100, 65.88 | 1,483 / 0 |

전체 정답 범위가 미판정인 고정 음성 계약 양성은 1,176→1,163행이다.
원문의 기존 분류와 제품 반환은 같다. 원문·교정문 입력 SHA-256은
`d6aafebead45cbcbbc5c97c2c6d50ce962fc307249fe54111dd8245285619966`,
인접 교정 입력은
`338b72c96dd6bc92fa2c7997a654e0b85b6537a084d250354200f3269a1e48cf`다.
