# 혼용 숫자 뒤 단위 명사

아라비아 숫자와 한자어 자릿값이 결합한 수량 뒤에서 단위 명사를 확인합니다.
`5억 원`과 `2천100억 원`의 `원`을 반환하고 잘못된 자릿값 순서 `2만억`은
수량 근거에서 제외합니다. [국립국어원 수량 표기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?qna_seq=320574)

#421의 고정 GSD 9,335행을 재실행해 부분 일치 890행과 겹치는 반환이 없는
223행을 재현했습니다. 이 1,113행을 ID로 연결한 최신 교정 GSD 9,314행에서
기준선은 정확 일치 900행, 부분 일치 86행, 겹치는 반환 없음 127행입니다.
후보는 기존 1,113행 중 네 행을 정확히 반환합니다.

숫자와 자릿값이 섞인 어절 뒤 공백을 기준으로 GSD 양성 9,314행, PUD 양성
798행, GSD·PUD 음성 53,308행과 사전 양성 4,458행을 검색했습니다. GSD의
14개 문장 263행 중 표적이 해당 수량 직후에 있는 25행을 대조했습니다.
PUD 양성에서는 9개 문장 12행에 표기가 있었고 표적은 해당 위치에 없었습니다.
음성 30개 문장 1,068행을 포함한 음성 전체의 반환 범위가 같았고 사전에는
해당 표기가 없었습니다. GSD에서 다섯 행의 반환이 바뀌었고 그중 한 행의
정답 범위는 기존에도 반환했습니다.

행렬은 TP, FP, TN, FN 순서입니다. 비율은 precision, recall, F1 순서입니다.
GSD 양성의 계약 검토는 0건입니다. 음성은 기존 계약 판정 27건을 적용했습니다.

## 성능

작업 시작점 `70a5d2d4`, 기준선 `0cafa1e4`, 후보 `b921e9a4`를 Apple M1 Max,
macOS 26.6.2, rustc 1.97.0 release 빌드에서 비교했습니다. 입력별로 실행 순서를
순환하며 새 프로세스에서 워밍업 1회와 측정 5회를 실행했습니다. 값은 중앙값
[최솟값, 최댓값]이며 p95는 최근접 순위입니다.
[입력과 실행 리소스](2026-11-13-adnominal-predicate-frame-matching.md#성능)

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```
