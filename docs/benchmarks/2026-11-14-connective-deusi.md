# 비교 연결형 듯·듯이의 검색 범위

사전의 `-듯/-듯이` 예문 13건을 점검했다. `보듯`, `말했듯`,
`읽으시듯이`, `이듯이`에서 연결형 끝까지 반환한다. `읽은 듯`의
의존 명사는 별도 어절로 남는다.
[표준국어대사전 -듯이](https://stdict.korean.go.kr/search/searchView.do?word_no=94654&searchKeywordTo=3) ·
[-듯](https://stdict.korean.go.kr/search/searchView.do?word_no=94247&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.
사전 계약 검토 0건으로 raw와 보정이 같다.

사전 `여서야:6`의 별도 활용 `장난하듯이`의 검색 범위도 달라졌다.
고정 GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
검색 범위는 일치했다. Raw·계약 보정 지표는
[고정 입력 보고서](2026-11-14-gu-exclamative.md)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `e8d3fec4`의 검색 코드 `65826d92`,
후보 `26526ae6`와 제품 파일이 같은 `340475bd`를 비교했다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행하고
버전 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다. p95는 최근접
