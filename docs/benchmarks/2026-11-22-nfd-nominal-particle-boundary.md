# 분해형 체언의 조사·지정사 음절 경계

NFD `보증기간`에서 명사 `가` 질의의 anchor가 `간`의 받침 앞까지
일치했다. 조사·지정사 branch가 그 범위를 원문 음절 경계로 매핑할 수 없어
검색은 구조 검증 미완료를 보고했다. 부사 경로에서 쓰던 합성 검사로
받침 앞 anchor를 먼저 거부하도록 했다.

UD 2.18 GSD 989문장과 PUD 1,000문장을 NFD로 변환하고 `가` 바로 뒤에
한글 종성이 이어지는 위치를 찾았다. GSD 314위치·243문장과 PUD
327위치·268문장을 모두 실제 CLI에서 검색했다. 반환된 17개 JSON 행과
각 바이트 범위가 일치했다. 기준선 종료 코드는 구조 검증 미완료를 뜻하는
2였고, 후보는 진단 없이 0을 반환했다. `난방·반대쪽·손님·핸드폰`의
대조 입력은 후보에서 진단 없이 불일치로 종료했다. 별도 완성 음절에 붙는
`문이·가에는·소는`의 전체 범위는 두 바이너리에서 같았다.

고정 12세트 83,081행에서 세 모드의 반환 목록 249,243개가 일치했다.
고정 평가 11세트의 FNc는 0, FPc는 1,681이다. 교정 GSD 9,298행과
고정 음성 53,308행의 원본·계약 행렬도
[기준선](2026-11-22-dependent-noun-boundary.md#네이티브-형태-판정)과 같다.

## CLI

`986f858a`와 `cc3faa1e`의 같은 release 설정을 Apple M1 Max,
32 GiB, macOS 26.6.2 (25G83), Rust·Cargo 1.97.0에서 비교했다.
리소스는 [Smart 기준선](2026-11-22-smart-performance-baseline.md)의
`087e0dbe`와 같다. 다음 네 줄을 순서대로 18,000번 반복해 72,000행을
만들었다. 각 줄은 LF로 끝나며 NFD 입력은 파일을 통째로 NFD로 변환했다.

```text
보증기간이 끝난다.
가에는 표시가 있다.
기간이 늘었다.
그는 휴가를 보냈다.
```

NFC 1,872,000바이트의 SHA-256은
`7455e27084d54fe7ff1f8eadc8e8a87614a9067279b87ef80736998825aec719`,
NFD 4,140,000바이트는
`d2a20638a922ef8ba2ce25965b45489d2bbfd6fb6c458630ea722326aab574b5`다.

```sh
/usr/bin/time -l "$runner" --data-dir "$data" --threads 1 --count --pos noun --unicode-normalization canonical -- 가 "$input"
```

버전과 입력별 새 프로세스로 워밍업 1회 후 순서를 교대해 5회 실행했다.
표는 중앙값 [최솟값, 최댓값]이다. 두 버전은 각 반복에서 18,000행을
반환했다. NFD 기준선의 종료 코드는 2, 후보는 0이었다.

| 입력 | 측정군 | 전체 시간 s | 처리량 MiB/s | 최대 RSS MiB |
| --- | --- | --- | --- | --- |
| NFC | 기준선 | 0.30 [0.30, 0.30] | 5.95 [5.95, 5.95] | 63.13 [63.00, 63.27] |
| NFC | 후보 | 0.30 [0.30, 0.31] | 5.95 [5.76, 5.95] | 63.06 [63.06, 63.30] |
| NFD | 기준선 | 1.37 [1.36, 1.41] | 2.88 [2.80, 2.90] | 63.23 [63.09, 63.30] |
| NFD | 후보 | 0.65 [0.65, 0.65] | 6.07 [6.07, 6.07] | 63.16 [63.13, 63.23] |

NFD 경계가 반복되는 입력에서 전체 시간 중앙값은 52.55% 감소했다.
NFC 중앙값은 시간 측정 해상도 0.01초에서 같았다.
