# 원문 GSD의 하다 품사와 표기

원문 GSD 계약의 미검출 558행 가운데 동사 `하다` 질의 9행을 전수
검토했다. 수를 나타내는 `한` 3행과 다른 표제어를 주석한 3행은
동사 `하다`의 계약 음성으로 확정했다. 표준 활용이 교정본에 있는
3행은 원문의 해당 범위만 계약 평가에서 제외했다.
같은 문장의 `만든신다고`도 별도 동사 질의와 높임 활용을 대조했다.
[GSD r2.18 원문](https://github.com/UniversalDependencies/UD_Korean-GSD/blob/r2.18/ko_gsd-ud-test.conllu)

| 원문 GSD 행 | 원문 범위 | 교정본의 분석과 반환 범위 |
| --- | --- | --- |
| s17:7, s815:7 | 한 60..63 | 관형사 한 60..63 |
| s428:9 | 한 56..59 | 관형사 한 56..59 |
| s38:4 | 키로야 27..36 | 길이 단위 킬로 27..33 |
| s425:3 | 키로야 23..32 | 길이 단위 킬로 23..29 |
| s671:4 | 키고 30..36 | 동사 켜다의 켜고 30..36 |
| s104:3 | 할려고요 14..26 | 동사 하다의 하려고요 14..26 |
| s228:5 | 하시구요 58..70 | 동사 하다의 하시고요 58..70 |
| s903:6 | 하더라구요 47..62 | 동사 하다의 하더라고요 47..62 |
| s903:5 | 만든신다고 31..46 | 동사 만들다의 만드신다고 31..46 |

`한 명`과 `한 곳`은 앞에 나온 집합에서 하나를 고르는 수량
표현이다. `몇 키로야`는 거리 단위를 서술격 조사와 결합한 표현으로
사전의 `킬로`에 해당한다. `내비 켜고`는 기기를 작동하는 동사
`켜다`의 활용이다. 원문과 교정문에서 `내비` 표기를 보존했다.
s671의 별도 동사 `가다` 질의에 있는 `찾아갔는데` 내부 추가 반환은
두 문장 모두 미판정으로 기록했다.
[수 관형사 한](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=73278)
· [거리 단위 킬로](https://krdict.korean.go.kr/m/eng/searchResultView?ParaWordNo=72175&nation=eng)
· [동사 켜다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=72168&lang=eng)

`하려고요`는 모음으로 끝나는 어간 `하-`에 의도 연결 어미를,
`하시고요`와 `하더라고요`는 표준형 `-고`와 `요`를 결합한다.
`만드신다고`의 높임 선어말 어미 `-시-` 앞에서는 어간의 ㄹ이
탈락한다. 같은 s903의 두 교정 범위를 각각 검색했다.
[연결 어미 -려고](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6501&mn_id=217&pageIndex=1)
· [국립국어원 일상 대화 말뭉치 구축 지침](https://www.korean.go.kr/common/download.do?c_file_name=bde4951e-ba07-4305-8f48-2175038d3299.pdf&file_path=reportData)

## 평가

`23ba55ad`와 같은 제품 트리의 Smart full-pos release와 동일 리소스를
사용했다. 원문·교정문에서 동사 `하다`와 해당 표제어를 대조하고,
같은 실행 출력을 기존 계약과 수정된 계약으로 채점했다.
[입력과 리소스](2026-11-23-degree-adverb-before-possibility.md#성능)

행렬 순서는 TP, FP, TN, FN이며 뒤의 세 값은 정밀도·재현율·F1(%)이다.

| 입력 | 원본 행렬 및 지표 | 계약 행렬 및 지표 | FPc / FNc | 검토 / 제외 |
| --- | --- | --- | ---: | ---: |
| 원문 GSD 기존 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,648, 9, 86, 558 / 99.90, 93.94, 96.83 | 20 / 558 | 602 / 34 |
| 원문 GSD 후보 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,648, 9, 92, 548 / 99.90, 94.04, 96.88 | 20 / 548 | 612 / 38 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 6 / 0 | 149 / 0 |
| 고정 음성 양쪽 | 0, 3,026, 50,282, 0 / 0, 0, 0 | 1,430, 1,481, 50,248, 0 / 49.12, 100, 65.88 | 1,483 / 0 | 1,589 / 149 |

원문 FNc 10건 감소는 범위별 계약 검토의 효과다. 추가 반환 미판정은
원문 515행 573범위, 교정 86행 92범위다.
