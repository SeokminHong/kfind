# 원문 GSD 명사 수식 표현의 반환 범위

앞서 띄어쓰기를 교정한 명사 수식 표현 11행의 표적을 원문 GSD
9,335행에 대조했다. 기존 원문·교정문 쌍과 문법 근거로 지명, 인명,
기업명과 범위를 나타내는 명사의 UTF-8 범위를 확정했다. `삼성 본사`
문장에서 서비스의 공식 표기인 `스트리트 뷰`를 적용하고, 붙여 쓰기가
허용되는 `보여주세요`와 날짜의 마침표는 유지했다.

`06f77ce9`와 같은 Smart full-pos 코드에서 원문과 교정문의 등록 질의
411쌍을 실행했다. 표적 11행의 교정문은 모두 정확했다. 원문 두 행에서
`경남도` [59, 68)까지 잘못 반환한 결과를 범위 오탐으로 집계했다.
교정문에서 명사 `국`의 질의에 `청국`의 끝 [153, 156)이 추가로 반환됐다.
붙여 쓴 `스트리트뷰` 질의의 반환과 `강남지역` 내부의 `남다`,
`아시아통화` 내부의 명사 `아` 반환은 해당 공백을 복원하자 사라졌다.
