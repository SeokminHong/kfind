# 원문 GSD 서술격 조사 앞 명사와 문장 내 반복 범위

원문 GSD 양성의 미판정·실패 목록에서 품사열이 `NNG+VCP`로 시작하는
40행을 검토했다. 서술격 조사 앞의 명사와 같은 문장의 다른 유효 범위를
26행에서 확정했다. `식기를`과 `식기더군요`는 각각 목적격 조사까지와
명사까지를 포함한다. `차종이 아닌`의 첫 `이`는 보격 조사이고
`차종이다`의 `이`는 서술격 조사다. `위원회`의 `위원`은
MeCab-ko-dic의 `위원/NNG+회/NNG` 분절에 맞는다.
`대학교`는 `대/NNG+학교/NNG`로 정렬되며 `대학`이 따로 나오는
서술격 조사 앞에서만 `대학`을 기록했다. 남은 14행은 비표준 표기,
복합 명사의 성분, 표제어 분절을 더 확인해야 한다.
[국립국어원 서술격 조사의 활용](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?pageIndex=1&qna_seq=316087)
· [원문과 정확한 범위](../../tools/morph-compare/contract-contrast-evidence.jsonl)

26개 문장의 양·음성 질의 891개를 원문과 검토문에 각각 실행했다.
교정문은 21개이며, 허용되는 준말과 구어체를 유지한 다섯 문장에는 별도
용례를 추가했다. 원문과 검토문에서 52개 목표 반환 목록을 확인했다.
쌍별로 바이트 위치 이동을 제외하고 반환 표면이 달라진 질의는 20개였다.
`간 콩`에서 `갈다`의 [20, 23)이 복원됐고, 같은 범위가 `가다`
질의에도 나타났다. `올 초`의 `오다` [77, 80), `인기 있는 집`의
`있다` [63, 69), `예약 못 하면`의 명사 `못` [7, 10)도 별도
범위로 기록했다. `활기를 불어넣었다는`의 `불다` 반환 범위는
교정본에서 [241, 259)로 넓어졌다. 이 교정문 결과는 원문 지표와
등록 교정 GSD 지표에 합산하지 않았다.
