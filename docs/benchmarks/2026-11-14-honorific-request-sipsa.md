# 정중한 청원형 십사·으십사의 검색 범위

표준국어대사전과 한국어기초사전의 `-십사/-으십사` 예문 7건을
점검했다. 동작 용언의 모음·자음·ㄹ 받침 어간 결합을 확인했다.
`참읍시사` 청유형도 유지했다.
[표준국어대사전 -십사](https://stdict.korean.go.kr/search/searchView.do?word_no=203561&searchKeywordTo=3) ·
[-으십사](https://stdict.korean.go.kr/search/searchView.do?word_no=465366&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
`십사:2`의 raw 질의 `돕다`와 정답 범위 43..58을 보존했다.
해당 범위가 가리키는 사전 표제어
[도와주다](https://stdict.korean.go.kr/search/searchView.do?word_no=84994&searchKeywordTo=3)로
질의를 보정해 다시 실행했다. 전체 사전에는
[앞선 보정 9건](2026-11-14-propositive-quotation.md#품질)도 포함한다.

## 성능

시작점 `70a5d2d4`, 기준선 `12f47345`, 후보 `bc5d490c`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `bcd0e326`과
`661dfc8d`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서는 순환했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접
