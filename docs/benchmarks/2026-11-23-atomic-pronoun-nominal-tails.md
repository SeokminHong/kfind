# 단일 대명사 안의 추론 명사

`이곳`, `그곳`, `저쪽`, `이것`의 사전 대명사 분석을 사용한다. 대명사와
조사 또는 복수 표지의 결합이 어절을 덮고 명사 분절 근거가 없으면
끝의 추론 명사를 제외한다. 같은 문장의 독립 `곳`, `쪽`, `것`과
`화산섬을`의 정렬 명사 성분은 반환한다.
[국립국어원 대명사](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=57322) · [한국어기초사전 이곳](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=71130)

고정 12세트의 Smart·Token·Any와 교정 GSD에서 반환 목록 258,541개를
대조했다. Smart 결과 9행에서 범위 하나씩을 제거했다. 고정 음성 PUD의
5행은 `이곳` 2행과 `이것` 3행이다. 교정 GSD의 같은 `이곳` 표적은
두 평가 실행에 나타났고, KAIST의 `이것은 … 될 것이다` 표적은 명시 품사와
자동 품사 실행에 나타났다. 원본 GSD 양성 9,335행의 반환은 같았다.

| 입력 | 원본 TP, FP, TN, FN / precision, recall, F1 (%) | 계약 TP, FP, TN, FN / precision, recall, F1 (%) | FPc 기준선 → 후보 | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 53,308행 | 0, 3,128, 50,180, 0 / 0, 0, 0 | 1,418, 1,599, 50,148, 0 / 47.00, 100, 63.95 | 1,605 → 1,600 | 0 |
| 교정 GSD 9,298행 | 9,288, 0, 0, 10 / 100, 99.89, 99.95 | 9,288, 0, 10, 0 / 100, 100, 100 | 3 → 2 | 0 |

두 실행에 동일한 정답 주석을 적용했다. 앞선 고정 음성 보고의 FPc 1,602에
`이것은/이것으로/이것으로도` 내부 오탐 3개를 추가로 확정하면 이 비교의
기준선 1,605가 된다. 미확정 범위는 고정 음성의 계약 양성 1,277행과 제외
108행, 교정 GSD의 추가 반환 141행·150개다.

## 네이티브 형태 판정

`a87f0fa1`과 `352779ae`의 release runner를 Apple M1 Max 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서 비교했다.
[교대 측정 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)으로
`boundary full-pos smart INPUT OUTPUT`을 새 프로세스에서 워밍업 1회와
교대 측정 5회 실행했다. 입력·리소스 체크섬은
[공통 component 비교](2026-11-23-source-aligned-nominal-prefixes.md)와 같다.
값은 중앙값 [최솟값, 최댓값]이다.

고정 음성 처리량은 2.04% 높고 p95는 1.04% 낮았다. 교정 GSD 처리량은
0.20% 높고 p95는 1.19% 낮았다. 두 입력의 처리량·p95 측정 범위는
각각 겹쳤다. 교정 GSD의 최대 RSS 중앙값은 32 KiB 늘었다.
