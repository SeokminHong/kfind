# 붙은 게 연결형과 생성 관형형

`선정의 영예를 안게 돼`에서 `안게`는 `안다`에 연결 어미 `-게`가 붙은
활용이다. `직접 안 게 하나 있다`에서는 `알다`의 관형형 `안`이 다음 어절의
의존 명사 `게`를 꾸민다. Smart는 붙은 `-게`까지 이어지는 용언 분석이
성립할 때 같은 어절에 포함된 짧은 생성 관형형을 제외한다.
[국립국어원 연결 어미 -게 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=324903)
[국립국어원 의존 명사 띄어쓰기](https://www.korean.go.kr/nkview/news_pdf/2020_11.pdf)

## 품질

기준선의 Smart 잔여 오탐 1,998행에서 동사·형용사의 반환 범위가 같은
어절의 `때`나 `게` 바로 앞에서 끝나는 경우를 전부 점검했다. 해당한 한
범위는 GSD `test-s205`의 `알다` 반환 `안`(167..170)이다. 원문은
`안게`를 `안+게`(`VV+EC`)로 표기한다. 고정 12세트 83,081행의 세 모드
249,243개 반환 목록을 비교해 이 범위의 삭제 한 건을 확인했다. 목표
11세트에서 Smart FNc는 0, FPc는 1,998에서 1,997로 바뀌었다. 나머지
잔여의 문법 판정은 별도 작업 범위다.

직접 대조 9질의에는 `안게 되었다`, `안게 했다`, `안 게`, `온 때`,
`풀게`, `풀 게`의 범위를 포함했다. CLI의 NFC와 canonical 모드 NFD에서
18개 반환 목록을 확인했다. 직접 대조의 계약 검토는 0건이며 고정 음성의
기존 계약 검토 1,398행과 제외 67행을 유지했다.

행렬은 TP, FP, TN, FN 순이며 비율(%)은 precision, recall, F1 순이다.

## 성능

각 값은 중앙값 [최솟값, 최댓값]이다. p95는 질의 시간의 nearest-rank
95백분위수다.

| Smart 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | 최대 RSS (MiB) |
| --- | --- | ---: | ---: | ---: | ---: |
| GSD | 기준선 | 60.991 [60.874, 62.327] | 30,408 [29,739, 30,535] | 0.07104 [0.07079, 0.07254] | 81.078 [80.969, 81.578] |
| GSD | 후보 | 60.788 [60.682, 61.590] | 29,881 [29,356, 30,433] | 0.07133 [0.07058, 0.07496] | 81.172 [81.078, 81.422] |
| 고정 음성 | 기준선 | 61.204 [60.347, 64.808] | 19,449 [17,086, 19,610] | 0.12913 [0.12783, 0.13758] | 127.500 [127.422, 127.547] |
| 고정 음성 | 후보 | 60.826 [60.523, 61.210] | 19,762 [19,586, 19,868] | 0.12612 [0.12471, 0.12671] | 127.578 [127.344, 127.594] |

GSD 처리량·p95 중앙값은 −1.73%·+0.41%였고 두 측정 범위가 겹쳤다.
고정 음성에서는 +1.61%·−2.32%였으며 p95 측정 범위가 개선됐다.
러너 크기는 5,177,920에서 5,178,672바이트로 752바이트 증가했다.
