# 지명 사이의 행정 단위 명사

GSD·PUD 원문에서 독립 토큰 `주·구` 15건을 대조했습니다. 현재 어절에
일반 명사 분석이 있고, 두 지명 사이에서 앞 지명과 결합한 형태에도 사전
고유 명사 분석이 있으면 일반 명사 범위를 보존합니다.
`버지니아 주`, `뉴욕 주`, `테네시 주`, `강남 구` 등 6건의 범위를
복구했습니다. 대조 14건에서 기준선은 정확 일치 1건과 음성 5건, 후보는
정확 일치 7건과 음성 5건입니다. 앞 지명이 없는 `구 관계자` 두 입력은
여전히 누락됩니다. 단위 명사 `몇 주`, 관형사 `주 업무·구 식민지`와
성씨 대조의 반환은 그대로입니다.

GSD 9,314행에서 `버지니아 주`와 `뉴욕 주` 두 행만 바뀌었습니다.
PUD 양성 798행과 사전 양성 4,458행의 반환은 같습니다. 고정 음성
53,308행에서는 `pud:w01147010:noun:주`의 `테네시 주` 한 행만
추가 반환됐습니다. 출처 문장의 실제 행정 단위이므로 계약 평가에서
양성으로 판정했습니다. raw 음성은 보존했습니다. 로컬 테스트 300건과
신규 gold 4건을 통과했고 기존 `verify-gold` 불일치 8건이 재현됐습니다.

행렬은 TP, FP, TN, FN 순서이고 비율은 precision, recall, F1입니다.
양성 계약 검토는 0건이며 음성은 기존 29건에 테네시 주 1건을 추가했습니다.
