# 대명사 뒤 종결형 라니

`찾던 사람이 바로 나라니!`에서 `나`는 대명사이며 `이-`가 생략됐다.
주격·주제 명사구와 문장 끝을 확인해 Smart에서 어절 전체를 반환한다.
`너라니`와 뒤에 다른 명사를 나열하는 `나라니 지역이니`를 대조했다.

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
사전 `라니` 예문 12건을 전수 대조했다. 해당 어미의 추가 보정은 0건이며
사전 전체에는 [기존 보정](2026-11-15-dictionary-mothada-and-hasio-review.md)을 적용했다.

## 성능

시작점 `70a5d2d4`, 최신 기준선 `e7905d04`, 후보 `e11bf92a`를 비교했다.
기준선 측정 빌드 `72f88a93`과 최신 기준선의 차이는 평가 스크립트와 문서다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS Smart로 워밍업 1회 후 새 프로세스로 5회씩 버전 순서를 순환했다.
