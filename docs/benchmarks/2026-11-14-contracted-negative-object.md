# 부정 연결형 뒤 목적격 조사 준말

`-지를`이 `-질`로 줄어든 어절은 바로 뒤에 부정 보조 용언이 올 때
끝까지 반환합니다. GSD·PUD 원문의 `질 (않|못|말|마)`와 GSD 교정 양성의
`질` 종결 표면을 검색했습니다. 원문에서 찾은 두 문장과 교정 양성에서
찾은 11행을 대조했습니다. GSD의 `돌아보질`, `보이질` 두 행이 이
구조에 해당합니다. 관형형 `가질`, `없어질`, 명사 `화질` 등은 그대로 유지됐습니다.

동사·형용사, 과거·추측·높임, ㄷ 불규칙, `않다·못하다·말다`,
`-진`, 관형형, 명사 주어, 쉼표 경계로 구성한 20개 대조 입력을 확인했습니다.
`token`과 `any`에서 `가질 물건`, `가질 못을`에 대한 `가다` 반환은
양쪽 빌드에서 재현됐습니다. `smart`는 두 입력 모두 반환하지 않았습니다.
신규 gold 10건과 morph·matcher 단위 테스트 215건이 통과했습니다.
`verify-gold`에서는 기존 불일치 8건이 재현됐습니다.

행렬 순서는 TP, FP, TN, FN이고 비율은 precision, recall, F1입니다.
음성의 기존 계약 판정은 29건입니다. 나머지 입력의 계약 검토는 0건입니다.
