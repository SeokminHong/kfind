기준선은 `da903e21`, 후보는 `8337e0a6`입니다.

## 품질

`출판통제라는`의 `출판`과 `통제`가 명사 경로를 이루면 생략된 지정사의 어절 전체를
반환합니다. `출력하라는 지시`는 동사 활용이며, `충분하다라는`의 `충분하다`는 이미
종결된 용언입니다. `대안인가라는`에서는 명시적 지정사인 `인가`를 확인합니다.
[한국어기초사전 -라는](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=82217) ·
[UD 회귀](../../data/fixtures/ud_morphology_cases.tsv)

GSD test, KAIST dev/test, KSL dev/test에서 `라고/라고요/라는`으로 끝나는 표면을
포함하는 고유 문장 381개에 `이다/adjective`를 질의했습니다. 반환 범위가 달라진 문장은
KAIST 9개였고 모두 명사 뒤 인용형의 어절 전체가 추가됐습니다. `코카콜라라는 브랜드`는
KAIST의 조사 분석과 지정사 생략 분석이 모두 성립합니다. 따옴표로 직접 인용한
`‘코카콜라’라는 글자`는 별도 음성 예문으로 검사했습니다.

회귀 대조와 GSD 양성은 정확한 범위로 채점했습니다. 회귀 대조 음성과 KAIST 양성은
표적과의 겹침으로 채점했습니다. 표의 행렬은 TP, FP, TN, FN 순서이고, 비율은
precision, recall, F1 순서입니다. 검토 0건인 행은 원본 기대값으로 계약 보정 지표를

full-POS release runner를 사용했습니다. 입력별 새 프로세스에서 warm-up 1회 뒤

GSD와 KAIST의 처리량 중앙값 차이는 −0.07%에서 +0.01%였습니다. 인용 표면에 한정한
질의에서는 처리량이 0.67% 감소했고 p95가 3.14% 증가했습니다.

```sh
cargo build --release --locked --manifest-path tools/morph-compare/runner/Cargo.toml
/usr/bin/time -l "$runner" boundary full-pos smart "$input" "$output"
```

인용 표면 입력은 GSD test, KAIST dev/test, KSL dev/test 순으로 CoNLL-U의 `# text`를
읽어 정규식 `(라고요?|라는)(?![가-힣])`으로 고르고, 같은 문장의 첫 출현만 보존했습니다.
각 입력의 `id`는 파일 이름과 `sent_id`를 콜론으로 연결했습니다. 이 입력에서는
기대값을 채점에 사용하지 않고 반환 범위의 변화만 검토했습니다.
