# 파생 용언의 어근과 내부 수식어

`저렴한·저렴하고·세밀한·세밀하게`의 첫 음절은 각각 `저렴`과
`세밀` 어근의 일부다. Smart 구조 판정은 `XR` 뒤에 파생 접미사
`XSA/XSV`와 어미가 어절 끝까지 이어지는지 확인한다. 이미 계산한
어미 경로를 재사용하며, 판정에 필요한 어근 범위는 기존 토큰
구조 근거에 기록한다.
[국립국어원 어근과 접미사 -하다](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=331570)

## 품질

관형사 잔여 53행에서 어절 내부 반환 17범위를 조사했다. 이 중
`저렴하다` 계열에서 6범위, `세밀하다` 계열에서 2범위가 어근
경로와 겹쳤다. 별도 대명사 `저` 질의에서도 같은 어근 내부의 반환
3범위를 확인했다.

기준선과 후보를 고정 12세트 83,081행과 세 모드에서 실행했다.
249,243개 결과 중 위의 Smart 11행에서 오탐 한 범위씩 사라졌다.
나머지 관형사 내부 9범위는 복합 명사나 별도 용언 활용 경로의
후보다. 목표 11세트에서 Smart FNc는 0이고 FPc는 2,271에서
2,260으로 줄었다. 고정 음성의 계약 검토는 1,329행, 제외는 66행이다.

추가 회귀 9행은 연결형·관형형과 다른 어근 `온순`, 독립 관형사와
대명사의 전체 반환 범위를 확인한다. 양성은 정답 범위 한 개와
일치해야 하며, 음성은 검사 범위와 겹치는 반환을 세었다. 회귀 행의
계약 검토는 0행이다. 행렬은 TP, FP, TN, FN 순서이고 비율은
precision, recall, F1 순서다.

## 성능

입력마다 워밍업 1회 후 양쪽을 별도 프로세스에서 교대로 5회 실행했다.
표에는 중앙값 [최솟값, 최댓값]을 기록했다. p95는 실행별 최근접 순위로 구했다.

겹친다. 러너 크기는 5,121,760바이트에서 5,121,520바이트로 줄었다.
