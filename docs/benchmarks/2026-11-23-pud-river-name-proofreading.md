# PUD 강 이름과 인접 표적의 띄어쓰기

2017년 외래어 표기법 개정 안내에서 `나일 강`은 `나일강`으로
바뀌었다. 고정 PUD에서 이 표기와 같은 방식으로 띄어 쓴 강 이름을
찾아 원문 두 문장과 관련 질의 60행을 대조했다. `나일강`과
`미시시피강`을 붙이고, 원문의 다른 공백은 ToDoOrigText대로
복원했다. 두 문장의 원문과 교정문은 같은 `852cae48` 실행 파일로
확인했다. [외래어 표기법 개정 안내](https://www.korean.go.kr/nkview/nklife/2017_2/27_0214.pdf) ·
[PUD 원문과 ToDoOrigText](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/e942f9c5e9351f37bcb8f202bb9df70f78c60d35/ko_pud-ud-test.conllu)

| 문장과 질의 | 원문 반환 | 교정문 반환 |
| --- | --- | --- |
| n01064113 명사·대명사 나 | 나 [56, 59) | 없음 |
| n01064113 동사 하다 | 하지 [76, 82) | 없음 |
| n01064113 명사 일 | 일 [151, 154) | 일 [152, 155) |
| w01028004 명사 것 | 없음 | 것은 [17, 23) |

명사와 대명사 `나`의 원문 제외 범위는 옛 지명 표기 [56, 66)이다.
`하다`는 기존 공백 누락 범위 [70, 94)를 고정했다. 원문의
`중요한것은` [7, 22)과 교정문 `중요한 것은`의 범위도 기록했다.
두 문장의 반환 목록에서 표기 변경으로 다른 문자열이 반환된 경우는
네 질의였으며 `일`은 교정된 위치에서 계속 반환됐다.
[원문 범위와 교정문](../../tools/morph-compare/contract-contrast-evidence.jsonl)

고정 음성 53,308행에서 같은 결과를 재채점했다. 범위를 확인한
비표준 검토는 62행이며 85행은 범위가 미확정이다.
