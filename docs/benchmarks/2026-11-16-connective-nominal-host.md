# 명사 후보와 연결 어미 `-고`의 경계

`내복 입고`에서 `입고`는 `입다`의 연결형이다. `입고 기록`에서는
`입고`가 통째 명사이고, `입은 작지만`에서는 명사 `입`에 조사 `은`이
붙는다. `한 주고 다음엔 두 주다`의 `주고`는 받침 없는 체언 뒤에서
지정사 `이-`가 생략된 형태다. `친구고 동료고`에서는 접속 조사 `고`가
같은 받침 조건에서 성립한다.
[국립국어원 지정사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=332679),
[국립국어원 접속 조사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=322439)

Smart는 받침 있는 체언 후보가 어절의 일부만 덮고, 같은 앞 범위에
용언의 완결된 `-고` 분석이 있으며, 그 범위를 지지하는 사전 명사
성분이 없으면 부분 반환을 제외한다.

## 품질

기준선 `a0ccc0cf`와 후보 `11506256`에서 고정 12세트 83,081행의
Smart·Any·Token 반환 249,243개를 비교했다. 이전 잔여에서 한 음절
체언 후보 뒤에 `고·지·게·서·아`가 이어지는 73범위 중 `고`는
26범위였다. 변경으로 `달고·길고·말고·품고·알고·입고·팔고·들고`의
Smart 오탐 11범위가 사라졌다. 한 행에는 `팔지`의 별도 반환이 남아
오탐 행은 10개 줄었다. 나머지 어미는 각각의 결합 조건을 검토해야 한다.

추가 회귀 12행은 용언 연결형의 잘못된 명사 반환과 용언 전체 범위,
통째 명사, 조사 결합, 명사 성분, 모음 뒤의 지정사 생략과 접속 조사를
검증한다. 행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision,
recall, F1 순서다. 추가 회귀의 계약 검토는 0건, 고정 음성은 기존
1,255건이다. 목표 집계 11세트에서 Smart FNc는 0이고 FPc는
2,342건에서 2,332건으로 줄었다.

| 추가 회귀 12행 | Smart 기준선 | 8, 4, 0, 0 / 66.67, 100.00, 80.00 | 8, 4, 0, 0 / 66.67, 100.00, 80.00 |
| 추가 회귀 12행 | Smart 후보 | 8, 0, 4, 0 / 100.00, 100.00, 100.00 | 8, 0, 4, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3594, 49714, 0 / 0.00, —, 0.00 | 1255, 2339, 49714, 0 / 34.92, 100.00, 51.76 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3584, 49724, 0 / 0.00, —, 0.00 | 1255, 2329, 49724, 0 / 35.02, 100.00, 51.87 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 교대로
5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했다. p95는
최근접 순위로 구했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.396 [60.265, 62.287] | 30,634 [29,827, 30,812] | 0.07092 [0.07021, 0.07313] | 81.094 [80.984, 81.125] |
| 교정 GSD | 후보 | 60.647 [60.304, 61.886] | 30,814 [28,505, 30,903] | 0.07021 [0.07000, 0.07458] | 80.938 [80.922, 81.141] |
| 고정 음성 | 기준선 | 61.009 [60.662, 61.290] | 19,772 [19,577, 19,858] | 0.12629 [0.12508, 0.12854] | 127.516 [127.141, 127.563] |
| 고정 음성 | 후보 | 60.803 [60.355, 61.195] | 19,885 [19,648, 19,913] | 0.12529 [0.12517, 0.12758] | 127.453 [127.375, 127.578] |

교정 GSD 처리량 중앙값은 +0.59%, p95는 −1.00%다. 고정 음성은
각각 +0.57%, −0.79%였다. 두 입력에서 처리량과 p95의 관측 범위는
겹친다.
