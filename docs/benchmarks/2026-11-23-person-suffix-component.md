# 사람 접미사의 compact component 품사

표준국어대사전의 접사 `-자(者)`와 의존 명사 `자(者)`를 대조했다.
붙임표와 원어가 접미사 결합을 가리키고, 같은 표기의 다른 분석이 없으며,
MeCab 일반 명사 자료의 마지막 `NNG`가 그 범위에 정렬된 1,192개 표면을
확인했다. 빌더는 마지막 성분을 `XSN`으로 기록하고 전체 명사의 품사와
앞 성분을 보존한다. `무식자`, `배우자`, `유도자`, `자각자`, `접촉자`,
`집전자`에는 다른 원어의 동형 표제어도 있어 기존 분절을 유지했다.
[표준국어대사전 -자](https://stdict.korean.go.kr/search/searchView.do?word_no=281809)
· [의존 명사 자](https://stdict.korean.go.kr/search/searchView.do?word_no=281505)
· [사전 출처와 추출 명령](../../data/SOURCES.toml)

기준선은 `5d067b61`이다. 고정 입력과 등록 교정 GSD의 반환 목록
258,541개를 같은 러너로 비교했다. 고정 Smart 음성의 14행이 달라져
16범위를 덜 반환했다. 13행에서 오탐이 해소됐다. `pud:n01002017`의
두 오탐은 사라졌고 `지명자는`의 범위 [120, 126)는 남았다. 원본 GSD
9,335행과 등록 교정 GSD 9,298행의 반환 목록은 각각 일치했다.

`-자(者)` 범위가 양쪽에서 사라졌다. 별도 대조 11행 중 접미사 음성 두

`근로자들이`의 전체 명사·조사 [0, 15), 일반 명사 `국물`의 `물` 뒤
조사·지정사 대조는 정확한 범위를 확인했다.

고정 음성의 양성 범위 1,207행과 제외 문장 42행의 반환 38범위는
미검증이다. 원본 GSD 양성의 추가 반환 640행 703범위, 등록 교정 GSD
양성의 추가 반환 119행 125범위가 미판정이다. 사전 자료에서 이번
조건을 확인할 수 없었던 성분은 기존 분석을 사용한다.
