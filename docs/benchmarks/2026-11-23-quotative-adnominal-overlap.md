# 인용 관형형 내부의 동사 범위

`진행되었다는 사실`의 `-다는`과 `걷자는 말`의 `-자는`은
각각 `-다고 하는`과 `-자고 하는`이 줄어든 형태다. Smart는
앞 용언의 평서·청유형과 뒤 명사구가 확인되면 인용 부분을 별개
동사로 반환하지 않는다. 평서형은 본용언·보조 용언·존재 서술어·
명사 뒤 지정사를 확인한다. 뒤의 명사구가 지정사를 취하면 의존
명사에 붙은 완결 범위도 확인한다. 사전의 합성 용언 분석에 해당
위치의 동사가 실제 구성 성분으로 기록돼 있는 경우에는 반환한다.
[국립국어원 인용 관형형](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=332600)

기존 경계 판정은 그래프를 조합해 `피었다는`과 `나가자는`의
일부를 독립 용언 경로로 만들 수 있었다. 인용형과 충돌하는 위치에서
사전에 직접 정렬된 범위와 그래프로 가능한 범위를 구별한다.
전체 `다는`·`자는`와 같은 자리의 `다`·`자` 부분 반환을 확인한다.
별도로 쓰인 동사는 유지했다. `끝냈다는 말을 듣고 벽에 다는`과
`나가자는 말을 듣고 자는 아이`에서 남은 정답은 각각 [41, 47),
[34, 40)이다. `매다는`·`잠자는`의 전체 합성 용언도 보존했다.

## 원문과 교정문

GSD 학습 4,400문장과 GSD·PUD 시험 2,016문장에서
`다는`·`자는` 표기를 찾아 261질의를 실행했다. 79행의 81범위가
사라졌다. `뛰어 달라는`의 독립 동사 `달다 [45, 54)`는 보존했다.
비교 조사와 보조사가 붙은 `가르치기보다는`의 내부 범위도 빠졌다.
후보가 반환한 41행에는 다른 문법 구조와 독립 동사가 함께 들어 있다.
이 비교는 261행의 전체 정답 확정에 사용하지 않았다.
[GSD r2.18 학습 원문](https://github.com/UniversalDependencies/UD_Korean-GSD/blob/r2.18/ko_gsd-ud-train.conllu)
· [시험 원문과 체크섬](../../tools/morph-compare/README.md#gsdpud-고정-감사-입력)

고정 음성에서 바뀐 6행과 교정문에서 오탐을 발견한 n01044009를
원문과 교정문에서 각각 실행했다. GSD 등록 교정문과
PUD `ToDoOrigText`에서 `과학적 방법`, `폐쇄되는 이유`,
`설명한 글`, `다양한 추측`, `겨냥한 지방`, `진행되었다는 사실`의
공백을 확인했다. 범위는 UTF-8 바이트 반개구간이다.

`verify-gold` 927개 및 walk/hang 검증을 통과했다. WASM 빌드별
NFC·NFD 66조합에서 후보 Smart의 정확 범위가 일치했다. 기준선의
추가 범위 16개가 빠졌고 Any·Token 범위는 같았다.

## 성능

기준선 `2f0e438e`와 후보 `7f172bd1`을 Apple M1 Max 32 GiB,
macOS 26.6.2 (25G83), Rust·Cargo 1.97.0, Python 3.14.8에서
같은 release 설정으로 비교했다. 기준선은 제품 트리가 같은
`6c20dea2`에서 빌드했다. 두 러너가 같은 full-pos, component,
확장 용언을 사용했다. 입력 SHA-256은 고정 음성 `482e55d4…`,
교정 GSD `66466637…`이다. 말뭉치 261개 진단은
`1f424a1ec019beb1f7bf5aa782d984c1e5d3886a52f5525b65ec28a550202e8d`,
원문·교정문 대조는
`7480b506b3fe93c03221509cab965ea0144e87cef12c6c32df1d301f7f89a10f`이다.
[고정 리소스와 WASM 빌드 명령](2026-11-23-degree-adverb-connective-context.md#성능)
