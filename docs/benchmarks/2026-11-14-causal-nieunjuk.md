# 이유 연결형 ㄴ즉과 ㄴ즉슨

`읽다`로 `읽은즉`을 검색하면 이유 연결형 전체를 반환한다. 표준국어대사전
표제 [ㄴ즉](https://stdict.korean.go.kr/search/searchView.do?word_no=59057&searchKeywordTo=3),
[은즉](https://stdict.korean.go.kr/search/searchView.do?word_no=470293&searchKeywordTo=3),
[ㄴ즉슨](https://stdict.korean.go.kr/search/searchView.do?word_no=59058&searchKeywordTo=3),
[은즉슨](https://stdict.korean.go.kr/search/searchView.do?word_no=261798&searchKeywordTo=3)의
사전 입력 8건을 모두 점검했다. `읽은 즉흥시`처럼 뒷말이 별도 단어인 경우도 대조했다.

`ㄴ즉:1`의 질의는 `이다`이며, 예문 `책인즉`에서 앞 체언 `책`은 지정사의
활용에 포함되지 않는다. 따라서 기대 범위를 18..27(`책인즉`)에서
21..27(`인즉`)로 수정했다. 원래 주석으로 평가한 후보는 표적 7/8건이다.

행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서다.
사전은 계약 검토 0건으로 raw와 보정이 동일하다.

| 입력 | 경계 | 버전 | Raw 및 보정 행렬 | Raw 및 보정 비율 (%) |
| --- | --- | --- | --- | --- |
| 교정 표적 8건 | smart·any | 기준선 | 0, 0, 0, 8 | 0.00, 0.00, 0.00 |
| 교정 표적 8건 | smart·any | 후보 | 8, 0, 0, 0 | 100.00, 100.00, 100.00 |
| 원래 표적 8건 | smart·any | 후보 | 7, 0, 0, 1 | 100.00, 87.50, 93.33 |
| 교정 사전 4,458건 | smart | 기준선 | 4224, 0, 0, 234 | 100.00, 94.75, 97.30 |
| 교정 사전 4,458건 | smart | 후보 | 4232, 0, 0, 226 | 100.00, 94.93, 97.40 |
| 교정 사전 4,458건 | any | 기준선 | 3812, 0, 0, 646 | 100.00, 85.51, 92.19 |
| 교정 사전 4,458건 | any | 후보 | 3820, 0, 0, 638 | 100.00, 85.69, 92.29 |

고정 GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
검색 범위가 모두 동일했다. 이 입력의 raw와 계약 보정 지표는
[기존 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `3ea8b573`와 트리가 같은 `5a48d91b`의 검색 코드
`b3ab0e1b`, 후보 `0240d120`과 트리가 같은 `8df9284a`를 비교했다.
Apple M1 Max arm64, RAM 32 GiB, APFS SSD, Darwin 25.6.0, Rust/Cargo
1.97.0 release를 사용했다. full POS `smart`에서 워밍업 1회 후 새 프로세스로
5회 실행하고 순서를 순환했다. 표는 중앙값 [최소, 최대]다. p95는
nearest-rank, RSS는 최대 상주 메모리다.
