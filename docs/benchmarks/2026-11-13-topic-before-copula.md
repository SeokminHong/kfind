## 품질

결과형으로 잡는 오탐을 제거했습니다. 명사 술어에 지정사가 드러나는 경우와
모음 뒤에서 생략되는 경우를 각각 검증했습니다. 두 리비전은 같은 검토 목록을
적용했습니다. 네 검토 중 두 건은 원시 음성으로 확정했고 두 건은 계약 양성입니다.

## 성능

Apple M1 Max arm64, macOS 26.6.2(25G83), Darwin 25.6.0, Rust·Cargo 1.97.0에서
동일한 리소스와 release 설정으로 입력마다 새 프로세스 warm-up 1회 뒤 5회를
측정했습니다. 실행 순서를 교대했습니다. 처리량은 평가 시간, p95는 nearest-rank,
RSS는 `/usr/bin/time -l`의 최대 상주 메모리를 사용했습니다. 셀은 중앙값 [최솟값, 최댓값]입니다.
