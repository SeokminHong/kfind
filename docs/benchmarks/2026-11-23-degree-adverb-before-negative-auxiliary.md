# 부정 보조 용언 앞의 정도 부사

`거의 일어나지 않았다`의 `거의`는 부정 용언을 꾸미는 부사다.
앞말이 조사로 절 성분을 이루고, 뒤에 `-지` 연결형과 부정 보조 용언이
이어지면 의존 명사 `거`와 관형격 조사 `의` 분석을 제외한다.
뒤 어절에 사전에 있는 전체 명사 분석이 있거나 앞말이 의존 명사를
수식할 수 있는 경우에는 명사 후보를 보존한다. 기존 수량·관형형
판정과 부정 보조 용언 판정에 쓰는 자원을 사용했다.
[국립국어원 부사 용례](https://korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=8047&mn_id=62&pageIndex=11)
· [한국어기초사전 의존 명사 거](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=62331&nation=eng)
· [검색 사양](../../specs/matching.md#101-체언)

고정 음성과 원문·교정 양성의 명사 `거` 질의에서 `거의`가 들어간
문장 16행을 확인했다. 그중 12행이 명사 오탐을 반환하고 있었다.
이번 조건에 맞는 고정 음성은 w01013083 한 행이다. 나머지
11행에는 앞 성분이 명확하지 않거나, 별도 부정 보조 용언 대신 수식어와
명사·다른 용언이 오는 경우가 포함된다.

| PUD 원문 | 교정 | `거의` 범위 (원문 → 교정) | 명사 오탐 (기준선 → 후보) |
| --- | --- | --- | --- |
| w01013083의 정치적지배 | 정치적 지배 | 175..181 → 176..182 | 원문·교정 모두 있음 → 없음 |
| n01128017의 측정하지않았다 | 측정하지 않았다 | 89..95 → 89..95 | 원문 있음 → 있음, 교정 있음 → 없음 |

두 원문은 고정 PUD에 보존했다. 두 문장의 부사 `거의`가 원문과
교정문 모두에서 위 범위로 반환되는 것을 확인했다. n01128017의
원문은 부정 보조 용언을 붙여 쓴 상태로 채점했다.
[PUD r2.18 원문](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu)
· [한글 맞춤법 제47항](https://www.korean.go.kr/kornorms/m/m_regltn.do)

회귀에서는 `손대지 않았다`·`고치지 못했다`·`측정하지 않았다`처럼
용언과 조사를 바꿨다. 같은 문장의 독립 목적어 `걸 [17, 20)`과
부사 `거의 [45, 51)`, `네 거의`와 `친구가 건넨 거의`의 명사
범위를 각각 확인했다. 기준선 WASM은 해당 음성 범위를 추가 반환했다.
NFC·NFD, 사전을 장착한 Smart·Any와 사전 없는 Token을 포함해 빌드당
48개 조합을 비교했다. 네이티브 327개 테스트와 `verify-gold` 927개
검증도 통과했다. 기존 258,541행 반환 비교에서 w01013083만 바뀌었다.

## 품질

행렬 순서는 TP, FP, TN, FN이며 뒤의 세 값은 정밀도·재현율·F1(%)이다.
검토 / 제외는 고정 음성 1,589 / 149, 원문 양성 602 / 34, 교정 양성
149 / 0행이다.

| 입력 | 원본 행렬 및 지표 | 계약 행렬 및 지표 | FPc / FNc |

| 고정 음성 기준선 | 0, 3,028, 50,280, 0 / 0, 0, 0 | 1,430, 1,483, 50,246, 0 / 49.09, 100, 65.85 | 1,485 / 0 |
| 고정 음성 후보 | 0, 3,027, 50,281, 0 / 0, 0, 0 | 1,430, 1,482, 50,247, 0 / 49.11, 100, 65.87 | 1,484 / 0 |
| 원문 GSD 양쪽 | 8,225, 0, 0, 1,110 / 100, 88.11, 93.68 | 8,648, 9, 86, 558 / 99.90, 93.94, 96.83 | 20 / 558 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 6 / 0 |

양성의 미판정 추가 범위는 원문 515행 573범위, 교정문 86행 92범위다.

## 성능

Apple M1 Max 32 GiB, macOS 26.6.2 (25G83), Rust·Cargo 1.97.0,
Python 3.14.8에서 `3f46d726`과 `1b0c9691`의 release를 비교했다.
기준선 실행 파일은 같은 제품·러너 트리인 `2be95cad`에서 빌드했다.
[러너 빌드와 교대 실행 명령](../../tools/morph-compare/README.md#smart-기준선과-후보-성능-비교)

양쪽은 같은 순서와 리소스를 사용했다. 고정 음성 53,308행의 SHA-256은
`482e55d417516e8db503dbd421725fcc7affc6c6afcf5b5d42cec3bbd4d35d54`이며,
교정 GSD 9,298행은 `ae694ce3309045bbe892bd151a51cb3bcc00ae0d0bf545b9014cc9664e274a5b`다.
사전·component·확장 활용의 SHA-256은 앞선 측정과 같다.
[리소스 체크섬](2026-11-22-smart-performance-baseline.md)

워크로드마다 새 프로세스로 워밍업 1회 후 교대 측정 5회를 실행했다.
표는 각 실행의 초기화 시간, 처리량, 최근접 순위 p95, 최대 RSS를
중앙값 [최솟값, 최댓값]으로 요약한다.

| 입력 | 측정군 | 초기화 ms | 처리량 cases/s | p95 ms | 최대 RSS MiB |
| --- | --- | --- | --- | --- | --- |
| 고정 음성 | 기준선 | 63.47 [63.06, 65.30] | 18,931.5 [18,738.4, 19,124.6] | 0.1303 [0.1285, 0.1319] | 127.95 [127.78, 128.06] |
| 고정 음성 | 후보 | 63.42 [63.19, 65.36] | 18,983.6 [18,846.4, 19,117.6] | 0.1298 [0.1281, 0.1308] | 128.06 [127.92, 128.19] |
| 교정 GSD | 기준선 | 62.37 [62.20, 64.03] | 28,867.5 [27,001.7, 29,007.5] | 0.0746 [0.0740, 0.0789] | 81.84 [81.63, 81.91] |
| 교정 GSD | 후보 | 62.14 [62.10, 62.97] | 28,580.7 [28,401.2, 28,952.4] | 0.0747 [0.0737, 0.0765] | 81.73 [81.70, 82.13] |

처리량·p95 중앙값 변화는 고정 음성 +0.28%·−0.38%,
교정 GSD −0.99%·+0.13%였다. 두 입력에서 기준선과 후보의
실행 범위가 겹쳤다.

WASM은 `wasm-pack` 0.15.0으로 `wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release --locked`를
실행했다. Node 26.11.1의 zlib로 압축했다. 기본 WASM의
원본·gzip 9·Brotli 11 크기는 각각
2,891,926→2,891,964 B, 983,567→983,620 B, 724,488→724,821 B다.
사전 장착 비교에는 동일 component 파일을 사용했다.
