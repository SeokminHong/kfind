# 용언에 붙은 고의 검색 경계

`확장되었고`의 연결 어미와 `그렇다고`의 인용 조사는 용언을 완성하는
형태 경로에서 확인한다. 같은 위치의 추론 명사 후보는 제외한다.
어절에 정렬된 `과학고`의 명사 성분과 독립 명사 `사고`는 검색한다.
[국립국어원 인용 조사 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=335167)

## 품질

기준선 `df6847ba`와 후보 `05e047b3`에서 고정 12세트 83,081행을
Smart·Any·Token으로 실행했다. 249,243개 결과 중 Smart의 명사
`고` 오탐 16행·18범위가 사라졌다. 제거된 범위는 연결 어미 5개와
종결 어미 뒤 인용 조사 13개다. 인용문의 형용사, 일반·파생 용언,
명시형과 축약형 지정사에서 확인했다.

기준선의 명사 `고` 오탐은 21행 23범위였다. 변경 뒤에는 5행
5범위가 남았다. `잘살펴야하고`와 여는 따옴표가 앞 어절에 붙은
인용문이 각각 한 행이다. 나머지 세 범위는 `과학고`, `고대로`,
`고농도`에 있다.

회귀 9행에서 어미·조사와 형태가 같은 명사 음성 4행, 용언·명사
양성 5행의 전체 범위를 확인했다. 양성에는 관형형 뒤의 의존 명사
`수`가 붙어 있는 `제공할수`도 포함했다. 계약 검토를 동일하게 적용한
고정 11세트의 Smart FNc는 0건이고 FPc는 2,392건에서 2,376건으로
줄었다.

행렬은 TP, FP, TN, FN 순서다. 비율(%)은 precision, recall, F1
순서다. 추가 회귀의 계약 검토는 0건, 고정 음성은 1,255건이다.

| 입력 | 모드·리비전 | 원본 행렬 / 비율 (%) | 계약 행렬 / 비율 (%) |
| --- | --- | --- | --- |
| 추가 회귀 9행 | Smart 기준선 | 5, 4, 0, 0 / 55.56, 100.00, 71.43 | 5, 4, 0, 0 / 55.56, 100.00, 71.43 |
| 추가 회귀 9행 | Smart 후보 | 5, 0, 4, 0 / 100.00, 100.00, 100.00 | 5, 0, 4, 0 / 100.00, 100.00, 100.00 |
| 고정 음성 53,308행 | Smart 기준선 | 0, 3644, 49664, 0 / 0.00, —, 0.00 | 1255, 2389, 49664, 0 / 34.44, 100.00, 51.23 |
| 고정 음성 53,308행 | Smart 후보 | 0, 3628, 49680, 0 / 0.00, —, 0.00 | 1255, 2373, 49680, 0 / 34.59, 100.00, 51.40 |

## 성능

입력별로 새 프로세스에서 워밍업 1회 후 기준선과 후보를 교대로
5회 측정했다. 표에는 중앙값 [최솟값, 최댓값]을 기록했다. p95는
최근접 순위로 구했다.

| 입력 | 리비전 | 초기화 (ms) | 처리량 (cases/s) | p95 (ms) | RSS (MiB) |
| --- | --- | --- | --- | --- | --- |
| 교정 GSD | 기준선 | 60.517 [60.478, 61.127] | 30,922 [30,317, 31,011] | 0.06996 [0.06958, 0.07158] | 80.984 [80.953, 81.141] |
| 교정 GSD | 후보 | 60.620 [60.515, 60.835] | 30,463 [30,248, 31,008] | 0.07108 [0.07008, 0.07187] | 81.094 [80.750, 81.438] |
| 고정 음성 | 기준선 | 60.940 [60.229, 62.391] | 19,617 [19,495, 19,897] | 0.12792 [0.12554, 0.12892] | 127.547 [127.219, 127.578] |
| 고정 음성 | 후보 | 60.807 [60.346, 62.015] | 19,837 [19,830, 20,106] | 0.12596 [0.12333, 0.12650] | 127.250 [127.031, 127.344] |

교정 GSD의 처리량 중앙값은 −1.48%, p95는 +1.61%다. 고정 음성은
각각 +1.12%, −1.53%였다. 두 입력에서 처리량과 p95의 관측 범위는
겹친다.

tools/morph-compare/runner/Cargo.toml`로 빌드했다. 각 실행에는
`/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`을
사용했다. [평가 입력과 리소스 체크섬](2026-11-16-auxiliary-competition.md#재현)
