# 소리 주어가 있는 나다의 동형 활용

`파열음이 나는`의 `나는`을 `날다`로도 반환하던 후보를
제외했다. 앞의 소리 주어와 `나다`의 완결 활용을 같이
확인한다. 현재·과거·미래 관형형에도 같은 판정을 적용하고
`허공을 총소리가 나는`처럼 경로를 표시한 경쟁 분석과
`새가 높이 나는`의 실제 비행 문형을 보존했다.
[한국어기초사전 나다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=62210)
· [한국어기초사전 날다](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=61530)

## 원문·교정문과 품질

PUD n01058064의 `교차하고갈등의`, `감지할수`는
`ToDoOrigText`에 따라 띄어 썼다. 10번 `파열음이`가 11번
`나는`의 주어이며, `나다`의 [107, 113)과 교정문 [108, 114)는
양쪽에서 유지됐다. 두 위치의 `날다` 오반환은 사라졌고
동일 위치의 대명사 `나` 오반환은 남았다.
[PUD n01058064](https://github.com/UniversalDependencies/UD_Korean-PUD/blob/r2.18/ko_pud-ud-test.conllu#L3443)

고정 음성·원문 GSD·교정 GSD에서 소리·신체 분비물 명사
62종과 주격·주제 조사, `나·날·난·납·났`으로 시작하는
뒷말이 차례로 나오는 `나다·날다` 질의는 한 행이었다.
신체 분비물은 인접 문형의 대조 범위였다. 원문과 교정문의
고정 질의 96건 및 대조 질의 66건을 실행했다.
SHA-256은 각각
`562b8cce5fb0d03724096e0a0c2c77d0cf86ee563daa98e98e3737289a6e5ec1`,
`9f900c1a70ad7b67d9951a947d02c9bdd2c09dea8a4a1828a37859e8430a153e`다.
역사 입력 258,541개 조합에서는 위 PUD 원문 한 건만 달라졌다.
고정 회귀 9행은 NFC·NFD와 리소스 장착 Smart·Any, 기본 Token으로
빌드당 54개 조합에서 확인했다.

행렬은 TP, FP, TN, FN 순서이며 정밀도, 재현율, F1의 단위는 %다.
두 빌드에 같은 입력과 정답을 적용했다.

| 입력 | 원본 행렬 / 정밀도·재현율·F1 | 계약 행렬 / 정밀도·재현율·F1 | FPc | FNc |
| --- | --- | --- | ---: | ---: |
| 고정 음성 기준선 | 0, 3,036, 50,272, 0 / 0, 0, 0 | 1,430, 1,492, 50,238, 0 / 48.94, 100, 65.72 | 1,494 | 0 |
| 고정 음성 후보 | 0, 3,035, 50,273, 0 / 0, 0, 0 | 1,430, 1,491, 50,239, 0 / 48.96, 100, 65.73 | 1,493 | 0 |
| 원문 GSD 양쪽 | 8,229, 0, 0, 1,106 / 100, 88.15, 93.70 | 8,652, 6, 82, 592 / 99.93, 93.60, 96.66 | 13 | 592 |
| 교정 GSD 양쪽 | 9,286, 0, 0, 12 / 100, 99.87, 99.94 | 9,285, 2, 11, 0 / 99.98, 100, 99.99 | 3 | 0 |

미판정 추가 반환은 원문 GSD 553행 613범위, 교정 GSD 104행
110범위다. 고정 음성 계약 양성 1,207행의 전체 정답과 제외
42행의 37범위도 검토가 남아 있다.
