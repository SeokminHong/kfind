# 선택 연결형 든가의 검색 범위

선택 연결형 `-든가`는 기존 `-든지`와 같은 어간 및 높임·과거 뒤에서
어절 끝까지 소비한다. 어간·과거·높임, `-든지`와 별도 어절을 대조했다.
[한국어기초사전 -든가](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=82342&nation=eng)

## 품질

고정 사전의 해당 예문 1건을 비교했다. 이 어미의 추가 계약 보정은 0건이다.
전체 사전에는 [기존 보정 입력](2026-11-15-honorific-directive-report.md#재현)을 사용했다.
행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1 순서다.

| 든가 1건 | Any | 후보 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 | 1, 0, 0, 0 / 100.00, 100.00, 100.00 |

| 사전 4,458건 | Any | 기준선 | 4288, 0, 0, 170 / 100.00, 96.19, 98.06 | 4361, 0, 0, 97 / 100.00, 97.82, 98.90 |

GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
반환 범위는 직전 기준선과 모두 동일했다.

## 성능

시작점 `70a5d2d4`, 기준선 측정 빌드 `8f8479d8`, 후보 `b060ff3a`를
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서 비교했다.
full POS Smart로 워밍업 1회 후 새 프로세스로 5회씩 순환 실행했다.
