# 예스러운 감탄 종결형 누나의 검색 범위

표준국어대사전의 감탄형 `-누나` 예문 3건을 점검했다.
동사 어간과 높임 결합을 확인했다. 음성 대조군 `오니 누나가 웃었다.`에서
감탄형 `-누나`는 성립하지 않는다. `오다`의 전체 검색 결과는
smart와 any 모두 `오니` 한 범위다. 명사에 주격·목적격·보조사가
이어지는 대조군 3건에서 전체 반환 범위를 검사한다.
[표준국어대사전 -누나](https://stdict.korean.go.kr/search/searchView.do?word_no=69100&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN 순서다. 비율은 precision, recall, F1 순서다.
표적의 계약 검토는 0건이다. 전체 사전에는
[앞선 보정 10건](2026-11-14-honorific-request-sipsa.md#품질)을 유지한다.

| 표적 3건 | any | 기준선 | 0, 0, 0, 3 / 0.00, 0.00, 0.00 | 0, 0, 0, 3 / 0.00, 0.00, 0.00 |

고정 GSD 9,298건과 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
검색 범위는 일치했다. Raw·계약 보정 지표는
[고정 입력 보고서](2026-11-14-gu-exclamative.md#품질)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `2a704ff6`, 후보 `223a724c`를 비교했다.
기준선과 후보의 런타임 소스·형태 리소스는 측정 빌드 `d86ba2e1`과
`161cd2eb`에 각각 일치한다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`로 워밍업 1회 후 새 프로세스로 5회씩 실행했다.
버전 순서는 순환했다. 표는 중앙값 [최솟값, 최댓값]이며 p95는 최근접
순위, RSS는 최대 상주 메모리다.
