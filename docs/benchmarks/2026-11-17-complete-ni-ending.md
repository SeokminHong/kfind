# 연결·종결 어미 니의 어절 경계

`아니었다`는 부정 지정사 `아니-`에 과거·종결 어미가 붙은 활용이다.
`알다`의 연결형과 의문 종결형 `아니`는 그 안에서 끝나지 않는다.
Smart의 생성 활용은 `-니/-니까`와 하오체 `-오니/-오면` 계열을
소비한 뒤 어절이 끝나는지 확인한다. `어제 일을 아니?`,
`문을 미니 조금 열렸다`, `먼저 가오니 뒤따라오시오`는 활용 전체를
반환한다. [국립국어원 ‘-니’ 결합 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=27&pageIndex=1&qna_seq=331775)

## 품질

기준선의 계약 오탐 2,053행에서 반환이 `니`로 끝나고 같은 어절에
한글이 더 붙는 술어 범위 12개를 모두 원문과 CLI의 생성 규칙에 대조했다.
`아니었다·아니기·아니냐며`에는 `알다`의 종결 또는 연결형 5개가
들어갔고, `매니시·미니스트리즈·미니앨범·미니홈피·모니터링할·주니어`에는
`매다·밀다·몰다·주다`의 연결형 6개가 들어갔다. `파이오니안`에서는
`파다`의 하오체 연결형이 반환됐다. 위 12개가 모두 사라졌다.

고정 12세트 83,081행에서 세 모드 249,243개를 비교했다. 위 12개 외에
역사 사전 예문 `으니라:2`에서 동사 질의의 부분 반환 `않으니`가 사라졌다.
해당 행은 양쪽 모두 원래 지정된 `않으니라` 전체 범위의 누락으로 집계된다.
형용사 질의의 완전한 `않으니라`와 동사 질의의 `않느니라`는 보존했다.
[한국어기초사전 ‘-으니라’ 결합 조건](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=86126)

직접 대조 23질의에서 정상 활용 15개와 음성 8개를 정확히 판정했다.
CLI의 NFC와 canonical 모드 NFD에서 총 46개 반환 범위가 모두 일치했다.
NFD `아니었다`의 형용사 질의는 양쪽 모두 정확한 범위와 함께 구조 검증
미완료 진단을 냈다.
고정 음성의 계약 검토 1,357행과 제외 67행은 동일하다. 목표 11세트의
Smart FNc는 0, FPc는 2,053에서 2,041이다.
`아니다`의 인용 연결형 `아니냐며`는 양쪽에서 누락됐다. 고정 자료에서
`냐며`가 있는 한 원문에 `아니다` 질의의 정답 행은 없다.
[국립국어원 표준모형의 의문 인용 연결형](https://www.korean.go.kr/common/download.do?c_file_name=2bfd3feb-997c-4c4d-8052-3d2a406c4be4_2.pdf&file_path=reportData&o_file_name=%EA%B5%AD%EC%A0%9C%ED%86%B5%EC%9A%A9+2%EB%8B%A8%EA%B3%84+%EA%B2%B0%EA%B3%BC%EB%B3%B4%EA%B3%A0%EC%84%9C%28%EC%B5%9C%EC%A2%85%EB%B3%B8%29.pdf)

GSD 처리량·p95 중앙값은 1차 −0.17%·+0.35%, 2차 −0.24%·−1.15%였다.
고정 음성은 1차 −1.60%·+2.74%, 2차 +0.37%·−0.59%였다. 고정 음성의
변화 방향은 차수마다 달랐고, 모든 지표의 측정 범위가 두 차수에서 겹쳤다.
러너 크기는 5,177,696에서 5,177,904바이트로 208바이트 증가했다.

## 재현

- 기준선 `6c0ff55d`의 검색 코드 `4f622cbf`와 후보 `abee64a7`을 Apple M1 Max arm64,
  macOS 26.6.2 (25G83), Rust/Cargo 1.97.0에서 `cargo build --release --locked
  --manifest-path tools/morph-compare/runner/Cargo.toml`로 빌드했다.
- GSD `gsd-saint-determiner.jsonl`과 고정 음성 `negatives.jsonl`을
  `/usr/bin/time -l morph-benchmark-runner boundary full-pos smart INPUT OUTPUT`으로 실행했다.
  실행마다 새 프로세스를 만들고 각 차수에서 예열 1회 후 측정 5회를 번갈아 수행했다.
- 고정 반환 비교는 `morph-benchmark-runner boundary full-pos MODE INPUT OUTPUT`을 사용했다.
  두 비태그 세트에는 `boundary` 대신 `untagged`를 사용했다.
