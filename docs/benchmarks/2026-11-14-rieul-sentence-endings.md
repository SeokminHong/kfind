# ㄹ지니라·ㄹ런고·ㄹ쏜가 종결형

교정 사전 4,458건에서 해당 종결형의 모음·받침 이형태 여섯 표제에 속한
14건을 모두 검사했다. 지정사 예문 세 건의 질의와 UTF-8 시작 위치를
원문에서 확인했다. `누구일런고`의 질의를 `이르다`에서 `이다`로 교정했고,
`일런고`, `일쏜가`, `일지니라`는 `일`부터 반환하는 범위로 교정했다.
기존 입력으로 후보를 채점하면 두 모드 모두 11/14건이 일치한다.
[우리말샘 -ㄹ지니라](https://opendict.korean.go.kr/dictionary/view?sense_no=456353) ·
[우리말샘 -ㄹ런고](https://opendict.korean.go.kr/dictionary/view?sense_no=138095) ·

행렬 순서는 TP, FP, TN, FN이며 비율은 precision, recall, F1 순서다.
