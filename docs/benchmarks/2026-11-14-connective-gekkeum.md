# 목적 연결형 게끔의 검색 범위

사전의 `-게끔` 예문 8건을 점검했다. 용언 기본형으로 검색하면
`지나가게끔`, `없게끔`, `들으시게끔`의 연결 어미를 어절 끝까지
반환한다. 뒤에 별도 단어가 있는 `읽게 끔찍한`도 대조했다.
[표준국어대사전 -게끔](https://stdict.korean.go.kr/search/searchView.do?word_no=390853&searchKeywordTo=3)

## 품질

행렬은 TP, FP, TN, FN, 비율은 precision, recall, F1 순서다.
사전 계약 검토 0건으로 raw와 보정이 같다.

| 표적 8건 | any | 기준선 | 0, 0, 0, 8 | 0.00, 0.00, 0.00 |
| 표적 8건 | any | 후보 | 8, 0, 0, 0 | 100.00, 100.00, 100.00 |

고정 GSD 9,298건, 음성 53,308건, KAIST dev 2,532건과 test 2,592건의
검색 범위가 일치했다. 이 입력의 raw·계약 보정 지표는
[고정 입력 보고서](2026-11-14-gu-exclamative.md)와 같다.

## 성능

시작점 `70a5d2d4`, 기준선 `c2a8a2d7`의 검색 코드 `ce171b26`, 후보
`8965af0c`와 제품 파일이 같은 `40156860`을 비교했다.
Apple M1 Max arm64, macOS 26.6.2, Rust/Cargo 1.97.0 release에서
full POS `smart`를 사용했다. 워밍업 1회 후 새 프로세스로 5회씩 실행하고
버전 순서를 순환했다. 표는 중앙값 [최솟값, 최댓값]이다. p95는 최근접
순위, RSS는 최대 상주 메모리다.
