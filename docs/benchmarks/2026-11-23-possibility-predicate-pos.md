# 가능성을 나타내는 있다의 검색 품사

`-(으)ㄹ` 관형형과 의존 명사 `수`가 결합한 주어 뒤에서
가능성을 나타내는 `있다`는 형용사다. `수가`, `수도`, `수는`과
불규칙 관형형을 대조했다. 실제 동사 `있어라`와 결과 상태 보조 동사
`있을`이 같은 문장에 나올 때 그 범위를 보존했다.
[국립국어원 수 있다의 품사](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=328954)
· [정확 범위 회귀](../../data/fixtures/ud_morphology_cases.tsv)

## 원문과 교정문

고정 음성 626행, GSD 원문 218행, 등록 교정본 218행의 `있다`
질의를 대조했다. 46문장의 원문 표적 53개에서 가능성의 형용사를
확인했다. 같은 문장의 `-고 있다`는 보조 동사로 확인해 전체 반환
범위를 채점했다. 예를 들어 `s684`의 [58, 64)와 [350, 356)은
보조 동사이고 [121, 127), [210, 216), [320, 326)은 형용사다.

원문 `들어와있음을` [278, 296)의 띄어쓰기 오류는 그 범위만
제외했다. 교정문의 `들어와 있음을`에서 형용사 질의가 잘못
반환하는 [289, 298)은 채점에 포함했다. `넥슨에 있어서`의
형용사 [10, 19)에 대한 동사 오반환도 원문과 교정문에서
계속 계수한다. `골라먹을`을 띄어 쓴 `골라 먹을 수 있다`에서는
교정문의 [79, 85)를 형용사로 반환한다.
[국립국어원 합성 용언과 보조 용언의 띄어쓰기](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=335621)
· [국립국어원 형태 분석의 있어서 분류](https://korean.go.kr/common/download.do%3Bfront%3D04A0277F686B98B20F0B3AE9199B8F23?c_file_name=35c6ff74-7598-438d-ab4c-a7d91a5908d9.pdf&file_path=reportData&o_file_name=2025%EB%85%84+%ED%95%9C%EA%B5%AD%EC%96%B4+%EA%B5%AC%EC%A1%B0+%EB%B6%84%EC%84%9D+%EB%B0%8F+%EB%AC%B4%ED%98%95+%EB%8C%80%EC%9A%A9%EC%96%B4+%EB%B3%B5%EC%9B%90+%EB%A7%90%EB%AD%89%EC%B9%98+%EA%B5%AC%EC%B6%95+%EC%97%B0%EA%B5%AC+%EA%B2%B0%EA%B3%BC%EB%B3%B4%EA%B3%A0%EC%84%9C.pdf)

## WASM

`wasm-pack build crates/kfind-wasm --target bundler --out-dir "$out" --out-name kfind --release`의
원본은 2,853,569 → 2,853,971 B (+402), `gzip -9nc`는
971,422 → 971,790 B (+368), `brotli -q 11 -c`는 714,170 →
714,989 B (+819)였다. Node 26.11.1에서 기본 Token, component와
full POS를 장착한 Smart·Any를 NFC·NFD로 비교했다. 각 빌드 72회 중
Smart의 동사 오반환 12범위가 사라졌고 Any·Token은 같았다.
