# 의존 명사 것과 거의 겁니다·겁니까

교정 GSD 9,306행과 고정 음성 53,308행에서 `겁니다|겁니까`가
포함된 문장을 검색했다. 양성 14행과 음성 36행에 해당하며,
두 코퍼스 모두 해당 문장은 2개다. `있을 겁니다`에서 `것`의
기대 범위 `44..53`을 복구했다. 음성의 반환 범위 변화는 0건이다.
관형형 뒤의 평서형과 의문형, 동사 `걸다`의 동형이의,
어절 내부 문자열을 대조했다.
신규 회귀 4행은 통과했고 기존 `verify-gold` 불일치 8행은 재현됐다.
[국립국어원 거입니다와 겁니다](https://korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5935&mn_id=217&pageIndex=212)

행렬은 TP, FP, TN, FN 순서이며 비율은 precision, recall, F1이다.
양성 검토는 0건이고 고정 음성의 계약 보정은 32건이다.
