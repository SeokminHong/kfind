# 한자 병기 뒤 조사가 붙은 고유 명사 검색

교정 GSD 9,300행과 GSD·PUD 음성 53,308행에서
한글 뒤에 괄호로 한자를 병기하고 한글이 바로 이어지는
표면형을 검색했다. 양성에 24종, 음성에 23종이 있었다.
검색 결과가 바뀐 질의는 같은 문장에 있는 두 `연(燕)의`의
명사 질의뿐이다. 둘째 위치만 반환하던 기준선에서 첫째
위치도 반환한다. 조사 없이 다음 어절이 시작하는 예와
괄호 뒤에 독립 명사가 붙은 예를 대조했다.
[회귀 입력](../../data/fixtures/ud_morphology_cases.tsv)

기준선 785c9c81과 후보 699e1e1d의 full POS `smart`를 비교했다.
양성은 정확 범위, 음성은 반환 여부를 평가했다. 음성의 반환 범위는
53,308행 모두 일치했다. 행렬은 TP, FP, TN, FN 순서다.
양성 검토 0건, 음성은 기존 검토 3건을 적용했다.

## 성능

Apple M1 Max arm64, Darwin 25.6.0, Rust/Cargo 1.97.0 release에서
같은 사전을 사용했다. 시작점 70a5d2d4, 기준선, 후보를 새
프로세스에서 워밍업 1회 후 5회 측정했다. 실행 순서를 교대했다.
p95는 nearest-rank, RSS는 최대 상주 메모리다. 표는 중앙값
[최솟값, 최댓값]이다.
